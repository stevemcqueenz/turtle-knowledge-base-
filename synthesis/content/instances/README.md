# Instance files — index

One file per custom instance and per significantly modified vanilla instance on Turtle WoW. The cross-instance overview — server-wide scaling and lockout rules, the full instance table, world bosses, and the overtuned/undertuned/buggy summary — is in [`../dungeons-and-raids.md`](../dungeons-and-raids.md). Machine-readable data is in [`../../../structured/content/instances.yaml`](../../../structured/content/instances.yaml).

Every file marks each claim as **official (staff)**, **guide writer**, **player** or **wiki** (turtle-wow.fandom.com, community-maintained, not official), and ends with a gaps section.

## Where the tactics actually are

Only three instances have substantial player-written tactics in the extraction:

- **[Lower Karazhan Halls](lower-karazhan-halls.md)** — a maintained community guide with per-boss handling, trash spell IDs and NPC IDs.
- **[Emerald Sanctum](emerald-sanctum.md)** — a raid leader's hard-mode positioning plan, with a contested line-of-sight debate.
- **[Molten Core](molten-core.md)** — a detailed player critique of the 1.18.0 rework that doubles as a mechanics description, plus a Golemagg tanking thread.

Every other file's mechanics come from staff hotfix notes and community-wiki ability lists. See the gaps section of [`../dungeons-and-raids.md`](../dungeons-and-raids.md).
