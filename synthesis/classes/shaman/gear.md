# Shaman — Gear Guide

Gear recommendations by spec, role and bracket, with where to obtain each item where the sources state it. See synthesis/classes/shaman/*.md for full talent/rotation playbooks; this file covers gear only. Raid tier mapping: T1=Molten Core, T2=Blackwing Lair, T2.5=AQ40, T3=Naxxramas, T3.5=Karazhan 40.

Sources consulted: synthesis/classes/shaman/enhancement-melee-dps.md, synthesis/classes/shaman/enhancement-tank.md, synthesis/classes/shaman/elemental-ranged-dps.md, synthesis/classes/shaman/elemental-pvp.md, synthesis/classes/shaman/restoration-healer.md, synthesis/classes/shaman/leveling.md, structured/classes/shaman/*.yaml, https://forum.turtlecraft.gg/viewtopic.php?t=21611, https://forum.turtlecraft.gg/viewtopic.php?t=20825, https://forum.turtlecraft.gg/viewtopic.php?t=21848, https://forum.turtlecraft.gg/viewtopic.php?t=21713, https://forum.turtlecraft.gg/viewtopic.php?t=22683, https://forum.turtlecraft.gg/viewtopic.php?t=19969, structured/patches/1.18.1-changes.yaml

## Caveats
- Raid tier mapping used below (per structured/glossary.jsonl): T1=Molten Core, T2=Blackwing Lair, T2.5=AQ40, T3=Naxxramas, T3.5=Karazhan 40. Kara10 (Lower Karazhan Halls, a Turtle-exclusive 10-man) sits below T1 in the sources' own usage and is treated as pre-raid-60/raid-t1-adjacent content here.
- The Enhancement-tank 'Pre Raid' and 'T1 BiS' slot lists below both come from one long guide post by Mimiwarmini (2024-12-02); item IDs are exact (the post links database.turtlecraft.gg by item ID) but the post does not state where most of these items drop, so source_place is unknown-in-sources except where the entity-index or another source confirms it (Araxxna's Husk and Totem of Tides are confirmed Lower Karazhan Halls / Stormwrought Ruins drops).
- Skegg's Shaman Leveling & Pre-BiS Guide is the single richest leveling source for all three roles (tank/DPS/heal share one build to level 33); item-by-level claims below are almost entirely from that one post plus Akos1896's reply in the same thread.
- T2.5 (AQ40) is explicitly the only shaman tank tier set (staff); Enhancement DPS has no T2.5 set at all ('a drought when AQ comes out').
