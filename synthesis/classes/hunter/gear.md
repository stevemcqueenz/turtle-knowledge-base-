# Hunter — Gear Guide

Gear recommendations by spec, role and bracket, with where to obtain each item where the sources state it. See synthesis/classes/hunter/*.md for full talent/rotation playbooks; this file covers gear only. Raid tier mapping: T1=Molten Core, T2=Blackwing Lair, T2.5=AQ40, T3=Naxxramas, T3.5=Karazhan 40.

Sources consulted: synthesis/classes/hunter/beast-mastery-ranged-dps.md, synthesis/classes/hunter/marksmanship-ranged-dps.md, synthesis/classes/hunter/survival-melee-dps.md, synthesis/classes/hunter/marksmanship-pvp.md, synthesis/classes/hunter/leveling.md, structured/classes/hunter/*.yaml, https://forum.turtlecraft.gg/viewtopic.php?t=14004, https://forum.turtlecraft.gg/viewtopic.php?t=16662, https://forum.turtlecraft.gg/viewtopic.php?t=18456, https://forum.turtlecraft.gg/viewtopic.php?t=21833, structured/patches/1.18.1-changes.yaml

## Caveats
- No Turtle-specific pre-raid or post-raid BiS list exists as a single forum artifact for any Hunter spec; the pre-raid-60 slot list below is reconstructed from one detailed theorycrafting post (Nurincarinun, 2023) that itemizes the gear it uses, corroborated by named items in other threads. Multiple threads (t14004, t16662, t21833) confirm no such list was ever published and point players to AtlasLoot/vanilla lists instead.
- Beast Mastery has no BM-specific pre-raid list in the sources; BM players are told to use the Marksmanship pre-raid-60 list below plus the pet-damage item bundle under raid-t1.
- Survival has no dedicated gear-by-phase list; its 'Gear, enchants and consumables' section only names a handful of melee-only BiS pieces layered on top of the ranged lists.
- Raid tier mapping used below (per structured/glossary.jsonl): T1=Molten Core, T2=Blackwing Lair, T2.5=AQ40, T3=Naxxramas, T3.5=Karazhan 40 (Kara40, also called the Trickster/Ravenstalker tier in Turtle-specific threads).
