# Wailing Caverns

Vanilla level ~17-24 Barrens dungeon. Turtle added two optional areas, The Overgrowth and Kolkar Falls, each with a new boss (1.17.2). It also buffed Lady Anacondra's loot, including a new bear-druid staff ([Akalix (staff), 2024-03-30](https://forum.turtlecraft.gg/viewtopic.php?p=91709#p91709)).

| | |
|---|---|
| Size | 5 |
| Location | Northern Barrens (vanilla) |
| Turtle changes | Vangros and Zandara Windhoof added; Serpent's Shoulders now Rare; mob pathing improved (2024-11-19) |

| Boss | Abilities ([wiki](https://turtle-wow.fandom.com/wiki/Vangros)) | Notes / loot |
|---|---|---|

Drops **Idol of the Apex Predator** (the -2 rage Roar idol), which players call the "crocodile boss" drop [[d:druid#1439092821196931123]], plus Band of the Claw |
| **Zandara Windhoof** (lvl 23, centaur, Kolkar Falls) | **Chain Lightning**, Gust of Wind | Totem of Static Charge (shaman relic); quest *Against the Kolkar Dream* ([wiki](https://turtle-wow.fandom.com/wiki/Zandara_Windhoof)) |

## Tanking and leveling notes

- **Druid tanks:** wait for Swipe at level 20 before tanking here [[d:druid#1442259854059245718]].
- **Shaman tanks:** WC mobs heavily resist Earth Shock. Tanking before 26 (Magma Totem, Water Shield) is rough, so start in Shadowfang Keep instead [[d:shaman#1448921448990244896]], [[d:shaman#1448921578992832714]].
- **Loot:** a level-19 bow [[d:hunter#1490658191065747506]]; Tail Spike, a dagger from Skum, around 18 [[d:rogue#1324107314747408587]].
