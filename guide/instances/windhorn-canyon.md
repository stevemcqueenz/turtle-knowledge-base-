# Windhorn Canyon

Turtle-custom level 26-30 5-man in Thousand Needles, added in 1.18.1. The Grimtotem have driven the Windhorn tauren out of the canyon. Staff billed it as "one challenging dungeon" ([Torta (staff), 2025-10-03](https://forum.turtlecraft.gg/viewtopic.php?p=154168#p154168)), and early players agree.

| | |
|---|---|
| Level / size | 26-30 (staff, wiki); 25-33 (LFT), 5 players |
| Location | Thousand Needles. The new Horde hub Sagh's Refuge sits in the canyon |
| Added | 1.18.1 (opened 2026-03-20) |
| Entry | None found |
| Bosses | 7. Final boss Chieftain Shalk Blackwind ([wiki](https://turtle-wow.fandom.com/wiki/Windhorn_Canyon)) |

## Group notes

- **Hard at its level.** "At its intended level Windhorn is pretty hard, there's so many packs and some mobs even got either knockbacks or summons" [[d:turtle-wiki#1485051244698402857]]. One priest healer's group took 3 hours "and very precise CC" [[d:turtle-wiki#1484921785421140140]]. Bring CC and plan for a long run.
