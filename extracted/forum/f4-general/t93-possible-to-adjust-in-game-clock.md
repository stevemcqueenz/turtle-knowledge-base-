As there are numerous events in-game which rely on in-game time (Gurubashi Arena, Ghouls in Westfall, etc.) there shouldn't be an addon or simple command for it. However, it may be possible with a hacked system file or client but I'm not 100% on that.

There may be addons that display both in-game time and local time, particularly UI ones but I'm not certain this was possible in the vanilla client.

Worst-case, you can always alt-tab and check the time.
