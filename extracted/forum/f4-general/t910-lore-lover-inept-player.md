Didn't exactly know where to put this, so I hope it's alright if I leave it here.

Tried to play WoW back in the day, but I was actually quite terrible at it.  I was a teenager who wanted to play a character like Dwarven Rifleman from Warcraft III.  Rolled a Dwarf Hunter, played the game a bit and did some questing and dungeons, but never got the knack for it.  My actionbars started to feel overwhelming.  I wasn't so much as interested in the RPG aspect of things as I was the setting.

I really just wanted to be in the Warcraft game, and the game itself always felt like there was a lot going on.  I could muddle my way through a dungeon run, but CC, kiting, threat, tanking, oh boy.
My Destiny 2 group started playing on a WotLK server and while I've joined them just to see some of the sights, I don't see myself every doing ICC or what have you.

One thing led to another and now I've gone down the server rabbit hole.  I've even started looking into SP repacks.  Now I've ended up here.  With the added content and the focus on RP/PvE, I think I might be able to get some of that "live Warcraft" I wanted back then.

Does this server have a place for someone like me?  I'm more interested in the setting and things than the actual game, if that makes sense.  I'm actually pretty terrible at WoW, but man did the Deathknight starting area make me happy.  Frozen Throne is back baby!
