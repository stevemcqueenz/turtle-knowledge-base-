Another point of view.
The more you want to make, the more you need to learn.
If you want just to make new NPCs, items and quests, then you need to know how to install vMangos and how to write SQL to add stuff.
Here is the guide how to compile vMangos on your PC [https://github.com/vmangos/wiki/wiki/Co ... on-Windows](https://github.com/vmangos/wiki/wiki/Compiling-on-Windows)
<https://github.com/vmangos/wiki/wiki/Getting-it-working>
There is no specific guides about how to add quest/NPC/item though. Documentation for open source projects is always a weak point.
There are a lot of examples in world database.
There is also Item, NPC and quest creator made by turtle team <https://dev.turtlecraft.gg/#!/home>
It will help you to make SQL queries for your own vMangos server.

I believe those skills are needed also to create spells, but it is more complicated than quests.

If you want to change appearance of the game, then you need to be familiar with Blender and various tools to inject your models to game files.

You don't need a development team if you play your server alone or in company of friends via Hamachi or local WiFi network.
