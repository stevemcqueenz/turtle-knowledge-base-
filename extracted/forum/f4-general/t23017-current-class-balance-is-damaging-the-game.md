# Current Class Balance Is Damaging the Game

## Post 160646 by Bau — 2025-11-25T13:15:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=160646#p160646 | page 1 | era: 1.18.1-announced-pre-release -->

I’d like to share some thoughts on the current state of Turtle WoW’s class balance, because I think many of us have been noticing the same issues.

Adding new abilities can be fun and refreshing, no doubt about that. However, when these abilities are extremely explosive or overtuned without properly adjusting class stats and overall character progression, the entire game — both PvE and PvP — suffers.

PvE: Bosses Getting “Deleted”

In PvE, I’ve seen entire raid bosses melt in seconds.
But where’s the fun if content becomes this trivial?
Original Vanilla was more challenging and demanding, but players didn’t quit because the game was “too hard.” On the contrary, content was always cleared eventually, and that progression felt rewarding.

Introducing absurdly high damage just to make the game easier repeats the same mistakes Blizzard made over the years. It wasn’t the only reason for the decline, of course, but it definitely contributed. Making everything easier does not make it more enjoyable.

PvP: A Completely Broken Environment

PvP might be in an even worse state.
In original Vanilla, there were strategies that allowed you to survive outnumbered fights. Now only a few “top” classes — druid, shaman, maybe paladin — can manage that. Everyone else gets deleted instantly, even with 4k–6k HP, without even understanding what killed them.

Some examples:

Mages bursting 2k damage with a single instant cast.

Paladins blowing players up with one button.

Feral druids critting harder than a fully geared Naxx rogue.

Rogues dealing more damage with poisons than with their core abilities.

Melee Hunters hitting harder — and more dangerously — than a Rank 14 Warrior.

At this point, with how classes are tuned, it honestly feels like we’re playing a pre-TBC environment but still stuck with Vanilla-era stats, and that combination simply does not work.
The result is a frustrating, unreadable PvP experience with almost no strategic depth left.

A Situation Many Players Notice

I know not everyone will agree, but many players I’ve talked to — in BGs and raids — see things the same way. The situation is deteriorating, and denying it won’t fix anything.
And yes, the player population is already dropping; you can see it in-game.

Conclusion

If the idea is that players should enjoy content only when everything is simplified to the point of being almost insulting, then maybe it is better to move on to another game. And that’s probably what I’ll end up doing.

Thanks to anyone who comments, even negatively.
I just wanted to express what I’ve seen since this massive power creep started, because I strongly believe the game deserves better balance and more thoughtful design.

For anyone wondering: yes, I used ChatGPT to help write this text, simply because my English is a bit limited. The thoughts and opinions, however, are entirely my own.
