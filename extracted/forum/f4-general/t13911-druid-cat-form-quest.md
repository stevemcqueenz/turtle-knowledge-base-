## Post 94903 by Itorch100 (Barrens Chat Casualty) — 2024-05-15T12:33:00Z

Something that always kind of bothered me about druids is that there is no cat form quest, but you instead simply learn it from a trainer.

It is pretty clear, however, that blizzard originally had plans to implement a quest for it, since there is a [Great Cat Spirit](https://www.wowhead.com/classic/npc=11957/great-cat-spirit) npc in Moonglade, similiar to the bear quest, but it was cut due to time constraints.

I think it would be awesome if cat form could be moved from trainer to a custom lore-oozing quest in one of the updates! Are there any plans for that? If not, there should be :D Especially since druids have some of the most immersive class quests, imo.

Now, to add to my main point, I think it would be amazing if we had more class quests in general, as those are some of the most flavourful to me personally and to many others I'd wager. But one thing at a time :)
