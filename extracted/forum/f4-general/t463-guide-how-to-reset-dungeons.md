# GUIDE: How To Reset Dungeons

## Post 2351 by Scorpf — 2019-03-26T11:26:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=2351#p2351 | page 1 | era: pre-1.18.1 -->

Hello, while I was farming the Corpsemaker 2H Axe in Razorfen Kraul one of the community were kind enough to provide this command to reset dungeon instances.

There are a few tricks to getting it to work though it would seem...

o It works if you don't have addons installed
o It works if you only have GroupCalendar 2.2.1 installed fron vanilla-addons.com
o It doesn't seem to work for some who have other addons installed (possibly Questie?)
o It must be done by the Group Leader of the Party and all party members must be outside the dungeon

Finally, here's the command and it goes into the chat text area:

/script ResetInstances()

(If it works correctly you will get a chat message saying 'all instances have been reset')
