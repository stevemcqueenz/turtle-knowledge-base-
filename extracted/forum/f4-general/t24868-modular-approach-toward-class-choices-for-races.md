# Modular approach toward class choices for races

## Post 175381 by Armordillo — 2026-04-15T21:29:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=175381#p175381 | page 1 | era: post-1.18.1 -->

I notice that the topic regarding the relationship between classes and races have long been a recurring subject; to allow more race-class combinations contesting whether it fits the lore/theme. After thinking about it for some time with some regard to technical feasibility I would like to put forth another direction on how classes are offered for each race.

As players would know each of the available classes currently consists of three talent specializations trees, each tree focusing on a different playstyle, role and RPG flavor. My idea is to have each specialization be redesigned into standalone modules, to be packed into a set of three each along with an overarching smaller set of abilities and passives that allows the modules to interact with each other. A working example would be Ascension's approach to having abilities from different classes work with each other but unlike Ascension it will **not** be a buffet of specs to choose from; only prepackaged sets that have its basis in the established lore and themes.

The following below is an quick example of the gist:
 **Tauren Earthwarder** [ Restoration | Enhancement | Holy ]
 *These honored warriors of ritual fight with spiritual might and powerful exorcisms, protecting their ancestors' resting grounds.*
- Access to **Earthwarder** abilities, passives, armor and weapon skills (e.g. Plate Training)
 *Passive example: Enemy struck by Lightning Shield takes additional Holy damage from Exorcism*
- Access to Restoration talents, abilities and passives

- Access to Enhancement talents, abilities and passives

- Access to Holy talents, abilities and passives

Through this we can create more class varieties for each race while maintaining the lore and theme that defines them. Matter of fact, it might even enhance their identity from each other even more. For example, is a human knight the same as an orcish blademaster? By current categorization they are both under the Warrior class yet this umbrella term doesn't fully capture the Knight's nobility or the Blademaster's cunning. Under this new system it would resemble something as below.

Human Knight [ Arms | Retribution | Protection ]
 *Ability example unique to '**Knight**' kit: Courageous Cry*
 *Passive example within the '**Knight**' kit: When under Seal of the Crusader, each strike reduces Charge cooldown by 0.5 seconds*
Orc Blademaster [ Arms | Fury | Subtlety ]
 *Ability example unique to '**Blademaster**' kit: Bladestorm*
 *Passive example within the '**Blademaster**' kit: Casting Charge when in Stealth increases critical strike chance by 20% for 3 seconds*

 **Implementation**
 ---------------------------------------------------------------------------------------------------------------------------------------------
Assuming that this truly is technically feasible and the developers are willing to undertake this massive overhaul of one of WoW's core systems, the question would then become of what to do with existing players of the current classes if such a system was not implemented from the very beginning. Personally, I don't believe that we should do away with the core nine classes as they can make the leveling journey of a character more interesting.

For example when you are first creating your character - an orc in this case - you are still presented with the same core classes as before (Warrior, Hunter, Rogue, Warlock, Shaman). You choose to play a warrior which contains its associated three specs (Arms, Fury, Protection), leveling until 60. At level 60 you have the choice to visit the Blademaster trainer in order to learn the 'Blademaster' kit and swapping the Protection spec with Subtlety.

 **In the case of the Blademaster, only orcs warriors are granted this option.** Upon learning the kit, your character is set back to level 30 for you to journey again whilst and for learning your new abilities and playstyle. You are only given the option to swap back to a core warrior after leveling to 60 again which from then on there is no level reduction when swapping between the core and racial class.

 **Closing**
 ---------------------------------------------------------------------------------------------------------------------------------------------
Even though Ascension has shown it's possible to balance it (I think), it still would be quite a daunting endeavor. Regardless, I believe this system can help enhance the RPG elements of the game while allowing more flexibility of gameplay options; preserving the immersion and lore of the world without being constricted by it.

Even if this is completely unrealistic or causes more problems, do also comment what kind of class you wish you could play in WoW if you got a choice alongside other ways to better address this ever-returning topic. For me, I would go with Human Crusader [ Fire | Fury | Retribution ], dual-wielding Holyfire weapons.

Yeah, don't forget the immense balancing work this would require.

It wouldn't necessarily have to follow a logic of "everyone should beat everyone", but each playstyle must have its niche, a raison d'être.

From a development perspective, such a system becomes really difficult to implement and modify over time.

The simpler way to do it is only to implement more racials, as with the priests, or the way retail has gone with paladin racial mounts, which are now extremely diverse, or with more class/race quests, such as the warrior armor questlines.

For example, an easy way to do it would be for Warlock content for Orcs and Dwarves to play deeper into the demonology / void themes, whereas Human and Undead warlocks delve deeper into necrology / shadow themes. Doesn't necessarily translate into significant gameplay changes, except perhaps damage classes (fire vs shadow), but substantial cosmetic changes such as gear style, undead pets/mounts instead of demons, etc.

Hell, you can even rename Paladin -> Sunwalker when played by a Tauren, instead of just leaving it as a lore-wise concept. Build flair around this difference, even if gameplay is largely the same.
