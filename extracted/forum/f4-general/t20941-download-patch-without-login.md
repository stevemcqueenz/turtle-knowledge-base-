# Download patch without login

## Post 145678 by warozell — 2025-08-15T13:40:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=145678#p145678 | page 1 | era: pre-1.18.1 -->

I'm not sure if I'm missing something, since everything seems to be done through the client now instead of the launcher, so feel free to correct me.

In order to download the new patch, I need to launch the game and log into my account. However, there's an afk protection timer in the character selection which kicks you after ~1 minute. Since it's downloading the patch, the game isn't on the character select screen, but it still kicks me out. This means that in order to download the whole patch, I need to login multiple times (it does resume the download from where it ended). This is honestly quite annoying, but it has to be even worse for people with slower download speed.
Another thing is that repeatedly logging in is just extra traffic for the login server, and if there was a queue, I don't want to imagine how it'd work and if I'd even be able to download the patch without having to wait for the queue multiple times.

While this probably isn't a big issue, since patches aren't that frequent, it's still a bit frustrating because you can't just wait for the download to finish, like all downloads normally work.
