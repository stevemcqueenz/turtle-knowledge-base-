New information about guild bases. [Addressing the guildhousing concerns](https://forum.turtlecraft.gg/viewtopic.php?t=8751)

This forum post linked [here](https://forum.turtlecraft.gg/viewtopic.php?f=2&t=2527) will give a guide on how to request for a guild base and what requirements you need in order to get a guild base for your guild.

Keep in mind most guild bases with flying mounts are not accessible by foot and require a guild tabard to get into.  Exceptions to this rule are Macrochelys guild base which can be accessed through a series of jumps up a mountain.  The Emerald Dream base is able to be entered into with the aid of the Macrochelys flying mount.

[Here](https://forum.turtlecraft.gg/viewtopic.php?t=11991) is a Comprehensive Cartography guide on all the new Turtle content sorted by level ranges made by Korval1.

[Here](https://forum.turtlecraft.gg/viewtopic.php?t=13429) is a more up to date and more detailed guide as to where all the guild bases are.  This guide is courtesy of Vallcow.

[Here](https://forum.turtlecraft.gg/viewtopic.php?t=17211) is the patch that addressed the new guild house deed that you can use to set to any hearthstone.  The deed costs 5000 gold.
