> **Avalok wrote: Mon Jul 24, 2023 3:42 am**
> Shouldn't that exist in Vanilla wow, since the game runs on the Warcraft 3 engine?

World of Warcraft does not run on the Warcraft III engine. This is a misconception from a game of telephone regarding the game's development. While originally planned to be made in the same engine as Warcraft III, it was determined this would not be feasible for the sort of game they wished to create. So, using Warcraft III's engine as a rough outline or template, a new platform was developed.
