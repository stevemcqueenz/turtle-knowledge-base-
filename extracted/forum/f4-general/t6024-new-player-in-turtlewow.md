## Post 37934 by Liatris — 2023-03-16T04:47:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=37934#p37934 | page 1 | era: pre-1.18.1 -->

As far as I'm aware, many macros aren't compatible with the version of WoW the TurtleWoW server runs on (I believe it's 1.12, but correct me if I'm wrong). I know for sure the #showtooltip macros don't work, but I can't be certain about other macros.

As for warmode, you can disable it only once. Yet if you decide you want warmode again, you'll have it forever. Many players go for warmode while leveling for the 30% exp. boost, and then disable it once they hit 60 if they decide not to PvP all the time. All you have to do is go back to the glyph master if/when you choose to disable it.

A few tips to remember:
There's an item that acts like a dual spec for 350g so you can play multiple roles.

If you're in warmode at lv 60 ppl won't invite you for world bosses, since their pvp will switch on the moment they buff you or heal you, so make sure if you turn it on for leveling to turn it off once 60

Warriors are very strong once they get 9% hit rating

While there are some changes, most clases play the same

For macros you need vanilla ones, which are long lua string like /lua if castspell...
If you want to be able to use easier syntax get roid macros addon. Get supermacro aswell, so you can create macros with 2500 characters.
