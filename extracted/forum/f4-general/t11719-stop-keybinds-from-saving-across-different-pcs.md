# Stop keybinds from saving across different PCs

## Post 77394 by Papichris00 — 2023-11-14T20:47:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=77394#p77394 | page 1 | era: pre-1.18.1 -->

I play Turtle WoW on my PC and Steam Deck. Playing on the Steam Deck is great when I just want to handle a few leveling quests and gather resources. However, because my second "PC" is a Steam Deck, I have some unique binds to make things work.

The issue is that binds and ability positions changes on the action bars persist across the Steam Deck and PC. For example, if I make heroic strike the second ability on the actionbar on my PC, I load up the Steam Deck and see that change, and vice versa.

It would be a headache to line everything up so it works good on both the desktop and Steam deck. My steamdeck UI looks significantly different from my PC UI as you can imagine, and I would like keybind and ability positions to be completely seperate. How can I disable the turtle-wow servers from syncing changes? Thanks.

## Post 77398 by Imonobor (Bug Report Enthusiast) — 2023-11-14T21:41:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=77398#p77398 | page 1 | era: pre-1.18.1 -->

I would guess it's impossible, because it's not "synching" the changes, the changes/config files are stored on the server. There is only one copy of the configs, which means that when you move an ability, it changes for all PCs you might log in from.

What I'd suggest is using an Action Bar addon to use different action bar "groups" on each setup. By default, the game gives you 10 action bar groups, with 12 buttons each, if I'm not mistaken. Some are used by the default UI for paging the main action bar (1-4 I think?), then 4 more for the "bonus" action bars you can bring up from the options (like bottom left, bottom right, right 1 and 2), and the last 2 are for stances, like warrior stances, stealth and druid forms or whatnot.
Again, I'm speaking from memory here so it might not be 100% accurate, but the methodology of it should work:

So if you install, for example, Discord Action Bars addon, and set up bar groups 1-5 on your main PC and 6-10 on your steam deck, they would not overlap and wouldn't change the other config.

Let me know how it works out and if you need further assistance.
