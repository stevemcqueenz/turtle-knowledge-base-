**Token Shop Illusions**

 **How illusions work:**

- Illusions persist in combat.

- Illusions don't get consumed on use and can be turned on and off

- Illusions don't show armor.

- Not all Illusions show all weapons animations. Please consult [Animations Table](https://forum.turtlecraft.gg/viewtopic.php?p=18183#p18183) for which illusions has which animations.

- You can't mount while using a illusions

- Druid Forms and illusions don't work toghether

- Some illusions have multiple models in the same illusion token that is randomly given upon use
