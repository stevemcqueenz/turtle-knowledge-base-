If you want addon to work, you must:

 1) add new quests (npc, descriptions, locations and so on). otherwise you got error window every time you point at unknown quest NPC

 2) correct existing vanilla data because turtle wow is not 100% the same. some lowlvl quests have slightly different starting lvl for example.
