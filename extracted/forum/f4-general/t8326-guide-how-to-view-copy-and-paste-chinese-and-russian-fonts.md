# GUIDE: How to view, copy and paste Chinese and Russian fonts.

## Post 53668 by Lexiebean (Barrens Chat Casualty) — 2023-07-16T11:15:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=53668#p53668 | page 1 | era: pre-1.18.1 -->

Here is a short guide for how to view, copy and paste Chinese and Russian fonts.

 **To view the fonts**

• Download this [font](https://drive.google.com/file/d/1xIWNIhj8b9qbOjhfCObe3HFOiBkWrqZy/view?usp=drive_link)

• Extract the fonts to ..\Turtle WoW\Fonts
○ You will need to create a new Fonts folder.

○ If you use pfUI, also copy the font to ..\Turtle WoW\Interface\AddOns\pfUI\fonts
○ You'll also need to change your font settings in pfUI.
![Image](https://i.imgur.com/JV0dlcd.png)

 **To paste the fonts**

• Download Locale Emulator: ([**Direct Download Linl**](https://github.com/xupefei/Locale-Emulator/releases/download/v2.5.0.1/Locale.Emulator.2.5.0.1.zip)) ([repo link](https://github.com/xupefei/Locale-Emulator/))

• Run **LEInstaller.exe** to install  Locale Emulator.
• Run **LEGUI.exe**
○ Create and save a Chinese profile using these settings
![Image](https://i.imgur.com/pqAC36A.png)

• Right click on WoW.exe or WoWFoV.exe > Locale Emulator > Chinese

![Image](https://i.imgur.com/HXlAK7x.png)

And that's it!

You can also use this [Shortcut Creator](https://github.com/Svintooo/LEShortcutCreator) to make a shortcut so you don't need to remember to right click every time.

To copy text from WoW, I recommend [ShaguCopy](http://shagu.org/ShaguCopy/) or pfUI.
