# buffing a spell and nerfing a spell to implement class balance

## Post 102360 by 987004590 (Barrens Chat Casualty) — 2024-10-02T07:46:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=102360#p102360 | page 1 | era: pre-1.18.1 -->

I do not advocate making a large number of changes to a class all at once, the more changes made, the more problems arise. Turtle already made a mistake with the Paladin once, Several seemingly ordinary changes put together can break a class. Therefore, this post hopes that you can identify the most prominent problems in each class in order to achieve maximum balance with minimal changes.

I am a shaman player, so I only make suggestions about shamans, and I hope you will not talk about a class that you are not familiar with.

SHAMAN：
buffing [Ghost wolf] : The most prominent problem with shamans is the lack of maneuvering ability, although shamans also have no defensive ability, but because they have healing ability, I think maneuvering ability is more suitable for shamans than defensive ability. Because the shaman is extremely aggressive, some would say that giving the shaman mobility would break it, and I agree with that, the shaman shouldn't have much mobility, but also shouldn't so no mobility that the enh-shaman doesn't reach out to his enemies and run away from enemies that are stronger than him. Therefore, the ghost Wolf should be properly strengthened so that the shaman has the proper maneuvering ability.

nerfing [ None ] : Some might argue that chain lightning should be weakened.  It's indeed strong in PVP,  but not without a Nemesis, a Sheen of Zanza can kill a shaman.  in addition to this, shamans no longer have any outstanding abilities.
