# Turtle WoW Discord Status Update

## Post 5370 by Torta (Turtle WoW Team) [STAFF] — 2020-03-14T14:42:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=5370#p5370 | page 1 | era: pre-1.18.1 -->

This small application helps Discord to recognize Turtle WoW and set a status **Playing Turtle WoW**.

 **How does it work?**

- Download this archive: <https://turtlecraft.gg/downloads/TurtleWoW.zip>

- Unzip & copy the **TurtleWoW.exe** to the folder with your **WoW.exe**

- Start **TurtleWoW.exe**, new system tray icon will appear.

- Click on it and pick **Launch Client**.
