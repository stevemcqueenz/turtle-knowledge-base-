Hi, I'm new to this server. So far I've loved it, but I've noticed a recurring issue.

Whenever I login with a character or join a major city that is heavily populated, it takes several seconds or more to actually load the character models, only the round shadows show up. If I try to use the hearthstone while my character is not fully visible the game crashes (I'm still teleported though). ## Post 131333 by ManceJoan — 2025-05-16T08:21:00Z

Hey, welcome to Turtle WoW!
What you’re experiencing is actually a pretty common thing on private servers, especially ones that use custom patches or have a lot of players in one area. The slow model loading is usually related to how the client handles DBC and patch files—it’s not always as optimized as retail.
One tip that might help: try clearing your cache folder and make sure you're not running any heavy addons on login. Also, keeping your draw distance and texture settings modest can improve loading time. You're definitely not alone in this—it’s a bit of a quirk we all get used to!
