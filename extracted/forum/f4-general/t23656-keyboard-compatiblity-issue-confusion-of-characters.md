# Keyboard compatiblity issue - confusion of characters

## Post 165579 by Sleeplust (Patch Note Conspiracy Theorist) — 2026-01-19T03:51:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=165579#p165579 | page 1 | era: 1.18.1-announced-pre-release -->

When I used my Microsoft Surface laptop to log in months ago, I found that my password was invalid. So, I changed my password in case my account was stolen, but the password was still wrong. After a good number of attempts, I eventually realised that it was a compatibility issue that Windows 11 or the client of TWoW mistakenly recognises the key and character "@" in the password input bracket as a quotation mark ". This issue seems to have never happened on my desktop PC.

I tested again using my Surface minutes ago and this issue still exits. **I toggled the typing input to ENG, or English (Britain), and then the @ I pushed down became a ".** This time I confirmed that same issue plagues all across my Windows system. When it is toggled to other languages, there is no such problem.

Or, it may not be a bug or malfunction, as some keyboards in 2020s may have the characters @ (shift+2) and " (second key on the right side of L) exchanged.
