Hello,I'm Tokai.
I cannot give you an accurate answer to this question, but the answer I can give you is: the thief's [Sprint] skill and the goblin race's [Exit Strategy] skill cannot stack the movement speed when used simultaneously (I mean using [Sprint] first and then [Exit Strategy]). I have used a MonkeySpeed plugin that can display the character's current speed in real-time. Under the prompt of this plugin, the character's default movement speed is 55%, When I used Sprint, it increased to 83%, but when I continued using Exit Strategy, the speed remained at 83%.
So I think there is no overlap between effects of the same type. Perhaps my judgment is incorrect, and you can also use this plugin to try controlling variables to observe the speed of characters.
