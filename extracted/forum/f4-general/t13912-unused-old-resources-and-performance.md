# Unused old resources and performance

## Post 94912 by Dracarusggotham (Grandmaster of Forum PvP) — 2024-05-15T13:38:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=94912#p94912 | page 1 | era: pre-1.18.1 -->

I've noticed that unused resources from old patches are still prevalent within the game.
Why don't they eliminate them?
For example, the old Alah'thalas maps are still there and are visible by removing the new patches.
Don't they affect performance?

## Post 94931 by Jan125 (Barrens Chat Casualty) — 2024-05-15T18:57:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=94931#p94931 | page 1 | era: pre-1.18.1 -->

While it would be possible to remove these areas from the files, there would be little practical benefit right now.
The size of the patches could be made smaller.

Due to how WoW loads resources, there is no performance loss.
If a file in a later patch exists, it overwrites any files in the previous patch internally.
