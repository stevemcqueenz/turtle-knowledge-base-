# Unreasonable expectations for the new PvP server

## Post 73371 by Jc473 (Patch Note Conspiracy Theorist) — 2023-10-24T13:53:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=73371#p73371 | page 1 | era: pre-1.18.1 -->

Anyone else looking at the feedback in the PvP Phase Schedule forum post? A couple of months ago, the idea of a PvP server was a complete pipe dream. When they announced it, I think many people just assumed it would launch as a fully progressed realm but they did a nice thing and delayed the AQ/Naxx phases. Fast forward to today - they've gone even further and fully phased it (although, they should probably lengthen each phase considerably).

Yet, we now have feedback asking for things like:
 1)	new PvP systems
 2)	overhauled PvP itemisation so it doesn’t become obsolete during the AQ/Naxx phases
 3)	removing all raids
 4)	my personal favourite – “”Don’t include custom content, PvP server is a PvP server, they want PvP no lore, so, don’t waste time in that””

I’ll repeat… a couple of months ago, the idea of TWoW launching a PvP server was a pipe dream. Why are people now expecting such radical changes, especially when the server is launching in a few days….! If people actually want TWoW to create some sort of PvP+ experience, they’d probably need 6-12 months to go away and design the damn thing. Please remember that no other Vanilla server has figured out how to balance parallel gear progressions of PvP/Raiding content. It is **not** an easy problem to solve!

Can you imagine everyone’s reaction if they were told their PvP server was going to be delayed like this in favour of a new PvP+ experience? I think people should just be happy that we got a PvP server at all.

I'll rewrite my suggestion from the other thread;

I think the only way to keep it fair would be to keep both types (PvP/Raid) of gear on par with each other every step of the journey. However, what this means is that you'd have to slow down the ranking system (sounds painful, I know) but given that you can't de-rank on this server, I think this might be a decent solution. But what about the AQ/Naxx gear imbalance issue? Well, perhaps the ranking system also needs to be extended (an additional 6 ranks, gated per phase) to offer further upgrades to match these later raids.

So, it might look like this;
Phase 1 - Up to rank 11 (blue set - on par with MC gear)
Phase 2 - Up to rank 14 (epic set - on par with BWL gear)
Phase 3 - Up to rank 17 (Upgrades to blue PvP items such as neck/cloak/bracers etc. Also, include rings and damage/healing trinket).
Phase 4 - Up to rank 20 (Perhaps just upgrades to the R14 armour and weapons?)

Additionally, you could gate the reputation for the three factions and buff the rewards to be in line with the phases.

The whole point of this suggestion is to keep the PvP itemisation in line with Raiding **but** to also ensure that the PvPers still have some sort of 'progress bar' to work on with each phase. Just rough numbers, but I'd expect getting from rank 14-->17 to take a couple of months and the same again for 17-->20. Why? Well, because a typical raider only gets a couple of pieces of gear each month.

The major benefit of this sort of change is that you could replicate it on the PvE server so the devs aren't 'forking the code'.

One last point - this obviously doesn't solve the issue of the gear disparity between a fresh 60 and a Naxx/Rank 20 player. I don't see how you can solve this particular issue without some sort of Retail-esque approach (e.g. automatic gear scaling in BGs..... yuck!)
