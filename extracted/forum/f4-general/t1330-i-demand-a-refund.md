[Abyss Shard](https://database.turtlecraft.gg/?item=20534)

This trinket can be used to **GAIN SOUL SHARDS** without needing to use Drain Soul on targets that yield XP or Honor.

All you have to do is use the trinket to:
1. Summon a Voidwalker (at no mana or Soul Shard cost).
2. Put the Voidwalker on Stay.
3. Move far enough away from the Voidwalker for the Voidwalker to despawn.
4. Gain +1 Soul Shard in your inventory.
Note that doing this gives you +1 Soul Shard more than you had before using the Trinket ... and it turns out that there are a surprisingly large number of edge cases where being able to generate a Soul Shard "out of nothing" is a Really Useful™ thing to be able to do.  For one thing, it basically means that with the trinket you shouldn't run out of Soul Shards as a Warlock.

Just FYI.
