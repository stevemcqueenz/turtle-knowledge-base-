Pardon the post, but I don't deal with closed-source software that a random person posts.
I use an alternative called 'Greenshot' that allows for taking screenshots without dealing with TGAs in the first place.
Source code & Download: <https://github.com/greenshot/greenshot/>

Fully open-sourced and FREE on Windows; costs like $2 USD if you want precompiled binaries on MacOS.
Greenshot is also available as a portable no-install version as well: <https://getgreenshot.org/version-history/>

I'd strongly recommend sticking to the last known 'stable' version from 2017 unless you like testing software.
