# Server-Populations Bug. What's the point of this?

## Post 147041 by Cynetic — 2025-08-19T16:36:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=147041#p147041 | page 1 | era: pre-1.18.1 -->

What's the point of this?
For days, the server list has said that the population on Tel'Abim is "high" and Nordanaar is "medium."

It's the other way around.

Tel'Abim is the server with the lowest population of all. When I started there a year ago, we had a maximum of 600 players online; now we recently hit the 3,000 mark, and the number is growing every day!
Thousands of new players, new guilds, and everyone will soon start clearing Molten Core.

Meanwhile, Nordanaar and Ambershire are developing into mega-servers with 10,000+ players. The capital cities are bursting at the seams, and players are fighting over every ore.

Is this a bug being ignored? Or should we see a conspiracy behind it, since this happened at the same time as the Ambershire server launch? Is Tel'Abim being artificially kept small in case Ambershire merges with Nordanaar at some point and brings enough players back? Are the devs afraid that their main server will die if the PvP server is pushed too hard?

I request that this error be corrected, as it gives the impression that the server is full, which discourages new players.
