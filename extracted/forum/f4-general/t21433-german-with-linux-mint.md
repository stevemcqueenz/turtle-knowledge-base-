I couldn't get the German version to work with Linux Mint.

It did work with Zorin OS, though. The AppImage file started there.
Zorin has an additional system tool called Windows App Support. This app must be installed and used as a launcher for the wow.exe file.

The game now starts and is in German.
It can now also be launched via Steam with the new Proton version.

I think Linux Mint, which is often used, should work well with Lutris.
Lutris doesn't use the launcher, but installs the game directly.
It would be desirable if the errors with the 1.18 file download were fixed, and if there was an option to choose which language support you want to use.
