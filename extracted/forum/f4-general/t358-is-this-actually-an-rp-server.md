# Is this actually an RP server?

## Post 1936 by Ridley — 2019-01-22T21:47:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=1936#p1936 | page 1 | era: pre-1.18.1 -->

I found this server just recently and gave it a go, but a few things have confused me. Is this a PvE server first, or an RP server first?

I ask because most roleplay servers give you tools for RP; roleplay add-ons, roleplay gear, custom zones or towns, flavor features (tents & campfires come to mind), inter-faction interaction. This server (from what I could explore) has absolutely none of that. Add traditional leveling, hostile mobs & gear dependency and I'm not sure how anyone is supposed to roleplay. You're even expected to roleplay in your leveling gear, i.e. clownsuit, since the server isn't big enough to cobble together a set from the AH nor can you get any immersive, "realistic" attire.

I know the server motto is "take it slow" and that's fine, I respect that. But there is a big difference between driving slow and not having wheels on the car. If you didn't tell me the server was roleplay-friendly I'd assume this was just another vanilla server. Am I missing the point?

Also: seeing 12 giant turtles wandering around Tirisfal Glades, right next to flesh-eating zombies, is really bizarre and immersion-breaking. I think that might be because I accepted a quest though.

## Post 2041 by Parcival (Barrens Chat Casualty) — 2019-02-08T22:23:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=2041#p2041 | page 1 | era: pre-1.18.1 -->

Welcome to the server!

As for the Roleplay - the server isn't a fully-fledged, RP centered one as some others are on the interweb; the main focus is still PVE, but with an emphasis on taking it slow, therefore working out the toxicity some other vanilla servers have (the race to max lvl, hard core raiding, etc.). Roleplay is still present on the server - simply play the game and meet new people and you'll have some buddies to begin your RP adventure in Azeroth.

As for RP gear - since the playerbase is small at the moment, the AH doesn't include much if any vanity items, but that shouldn't discourage you. There are many people online who will be glad to help you cloth your character - especially some simple attire, which can be crafted with little of any valuable and expensive materials from a moderately skilled crafter. For some other items you wish to acquire which can't be crafted, it is best you set out your desired appearance before hand, keep it in mind while questing and leveling and store those items (world drops, mob drops, dungeon drops or quest rewards) - I do this all the time and have a special bag in my bank just for that.
