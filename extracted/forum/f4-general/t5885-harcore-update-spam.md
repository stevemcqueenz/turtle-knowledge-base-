## Post 37056 by Ravenstone (Patch Note Conspiracy Theorist) — 2023-03-07T13:13:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=37056#p37056 | page 1 | era: pre-1.18.1 -->

type Code: Select all

```
.hcmessages x
```

x being the level you want to see messages equal to and higher.
