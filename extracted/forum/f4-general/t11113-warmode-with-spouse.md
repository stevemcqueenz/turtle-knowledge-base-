## Post 73078 by Jolikmc (Patch Note Conspiracy Theorist) — 2023-10-23T16:31:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=73078#p73078 | page 1 | era: pre-1.18.1 -->

A multi-boxing "false positive" is possible if you and another person – spouse or otherwise – are playing at the same time from the same IP address – which is extremely likely if you're in the same house.  However, if a GM watches you guys scurrying about for, like, *two minutes*, it should become pretty apparent that you're two completely separate players doing completely separate things.

But, yeah.  If a GM stupidly starts pressing you when one character is running around and the other is focus-firing manual-cast spells or something, just explain the situation.  There's no rule against two or more **distinctly unique** players partying from the same IP address even if they're doing a Hardcore or War Mode run.
