# .bat file to DELETE your WDB folder

## Post 2141 by Jcarrill0 (Patch Note Conspiracy Theorist) — 2019-02-24T20:43:00Z

I provided a .bat file I wrote/copied from a text file that will automatically delete your WDB folder, then launch wow.exe if anyone likes.
I use it since I switch servers a lot and DBs are always different.
Code: Select all

```
@echo off
rd /s /Q "WDB"
start WoW.exe
exit
```
