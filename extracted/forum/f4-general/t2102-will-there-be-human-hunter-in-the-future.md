Yeah but the game architecture doesnt permit it. Unless you want to *lose* a human class.

And lets be honest, if we gave hoomen all classes that "made sense", they would have ALL the classes, as IRL we hoomen do all activities that can exist (and even try all the dumb impossible activities that can kill us, like tasting unknown mushrooms because they are pretty, or jumping off a cliff attached to a string just to see how it feels). So that's not a reasonable metric to use to guide game design.

Each race needs to have class limitations to make each one flavourful and asymetric. To create player choices. That's more fun than being able to do all race-class combos.
