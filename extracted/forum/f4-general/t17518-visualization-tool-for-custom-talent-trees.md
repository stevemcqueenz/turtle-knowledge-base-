## Post 119563 by NoktDraz — 2025-02-10T20:02:00Z

Hello everyone!

I've made an app that allows you to create mock-ups of custom talent trees and then theorycraft builds with them. The custom talent trees are easily shareable and adding new builds is as simple as moving a folder to the '***Custom Sets***' directory, where custom sets are loaded from.

Check out the source code on [GitHub](https://github.com/NoktDraz/WoW-Calcomizer)

... Or just download the files, run the .exe and start brainstorming
