Lot of incorrect information here. If you want the functionality where you hold alt and it modifies to self cast only when youre holding, you have to go under keybindings and set "self action button 1-12" to be alt+keybind. For this reason, any spells you want to be affected by this function must be on your main action bar.

the general "hold to self cast" button wasn't added until a later client, not sure which as I only remember classic/mop client at this point where it is a built in function
