# If your game keeps downloading a patch...

## Post 106042 by Manateufel — 2024-11-02T21:32:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=106042#p106042 | page 1 | era: pre-1.18.1 -->

If your game keeps downloading a patch each time you launch WoW, here’s how to fix it:

Run the shortcut as an administrator.
Ensure the shortcut targets WoW.exe (not WoWFoV.exe).

That’s it — you're all set!
