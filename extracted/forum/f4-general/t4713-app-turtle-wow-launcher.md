Fellow players,

I'm very excited to inform you about that my home-made project have reached a state where it can be shared with you.

In my free time, I've created a launcher application for Turtle WoW that provides you some QoL features when playing on this great server.

Some of these features are:
- Download and install Turtle WoW client

- On launch, sets the realmlist to the Turtle WoW server's login address

- You can easily clean WDB folder with one click

- Direct link to website

- [OPTION] Auto-Launch World of Warcraft when the application starts

- [OPTION] Auto-Clear WDB folder when WoW launches
The application is themed around Turtle WoW (thank you Torta for the assets).

 ***Download from here: <https://github.com/farblayz/turtle-launcher-release>***

You can download the application from it's RELEASE REPOSITORY (linked above) where you can read about installation and setup and in case you encounter any bugs, you can create an issue in the tracker.

 *Please note that, this application is in beta-phase, so there can be bugs. If you happen to find any, please report it in the Issue Tracker or contact me at the Turtle WoW Discord server, or on the Turtle WoW forums via PM.*

Any feedback would be much appreciated!

 ***Changelog:***

 *Version 0.9.6:*
Fixed a possible issue regarding client download process
Updated client download URL

 *Version 0.9.5:*
Added exception handling (the program's robustness is vastly increased)
Refactored the code
Added logging (in case of any exception, you can find the log in C:\temp\ folder)
Addedd progress bar for the client unpacking phase
Added an error message section to the main window (in case of any errors, a short message will be printed there and more specific message will be written to the log)
Fixed application crash when connection is lost during client download
