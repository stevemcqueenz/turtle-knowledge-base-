## Post 41689 by Portholes — 2023-04-15T23:12:00Z

You'll always get the answer "Play what you want" or "Play what you enjoy" and it ain't wrong
If you're looking at what is most needed you'll probably end up burning out on a class/spec that you won't enjoy and end up rerolling later on for a more enjoyable class/spec (theres a lack of them for a reason)
If you're looking for an "easy in" for dungeon leveling, both heals and tank are equally needed but you probably won't see that.  If you roll heals, you'll always be waiting for a tank; if your a tank, you'll always be waiting for heals.  Either way you'll question if you should reroll, you'll end up believing there is a lack of the other.
For Raids it'll be easier to get started as a healer (less gear required + more raid spots) and as a tank it'll be more of a process to gear up, but once you're in, you're in.
If you're set on tanking, Bear is really nice for gearing early on and pre raid (has a nice Epic BoE set that will get you far), if you're set on warrior i'd assume you'd already be a warrior without question, prot paladin is pretty alright (still needs some work but its doable), and do shaman if you just want to meme (its not a question if you can, but if you should)
Healers are pretty much the same as Vanilla/Classic, nothing special.  Only real difference is that Druids get Tree Form, which means they can continue being a mediocre healer but look like a Tree while doing so.
