# Scythe of Elune Class Restriction

## Post 70153 by Ghola (Patch Note Conspiracy Theorist) — 2023-10-11T07:19:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=70153#p70153 | page 1 | era: pre-1.18.1 -->

Can someone explain the reasoning behind gatekeeping shamans from another caster legendary? I know it may be far too early to make assumptions considering the actual item is still unknown, but the class restriction listed on the tooltip will dissuade any shamans from going for it even if in the end they are able to use it.

possible explanations I can think of are:
 1. Don't want a legendary available to a faction specific class that's not attainable by the other faction's class - paladins can already use thunderfury while shamans cannot
 2. Don't want more legendaries available to shaman - again, paladins and warriors can use both melee legendaries (and the neck)
 3. New legendary might be overpowered on shaman - balance it?
 4. Too many classes might have access to it - could easily have been a healer dagger or caster sword, id prefer that over being left out purposefully

Turtle made some great changes by making eye of the beast available to paladins and don rodrigo's band usable by shamans. I understand not adding in a shaman version of atiesh because it is an established item, but adding class restriction to a custom caster legendary stings. Especially when atiesh can be used by both spriests/healing priests and feral druid/healing druid
