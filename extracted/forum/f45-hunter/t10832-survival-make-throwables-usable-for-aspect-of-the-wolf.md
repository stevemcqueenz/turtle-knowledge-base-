Hi,
so as you know one of the new features added for hunters in Turtle WoW (in comparisson to original vanilla) is an ability to learn Thrown Skill at weapon master in Orgrimmar. Using throwables makes You unable to use most of your abbilieties that you'd normally use as a ranged hunter, yet You can use **Scorpid Sting** and specificly **Wyvern Sting**, which is the last talent in survival tree, which esentially designed for melee hunters. Since throwables ain't no competition for bows, guns and crossbows, wouldn't it make sense to be able to use throwables while using Aspect of the Wolf? Using it as an opener would add a lot of flavor to the spec, You'd us Hunter's Mark -> Place trap -> Bait mob into it with throwables -> Hack it down with melee. Plus there is also auto shot added for throwables, yet I see no other reason for all these to be added other than RP reasons which is okay I quess but meh. I think adding an abbilitie to use throwables while using Aspect of the Wolf would add loads of flavor, would make sense that there is ranged ability (Wyvern Sting) in melee talent tree, would make survi more interesting and playing with traps way less frustrating, in the end these are also a part of survi kit. Please share Your opinion brother hunters and maybe We could actually make it a thing? What you think?
