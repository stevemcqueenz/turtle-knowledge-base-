# The way druid tier sets work is disappointing

## Post 128355 by Lunadrix — 2025-04-24T19:16:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=128355#p128355 | page 1 | era: pre-1.18.1 -->

I'm new to druid in twow so unless I've majorly misunderstood something (which I don't think I have have), then I don't know if anyone else feels this way but honestly for me it's drove me away from playing the class...

One of my main draws to turtle wow was that all specs have become viable and with that, tier sets have been adjusted so there is mostly one available for each role a class can play. So for example, paladin has 3 roles, and now has access to 3 tier sets options for each raid tier, one for healers, one for dps and one for tanks.

For druids for some reason it just doesn't work this way. If you want to tank, you get to 60 and start running MC and realise all of the tier 1 gear is specced for a feral dps. Then tier 2 is specced towards tank druid, tier 3 also tank druid, and kara40 gear is specced for a dps druid again.

One thing that really bothers me is that I think its disheartening doing a whole raid tier and you're not going to be working towards any cool class identifying gear set. Also, kara40 just came out and the gear looks sick, and its pretty pointless to even bother collecting that if you're a druid tank. I just don't really understand the reasoning for this at all considering all of the alternative tier sets they've made for each class. I really think considering adding feral dps and feral tank sets to each tier would be welcomed and bring more people to the class...
