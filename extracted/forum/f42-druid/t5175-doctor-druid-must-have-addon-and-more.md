## Post 31453 by Moomoomoo — 2022-12-23T18:52:00Z

Hello Druids!

Doctor Druid

You should be using this addon with any Vanilla WoW client:
<https://legacy-wow.com/vanilla-addons/doctor-druid/>

It has all the Druid macros that you may need built into it and a lot of 1-key quality of life features too.  Do yourself a favour and go grab it now!

Bounus:   Benecast

Here is another great addon for any healing class, but especially for Druids:
<https://legacy-wow.com/vanilla-addons/benecast/>

This allows you place healing button icons on any on-screen portrait and use those to cast damage and mana based heal spell ranks that it will calculate for you.  You can also add some tweaking for overheals.  Again, do yourself a favour and grab it!

Note: if you want it to work properly within a party, you need to have "auto-self cast" turned off.

I have tested both of these with my Turtle WoW install and they seem to be working correctly.   Benecast had some issues when I also had Bugsnag enabled sometimes, so I removed Bugsnag.

>
>  how do I access the Doctor Druid macros?

There is a Readme file in the package, but quite simply you write your own macro and in there use: Code: Select all

```
/dd bear
/dd cat
/dd cursepoison
/dd catbehind+
etc....
```

If at console you just type: Code: Select all

```
/dd
```

It will bring up a dialog to configure each of the commands above even more.
