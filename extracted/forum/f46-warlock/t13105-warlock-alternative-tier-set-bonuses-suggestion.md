# Warlock Alternative Tier Set Bonuses Suggestion

## Post 87844 by Krotux (Barrens Chat Casualty) — 2024-02-15T13:16:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=87844#p87844 | page 1 | era: pre-1.18.1 -->

So the new tier set is a fire destruction warlock set. I thought I would spice it up by making not pure fire damage bonus and instead incorporate pets into it as well.

I propose the following set bonuses, in no particular order, potentially for T3:

 1. Remove cooldown of Soul Fire

 2. Soul Fire and Shadow burn no longer require soul shards

 2. Your pet's attacks do an extra 20% as fire damage. (buff this if still too weak)

 3. Infernal cooldown reduced by 10 minutes, duration increased by 5 minutes.

Why:
The goal is to make fire viable without making it OP and boring.

With this, you could go full destro with the fire damage buff, or even half demo half destro and sacc the imp. If the set bonus focused on conflag, it would reduce the number of viable builds capable of using this set. It would also break pvp potentially.
