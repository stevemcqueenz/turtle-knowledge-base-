# Definitive Demo Warlock Changes Thread

## Post 107192 by Krotux (Barrens Chat Casualty) — 2024-11-09T05:32:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=107192#p107192 | page 1 | era: pre-1.18.1 -->

*Going to make this the definitive thread for Demonology suggestions. If you want to add something let me know on discord. I have included here ideas from both discord and previous posts. Will edit this post as ideas come.*

In this thread, we will discuss two specs and try to make them feel distinct from each other.
Soul Link Warlock
Demo / Ruin Warlock

My hope is that Soul Link Warlock focuses on Greater Demons, while Demo / Ruin focuses on Common Demons and strong Shadowbolt Damage.

 **GREATER DEMONS:**

Starting with Soul Link and Greater Demons, I believe the current design of DPS cooldowns is not good. **Short durations and high power is impossible to balance.**

It will either be useless in PvE or OP in PvP.
In PvP, duration doesn't matter much. Fights end in like 30s or 1 min. So if an Infernal or Felguard is worth using in PvE, it means during that 30s/1min window it is going to be OP in PvP.

Another issue is that the entire spec will revolve and be balanced around "The Black Book" trinket.

 **Greater Demons should not be balanced around short durations.**

 **Suggestion:**

Since you already need Soul Link to safely use them, let's go one step further to make deep demonology more interesting and different.

This is the new and improved "Master Demonologist". Please note that this **may need further tweaking**, but the design is to give deep demo warlocks the fantasy of controlling something they can barely control. The warlock struggles to concentrate on their magic while controlling the demon. **I put 25% slow below but that's probably too much, maybe 10% or 15% is more fair.**

![Image](https://i.imgur.com/Zz8duyk.png)

Warlock demons are disposable but not meant to be suicide bombers. That's why we have things like health funnel and mana funnel. The gameplay using Greater Demons will definitely include some health funneling here and there.

It also includes the Doomguard into the mix, which so far has been completely ignored. Finally, it will be possible to use Demonic Sacrifice as deep demo with this design. It was very weird how a talent is useless in the tree that it is in. Now this is fixed too.

 **COMMON DEMONS:**

This will be the focus of Demo/Ruin builds. You choose to focus on your Shadowbolt damage, but still invest in making your demon pets stronger. The reworked Master Demonologist talent above tries to give the following roles to pets:

Imp: Best ranged dps, has nice buffs.
Succubus: Best melee dps, gives threat reduction.
Felhunter: Anti Magic and Debuff.
Voidwalker: Anti Physical and Pushback.

While the Imp & Succubus are the main demons for destruction warlocks, we want to add some niche to the others too. **I would like to add that this assumes common demons get rebalanced. Currently, only Imp is usable.**

There was some talk about replacing the Felhunter's Tainted Blood with either a stacking dot or shadowbite (damage based on how many dots are on the target). If we get shadowbite, it would be the go-to pet for affliction locks.

Another Common Demon idea is for the Succubus. Soothing Kiss is completely useless, but it could be useful if it also reduced the warlock's threat slightly. This would tie in with the idea that Succubus is the best for threat reduction.

 **OTHER:**

Demonic precision should prob also give crit if you want destro/demo warlocks to share the same gear.

Power Overwhelming should probably have a lower penalty than 40% HP loss since we do not want to kill our pets asap.
