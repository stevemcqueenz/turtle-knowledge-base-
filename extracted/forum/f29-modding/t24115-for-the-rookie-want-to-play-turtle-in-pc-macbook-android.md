 - Device： Macbook Air M1 8G /  Macbook Air M4 32G Tahoe 26.3
 - Approach：Turtle Silicon
 - Step：
 1. Download the official TurtleWoW client (not the launcher!): <https://eudl.turtlecraft.gg/twmoa_1180.zip>
 2. Unpack the ZIP file and place it where you prefer
 3. Download  CrossOver 25  (26 not supported yet) and make sure it is inside your Applications directory (the trial is enough and it will still work after trial expiration): [https://media-zh.codeweavers.com/pub/cr ... 25.1.1.zip](https://media-zh.codeweavers.com/pub/crossover/cxmac/demo/crossover-25.1.1.zip)
 4. Open CrossOver at least once, then close it again
 5. Download the latest TurtleSilicon app from *Discord*
 6. Unzip it and drag TurtleSilicon.app into your Application directory
 7. Open Terminal and run `xattr -cr /Applications/TurtleSilicon.app`
 8. Now you can launch TurtleSilicon
 9. Accept any permissions it is asking for
 10. Set your Game Path to the place where your downloaded TurtleWoW client is located
 11. Select your CrossOver.app (usually within Applications)
 12. Patch both the Game and CrossOver (if you get an error, make sure TurtleSilicon has permissions for Files and App management. Go into System Settings > Privacy & Security)
 13. Click play and enjoy
 - TroubleShot：
 - Character's avatar render black
 1. you need open multisample to 2x in TurtleSilicon
 2. close all addOn and enter game
 3. close game close TurtleSilicon, then reopen addOn in next run

## Android

 - Device： Xiaomi 14 Pro (16G/512G) HyperOS 3.0.8.0
 - Approach：Winlator
 - Step：
 1. Download the official TurtleWoW client (not the launcher!): <https://eudl.turtlecraft.gg/twmoa_1180.zip>
 2. Download release apk from <https://github.com/FrontMage/winlator-llm>
 3. Copy game to you phone's download directory
 4. install apk and wait the setup
 5. create a container then enter the D: Driver
 6. D: Driver will link to the phone's download directory , just click the WoW.exe
 - TroubleShot：
 - Game network is a problem if you need a proxy for it
