<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=117019#p117019 | page 1 | era: pre-1.18.1 -->

Hi!

Does the gamelauncher settings work when starting the game from vanillafixes?

Is vanilla tweaks even needed now that the game launcher has the same stuff in it?

## Post 117076 by Zeran (Patch Note Conspiracy Theorist) — 2025-01-17T14:21:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=117076#p117076 | page 1 | era: pre-1.18.1 -->

Vanilla Tweaks is integrated into the launcher so you no longer need a separate installation of it.

Vanilla Fixes is currently NOT integrated, so you still need to download it separately and run the game from Vanilla Fixes.exe

So you can apply the settings you need in the launcher, then close the launcher and start the game from the Fixes exe.

## Post 121559 by kangytrsa — 2025-03-04T02:37:00Z

It’s great to see that Vanilla Tweaks is now integrated into the launcher, making it much more convenient for players. However, it’s a bit disappointing that Vanilla Fixes still requires a separate installation.

For now, the workaround of applying settings in the launcher and then launching the game via VanillaFixes.exe seems like a reasonable solution. Hopefully, future updates will bring full integration for Vanilla Fixes as well. That would make the experience even smoother for players who rely on these fixes for better performance and bug fixes.
