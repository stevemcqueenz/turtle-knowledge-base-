# Night Elf Glow Effect Removed [Custom Patch]

## Post 3551 by Kazgrim (Patch Note Conspiracy Theorist) — 2019-07-25T02:05:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=3551#p3551 | page 1 | era: pre-1.18.1 -->

This patch removes the glowing eye effect from Night Elves for both male and female characters. This was an experiment at first, but I actually liked how the faces looked without the glowing eyes. In my opinion, removing the glow effect brings out more personality from the faces.

Here are some pictures. Note that the blindfold face on males now doesn't have annoying glow!
