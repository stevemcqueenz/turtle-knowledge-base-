**>Blood Elf Female Underwear Mod<**
![Image](https://i.ibb.co/bjTwtf6q/OldNew.png)

Hello, hello.   smiling_turtle_head

I did a little bit of an Texture Edit for the Female Blood Elf Texture used for the Donation Reward Texture contained in TurtleWoW's Female Blood Elf illusion reward you can buy from the Donation Shop.

The reason I made this is to give my character actual underwear that fit into the style of WarCraft since I wasn't satisfied with the "patches" on the top and the bottom's appearance.

it kind of aims to be in touch with Blood Elf aesthetic without trying to be too distracting whatsoever.

Only a single file has been edited for it. The .zip includes a ReadMe with a brief tutorial on how to activate/install the Mod. Check the image inside the .zip to see what changes have been made.
