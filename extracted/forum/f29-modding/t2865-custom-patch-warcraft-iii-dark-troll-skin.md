After some research (quotes and wowpedia links below), yes, they were but Troll Compendium states that their skin varies from "gray to black". Sure. You'll need a few softwares:
 - one to open mpq files, look into it (and extract what you're looking for, in our case it's texture files which are blp files) and create custom mpq, such as MyWarcraftStudio.
 - one to convert blp files to png (and vice versa) like BLPconverter or BLPlab.
 - one to modify your png. I'm using Photofiltre.

You can't add custom stuff (new items, new weapons, etc.), it's server side only. What I'm doing is simple texture swap. Read below for the procedure to make a custom skinpatch:
 - 1: Open MWS, take a look at mpq files, extract what you want. If it's a non-basic skin (that you can't select from the character creation screen IG), you will have to swap it with one of the basic skins, so copy the basic skin's file path.
 - (2): Convert it to png I you want to modify it on Photofiltre. Don't forget to convert it back to blp.
 - 3: Still on MWS, create a custom mpq, add to it the blp files you extracted and/or modified. Keep addin'. For each blp file you add, you'll have to paste the right path you copied earlier. If I use my skinpatch as an example, copied path was something like "*Character\Troll\Male\Nameoftheblpfile00_105.blp*". Make sure you put the right path for the right file: Character\Troll\Male\TrollMaleLowerFace path with TrollMaleLowerFace file etc.
 - 4: Save the patch.
 - 5: Put it in your WoW Data folder.
 - 5: Enjoy!
