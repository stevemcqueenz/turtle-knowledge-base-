How to install:
Download patch-A and patch-B. Go to your Turtle WoW folder and place them inside the Data folder. Also, delete the WDB folder in your Turtle WoW folder. Then, open the Turtle WoW Launcher, and under the Mods tab, make sure both patches are ticked.

 **- **Once in game click on your addons and set Script Memory to 512 and thats it!**  smiling_turtle_head  - This resets sometimes so make sure to change it.**
______________________________________________________________________________________________

Mostly works, but crashes are still possible. I made this for a friend—I'm not a modder, so updates will be rare to none.

Ways to reduce chance of crashing/fix textures or lag:
⦁	Delete WDB folder - if you see messed up pixels on the floor or crash
⦁	Reopen the game - if you see some white textures as sometimes that fixes it
⦁	Disable Mod no1600x1200 - could be causing a window error not the hd mod
⦁	If laggy - Disable Dxvk (sometimes helps)
⦁	If laggy - Turn off in game fullscreen glow and then back on or keep off.
⦁	If crashes happen change Script Memory (in Addons) to 512
⦁	Redownload patch-A and delete old one + delete WDB folder

Known bugs:
⦁	Some faces are messed up
⦁	Some things are missing textures showing in green/white/blue or as a cube
