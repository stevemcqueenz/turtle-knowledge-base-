# [Tutorial] Custom Main Menu Music

## Post 44498 by Witchblade — 2023-05-04T21:06:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=44498#p44498 | page 1 | era: pre-1.18.1 -->

Okay so this tutorial will allow you to change the vanilla theme music you hear while logging in and selecting character

Head over to your Turtle WoW folder and open up the folder titled "Data", create another folder within "Data" titled "Sound", open the folder titled as "Sound" and make a new folder and call it "Music", within "Music" make a final folder named "GlueScreenMusic" (everything is case sensitive). Inside "GlueScreenMusic" insert an mp3 of your choice titled as "wow_main_theme.mp3"

you are done
