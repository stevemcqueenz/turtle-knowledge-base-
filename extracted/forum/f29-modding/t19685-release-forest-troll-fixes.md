# [Release] Forest Troll Fixes

## Post 133912 by Ace1226 — 2025-06-01T21:34:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=133912#p133912 | page 1 | era: pre-1.18.1 -->

A redditor asked if it's possible to restore the original Forest Troll NPC Skin for player Trolls since the Forest Troll skins of Turtle WoW don't quite match. Offering trying to make a mod to restore it, here it is.

And more interestingly, looking into Forest Trolls I also found some bugs that I fixed. So the mod changes 3 things:

 **1. Recreating the original Forest Troll Skin for players**
The original Forest Troll skin doesn't support different faces, so I created a custom texture the player Forest Trolls can use with the different faces to choose from. This replaces the green Forest Troll skin.
![Image](https://i.imgur.com/cgCngVC.jpeg)

 **2. Fixes Skincolors Tusks**
it seems like the Forest Trolls skins for Turtle were created in a rush, so the color changing in the textures also colored the tusks in skincolor. This mod fixes that so all Forest Troll Skincolors now have a proper tuskcolor back
![Image](https://i.imgur.com/B4NFr0R.jpeg)

 **3. Fixing broken custom faces for Female Forest Trolls**
This one took me by huge surprise. The devs of Turtle WoW actually created custom female faces for the Forest Troll skins. They just made an error and named them Male in the filename instead of Female, so they are broken and not working ingame. This mod fixes that too, so now all Female Forest Trolls use the intended custom Faces (even the new original forest skincolor)
![Image](https://i.imgur.com/ty3pyQB.jpeg)

Installation is simple: just put in it your data folder and apply it under Mods in the launcher. This is named as patch-i.mpq, but feel free to use any other letter than i if that's already taken for you.
