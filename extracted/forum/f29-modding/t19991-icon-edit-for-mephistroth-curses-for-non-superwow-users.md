# Icon Edit for Mephistroth Curses for non Superwow users

## Post 136672 by excin (Barrens Chat Casualty) — 2025-06-22T22:19:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=136672#p136672 | page 1 | era: pre-1.18.1 -->

This patch will replace the identical Icons of Doom of Outland and Dread of Outland.
This makes it possible for Decursive to not confuse them due to icon caching in the absence of Superwow
![Image](https://i.imgur.com/UceawNn.png)

[Patch-K.MPQ](https://drive.google.com/file/d/17r3GoeBoR8yLUmCdtTMxFdUvCiS2r8U3/view?usp=sharing)

If you have another file with the same name, use a different letter than K.

Place in the data folder:
![Image](https://i.imgur.com/fBR18Bc.png)

And in Decrusive's  Localization.LUA  you can add the exclusion to the list

![Image](https://i.imgur.com/17HLXGx.png)
