Hello all,

For those druid players, I have been tinkering with many different form swaps with other existing creature models. The most polished one I have so far is swapping the bear form to the thunder lizard model. Drag and drop the MPQ file into the data folder to install.

I also used a DBC editor to swap the visual effects of various bear form abilities with other spell visuals that match the new look. If the Turtlewow team updates their spell.dbc file from patch-8, then this may lead to issues which will need to be patched using a DBC editor.
