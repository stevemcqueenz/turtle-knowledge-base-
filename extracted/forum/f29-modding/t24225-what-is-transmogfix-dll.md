Microsoft Defender and Smart App Control may block .dll files due to false positives, especially when the file is from an unknown or untrusted source.  This often happens with legitimate software like the Beyond Identity authenticator or third-party tools such as Files.app, where Windows Defender incorrectly flags the DLL as malicious.
