It's actually quite simple. Download [Ladiks MPQ Editor](https://www.hiveworkshop.com/threads/ladiks-mpq-editor.249562/). Open the patch-*.mpq from the mod you're using, it should list tons of creature folders with all the models that get replaced. Now you just have to find the correct model and delete it's folder in the MPQ editor and save it.

I think the nightelf mount model is in the creature/tiger folder, not sure about the epic mount model though
