It appears that the dark ranger skin is using only a single skin texture rather than including separate textures for top and bottom underwear when you don't have anything equipped, which is typical for most skins. In the HD Patch, underwear has been "baked in" to the skin texture, so it shows up underneath other gear. For non-HD users, I'm not sure how the dark ranger skin is handled.

If you're using the HD patch (or the character-only HD patch), I've made a new patch that overwrites the HD dark ranger skin. This removes the underwear from the skin, so it won't show up while wearing other gear. Unfortunately it also means that if you unequip your gear you'll have no underwear.
