# HD Druid forms

## Post 122405 by Lorren19 — 2025-03-12T18:42:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=122405#p122405 | page 1 | era: pre-1.18.1 -->

Hey guys, almost all HD mods for druid forms suffer from glitch that makes equipped weapon visible in bear form. After some searching around I found one that actually worked. It's the Improved Models for 1.12.1 mod ([https://www.wowmodding.net/files/file/3 ... 1-clients/](https://www.wowmodding.net/files/file/361-improved-models-for-1121-clients/)).

As the original mod is buggy as hell on Turtle and also makes some questionable changes to music and some other vanilla models, I just pulled out models affecting cat, bear, aqua and moonkin forms from it and made it into a separate MPQ. I've only tested horde cat, bear, aquatic forms and it seems to be working fine, but it might require more testing. There's only so much I can test being a lvl 20 tauren druid noob lol.

It goes without saying that the original modder(s) are responsible for all the actual work, so all the credit for this goes to them.
