Hi Turtle WoW team!

First of all, thank you for all the amazing work you do to keep this server vibrant and full of life. It's always a pleasure to experience Azeroth through the lens of Turtle WoW!

I’d like to make a small visual request regarding the Alliance PvP sets:
The Lieutenant Commander’s Battlearmor (warrior set) features a distinctive and appealing color scheme. Meanwhile, the Lieutenant Commander’s Redoubt (paladin set), which shares the same model, uses a different and less vibrant color palette.

I’m not asking for any redesigns or improvements—just that the same color scheme used on the warrior set be applied to the paladin set as well, to make them consistent and visually aligned.

To support this suggestion, I’ve attached an old piece of promotional material where this color alignment is visible, and it helps show how fitting it looks when both sets share the same tones.
