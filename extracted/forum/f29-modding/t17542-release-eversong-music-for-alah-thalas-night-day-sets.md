Small WDB edit assigning the Sunstrider Isle tracks to Alah Thalas Zones.
This differs from replacing the soundtracks files in that there would be different tracks playing in day and night.

The [MPQ file here](https://drive.google.com/file/d/1b5xOdM6KdGorRlyMAlnVty0n49Qex48z/view?usp=sharing) contains two DBC files, it will be compatible with anything that doesn't edit those. It will need an update once more Zones and Dungeons are released.

If you have something else with the name Patch-J.mpq, use another letter.

Tools used : [Ladik's MPQ Editor](http://www.zezula.net/en/mpq/download.html) , [WDBX Editor](https://github.com/WowDevTools/WDBXEditor)
