# Leathertank's PerfectPack

## Post 24408 by Leathertank — 2022-09-05T10:22:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=24408#p24408 | page 1 | era: pre-1.18.1 -->

This is a collection of graphic updates that make twow a perfect game for me.  The graphical portions are the hd patch from [viewtopic.php?f=29&t=2496&sid=058da3d8c ... 111f1f4265](https://forum.turtlecraft.gg/viewtopic.php?f=29&t=2496)  and no-bone skeleton models from ownedcore. The addons are mainly QoL, making turtle more like modern wow. List follows:

- OmniCC            -     timers for cooldowns
Questie          -       Shows available quests
AtlasLoot        -         Turtle edition, shows instance & rep loot
Attack bar       -       Swing timer, quartz for vanilla
aux-addon        -        AH mod
Bagnon             -        One giant bag
Bagnon_Core     -        library
Bartender2         -       Action bar replacement, great program
BEB                   -       Experience bar replacement
BEBOptions        -      library
BetterCharacterStats  -    Character stats have pulldown categories like modern wow
BonusScanner      -     enhanced tooltip
Cartographer         -      Map addon, used by questie
Clique               -         Click-bind spells
DruidManaBar    -       Shows mana in forms
EQL3             -           Enhanced quest log
Grid              -           Better raid frames
Interface          -       Lighter background for EQL3
Mail               -       Modern wow like mail experience
MobInfo2         -         Shows enemy hp/mana
RangeRecolor     -       Out of range spells visually markes
SaySapped          -       if sapped you say it
ShaguDPS            -      best dps meter
ShaguTweaks       -    great addon, replaces multiple
Stubby               -      library
SuperMacro         -    enhanced macro language
Talentsaver         -     save talent builds
TheoryCraft        -      shows estmated heal/dmg numbers on spells
TomTom           -      navigation
WHDB              -        Database of quest comments, works with EQL3
Very reccomended you use  the byte patcher from here [viewtopic.php?t=2331](https://forum.turtlecraft.gg/viewtopic.php?t=2331)
for increased FoV, autoloot, and 4gb patch.

To use, drop both folders in the zip into your twow folder.
Have fun with it!
