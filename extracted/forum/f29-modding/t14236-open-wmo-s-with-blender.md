# Open WMO's with Blender

## Post 97089 by Dracarusggotham (Grandmaster of Forum PvP) — 2024-06-16T04:43:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=97089#p97089 | page 1 | era: pre-1.18.1 -->

Well, I've done it, I opened the WMO's of WoW cities with Blender, and they are editable as far as I know:
Requirements:
[*]-Blender 3.4
 -Blender WoW Studio
 -WoW Lich King Client 3.3.5
 -Turtle WoW Client Files[/b]
 -(I uploaded the Blender build with the addon, you just need to download it, open it and enable the WoW Blender Studio addon in the preferences, search with "WoW" in the addons search bar to find it in the list)

 ***Step 1:***
Configure the path of your 3.3.5 client in the addon in Blender.

 ***Step 2:***
Extract all content from TWoW patches:
wmo.mpq
Patch.mpq
Patch2.mpq
Patch3.mpq
Patch4.mpq
Patch5.mpq
You should create a folder called "Work" and inside it would contain all the BLP, wmo and so on from the Turtle WoW client.

You got it? Perfect!

 ***Step 3:***
Now copy the entire folder to your 3.3.5 client location, don't worry, it won't overwrite anything, just copy and paste.

 ***Step 4:***
If you have the addon active, "Import" should appear to import WMO and M2, let's try with WMO.
When you click it will ask you to choose a file, in this case look for a WMO, for example, Orgrimmar.
Go to TheNameOfYour3.3.5Client\Work\World\wmo\kalimdor\Ogrimmar\Ogrimmar.wmo, open it and it should start loading all the plugins without problems.
Upon completion you should be able to see the entire Orgrimmar model without much difficulty.

READY! You have already opened a WMO in Blender, experiment with it, for now, I have only opened it, it is already a big step.
