# Smaller original client size.

## Post 118968 by Namek — 2025-02-04T23:03:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=118968#p118968 | page 1 | era: pre-1.18.1 -->

Hi everyone.

My name is Alberto, and I love WOW from the first time I try the 10 days demo, I like modding original clients with better graphics and I dream with an Android version of the game.

Some time ago someone created a reduced size version of the original 1.12.1 client from 5.15GB to around 3.5GB removing duplicate files replaced by cumulative patches. Yes, the original updated files by patches are not deleted and keeps installed taking disk space. Unfortunately the reduced size version was missing some sound effects, so I fix the sounds and make the installation even smaller removing unnecesary MPQs and videos. After doing this I noticed that all sounds of the game were not compressed in any way, so I compressed all the sounds and reduced the installation to around 2.5GB, the compressed sounds have a bit worse sound quality, but its perfectly playable. This version is perfect for low end PCs or even small Windows tablets.

Playing WOW on windows tablets with the touch screen is possible using the "Click to move" option, but you must make a long touch on the screen to make a right mouse click, it would be better if we can use left mouse click to move. Someone knows how to do this?

You can find reduced size versions of Vanilla (with and without sound compression), Burning Crusade and Wrath of the Lich King on my web <http://wowdl.free.nf>

You can use Mods and Patches with this versions too.

Tell me what do you think, thank you.
