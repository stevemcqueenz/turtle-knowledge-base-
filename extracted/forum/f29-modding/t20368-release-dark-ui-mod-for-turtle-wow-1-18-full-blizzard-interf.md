Hey everyone!

I've been working on a Dark UI Mod to give Turtle WoW a sleek and immersive dark theme that blends beautifully with the game's aesthetics. I'm excited to share it with the community.

Here’s what it includes:

 1. Full Dark Textures

Complete retexture of the default Blizzard UI to a dark theme

Extended to   turtle_tongue_head   Turtle WoW exclusive windows, including:

- **Shop window**

- **Transmog window**

- **LFD window**

also(All addons that uses interface textures should also be darkend)

 2. Text Color Adjustment Addon ( [DarkUI] ) this is a separated addon can be found with addons not the dark ui tweak in shagutweaks.

A small addon that adjusts in-game text colors to enhance readability and fit the new dark ui + White hotkeys text + range overlay

 3. Addon for ShaguTweaks ( [ShaguTweaks-extras-DarkUI] )

make shaguTweaks compatible with my mod with extra tweaks.
