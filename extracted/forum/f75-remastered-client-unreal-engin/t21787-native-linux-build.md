GameMode is a daemon that sets some CPU settings for whatever you run through it. For example, it can be used for restricting number of cores used. GameScope is Valve's weird Wayland 'microcompositor', it lets you run games in a window you can control better and do upscaling and other useful things with. You don't need them to run a game in Proton, but they're fairly common tweaking tools. But if you're using them the command to launch becomes like GameMode GameScope TheActualGameExe (args for the game) (args for game scope) (args for game mode). Add in a launcher system like FlatPak or Steam and you got another program and set of args in the command. Lutris and Heroic Games Launcher are both good at managing this kind of stuff.

For the record, I had problems with GameScope in this and it worked better without it.
