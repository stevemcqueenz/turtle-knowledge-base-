# If the classes had four talent trees

## Post 158188 by Akos1896 (Grandmaster of Forum PvP) — 2025-11-03T11:19:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=158188#p158188 | page 1 | era: 1.18.1-announced-pre-release -->

As the title says.
I wanna explore how the fourth talent trees could look like.

Easy Mode: Druid and Shaman.
Druid was already given a fourth tree in retail and separating bear and cat is a good move. Druid can do all, and each build having its own tree is fair.
TWOW pushed the shaman tank agenda into reality. A fourth tree could separate enh DPS and warden shaman.

Paladin: There are two ways I see.
The I like it way: giving spell-ret an own tree.
The I don't like it way: giving pallie two healer trees, one for melee heal, one for ranged heal.

Warlocks: Building a whole tree around demonic sacrifices bonuses. Moving sacrifice to this tree and making the warlock increasingly more powerful if using no demons.

Priests: I see a realistic and an irrealistic way.
The realistic one: Making discipline heal return, possibly receiving the talent like stronger divine shield. The less healing power, more utility healer build, kinda what discipline used to be. It is in flavor for priests to have 2 healer trees.
The irrealistic one: since TWOW has no monks, priests can in theory turn into a staff-wielding, melee build. Would need way too many revamps to make it viable though.

Mages: I'd give a 4th tree of what arcane used to be. We have the big pumper arcane mages now. Would enable the mana battery-utility arcane mages through a different tree.

Hunter: Would add some pet-user damage combos to survival and move away traps and kiting from them. Instead, would create a utility hunter via the fourth tree: traps, kites, buffs. Kinda the modern sub rogue's equivalent.

Rogue: My heart says tank rogue but I understand why it couldn't really be a thing. Would probably go with a tree allowing them to wield 2handers and become big-mace-wielding, leather armored thugs.

Warrior: Kinda what gladiator warriors were supposed to be during Draenor but done well. A 1h+shield-wearing DPS. It would be unique, having a non-tank build being interested in shields, spec if they have things like strength.

I think it is important not to think about talent trees as roles to be performed.
Player often pick builds like 31+20 or 30-21 or some other combination like that.

In Vanilla there was reckodin - prot specced retribution paladin with 2h weapon.
There were furytank. heart-of-the-wild druid healers, SM-ruin.

Making talent trees "pure" is retail way. Especially when talent trees has become longer, with all cool talents in the bottom.
On the other side - if talent is not so high, it is available to more combination of specs.
