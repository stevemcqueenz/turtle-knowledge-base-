Hello! I'm new around here and I'm looking for some advice for PvP.

Before we start let's get some things out of the way: I'm both a PvE and PvP player, favoring PvP a bit more. Yes, I read all the complaints about the state of PvP, yes I know the devs are mostly focused on PvE content. I don't pretend to have an amazing open world PvP experience or anything like that, I'd be content with having a good experience in BGs and Arenas. Yes, I know PvP gear is lacking. As I mentioned, I enjoy PvE as well so I wouldn't mind getting my gear there.

Also, I've never player classic, only TBC onwards and I haven't touched WoW at all in a while so I'm a bit rusty on everything.

That being said, I'll list the classes/specs I like playing so maybe you guys can orient me on what's viable here:
 - Frost mage, my beloved. I love the poking playstyle and the defensive tools it has to keep the melees away. I've read about the addition of icicles and it seems like using that on PvP would be the worst idea ever, am I reading that correctly?
 - Warlock, my second beloved. I like playing around LoS, poking out to reapply dots and sneak in channels while my demon pesters my opponent. I favor affliction locks and I don't really like playing the bursty builds, so if that's the only viable option I'm probably not going to play warlock.
 - Shadow priest, not my absolute favorite but really fun spec. I read that fears are quite underpowered rn, is that so? If so, is this spec viable? It depends a lot on its fears.
 - Rogue, the only melee I tolerate playing. It seems like the PvP spec was remade into a support spec, so I guess I'm not playing rogue at all? Is there any PvP viability? How is the new Assassination spec?
 - Shaman. I've never played Shaman, but I heard good things about it. The elemental spec is the only one that catches my eye, so if it's viable and it has OK tools to keep the melees away, I might give it a go. I remember them having a nasty AoE stun totem that always got me when playing rogue vs them, but I'm not sure if that's in classic or what other tools they have.

Thanks for reading if you made it this far.
