# Remove and gut zookeeper spec for good.

## Post 171927 by Ellifta (Barrens Chat Casualty) — 2026-03-23T12:08:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=171927#p171927 | page 1 | era: post-1.18.1 -->

In this picture we can see one shockadin with 3 "The Lost" pets + spirit wolves we don't see in the screenshot. The Lost set in particular is extremely oppressive, each add has 3k HP and they do 200 damage attacks, there's no limit to how many one person can have other than pure luck.

![Image](https://i.ibb.co/spmgTfd4/zookeeper.png)

Considering this Lost set can be bought from AH set for outrageous prices, it should be gutted entirely and made useless. It's the biggest problem in PvP at the moment apart from class balancing. An item set someone can just buy from AH shouldn't be impossible to counter and magically give someone 600 DPS extra. I don't care what replacement stats it gets, but the pets it summons should be gone, period. No one can come up with a justification as to why this pet should be this good and have no ICD on how many you can summon.
