# Quitting AV - PvP problematic

## Post 142914 by Matches (Barrens Chat Casualty) — 2025-08-03T12:01:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=142914#p142914 | page 1 | era: pre-1.18.1 -->

I've given up on AV.  I will not play again.

I enjoy AV as a large-scale PvE event; big team, open map, goals.

The PvP part was never anything for me.

PvP I find now is unavoidable, because to come within 30 yards of a ranged character is to die in a few seconds; stun/slow/polymorpth/whatever, then death.

It seems to me if I want PvE, I need to start an AV at the very beginning, so I can get past all PvP to the first GY; if that opportunity is missed, or if you do meet an enemy player (perhaps on defence), then you're back at the start and then you have to wait until SP GY is taken to be able to move forward again, which takes a relatively long time.

In any event, the frustration of PvP is now so great and so difficult to avoid that AV for me is unplayable.
