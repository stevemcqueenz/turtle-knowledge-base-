# Do I really need to AoE Frost spec for leveling?

## Post 107433 by Rudyraccoon — 2024-11-10T19:56:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=107433#p107433 | page 1 | era: pre-1.18.1 -->

So, I noticed there's two different ways of leveling as Frost, there's the single target spec that makes use of Frostbite which can come extremely handy to kite tougher mobs, or there's the more popular AoE Frost spec that makes use of Improved Blizzard and Permafrost, but you can't have Frostbite, else it'll ruin your AoE pull if one gets frozen from Frostbite. Now personally I'd go with the single target spec, it's easier for me and I think AoE farming seems a bit risky, especially if you're doing the hardcore challenge, but I would also include Permafrost for the extra kiting. However, I once got told off by somebody for doing this, so do I really need to AoE Frost spec for leveling?
