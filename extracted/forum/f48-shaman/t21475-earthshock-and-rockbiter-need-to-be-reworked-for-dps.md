# Earthshock and Rockbiter need to be reworked for DPS.

## Post 148834 by Aralise (Barrens Chat Casualty) — 2025-08-28T06:05:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=148834#p148834 | page 1 | era: pre-1.18.1 -->

As a tank It's genuinely frustrating how easily DPS shamans rip threat from tanks.

I can imagine this is a frustration while playing a shaman as well, and it would be lovely if the threat caused by these abilities was part of an existing talent for tanks.

I know people say to just not use Earthshock then, but i honestly haven't met a single shaman who doesn't aggressively rip threat compared to any other DPS, and i feel like this should be addressed, i shouldn't have to growl my primary target 5 seconds into a pull only to lose threat again 3 seconds later.

I must stress: I'm not asking for a DPS nerf, or additional points in the talent tree that make your lives harder, just for this threat problem to be addressed.
