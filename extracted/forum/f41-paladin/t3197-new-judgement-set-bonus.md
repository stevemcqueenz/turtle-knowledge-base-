# New Judgement Set Bonus

## Post 19466 by Ghola (Patch Note Conspiracy Theorist) — 2022-06-30T06:35:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=19466#p19466 | page 1 | era: pre-1.18.1 -->

With the upcoming class changes giving Holy Paladins more shockadin potential with reduced Holy Shock cooldown and increased holy damage synergy, I was disappointed to see the iconic shockadin set be changed into a more melee focused set. The old set bonus was great for shockadin as it was essentially a 70-120 spellpower increase to your judgements, and this set bonus would really shine with the upcoming changes, along with the spellpower already present on the set. Additionally, none of the pieces have melee crit on them anyway, only the increased agility that's been added.

With the original vanilla talent trees, melee crit on shockadin was useful because your judgement of command scales with melee crit and spellpower, allowing you to get big crits in hybrid gear. However, when the talent changes eventually release, you will no longer be able to get both holy shock and seal of command, and shockadin builds will solely scale with spellpower and spellcrit. Adding agility and a set bonus that activates on melee crit is redundant.
