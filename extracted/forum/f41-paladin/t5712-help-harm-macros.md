## Post 35757 by Woogy — 2023-02-23T01:11:00Z

Hey turts,

In my experience playing WoW I have used the Help/Harm (example down below) to increase action bar real estate. I was not able to do it in the typical way that I write it out in the command box. If anyone has any suggestions or links to threads I have missed while browsing the forum I'd love some suggestions.

Example of macro is:

#showtooltip
/cast [help] Holy Light; Crusader Strike

Essentially if I target a friendly it will change the action bar ability to the heal. If I am not targeting a friendly or don't have a target it shows Crusader Strike.

Thanks in advance!
