# Announced changes to Paladin T1

## Post 19429 by Karpfend — 2022-06-28T16:14:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=19429#p19429 | page 1 | era: pre-1.18.1 -->

Hello!

First of I really like the love we get with the new prophecy sets and cleaning up our sets stats. One thing I disagree on is the handling of T1 though. Don't get me wrong, giving it spellpower makes it more viable for every paladin specc that is not holy and those guys usually wear their cloth leather combo anyway.

But over time, using this set in a lot of different situations, I really came to like it's value as a tanky healing set. The announced changes would gimp it's healing power by 55, which hurts a lot given the already low addheal it comes with.

One small change I am therefore suggesting is to also give the mentioned pieces +7/+9 healing respectivelly, so to keep it somewhat viable as a niche healer set.

Much love!   turtle_in_love_head
