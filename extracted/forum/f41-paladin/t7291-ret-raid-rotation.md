Thats not too bad of a prio list if you don't get windfury.

But generally in Raids should be among the first ones to get totem support.

So if you have Windfury you want to start the fight out with JoW/JoL
Keep **Seal of Righteousnes** up at all times. Since SoR can trigger windfury & crusader enchants it outperforms SoC in most circumstances.
Keep Holy Strike on CD
Apply 5 stacks of CS
Judge on CD (pay attention to swingtimer, you don't wanna hit without a seal active)
Drop Consecration if mana allows it
Use remaining free CDs for crusader strike (either rank 1 or max rank depending on your manapool)

Your swingspeed is still relevant if you use SoC as expected.
But when using SoR Swingspeed is also relevant in some ways. You want ideally a swingspeed of 3.4 seconds. That is slow enough so the extra wf procs are chunky and it gives you a perfect swingspeed to keep holy strike on cooldown.
If you have a swingspeed below 3.33 you can only use holy strike every 4 hits instead of every 3. If you have slower weapons, feel free to stack some haste, but if you are faster than 3.33 you might end up loosing dmg from getting more haste.

Mana will be an issue (especially starting out), Additionally to leaving out consecration, you can use holy strike rank 1 in a pinch. Particularly while lvling thats a great way to save mana!
