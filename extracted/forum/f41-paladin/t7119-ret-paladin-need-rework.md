Have said this many times across the several threads calling for/suggesting changes to ret, so i'll say it again here:

in a single moment a ret paladin can:
Holy Strike
Proc Seal of Command
Judge Command

... and none of this uses a global cooldown. Adding any form of on-demand damage to this combination will break pvp worse than it already is.

Twow claim in their class design principles that they didn't want ret to become warrior-lite, but the only 2 meaningful changes to ret's damage output that they've implemented has been a Heroic Strike knock-off and a selfish version of Sunder Armour. The attachment to Holy Strike and refusal to change Seal/Judgement of Command will trap this spec's pve potential in a corner forever.

But the worst part of all this is to be in any way viable in a raid setting ret is completely dependent on a Windfury totem. When a spec's acceptable performance is dependant on not only another class but a specific group combination highly sought after by all other melee dps, that's a clear indication of bad design.
