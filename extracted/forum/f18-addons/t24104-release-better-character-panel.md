# [Release] Better Character Panel

## Post 169505 by Walterbennet — 2026-02-27T08:27:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=169505#p169505 | page 1 | era: 1.18.1-announced-pre-release -->

**The gear scoring system has been completely removed as of version 1.1.0.**

---
Hey!

I've made an addon that improves the character and inspect panels.

The addon shows permanent and temporary enchant descriptions next to their gear slots, both on the character panel and when inspecting other players. It also puts a small indicator on slots that could be enchanted but aren't.

The addon also adds an improved character panel layout that works with both the default UI, pfUI, and that should remain functional no matter which UI addon it is used with.

The addon also come with an integrated Better Character Stats compatibility system that display all of BCS' statistics directly inside the new layout.

All the features can be toggled through the configuration GUI accessible with /bcp or with the minimap button.

This addon **REQUIRES Nampower** to work so make sure you have it installed first. I also strongly recommend getting Better Character Stats as this addon was designed around it.

The installation instructions are on the repository. If you encounter any issues or have any suggestions to make, please do so on the repository or under this post!

Download: <https://github.com/Arthur-Helias/BetterCharacterPanel>
