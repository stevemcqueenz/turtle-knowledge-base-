Good day.
Since you seem new to WoW in general, here are some general ideas about addons:
 - Do not confuse 'Classic' with 'Vanilla'. Addons created for 'Classic' do not work on Turtle Wow, as it is using a 'Vanilla' client.
 - There is a nice list of addons on the wiki, at [https://turtle-wow.fandom.com/wiki/Addo ... ddons_List](https://turtle-wow.fandom.com/wiki/Addons#Full_Addons_List). This list should be more or less up-to-date.
 - As it is mentioned above, if you download an addon from Github, make sure you remove the '-master' ending from the folder name when you copy it into your addons folder.
 - If you plan on using quite some addons, I would recommend to set the addon memory use to 0 (that means no limit) on the addon selection screen (button for that is on the character selection screen).
