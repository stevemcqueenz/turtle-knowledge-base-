## Post 91990 by Redmagejoe (Grandmaster of Forum PvP) — 2024-04-03T08:49:00Z

You all may be misunderstanding how TWThreat works. It only shows you the threat values on elites, and only if you are in a party. This is because unlike other threat addons which "guess" your threat based on combat logs, this addon is directly pulling threat values from the server itself, meaning they are 100% accurate at all times.

However, this means that this has the potential for Denial of Service or at the very least serious load upon the server with client requests to display threat data. In order to avoid this, its functionality is limited.

I don't know if this helps as how it's actually "not working" wasn't really elaborated on.
