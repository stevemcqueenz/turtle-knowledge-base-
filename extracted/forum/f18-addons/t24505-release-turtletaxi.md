**TurtleTaxi**
| Addon for  port and summon requests |
[![Image](https://img.shields.io/badge/GitHub-TurtleTaxi-blue?style=for-the-badge&logo=github)](https://github.com/Fragglechen/TurtleTaxi)

---
 **What is TurtleTaxi?**

Until now if you needed a port to one of the big cities or a sommon to any place like Hyjal, you had to yell in the City or use the world chat to ask for port or summon.
As mage or Warlock you wanted to do the port / summon you had to see this and invite the player then.

Think about to have that easier?

Turtle Taxi provides an UI which is similar to the Uber App
As a passenger you can create requests there for Portals or summons
Once created, it will be broadcasted and all players who could fulfill your request (Mages and Ingis  for ports, Warlocks for Summons) will see that request in the list and could accept it.
With the accept you will be automatically invited to the group, You can see who accepted your request and in which zone the transporter is.
As Transporter you can see where the passenger is and where he wants to go to.
After the transporter has reached the destination, the request will disappear automatically

---
 **Features**

- **Passenger UI** — You can create transport requests and see a list with active requests and status (if accepted you see the current location of the transporter)
- **Transporter UI** — Shows all open requests which could be accepted and all accepted requests with the status
- **Auto Invite** — If a transporter accepts an request the addon automatically send an group invite to the passenger.
- **Notifications** — You can configure if you want to see and hear a notification if a new request appears or if one of your requests is accepted.

 **Commands**
Code: Select all

```
/tt
/turtletaxi
```

Opens the TurtleTaxi window.
Code: Select all

```
/tt options
/turtletaxi options
```

Opens the TurtleTaxi options window.

---
 **Installation**

 **TurtleWoW Launcher:**

1. In the Addons tab of the launcher, click **Add New Addon**
2. Paste this .git link into it and install Code: Select all

```
https://github.com/Fragglechen/TurtleTaxi.git
```
