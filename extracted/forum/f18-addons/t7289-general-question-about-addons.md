## Post 46186 by Jolikmc (Patch Note Conspiracy Theorist) — 2023-05-17T07:02:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=46186#p46186 | page 1 | era: pre-1.18.1 -->

AddOns created for v1.12 or earlier are fully compatible with this version of *World of Warcraft*.
AddOns created for v1.13 or higher **do not** work.  Those are for *World of Warcraft Classic*, which is based on the modern version of *World of Warcraft*.

As Kiersteadmo mentioned, some AddOns that are hosted on *GitHub* come in ZIP files which end with "-main", "-master", or sometimes something else.  When unZIPped, the folders also end like this.  Simply remove the "-main" or "-master" from the folder name and it should work fine.

Examples
PallyPower-master → **PallyPower**
GlobalFriendsList-main → **GlobalFriendsList**
aux-addon-vanilla-master → **aux-addon**

Basically, if the **folder name** is the same as the **.toc file inside it**, it should be good to go.
