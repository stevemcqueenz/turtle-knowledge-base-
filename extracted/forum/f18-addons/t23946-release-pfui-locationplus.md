# [Release] pfUI-LocationPlus

## Post 168098 by Walterbennet — 2026-02-13T00:22:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=168098#p168098 | page 1 | era: 1.18.1-announced-pre-release -->

Hey!

I've made an external module for pfUI based on LocationPlus for ElvUI.

It was one of the external module that I missed the most from ElvUI, so I decided to remake it from scratch for pfUI.
I've tested it to the best of my abilities and I did not ran into any issues, but please do report any issues you might encounter on the repository page. Feel free to leave any suggestions for features onto the repository too.

All the information, features and screenshots are available on the repository page.
You can download the addon here: <https://github.com/Arthur-Helias/pfUI-LocationPlus>

I really hope you'll enjoy it!

Glad you enjoyed the addon!

pfUI modules do not usually come with their own minimap icon for configuration as settings are handled directly by pfUI (in this case in Thirdparty -> Location Plus). I pushed an update that allows users to ctrl+click on the location frame in order to open and close the module's settings directly, as an alternative to the standard minimap button.

I hope this will be an adequate substitute, and I thank you for the suggestion!

Have a good day!
