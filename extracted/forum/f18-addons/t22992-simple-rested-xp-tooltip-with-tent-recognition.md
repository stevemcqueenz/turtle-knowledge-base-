# Simple Rested XP Tooltip with Tent recognition

Hey all,

so here is a very small and simple addon to show a tooltip on the XP bar with the current percentage of rested XP left and the "charge rate" when near one or more tents.
That's it.

![Image](https://i.imgur.com/ADlpluA.png)

Found it to be more convenient than some other rested xp addons I tried, so maybe it'll be of use to you.

get it at: <https://github.com/LittleMolly/RestedXpInfo>

Any feedback is welcome.
