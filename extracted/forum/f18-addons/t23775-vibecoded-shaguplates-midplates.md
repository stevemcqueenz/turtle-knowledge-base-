# 「VIBECODED」ShaguPlates-Midplates

## Post 166734 by Icedtea12 — 2026-01-28T11:16:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=166734#p166734 | page 1 | era: 1.18.1-announced-pre-release -->

<https://github.com/roushinkai/midplates>

ShaguPlates configuration to resemble the default Midnight nameplates.
Features:
Name Abbreviation : Already existed in the addon, but now is stricter and abbreviates anything above 5 characters
Show only the last name of mobs
Show cast target  name
Hide debuff timers
Backdrop alpha for health bar, cast bar
