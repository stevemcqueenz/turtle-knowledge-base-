 **Cursive** - <https://github.com/pepopo978/Cursive.git>
+ Dependency
 **SuperWoW** - <https://github.com/balakethelock/SuperWoW.git>
 -Cursive is a great addon that it primarily focused around warlocks but honestly I don't see why any class with multiple DoT's can't use it. By running the command; Code: Select all

```
/cursive curse <spellName:str>|<guid?:str>|<options?:comma separated str>
```

For example like this; Code: Select all

```
/cursive curse Corruption|target
```

It allows you to put a dot on a target. So far this addon seems useless but what makes it really cool is the fact that you can use the command to trigger multiple DoT's in succession on the target that you want, not only that you can make it so it automatically will target something of which you can specify the priority, like highest health which they call multicurse. An example of each of these are as shown below:
Code: Select all

```
/cursive curse Curse of Recklessness|target|refreshtime=1
/cursive curse Corruption|target|refreshtime=3
/cursive curse Siphon Life|target|refreshtime=1
```

Code: Select all

```
/script if not Cursive:Curse("Curse of Recklessness", "target", {refreshtime=1}) then if not Cursive:Curse("Corruption", "target", {refreshtime=3}) then Cursive:Curse("Siphon Life", "target", {refreshtime=1}) end end
```

Code: Select all

```
/script if not Cursive:Multicurse("Curse of Recklessness", "HIGHEST_HP", {refreshtime=1}) then if not Cursive:Multicurse("Corruption", "HIGHEST_HP", {refreshtime=3}) then Cursive:Multicurse("Siphon Life", "HIGHEST_HP", {refreshtime=1}) end end
```
