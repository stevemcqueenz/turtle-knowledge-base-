My go to recommendation for any UI related changes is pfUI <https://github.com/shagu/pfUI/>

It is a comprehensive all in one solution for a complete UI overhaul, but you can turn off all elements you do not want in the setting. Allowing you to pick only the elements you want.

It offers fantastic nameplates with target debuff support.
