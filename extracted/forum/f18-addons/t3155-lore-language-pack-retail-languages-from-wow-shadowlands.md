I've only gone and "ported" the languages from *World of Warcraft: Shadowlands* into a *Lore* dialects.lua file~

Quick Rundown
> **What It Do**
>  It allows users of the awesome language AddOn, *Lore*, to use a wider range of languages – including "Thalassian" (for high elves) and "Goblin" (for Tuskarr, obviously~).
>
>  **Ported Languages**
>  *Worgen*, *Gilnean*, Draenei, Zombie, Gnomish Binary, Goblin Binary, Goblin, Pandaren, Sprite, Shath'Yar, Nerglish, Moonkin, Shallasian, Vulpera, Basic Cypher
>  ("Worgen" ported from *[Tongues](https://www.curseforge.com/wow/addons/tongues)* AddOn, "Gilnean" created from scratch.)
>
>  **Improved Languages**
>  Eredun, Titan, Thalassian, Draconic, Kalimag
>
>  **"Enabled" Languages**
>  Orcish, Darnassian, Taurahe, Dwarvish, Common, Gnomish, Troll, Gutterspeak
>
>  *Aliased to…*
>  Orkish, Darnassae, Taur-ahe, Dwarven, Low Common, Gnome, Zandali, Forsaken
>  (This **will not** allow communication across factions *or* with players using the **real** languages and is only for fun and RP.
>  *Actually* enabling these "for real" would require a modifying the AddOn, itself.)
>
>  **Removed Languages**
>  Dark Iron, Tier, Nerubian

Usage
> **Things You'll Need**
>  - *[Lore v6.0](https://www.curseforge.com/wow/addons/lore)* for *World of Warcraft* v1.12
>  - The ability to rename files.
>
>  **How to Add This to Lore, The Simple Way**
>  - **Extract** the JDC_WoWv9-dialects.lua file somewhere.
>  - **Rename** "JDC_WoWv9-dialects.lua" to "dialects.lua".
>  - **Copy** (or **Move**) the newly-renamed dialects.lua into your *World of Warcraft* "Interface\AddOns\Lore" directory.
>  - You're good to go~
>
>  **Extremely Important Note**
>  This is intended to be used as a **replacement** for your existing "dialects.lua" file.  As such, it contains *all* of the language pools from the official release.  If you have any **custom languages**, make sure to save them to a document file and manually insert them into the new file at a later date!
