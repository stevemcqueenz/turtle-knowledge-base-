# StealthAlerter Backport Request

## Post 165193 by Kaizod — 2026-01-15T02:37:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=165193#p165193 | page 1 | era: 1.18.1-announced-pre-release -->

Hi all, This addon is really nice for mainly PVP, but also sometimes for PVE with stealthie NPCs and whatnot. It's very simple, too. Every time it detects a rogue stealthing or a Night Elf shadowmeld, as examples, it outputs a line of text that just says "XYZ character cast stealth". Especially good in Arathi Basin if you're guarding a flag without Catseye potion.

Unfortunately, this addon was created in 2009, which I think was WotLK, and was never made for Vanilla. If anyone could backport this addon I would be greatly appreciative. Hell, I might donate some money to the cause. Sadly, i don't know how to backport or code, but I think many people would appreciate this addon for Turtle/Vanilla.

Here is the link:
<https://github.com/ghankins/StealthAlerter>
