Press Ctrl + F to search what you need.

After downloading, extract the folder inside WoW / Interface / AddOns.

REMEMBER TO RENAME THE ADDON FOLDER AND DELETE THE **"-master"** or **"-main"** PART FROM IT'S NAME.

Now the **.toc** file inside the folder should match the folder name (WoW / Interface / AddOns / ADDONNAME / ADDONNAME.toc).

Make sure the actual addon **isn't** contained inside another folder like so: ADDONNAME-master / ADDONNAME / ADDONNAME.toc

Hello. I am new to this private server, but I have played the original Vanilla and TBC retails, and one of my favorite addons from that time that hasn't been mentioned here is Bookworm. If you're interested in the lore of the game (and isn't that sort of the point of this server?), this addon is for you. The default is to only record the name and location (aka zone) of any book you find and click on (to save space it would default to storing the least amount possible... which these days shouldn't be nearly as big a concern as it was 18 years ago), which means you would have to go back to that location to read it again. However, if you're okay with the database constantly growing bigger all the time, you can turn on auto page turning with "/bw auto" and storing of the books (auto page turning has to be on because it'll only capture the pages that show up on the screen) with "/bw store all" (there's several other options as well, access the full list with "/bw help"). Then later you can use "/bw browse" to see all the books you've come across, and if you've turned on store you can read the books at your leisure.

I first stumbled on this addon during vanilla because I came across a book that was marked as part 5. I had never even found parts 1-4. I wanted to read all the parts in order, so I tried to look up the books and at least at the time, I couldn't find any sort of database of all the books in the game. Using this addon, I was able to locate the other books (also out of order, I want to say it was something 2, 4, 1, 3 or something like that) and then I could read them all.

<https://legacy-wow.com/vanilla-addons/bookworm/>
