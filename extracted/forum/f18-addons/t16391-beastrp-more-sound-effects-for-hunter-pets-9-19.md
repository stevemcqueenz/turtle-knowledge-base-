# BeastRP - more sound effects for hunter pets (9/19)

## Post 111755 by Foreverdelta33 (Patch Note Conspiracy Theorist) — 2024-12-08T06:56:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=111755#p111755 | page 1 | era: pre-1.18.1 -->

Hey guys,

in order to celebrate the new 1.17.2 patch, Ive made an Addon that adds
more sound effects to hunter pets.

You can enable or disable the events where you want the sound to be played,
and configure the chance and times.

So far the AddOn supports 9/19 pet familys.
I couldnt find good sound effects for the others yet, but we will see.
You can always add your own mp3 files if you like, the addon will detect them if you name
them "1.mp3" - "4.mp3" like the others.

PREVIEW:

[embed: https://www.youtube.com/embed/QCDGxkb2dt4]

USAGE:
 - Download and remove "-main" or "-masteR" from folder, place inside Interface\\AddOns\\
 - /brp or /beastrp for config menu
 - Enjoy and report feedback

SUPPORTED PET FAMILYS AS OF 12/2024 :

===================

 **WORKING**: Bear / Boar / Cat / Crocolisk / Gorilla / Hyena / Owl / Raptor / Wolf
NOT SUPPORTED YET: Bat / CarrionBird / Crab / Scorpid / Spider / Tallstrider / Turtle / Foxes / Serpents

===================

DOWNLOAD:
<https://github.com/MtxGrower33/BeastRP>

Take care and please report bugs.

> **Infantoooooooo wrote: Thu Apr 03, 2025 9:39 pm**
> Can I literally just change the audio file with another one and the game will play it with my pet?

Yes, as long as you keep the naming conventions.
The tool checks the folders inside sounds (bear, cat, etc...) and adds "1.mp3", "2.mp3" and so on to create its soundmap.
You can just swap out sound effects as you wish (make sure to restart client).

You can also add a sound effects for the unsupported pets.
Lets say you find a good spider sound effect. Make a folder called "Spider" and put "1.mp3" in there.
The tool will use it.
