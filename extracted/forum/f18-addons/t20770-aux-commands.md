Hey, no, you're not doing anything wrong. This is just how Aux is configured. You can use the /aux commands above to adjust what's on or off by default. The interface for Aux is just the normal Auction House window but it'll be adjusted to show the Aux interface instead. In order to use the configuration options above you'd just type "/aux" and then add the thing to adjust (e.g. "/aux scale .9" which would shrink the Auction House window slightly). Hope that helps!

Here's a link to the Wiki which explains a bit more: <https://turtle-wow.fandom.com/wiki/Aux>
