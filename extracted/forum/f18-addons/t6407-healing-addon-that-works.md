**Try.....   Benecast**

It is a great addon for any healing class, but especially for Druids:
<https://legacy-wow.com/vanilla-addons/benecast/>

This allows you place healing button icons on any on-screen portrait and use those to cast damage and mana based heal spell ranks that it will calculate for you. You can also add some tweaking for overheals.  It works well with Swiftmend too.

Note: if you want it to work properly within a party, you need to have "auto-self cast" turned off.

I have tested it with my Turtle WoW install and they seem to be working correctly.  It had some issues when I also had Bugsnag enabled sometimes, so I removed Bugsnag.

Many of these addons like healersmate seem to need SuperWoW to track druid HoTs, the only addon I've found that doesn't need this is Luna Unit Frames.

You basically set the raid frames as party frames and manually enter the things you want it to track and then it does with a full number countdown, and you can just disable all other ui changes it makes.
