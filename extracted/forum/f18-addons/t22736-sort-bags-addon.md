# Sort Bags Addon

## Post 158480 by Magues18 — 2025-11-05T17:15:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=158480#p158480 | page 1 | era: 1.18.1-announced-pre-release -->

Message:
Hey everyone! ![👋](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f44b.svg)

I’ve released a new Sort Bags addon for Turtle WoW (v1.18).
This addon automatically organizes your inventory with a single click — no setup, no chat commands, just press the button and magic happens.

![🧩](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f9e9.svg) Features

One-click bag sorting – instantly orders items by type, quality, and level.

Multi-pass smart algorithm – runs several passes to catch misplaced items.

No configuration needed – plug & play; works out of the box.

Lightweight – zero dependencies.

Movable UI button – an SB (Sort Bags) minimap-style button you can shift-drag anywhere on screen.

Fully offline – works on Turtle WoW v1.18 client (Classic 1.12 Lua 5.0).

![⚙️](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/2699.svg) Installation

Download: GitHub → SortBags

<https://github.com/Magues17/SortBags>

Extract the ZIP file into your Turtle WoW AddOns folder:

…\TurtleWoW\Interface\AddOns\SortBags

the folder name should be  "SortBags"

Launch the game and make sure “Load out of date AddOns” is checked.

![🧭](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f9ed.svg) Usage

Click SB button: Sorts all your bags.

Shift + Drag: Moves the button anywhere you like.

Tooltip will remind you of the shortcuts.

That’s it!
Feedback, bug reports, or ideas for improvement are very welcome.
Enjoy a cleaner bag space ![👜](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f45c.svg)

— Mags
