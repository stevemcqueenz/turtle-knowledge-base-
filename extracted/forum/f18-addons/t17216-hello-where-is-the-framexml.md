The FrameXML folder is usually found within the installation directory, often under the Interface folder. If you want to change the buff display limit or similar UI settings, you may need to use an addon or script instead. You can try searching for an addon that lets you customize the UI or modify the BuffFrame.lua file if you manage to extract FrameXML.
