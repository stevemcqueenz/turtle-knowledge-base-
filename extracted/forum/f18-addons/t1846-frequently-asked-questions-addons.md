**Why does my AddOn not show  in-game?**

The name of the addon folder  needs to match the name of the .toc file inside the folder.

Example: Rename the Folder and remove master: from pfquest-master to pfquest.

![Image](https://i.ibb.co/RPJH3fd/explorer-Awx-WAhmd-YU.png)

![Image](https://i.ibb.co/bQ83Drv/explorer-d3-LKv-Jo-Ei-G.png)

![Image](https://i.ibb.co/YDxztsD/explorer-6gfeyvd-Dog.png)

![Image](https://i.ibb.co/8Bnb8KH/explorer-i-Ut-D0gf-TVh.png)

The .toc file needs to be in the main directory, not in a subfolder.
You will need to copy the subfolders that contain the .toc file to the AddOn directory.

Example: Metamap-vanilla-master has no .toc file inside,  the .toc file  is inside the Metamap folder.
You are gonna need to  copy the folders inside the Metamap-vanilla-master that contain .toc files to  the AddOn folder.
