The thing with Titan panel is you need to download and add the mod folders to the AddOns root for each mod you want active in your Titan.  For example, you'll have TitanAmmo inside Titan and a different TitanAmmo folder in the root.

You can download them all at:
<https://legacy-wow.com/vanilla-addons/>

or a massive repository here:
<https://github.com/rootedCF/classicaddons>

I pulled all the Titan Mods I'm using from this one. =)
