Ok, downloaded the latest updates for Atlas -
 1. [viewtopic.php?t=7958](https://forum.turtlecraft.gg/viewtopic.php?t=7958)
 2. [viewtopic.php?t=7959](https://forum.turtlecraft.gg/viewtopic.php?t=7959)
 3. <https://github.com/Lexiebean/AtlasLoot>

Then, before installing, delete the old Atlas and everything related to it - Folder game -> WTF -> Account -> (Name account) -> SavedVariables - delete everything with name Atlas.
And the same with - Folder game -> WTF -> Account -> (Name account) -> Nordanaar(name server) -> (Character name) -> SavedVariables - delete everything with name Atlas.

Then we transfer the addon from the archive to the folder with the game - Folder game -> Interface -> AddOns
The name of the addon folders should be as follows -
Atlas
AtlasLoot
AtlasQuest

Next, enter the game, and in the character selection window in the lower left corner, click AddOns, and if you have an active !Libs addon there, then just deactivate it.

All this solved my problem with the Atlas not displaying correctly.
