turtle_in_love_head  **TurtleBeastiary**   turtle_in_love_head

I just released my first addon TurtleBeastiary. This Addon shows the abilitys from NPC. So you can prepare mentaly for the next fight. This could be very helpful for Hardcore Players.

![Image](https://raw.githubusercontent.com/CamA-dev/TurtleBeastiary/main/img/example.png)

 **Attention** There are no functions to get the abilities. All Data comes from an internal Databases.

 **[Get it on Github](https://github.com/CamA-dev/TurtleBeastiary)** Read the README for install instructions.

Hope you all like it. Any feedback would be much appreciated!
