You can do that with Steam inputs :

Add a non-steam game -> look for TurtleWoW executable
![Image](https://image.noelshack.com/fichiers/2023/10/7/1678660481-sans-titre.jpg)

Then Select Turtle WoW in steam and go in Proprieties
![Image](https://image.noelshack.com/fichiers/2023/10/7/1678660550-sans-titre2.jpg)

Controller -> Enable Steam Input
![Image](https://image.noelshack.com/fichiers/2023/10/7/1678660595-sans-titre3.jpg)

Configurate controller
![Image](https://image.noelshack.com/fichiers/2023/10/7/1678660642-sans-titre4.jpg)

After you'll need a tutorial on Steam Input itself.
