If you encounter an error when clicking on the add-on, it may be because the add-on configuration is incorrect. Try resetting the add-on configuration or deleting old configuration files in the add-ons folder. Check the game's error files and logs to see if there are any error messages related to the add-on you are using.

## Post 125974 by Drubarrymooer (Grandmaster of Forum PvP) — 2025-04-08T10:44:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=125974#p125974 | page 1 | era: pre-1.18.1 -->

1. Get the add-ons from <https://turtle-wow.fandom.com/wiki/Addons>

 2. Read the instructions carefully in each git.  Many of them have add-ons for classic as well as vanilla, which are 2 different client versions.  If you have the wrong version installed, it won't work.

 3. Remove ”-master" from the folders

 4. Put in add-ons in your add-ons folder

 5. Double check the addon shows up in your add-ons list before you log on.
