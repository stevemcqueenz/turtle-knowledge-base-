# [Release] BoaringChallenge (Boaring Adventure Add-on)

## Post 170446 by Azlynnbot — 2026-03-09T20:56:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=170446#p170446 | page 1 | era: 1.18.1-announced-pre-release -->

Hi All,

I have been playing a Boaring Adventure character, and I thought it would be great to have some data to push me forward. I saw some other posts in here on exactly what I wanted, but those links seemed to be dead now. So with the help of AI, I was able to create my own!

![Image](https://github.com/AzlynnForge/boaring-challenge-addon/raw/main/screenshots/tracker-ui.png)

BoaringChallenge:
- Character-specific session + lifetime boar kill tracking
- Kills per hour (KPH)
- XP per hour (boar-only XP)
- Average seconds per kill
- Rolling average of last 10 kills
- XP per kill (session + last 10)
- Estimated boars remaining until next level
- Optional time-to-level estimate (TTL)
- Optional death counter
The addon can be found here: <https://github.com/AzlynnForge/boaring-challenge-addon>

Feel free to post any issues on GitHub directly, so I can address them as they appear!
