# Any addons to mute annoying pet screeching sounds, gun shots etc?

## Post 84665 by Joeblondie — 2024-01-14T13:06:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=84665#p84665 | page 1 | era: pre-1.18.1 -->

There are some addons for Retail and Classic WoW called MuteSoundFile or "Mute Annoying WoW Sounds", that allows you to mute specific sounds in the game like pet screeching, spell fizzle, gun shots and reload, and many other annoying sounds that make your head explode. Since Vanilla WoW has different sound system which changed with release of TBC those addons doesn't work for TWoW. Any options?

you can make modified sound file for the pet to mute it if you can find the name of the specific sounds. here is a guide for how to make them. <https://turtle-wow.fandom.com/wiki/Making_Custom_Sounds>
there is some files made already at the end of the guide you can probably copy one of them and re name it.
