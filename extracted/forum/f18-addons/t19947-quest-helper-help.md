## Post 136407 by Hctwowfan (Bug Report Enthusiast) — 2025-06-20T13:45:00Z

Here's two possible steps to make pfquest work for you:
 1. Enter the game and login your toon, then type the following into chat and hit enter: /db query
Your addon will query the server for all completed quests and mark them as completed in your addon so any already completed quests are no longer shown on the map and mini-map.
 2. Make sure your wtf-folder (in the folder where your installation of turtle wow is found) is NOT set read-only.
