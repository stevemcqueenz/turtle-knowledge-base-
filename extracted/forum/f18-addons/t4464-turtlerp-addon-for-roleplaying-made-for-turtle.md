# TurtleRP - Addon for Roleplaying made for Turtle!

## Post 26683 by Ashkir — 2022-10-04T03:53:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=26683#p26683 | page 1 | era: pre-1.18.1 -->

Tired of MRP being broken? Don't like Immersion because it doesn't work? Miss TotalRP from retail? No worries, Vee and Ashkir have banded together to make a new addon for Turtle WoW... TurtleRP!

TurtleRP is officially out of beta.
[https://github.com/tempranova/turtlerp/ ... /tag/1.1.1](https://github.com/tempranova/turtlerp/releases/tag/1.1.1)

We are now at a stable release, and you are now, welcome to share to people who aren't beta testers. We appreciate everyone's support in this endeavor so far. Vee and I want to play a bit of Turtle WoW now, and, we concur that this is a great place to release the first stable version. We still have plenty of ideas how to go into the future. This has been an exciting and fast paced beta.

Features:
 * Customize your Character Name (title and full name)
 * Choose your own custom class
 * Choose your own custom race
 * Choose your own class color
 * Choose your class icon
 * Quick at a glance IC and OOC tooltips
 * Pronouns in your tooltips so, you can be your true self.
 * At a glance on target, that shows three tidbits of your character for others to see with icon support
 * Freeform character description, with, HTML support
 * Others can see your RP profile!
 * Clean interface utilizing spellbook design
 * Private notes section that aren't shared with others
 * Chat splitter for allowing you to make posts longer than 255 characters
 * Ways to hide your username in emotes
 * White text for "quotes" within emotes
 * Full compatibility with PFUI, Shagu Tooltips, and Shagu Tweaks
 * Efficient backend communication
 * Much more
 * Widespread RP support already, (over 100 testers total)

we invite people to share their screenshots and use in the RP channels ![😄](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f604.svg) we'd love to see how it is being used

Official website: <https://tempranova.github.io/turtlerp/>
Official discord link: <https://discord.gg/jqEx6NMabt>
TurtleRP Donations (Optional) to fund future features and thank the dev: <https://tempranova.github.io/turtlerp/#donate>

Thank you everyone, enjoy the official stable release of TurtleRP.

New RP features :D Lots of new features!

New TurtleRP Version 1.1.0
 1.0.0 is no longer supported

Notes when upgrading:
 - If you have been using 1.0.0 after 1.1.0 is released, it's very likely you've gotten some players with strange characters in their name ("°", or "§") or description. This is because of the new system that gets around "drunk text" through text replacement. In order to fix this, you can press "Clean Directory" in the Directory window after you install the new plugin. If you continue to have issues, tell us or optionally wipe your entire player directory (Settings > About > Clear Directory button)

New Features and Fixes
 - Directory window (accessible using /ttrp dir or pressing the icon in the Icon Tray)
 - Can see other players with the addon
 - Click on players to open their Profile window with whatever information is available (fetches if they are online)
 - Shows online/offline status
 - Filter/search by text for player names or character names
 - Sort by clicking on column names
 - Map window pinging
 - Pinging of your current location (option to turn off in settings)
 - Can browse into zones around the world and see locations of current online players
 - Revised Description / Public Profile window
 - Blizzard frame style
 - 3 tabs: Profile (general information, at-a-glance, and RP style), Description, and Personal Notes
 - Personal Notes added for more space to take notes on relationships with a character
 - Ability to set RP style in Settings
 - Icon Tray now includes cloak and helm buttons
 - Minor fixes
 - Confirmation for odd " characters in Chat Box, and improvements to errors in /e coloring
 - Chat box stays visible in RP mode
 - Version tracker (chat message sent to you if out of date, only sent once per game session)
 - No more breaking text when characters are drunk
 - "%" character now allowed in emotes

**TurtleRP Optimized**: <https://github.com/OldManAlpha/TurtleRP>
 *TurtleRP has an issue that causes the game to freeze frequently. This is caused by the addon generating an extreme amount of memory garbage, triggering more garbage collections, which will freeze the game for its duration. It also uses a lot of CPU, reducing average framerate. This fork addresses these issues, likely reducing resource usage by 99%+, while preserving all the functionality of the addon.*
