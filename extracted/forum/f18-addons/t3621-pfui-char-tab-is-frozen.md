I know this is a little necro, but I was recently having the same issue.  If someone else is having this issue, go to pfui config menu, select components (bottom of the menu), then in the middle menu select skins, then in the right page select "Disable Skin Character".

It won't have the same PFui skin, but you can interact with the character panel, and its the only thing affected.  If someone else is having the issue, I hope this helps.
