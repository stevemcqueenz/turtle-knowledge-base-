The hardcore mode is a great addition to this game however, as a casual player I'd like to implement something of my own outside of the hardcore mode.

I'd like to know if this is possible through addon code or somehow manually by keeping track myself.

 1) Death = 10% loss of xp
 2) Mark where xp now is with loss, turn xp gain off.
 2) Keep track until threshold is reached, turn xp gain back on.

Has anyone implemented their own versions of consequence? I thought about maybe just not playing for a given amount of time after a death? Must be left as a ghost for a day or something like that.
