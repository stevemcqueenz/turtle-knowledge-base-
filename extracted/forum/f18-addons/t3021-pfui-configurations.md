Here is my config, a bit unconventional, but that's how I like it.
I've disabled the action bars, bags and right chat entirely, and use Discord Action Bars (for page switching on Shift) and Bagnon instead. I also use CTviewport to not render the game under my UI, giving me a ghetto ultrawide aspect ratio on a FHD display.
Code: Code: Select all

```
pfUI_config = {
["disabled"] = {
["totems"] = "0",
["pixelperfect"] = "0",
["skin_Spellbook"] = "0",
["skin_Options - Sound"] = "0",
```
