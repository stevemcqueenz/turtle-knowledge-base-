# Mijk's Raid Assist (high end raids)

## Post 45413 by Mijk — 2023-05-10T23:24:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=45413#p45413 | page 1 | era: pre-1.18.1 -->

As i figured, there was no very good option to use retail addons and see which player used what consume in raid. So i also figured we (as THC) wouldn't be the only guild having problems with this, this is why i built an addon myself and  thats why i'm sharing it.

You can view which user used what consume. This works for ;
"/mra flask" - All Flasks
"/mra gspp" - GSPP - Shadow prot potion
"/mra gnpp" - GNPP - Nature prot potion
"/mra gfpp" - GFPP - Fire prot potion
"/mra gapp" - GAPP - Arcane prot potion
"/mra gfrpp" - GFrPP - Frost prot potion
"/mra mm" - Mageblood/Mongoose

You can also use; "/mra gpp" this will show ALL protection potions.

You can find the addon here;
<https://github.com/mijkrofl/MijksRaidAssist>

![Image](https://i.imgur.com/z8jE7uX.png)

So in the image you see the "/mra gspp" command shown.

Now you can also type "/mra gui" to have a gui style window if you're lazy;

![Image](https://i.imgur.com/NdDoioU.png)

You can use this by typing "/fc" or "/mra" in your chat. This won't announce in chat who's got what, but it's mainly for raidleaders who want to know who used what. I'll be adding some more features lateron, maybe.

Good luck, have fun.
