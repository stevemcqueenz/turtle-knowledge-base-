To install add-on, you need to download it. Use your browser and visit the github page of an addon. For example Aux page is <https://github.com/gwetchen/aux-addon-turtle>
On github page click the green <> Code button, and select Download ZIP.
If you are on Windows, then you can unzip with standard tools. You can double click .zip archive and it will be opened like folder. Then you can select folder with add-on, copy it and paste to the location of your TurtleWoW/Interface/AddOns/
