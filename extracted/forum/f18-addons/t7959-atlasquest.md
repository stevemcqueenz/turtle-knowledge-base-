Last Update: 06(June).12(12th).2025 for TurtleWOW 1.17.2

GitHub Otari98 AtlasQuest page
<https://github.com/Otari98/AtlasQuest>

After downloading from GitHub, extract the folder inside WoW/Interface /AddOns
REMEMBER TO RENAME THE ADDON FOLDER AND DELETE THE “-master” or “-main” PART FROM IT’S NAME.
