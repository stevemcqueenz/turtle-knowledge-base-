# [Release] pfUI-MoreDatatexts

## Post 168250 by Walterbennet — 2026-02-15T08:35:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=168250#p168250 | page 1 | era: 1.18.1-announced-pre-release -->

Hey!

I've made an external module for pfUI that adds extra datatexts for your panels.

As of 1.0, it only adds two extra datatexts: a reputation tracker and a WIM conversation tracker.
I plan on adding more datatext in the future, some requiring extra addons, some not. Feel free to leave any suggestions here or on the repository.
If you encounter any issues with the addon or its added datatexts, please leave a report on the repository so that I may fix it.

All the information, features and screenshots are available on the repository page.
You can download the addon here: <https://github.com/Arthur-Helias/pfUI-MoreDatatexts>
