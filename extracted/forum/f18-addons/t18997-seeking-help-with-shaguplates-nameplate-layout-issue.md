# Seeking Help with Shaguplates Nameplate Layout Issue

## Post 129271 by Danwith — 2025-05-01T16:32:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=129271#p129271 | page 1 | era: pre-1.18.1 -->

Hi everyone,

I'm currently using the Shaguplates addon, which has been fantastic and nearly indispensable for my gameplay. However, I've encountered an issue: when there are multiple enemies on screen (typically more than 4), the nameplate health bars become extremely disorganized. They stretch haphazardly across both sides of the screen instead of properly aligning above each enemy's head. Additionally, when I adjust my camera angle slightly, the nameplates "jump" unpredictably, causing significant positional shifts. This makes it very difficult to efficiently apply DoTs (damage-over-time effects) to individual targets.

I've checked the /sp configuration settings but couldn't find any relevant options to address this. Has anyone experienced similar issues? Are there fixes or workarounds for this behavior? Alternatively, if this is a known limitation, could you recommend alternative nameplate addons that handle dense enemy scenarios better?

Thanks in advance for your help!
