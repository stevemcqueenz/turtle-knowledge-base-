**Improved Guild Window (IGW)**
Enhanced guild management UI for **World of Warcraft 1.12.1 (Turtle WoW)**.

[https://github.com/totalllyswede/Improv ... Window.git](https://github.com/totalllyswede/ImprovedGuildWindow.git)

![Image](https://i.postimg.cc/GtxGFtrX/Improved-Guild-Window-A.png)

 **Current Version:** 1.8
 **Author:** Olzon

 ---

 **Features**
- Three main tabs: Guild Members, Member Details, Guild Info
- Advanced per-column search (name, public note, officer note)
- Right-side member details panel with notes, alts, whisper & invite
- Left-side guild info panel with statistics & class distribution
- Alt detection via public notes (bidirectional)
- Sorting, rank filtering, show/hide offline members
- Draggable windows with saved positions
- Class-colored names and auto roster updates
 ---

 **Commands**

/igw        - Toggle window
/igw show   - Show window
/igw hide   - Hide window

 ---

 **Installation**
- Copy Github clone link into TurtleWoW launcher
- OR
- Extract **ImprovedGuildWindow** to: World of Warcraft\Interface\AddOns
- Restart WoW or /reload
- Open with /igw or set a keybind)
 ---

 **Notes**
- Officer detection is rank-based and language-independent
- Alt detection uses public notes (e.g. “Alt of Name”)
