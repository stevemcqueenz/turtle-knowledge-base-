## Post 88410 by Xudo (Grandmaster of Forum PvP) — 2024-02-22T10:56:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=88410#p88410 | page 1 | era: pre-1.18.1 -->

You normally don't need to scan whole auction.
Install Aux and scan only for items you want to post.
If you want to get disenchant price data, then scan for "dust", "essence" and "shard". It will also scan some similar items, but will be fast enough.
If you want to gamble on prices, then you'd better to focus on specific lots. So scan only for them.
If you need gear, use auction filters.
