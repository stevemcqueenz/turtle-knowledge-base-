# Carapace - A TurtleWoW Addon Manager

## Post 147324 by Miklos — 2025-08-20T17:11:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=147324#p147324 | page 1 | era: pre-1.18.1 -->

Hey everyone - I was unsure where to post this, so I put it here, hope that's okay.

I’ve just pushed the first public release of Carapace, a lightweight addon manager built specifically for TurtleWoW.
It handles browsing, installing, updating, and keeping your addons organized —and soon will have addon sets/compilations for easy managing different addon setups and/or for easy sharing/backup.

![🔗](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f517.svg) Project page: <https://github.com/mikl0s/Carapace>

![🔗](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f517.svg) First release (v0.1.2): <https://github.com/mikl0s/Carapace/releases/tag/v0.1.2>

Feedback, bug reports, and suggestions are very welcome — especially from people more experienced with Python than me!

Hope this makes addon life a bit easier for fellow TurtleWoW players.  ![🐢](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f422.svg)
