# [Release] pfExtend - Extension for pfQuest | Loot Display & Quest Chain Browser

## Post 167878 by Cliencer — 2026-02-10T11:18:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=167878#p167878 | page 1 | era: 1.18.1-announced-pre-release -->

****pfExtend**** **is an addon extending pfQuest, featuring monster loot display and quest chain visualization.**

---
 **[**ShowLoots** - Monster Loot Display]**

Hover over monsters to see full loot tables with drop rates and quality colors.
- Alt+Ctrl to open detailed browser with item sources and locations
- Favorites system to highlight items
- Supports NPC drops, chests, mining nodes, herbs

---
 **[**QuestHelper**- Quest Chain Browser]**

Interactive quest tree on world map showing all available quests and complete chains.
- Smart filtering by race, class, profession, level
- Status colors: Green (active), Yellow (available), Red (prereq missing), Gray (completed)
- Click to pin on map, Ctrl+Click to track prereqs across zones
- Supports item-start quests with drop source locations

[Installation]
 1. Download [pfExtend_X.X.X.zip](https://github.com/Cliencer/pfExtend/releases)
 2. Extract to Interface\AddOns\, folder must be named "pfExtend"
 3. Requires: [pfQuest](https://github.com/shagu/pfQuest) (and [pfQuest-turtle](https://github.com/shagu/pfQuest-turtle) for TurFtle WoW)

[Command] /pfex - Open configuration

GitHub: <https://github.com/Cliencer/pfExtend>
