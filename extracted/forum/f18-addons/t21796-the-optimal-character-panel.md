Yes, it was a cool time for sure.

And yea you can change basically anything you see in your UI except for the 3d game world.
Working with textures in vanilla however is annoying because
vanilla only gives you a 1300x768 canvas size, so when you change the size of a texture,
the engine also interferes and applies its own scaling.

For example, in Dragonflight, when you change the size of the minimap with the slider, the border
uses a math function to calculate offsets, so you don’t see how the border gets misplaced
by the engine. Little things like this make it so stressful to work with textures in vanilla.
They fixed that with TBC... :/
