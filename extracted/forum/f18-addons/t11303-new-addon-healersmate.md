## Post 117210 by Oldmana (Barrens Chat Casualty) — 2025-01-19T02:24:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=117210#p117210 | page 2 | era: pre-1.18.1 -->

> **Tredecim wrote: Sun Jan 19, 2025 12:14 am**
> Thanks you for your updating this addon, it's a great QoL. I'm using the style "Long (Intergrated)" and I tried differents commands to see the colors but it didn't works. Could you give the command to see see colors with this style ? Ty !

Hey, running that command won't update the colors until after you hover over the frames, and only persists until you reload the UI. Thankfully, in the recent alpha5 update, I added the ability to run load scripts so this can be ran every time you open the game/reload the UI.

Go to the HealersMate Settings>Customize>Advanced Options>Edit Load Script
Paste and save this code, replacing the profile name with what profile you'd like to change: Code: Select all

```
local profile = GetProfile("Long (Integrated)")
profile.HealthBarColor = "Class"
```

If you'd like the player name to no longer be class colored, you can also add Code: Select all

```
profile.NameText.Color = "Default"
```

Reload or relog for the changes to take effect.
