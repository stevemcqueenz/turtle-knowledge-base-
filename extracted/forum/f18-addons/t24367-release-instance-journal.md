**Instance Journal**
A reimagining of the Encounter Journal, built for TurtleWoW
[**[ GitHub Repository ]**](https://github.com/Arthur-Helias/InstanceJournal)

---
 **What is Instance Journal?**

Instance Journal brings a fully rebuilt Encounter Journal to TurtleWoW!
Whether you're a veteran farmer or a fresh adventurer stepping into Deadmines for the first time, the journal gives you everything you need to know about every dungeon and raid, right inside the game.

Open the journal with **Shift+J**, or rebind it at any time through the **Key Bindings** menu.

---
 **Features**

- **Complete instance coverage** - all dungeons and raids, including custom TurtleWoW content
- **Boss encyclopedia** - every boss's abilities and loot, in one place
- **Powerful search** - instantly find any item, ability, instance, or boss
- **World map integration** - instance entrances and bosses shown directly on the map; click any boss to jump straight to their encounter
- **Improved world map** - a better overall map experience
- **Multilingual** - localized in enUS, deDE, esES, frFR, ptBR, ruRU, and zhCN

 **Installation**

 **Via the Turtle WoW Launcher (Recommended)**
1. Open the Turtle WoW Launcher and navigate to the **ADDONS** tab.
2. Press **Add new addon** and paste in this URL: Code: Select all

```
https://github.com/Arthur-Helias/InstanceJournal.git
```
3. Enable the addon from the addons menu on the character selection screen.
 **Manual Installation**
1. Download the [latest version](https://github.com/Arthur-Helias/InstanceJournal/archive/refs/heads/master.zip).
2. Extract the archive.
3. Rename the folder from *InstanceJournal-master* to *InstanceJournal*.
4. Copy the renamed folder into **WoW-Directory\Interface\AddOns**.
5. Enable the addon from the addons menu on the character selection screen.

No offense taken! I'm glad you enjoyed the addon.

Some UI elements, like the buttons, the new scrollbar, etc, were pulled from the UI. Some of the stories for the bosses and instances too. The window UI, outside the top left book icon, are custom. All bosses frame (their model that shows on the left of the button to select a boss) and boss's map icon are (painfully) custom made. All the custom TWoW content was readapted. Even the UI that I pulled from the original Encounter Journal had to be touched up and adapted. It wasn't a simple drag and drop let me tell you that lol.

None of the original code was taken. I've simply used screenshots and interacted with the UI to recreate the behaviors.

Overall, this project from its creation all the way to the 1.0.0 release took around 300 hours of work.
