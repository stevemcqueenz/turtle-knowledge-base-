Hi ... I'm using FuBar_SpeedFu - a plugin for Fubar. It works.
Well you need the FuBar for it ...

If you don't like this solution you could try MonkeySpeed ... then you get a little extra box with colored speed percentage.
To calibrate the speed ... run at 100% and hit /mscalibrate ... should be necessary for every zone.

[![Image](https://s20.directupload.net/images/220822/o9eikhrv.jpg)](https://www.directupload.net)

or
MonkeySpeed + MonkeyLibrary
