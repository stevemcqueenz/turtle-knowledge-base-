# Warcraft 3 UI — WIIIUI

## Post 122648 by Fiur — 2025-03-15T19:12:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=122648#p122648 | page 1 | era: pre-1.18.1 -->

![Image](https://user-images.githubusercontent.com/97316608/149594045-c5f69b42-0634-4792-a9a6-820b3527971b.png)

WIIIUI is a custom UI addon for WoW, designed for Warcraft III fans or anyone who enjoys its aesthetics. It features four faction themes: Human, Orc, Undead, and Night Elf. Custom themes are somewhat supported, check out the github page to see custom themes and how to make your own.

Features:
 * Four Warcraft III themes.
 * Customizable UI elements (minimap, chat, action slots, etc.).
 * Extra bindable action slots.
