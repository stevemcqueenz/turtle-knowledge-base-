TurtleTranslator – Real-time chat translation for multiple languages (EN/ES/FR/DE/IT/PT/PL/RU/RO/CS)

Turtle Translator is a real world language translation addon. It translates chat messages from a number of languages into whichever language you specify.

Turtle wow is enjoyed by players from all over the world. For many of them, English is not their first language. Turtle Translator is designed to make it easier for players with different language backgrounds to communicate in-game.

Features:
- Real-time translation of chat messages from selected channels
- Supports 10 languages: English, Spanish, French, German, Italian, Portuguese, Polish, Russian, Romanian, Czech
- Extensive built in dictionaries
- Translate messages from any language to any language, using English as a pivot language
- Configurable via Settings: enable/disable translation, select channels, choose target language, enable or disable specific languages
- Settings saved between sessions
- Debug mode (/tt debug) for troubleshooting
Installation:
Download from GitHub: <https://github.com/picardebooks/TurtleTranslator>
Unzip into Interface\AddOns\
Restart client or /reload
Type /tt to open settings

Notes:
For best experience with Russian/Polish/Romanian/Czech, you may need to install a new font such as Noto Sans or DejaVu Sans.
Detection works best with longer messages; very short messages may produce false positives or mistranslations

Known Issues:
- Detection is dictionary-based and can occasionally misidentify language
- Some non-english characters are unable to be translated currently
- Translation depends on the completeness of the dictionaries, some gaming terms are not currently included in the dictionaries, and are not correctly translated
Please use this thread to submit questions or feedback. I'm open to making changes if there is enough demand. Or just let me know what you think. Thanks!
