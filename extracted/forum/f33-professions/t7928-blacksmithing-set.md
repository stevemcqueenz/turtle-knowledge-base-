## Post 50973 by Mcnair (Barrens Chat Casualty) — 2023-06-22T11:09:00Z

Good day.
If you are looking for a set similar to the Bloodvine set tailors tend to make for almost all the fresh 60 casters, then there is The Darksoul set from the same source: Zandalari reputation (Zul Gurub, 20-man raid)
<https://database.turtlecraft.gg/?itemset=444>
If you are looking for a set while levelling up your Blacksmith character, there is the Imperial Plate set, with items in the level range of 47-56, using a lot of Thorium, some gems, and some Rugged Leather.
<https://database.turtlecraft.gg/?itemset=321>
If you are looking for 'sets' as in items that are looking nice together and not just items with set bonuses, then there are a lot of them, almost all the armour you craft with the same prefix usually have matching looks.
