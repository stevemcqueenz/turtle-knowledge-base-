# Add Envenom to the Veiled Shadows 2 piece set effect

## Post 148335 by Apav (Barrens Chat Casualty) — 2025-08-26T04:58:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=148335#p148335 | page 1 | era: pre-1.18.1 -->

The Veiled Shadows 2 piece set effect reduces the cost of Slice and Dice by 10 energy. This itemization was changed before Envenom was added to the game and I don't think has been considered since. I propose adding Envenom to the 2pc set effect. Both Envenom and Slice and Dice have the same energy cost and both are abilities you want to keep up constantly and would cost one energy tick, so this would go hand in hand. It would also make it more competitive with Naxx and Kara gear, as you would have to choose between holding onto the set bonus or better individual stats on your cloak and ring. Slice and Dice being 10 energy feels better energy wise, even if it doesn't result in more dps if you have better gear that breaks the set bonus. Not to mention the cloak has hit and the ring has haste, which Assassination rogues who use Envenom value more than other rogue specs anyway.
