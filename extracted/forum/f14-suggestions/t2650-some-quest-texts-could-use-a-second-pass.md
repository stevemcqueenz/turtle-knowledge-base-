# Some quest texts could use a second pass.

## Post 16570 by Jubling — 2022-02-01T15:34:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=16570#p16570 | page 1 | era: pre-1.18.1 -->

The quests added by turtle wow are very neat and a welcome addition, however, the quest text often leaves a little to be desired. For example the quest Further Studies from Nessa Shadowsong asks you to kill crawlers for samples.

All the quest states is: "Fascinating... I wonder if such changes may cause other creatures in the food chain to be affected. I think it is a matter worth studying further! But for that I would need samples of something larger... Ah, crabs! Yes. I believe we could find something new if we study those crustaceans."

The objective doesn't offer much more help: Gather 10 Crustacean Carcasses from crabs in Darkshore, then return to Nessa Shadowsong in Rut'theran Village.

(It also calls them crabs which seems odd? But I acknowledge that is at least easily understandable.)

The text at no point mentions which crawlers you need, there are about 6 varieties of crawler in Darkshore, and two of them drop the item, not at 100% rate, so without looking into the database you're left completely blind. I feel like googling every quest added really isn't the vibe Turtle wow is going for. I think the teams doing a great job adding quests, but think it would help slot more seamlessly into the base game if a bit more care was put into what details can be mined from quest text.

A partial solution (for this kind of quests): if the description is vague, instead of making it exact, make all creature varieties (in a zone) drop quest items, with different drop rates (the stronger the creature, the higher the drop).
This would also make questing by an overleveled character less tedious, as one could seek higher level creatures in a zone (more challenge and less kills).
