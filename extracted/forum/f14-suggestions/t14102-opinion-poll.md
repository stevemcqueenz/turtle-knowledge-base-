i'll comment on the only ones i'm more familiar with.

 1. Making Survival tree into a valid melee hunter build.
A: Survival is already a valid tree for Hunter. It has great survivability features and a lot of useful stuff. The problem with melee hunter is not that it isn't good, but that the other specs are that much better. This isn't an issue though, as hunters aren't designed with melee a core mechanic of the class. You could argue that warriors can use bows and guns but there isn't anyone advocating for a ranged warrior buff or something. What could be done to Hunters and survivability, in my opinion, it to focus more on traps. Like having a talent that allows to put traps while in combat or give new kinds of traps and so on. This way you could have a hunter go melee to lay traps or spec survival for pvp.

 4. Adding a new heal to hpala so gameplay gets more interesting.
A: Hpala already have 3 great heals (Holy light, Flash of light and holy shock) + Blessing of light. Can't see how adding one more heal would make it better or more engaging

 9. Allowing cats to cleave.
A: Druids can already cleave, as bear, or cast spells, as balance. Cat is the part of the kit focused on single target damage. If cat can do everything, why have the rest?

 14. Allowing shamans to tank.
A: Just because shamans can use shields, it doesn't mean they should be tanks. The shield is a great help during leveling as the shaman lacks pets or hard cc that other classes have or Heavy armor like pally or warrior. The shield helps in that regard.

 15.  Same with hunters, rogues and warlocks.
A: This isn't season of discovery, class distinction is important.

 18. Giving class racials to other classes, not just priest and shaman.
A: I do like this idea as it would help differentiate classes even more without touching specs. Just have to be careful not to do it like priest where dwarf is BIS. Class racial can be tricky to balance but i think it would be loads of fun.

 19. Reworking racials (like buffing nelf ones).
A: I'm all for reworking racials, as i don't think there are such a big part of the game to have much of an impact, if changed (of course, people who like weapon racials might disagree with me). Personally i would like racials to be minor things but with some significance, like crafts bonus and maybe a minor ability.

 20. Racials can be switched with a quest chain.
A: Something racebound should not be changeable, not matter the circumstance. If it gets to this point is because there are outliers in racial bonuses that should be reviewed and corrected.

==============================
Well, these are my two cents. I'm not necessarily correct in any of them, but its how i feel about each one. GL HF
