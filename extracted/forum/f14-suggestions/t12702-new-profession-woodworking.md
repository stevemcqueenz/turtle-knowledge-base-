The problem with adding in new primary professions is that it has to be considered in junction with all the other professions and economy. All the current professions are interwoven together so that there are several recipes which need materials made only by other professions. Professions are kept relevant and useful by this.
Also, a natural progression 1-300 during leveling with rare recipe drops at appropriate levels and appropriate profession level nodes at appropriate player level zones which also make sense in context of the zone geography.
So, if you want to add a new profession and do it well, you would have to change all the other professions and all the zones. Now that's a difficult thing to pull off well.
