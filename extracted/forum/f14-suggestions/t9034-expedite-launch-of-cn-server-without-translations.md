As Subject states, I am suggesting the Twow devs consider launching the China server sooner without translations done. Translations can wait, I have players from China in my guild and their translation software works fine for them for the time being.

What is not fine though is the server stability the past few weeks, and it is only getting worse. I understand the devs probably don't want to release the China server half baked, but the lesser of two evils seems to be doing so now and having a transfer service in the meantime to said server to relieve the obvious strain the population boom is having on the base Twow servers.

Alternatively, open a 2nd Twow server with transfers available for guilds that mirrors the existing server. The near doubling of latency for players outside of EU, along with the lagspikes is making the game practically unplayable during peak times. I'm sure you guys have access to demographic data to determine an appropriate location for a mirror server for Twow that would best serve the community.

If there was ever a time to pull the trigger on launching an additional server, it would be now.
