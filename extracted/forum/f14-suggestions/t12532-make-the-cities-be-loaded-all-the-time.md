# Make the cities be loaded all the time

## Post 83464 by Dracarusggotham (Grandmaster of Forum PvP) — 2024-01-02T20:47:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=83464#p83464 | page 1 | era: pre-1.18.1 -->

As you know, the developers made it so that the cities were never rendered on the game map like the other areas for "Performance Reasons", which I find silly, because you have THE ENTIRE MAP, rendered all the time, but you save the cities, something that causes such annoying bugs, like for example, you fly towards Stormwind and when you arrive you can clearly see the blank space behind the wall, it is even possible to see that the Cathedral of Light is superimposed there to make it look like It's like it's giant, but you can see it's there floating in a big empty space.
That's why I ask, is it possible to make the city loaded with the rest of the map? Would it affect the game a lot? Is there any impediment to doing that?
Even this can help expand to cities more easily, by mistake I fell through Stormwind without being loaded, and I saw that there is a huge space without using, it would be great to be able to expand the city, and a good first step would be try to implement the city to the map as such.
