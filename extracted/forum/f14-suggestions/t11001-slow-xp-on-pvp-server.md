# Slow XP on PvP server

## Post 71994 by Bimbombo2 — 2023-10-18T22:42:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=71994#p71994 | page 1 | era: pre-1.18.1 -->

In the latest announcement, it was confirmed that the new pvp server will NOT have levelling challenges such as hardcore, vagrant’s endeavour and slow and steady. The rationale being that these challenges are not suited for a pvp server due to the frequent pvping and thus frequent dying. This makes sense for hardcore where one death means game over, and for vagrant’s endeavour where you’re stuck using crap gear. But I do not understand the reasoning behind disabling slow and steady.

The 0.5x xp rate of slow and steady does not influence pvp fights, nor does it punish you for dying in pvp. All it does is slow the progression to 60 down. 0.5x xp on a pvp server does not hinder your progression or success any more so than it does on the pve server.

Turtle WoW has a lot of new content, including zones, dungeons, and quests. There is so much new content that it had trivialised my progression to 60 on the pve server, and I had to leave entire zones earlier than I would have liked because I had outlevelled them.

Please allow a 0.5x xp rate on the pvp server so that me and my levelling partner can enjoy the journey to 60 as much as possible. Levelling is the most fun part of the game in my opinion, and I thoroughly enjoyed slow and steady. I will play the pvp server anyway, but a reduced xp challenge will make it much more fun   satisfied_turtle_head
