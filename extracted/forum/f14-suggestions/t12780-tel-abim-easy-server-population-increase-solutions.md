This is just naming some easy solutions to atract more players to the **PVP** Server or distributing them from the current **RP** server (even if 1000 players would go there it would be in an better state for maintaining an server, yet it could also attract new players in this way).

 1 - Make all Challenges Available in the **PVP** ***Tel'Abim*** Server, players love the challenges and thats also an reason why people don't go over to the ***Tel'Abim*** Server:
 - Hardcore would be changed to make contested zones act as if they were non contested ones for the sake of not being ganked that would be the only non **PVP** type of change to be made and would last till reaching lvl 60.
 - War mode would be active even in non contested areas as it stands even in the **PVP** Server the non contested areas are safe havens still.
 - Rest of the challenges remain the same.

 2 - Enable Cross faction team-ups (so you won't be able to attack the other player only if he's in your team) and guild forming. (Low population helps doing dungeon and raid stuff, lore wise it has happened uncommonly that horde characters would team up with alliance to get stuff done, see the intro orc vs human battle that turned into an team-up against the infernal at the cinematics for Warcraft 3 as one ex. of this)

 3 - Enable Transfers to the **PVP** Server from the **RP** Server, yet the characters will lose any progress and items beyond what the currrent Server progress limit is. This can be done by paid migrations, and limited for a small time for free when implemented.

For all the talk of HC bad (that is an personal choise that doesn't affect others), it is **PVP** Server not an **PVE** Server (you still do a lot of PVE), etc. ..., well **PVP** realms is not only **PVP** but more FOCUSED towards it, it still has **PVE** and other content for you to ammuse yourself with, so all the proposed is normal in an **PVP** Server enviroment.
