# Alah'thalas could use some redecorating

## Post 33847 by Maesus (Barrens Chat Casualty) — 2023-02-02T17:42:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=33847#p33847 | page 1 | era: pre-1.18.1 -->

Some suggestions to improve and upgrade Alah'thals to make it into more of a town...

 - Bank + AH
 - Permanent Moonwell *(the current quest-chain which ends with a Moonwell being constructed in Alah'thalas might be replaced with the same quest chain simply resulting in blessing in the Moonwell which would be there permanently)*
 - Ship connection from AT to Auberdine's westernmost pier
 - Enlarge the landmass on which Alah'thals stands; add more residential buildings and trade buildings, proper stables, a smithy, a library, training grounds, a fishing pier with fishing boats, etc.
 - Profession trainers sprinkled throughout the town, some of which would be in newly added buildings (the library could be there for Enchanters, for example, or an alchemical garden + an alchemical shack for Alchemists, etc.)
 - Only Priest and Paladin trainers ought to be in the Citadel of the Sun, rather than the Citadel hosting all class trainers... Hunters should have their own lodge, Rogues can be there with them, Mages can have a Spire/school of their own connected to the Inn (where you teleport to from SW).

Just some ideas :)
