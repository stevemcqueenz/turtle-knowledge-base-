## Post 42630 by Whalemilk (Patch Note Conspiracy Theorist) — 2023-04-22T21:44:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=42630#p42630 | page 1 | era: pre-1.18.1 -->

This is something that just popped into my head.

If I'm not mistaken, not a lot of people PVP or play Battlegrounds.

I propose a way to encourage battleground participation (I don't PVP so I don't know if this is even necessary)

Allow PVPers to purchase keys which allow them to access optional dungeon/raid bosses. So, if there is a boss you want to kill, you must have someone in the party with the one-time use key to access it.
