Hi, I loved the changes to the Druid t0,5 set. It was an epic quest, and now it has an epic reward.

What are some of set bonuses being considered?

Here are some ideas that I have been considering for set bonuses for any tier:
 - 2% Crit from 3 pieces -  (to replace bloodline and provide more damage output to make Dmg comparable to other classes)
 - Insect Swarm lowers chance to hit by 6% (or just bigger) - (to makE boomkin more desirable spec for raids with more utility for fights like Nef, Patchwerk, etc)
 - reduced CD on Hurricane  - (to allow for higher dps output during trash packs)
 - 4% haste bonus - (to help provide higher dps output)
