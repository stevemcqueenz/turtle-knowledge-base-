# Naxx T3 tokens, specifically the warrior/rogue one

## Post 121889 by Abiozan — 2025-03-06T17:22:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=121889#p121889 | page 1 | era: pre-1.18.1 -->

Hello! It's a discussion I've been hearing very often recently, especially after new alt sets were added, but I think it's worth the talk.
The issue is really simple, honestly. ![Image](https://cdn.discordapp.com/attachments/1346960613540233308/1347256196628877443/image.png?ex=67cb299c&is=67c9d81c&hm=b7169c06c03c26a2c613c0518fc41d66a73950d03272877c1563efd4f4e4b62e&)
Tokens currently for warrior rogue are in a weird spot where despite having higher pop of warrior rogue together they usually still get way less use than the other two, and the problem quickly becomes an issue for the pally/hunter/shaman/druid token because that's 4 classes, 3 of which are hybrids with 3 tier sets. That's a lot of hybrid tokens for 1 token and it makes the competition on it absolutely unhinged compared to the warrior rogue one which usually gets disenchanted after like 2 weeks of a core of warriors and rogues rolling on it.

So the solution is really simple: move either paladin or hunter to the warrior rogue token.
Hunter would make sense in the logic of its a pure physical dps class like warrior and rogue and its not a hybrid so it would work nicely like for rogues.
And moving paladin would fit more to the plate idea of the tokens, as well as the fact that it would greatly reduce insane competition for hybrids for rolling on this gear.

Do tell me your suggestions, but I think it's fair that each token should be 3 classes split, and caster token should be left as is.
