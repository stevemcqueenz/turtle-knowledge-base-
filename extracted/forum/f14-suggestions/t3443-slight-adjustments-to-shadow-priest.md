# Slight adjustments to Shadow Priest

## Post 20797 by Cynric — 2022-08-01T17:02:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=20797#p20797 | page 1 | era: pre-1.18.1 -->

First of all, the current changes to Shadow Priests are awesome! Great job on that.
As someone who is currently raiding as SP and would like to do so (efficiently) in Naxx aswell, I have 2 suggestions for the devs:

Firstly, the current passive mana gain from imp Vampiric Embrace is around 8-9%. It's supposed to be 4%, which is too little for high end content. Mana management is still fairly difficult on bosses that take several minutes (not saying it's impossible).
How about you guys change the tool tip to 10% and keep it as it is?
Or increase it to 12%, which would still make it viable without being too strong. (You can only bring 1 SP anyways because of the debuff slot limitations)

Secondly, please think about giving SP slightly better dmg and crit modifiers. We're able to do decent damage with a LOT of effort whereas mages or warlocks can do the same by pressing 1 button without using many consumables.

The aforementioned suggestions should result in stabilizing SP more for PvE and making it viable for endgame content as any other meta class.
