# Make Triskelion of Roving Elements speed bonus stack with boots minor speed increase bonus

## Post 88909 by Melg — 2024-02-28T08:47:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=88909#p88909 | page 1 | era: pre-1.18.1 -->

**How it should work**
When Triskelion of Roving Elements(<https://database.turtlecraft.gg/?item=60860>) used with boots enchanted with minor speed increase their bonuses should stack giving total of 116 speed, while in current version each of boots and item gives 108 speed, but when combined total speed stays same - 108.

 **Motivation for that change**
 1. Initially this behavior was already implemented in game. But after some time it was changed to current variant (nonstacking) and within github issues opened on this matter were given this motivation by twowTurtReynolds:
"Blizzard demonstrated a policy with wow that no movespeed enchants or talents would ever stack. TWoW is sticking with this design and while I cannot find a public report, this was likely fixed on purpose."  but i think twow is actually about vanilla + experience. If i remember correctly some time ago + mounted speed bonuses didnt stack in the past, for 2 trinkets, but they do now. Also we got more speed boosts for mounted players - like mithrill spurs vs thorium spurs, or mount speed bonus on AV for a team with fewer players, i think its time to go to original design of this item, i didnt find any complains of people about this item being too op or somehow bad for community.

 2. Also it would be coherent behavior with other speed increasing trinkets, for example - mount speed increase trinkets. If you put on gloves enchants + thorium spurs + carrot trinket + goblin car key trinket - they all stack up and give sum bonus to speed.

 3. Even for increase swim speed bonus it works same way, if you put on Azure Slik Belt and Murlock's Flippers which also have + swim speed bonus, this values stack and you swim with speed equal to 100+ both of their bonuses.

 4.  Everyone loves speed, it would make this item truly great trinket and balance out current meta around Gelkis vs Magram.

 5. Simmilar quest with Magrams provides Dyad of Twitching Elven Ears which is great for stealth users, it would be fair if Gelkis allies also get something usefull - trinket that stacks speed with boots would be realy good for stealth users which would provide additionaly speed for their stealth movement. Giving both questlines usefullness parity.

 6. It wouldn't affect pvp or pve balance that much but would really increase value of item and motivation of players to participate in this questline.

 7. Alot of buffs and effects are present in game already which increase movement speed for greater values. Think of [Swiftness of Zanza](<https://database.turtlecraft.gg/?item=23796>) for example. So even with stacked bonus player will have running speed increased less then Zanza provides.

 8. This quest item is available for both factions in any given moment, so it doesn't discriminate agains any group of players.

 9. Literaly in description of item it says that it does "Minor increase to running and swimming speed" which player with boots enchant just doesnt observe at all. Imagine dissapointment of player who farmed so much reputation, did all quests, choose this trinket and saw its basically not working.

P.s. Initially this was opened as issue on github with explanation how to measure values of running speed. If someone intrested in technology of measurement: [https://github.com/slowtorta/turtlewow- ... ssues/6376](https://github.com/slowtorta/turtlewow-bug-tracker/issues/6376).
