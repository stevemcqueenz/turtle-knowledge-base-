# Few suggestions

## Post 11534 by Kelerun — 2021-08-05T21:49:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=11534#p11534 | page 1 | era: pre-1.18.1 -->

1. Make high level dungeon boss drop badges/currency for purchasing pvp items like rank gear, don julios band, unstoppable force etc. This would probably incentivise people into running more dungeons with other people at lvl60. Maybe T0 gear etc also. Having pvp gear available is a plus also considering not much pvp is happening on this server. If there is worries make the gear take a while to acquire.

 2. Maybe tune/re-balance a few speccs like Moonkin Druid and other "forgotten" vanilla "meme" speccs, this would make leveling a bit more fun where you have more choices. Maybe add a few TBC spells for certain classes. Someone with great knowledge of vanilla classes should be able to do this. So no class will be completely overpowered.

 3. Make players able to defect to other faction, this happens in lore. For technical reasons maybe make it so only lvl1/new characters can choose to play as the other factions. This would just be neat.

 4. Maybe allow cross-faction pvp, it's already allowed in PvE so why not for PvP?

 5. Will zones/subzones like Isle of Dread or Azshara be re-purposed? Isle of Dread feels like a missed opporunity from Blizzards side.
