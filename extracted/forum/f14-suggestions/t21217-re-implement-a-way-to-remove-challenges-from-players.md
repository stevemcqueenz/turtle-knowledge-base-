# Re-implement a way to remove challenges from players.

## Post 147319 by Brolomax — 2025-08-20T16:58:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=147319#p147319 | page 1 | era: pre-1.18.1 -->

Like the title says really. If I recall correctly you used to be able to just turn off challenges at the glyph master but ever since the challenge interface on character creation screen was added this is no longer an option.

I am one of a few players that I have seen since Ambershire launched who started a slow and steady character for example but eventually would regret that decision and the only way to remove it is by starting at level 1 which can feel rough if you have spent donation points on that character for a mule or brainwashing device.

It doesn't even have to be free to remove the buff, but I think giving the players a choice would certainly help myself and might even make me more likely to try new challenge modes on alts in the future.
