Hello administrator, I have a suggestion

Here, I have learned that some people may not be players. Some of them maliciously queue up and occupy server resources, and use BOT queuing, while others use proxy queuing and charging services,

To avoid trouble, they will enter the game from noon and remain stationary to occupy their position until evening before taking action.

I have reported a lot of players in the last two days, who are using the script to automatically jump, turn around, move forward, use magic, and hang up in different ways, although it is easy to find out and punish them.

But some players find that we can't observe them long enough to know if they're using a script, so they've increased the interval between automations so that we can't see them cheating.

My suggestion is to reduce the timeout to two minutes while the player is still, so that we can see for a short time if they are using a script to do a loop, it's easier to find cheaters.

It's not enough to just do this. The time to return to the character interface after leaving should also be shortened accordingly. After leaving for 5 minutes, return to the character interface,

If the player does not enter the game again in a short period of time, they will enter a reverse queue, with a reverse of 20 or more points per minute. At this point, if the player wants to re-enter the queue, they must enter a verification code.

If the player does not enter the queue for a longer period of time, it will be considered as leaving the game.

Doing so would allow temporarily busy players to return to the queue. It would also give players who had been in the queue for too long more opportunities, reducing the need for stationary players to occupy positions in the game

That's all，I hope it works
