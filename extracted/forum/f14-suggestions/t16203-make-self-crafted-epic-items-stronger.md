# Make self crafted epic items stronger

## Post 110498 by Caos (Barrens Chat Casualty) — 2024-11-29T11:43:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=110498#p110498 | page 1 | era: pre-1.18.1 -->

Crafted items are pretty weak compared to raid ones. And although buying them from the AH is pretty easy, leveling the profession to 300 and gathering the recipes (most of which are gatekeeped behind raid reps or droped by bosses) is a pretty big hasle.

So what if the profession items where a little stronger if you crafted them yourself? (late game ones)
All items already have the information of the crafter. It would be cooler that they are automatically stronger if the crafter and wearer match but a probably easier solution would be using the item to craft another soulbound one with better stats and only allow this if the item is crafted by yourself.

Its actually not a profession bonus like WOTLK as you can still get better gear by raiding and you would then get 0 benefit from this, so you can still pick whatever profesion you want.
