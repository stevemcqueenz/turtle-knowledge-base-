# Bow for Сasters!

## Post 152802 by Kainrick — 2025-09-23T12:23:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=152802#p152802 | page 1 | era: pre-1.18.1 -->

I understand that only 1 magic class in the game can use bows (Night Elves - Priest), but using auto-shot and the only Searing Shot makes this option weak, as it results in a loss of stats due to give up using the wand: spell power + intelligence/critical strike with spells.

I'm not suggesting changing the current bows (although a slight increase in intelligence wouldn't cause an imbalance on the hunters' side), but adding an item to the engineering, such as a scope that grants spell power, is a great idea in my opinion.
