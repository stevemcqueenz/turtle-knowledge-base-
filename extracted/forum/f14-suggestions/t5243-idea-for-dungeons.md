# idea for dungeons

## Post 31843 by Ibux (Patch Note Conspiracy Theorist) — 2022-12-31T08:33:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=31843#p31843 | page 1 | era: pre-1.18.1 -->

could we add some rare drop recipes, that when crafted makes items that depending on what item you get sends your party to a hard mode version of one of the existing dungeons (or a new dungeon). if you die inside you spawn at the nearest grave yard in the zone you entered from and the dungeon is failed (at least for the dead). a fun way to re use the old content, you could even add new challenges to the hard modes. and a good opportunity to add more value to existing items people farm for.
