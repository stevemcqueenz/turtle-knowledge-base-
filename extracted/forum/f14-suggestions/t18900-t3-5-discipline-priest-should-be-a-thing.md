# T3.5 discipline priest should be a thing

## Post 128609 by Kryso — 2025-04-26T15:26:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=128609#p128609 | page 1 | era: pre-1.18.1 -->

Hello, could you please provide any logical argument why wouldn't discipline (smite) priest receive any tier set update since t2.5? Even boomkin and ferals - which are niche specializations - received it lately with the update of t3.5 sets and the priest is totally skipped in this. First, you made class changes that allowed this specialization to be available as an considerable option and then you do not care with the sets to provide it any progress in building. The BiS items were hard enough to get, and now spec like boomkin can obtain way more better items through the set. Sincerely, I would like to see an update for the t3.5 sets that make disci/smite priest shine again with either dps or supportive capabilities. It should be optional for every player to choose freely whether they would like to play this specialization or not - and right now you make it even harder by not adding new content for ONLY this specialization regarding all the t3.5 sets that have a lot of freedom to choose. Please consider it and make an update to help this niche specialization in both their DPS and supportive journey.

## Post 128701 by Zvyrhol (Grandmaster of Forum PvP) — 2025-04-27T13:22:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=128701#p128701 | page 1 | era: pre-1.18.1 -->

First logical argument I can think about is lack of time from the team. New 3.5 set for priests would require artists to create recolor of the plague doctor set. Secondly, new set means new itemization and set bonuses - devs must invest their time again.

Second logical argument that also supports the first one is that priests received 2.5 set not long ago. Devs probably assumed they can skip 3.5 set this time and focus on other important things because Smite priests should already be satisfied anyway.

Third logical argument is that devs likely lack ideas for good Smite sets and itemization. 2.5 proved that. They thought Smite needs only "damage by Holy spells" stat instead of "damage and healing" which led to killing the hybrid between healing and damage at least in PvP. Best items for Smite are definitely not these from 2.5 set. Tier bonuses are bad on paper in my opinion (I haven't collected whole set yet so I can't say how really bad it is).

It's still amazing to me that the best set in terms of bonuses for Smite is ZG-meme-set that gives your Smite/Holy Fire spells extra 5 or 6 yards range. This meme set actually allows the Smite priest to become caster with the longest offensive abilities in the game (42 yards with talent). That allows the caster to effectively avoid some mechanics of bosses in raids without moving, making more dps when clearing trash in raids because you don't have to move that much to have range. This range is also amazing in PvP.

If I were dev, I would definitely steal that set bonus from ZG set (extra 5 yards for Smite/Holy Fire) and I would place it in new 3.5/4.0 set just because how great it works. ZG set could receive a small revamp of bonuses instead.
