# Hungry debuff

## Post 27789 by Bloodline1x9 (Patch Note Conspiracy Theorist) — 2022-10-23T18:13:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=27789#p27789 | page 1 | era: pre-1.18.1 -->

Make Vanilla more realistic!
If character doesn't eat 3 more hours will get a debuff "I'm hungry!". It's lock the rested bonus and reduces all stats by 10% (for example)

Food must suit to the level of the character in order to satisfy hunger.

In addition to the decorative implementation of this innovation, it will also lead to the fact that the players will start to think more about buying food from the Auc and will give space for new recipes in Survival to find food according to Bear Grylls' guides.
It would also make bonfires a bit more popular than it's now. In short, as a base, it provides new opportunities for ideas.

P.S. Conjured mage-food does not satisfy hunger!

If it is optional then it should give a bonus when the character is not hungry. Because people choose easy ways if there is no bonus for difficult choices.

(an easy solution would be to give +5% damage, but this will increase Raids power.)

Therefore, I suggest giving +3% movement speed out of combat
and + spirit bonus equal to character lvl. For example 25 lvl character = +25 spirit
Someone can say that the spirit is trash, but I want to note that it will reduce the drinking-eating time not only of casters, but also for warriors. Especially them, because they get most of all health regeneration from spirit.
