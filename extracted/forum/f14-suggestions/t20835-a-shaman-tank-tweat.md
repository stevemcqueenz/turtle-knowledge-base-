# A shaman tank tweat

## Post 144741 by Akos1896 (Grandmaster of Forum PvP) — 2025-08-12T08:38:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=144741#p144741 | page 1 | era: pre-1.18.1 -->

Hey!

I know I've written similar articles before but I think this is an important topic.
It's regarding the new class changes giving extra threat to tank shaman by adding those modifiers to random talents.
I think it is a bad idea because there is a much more interesting and natural way to help shaman tank threat.
Gluing +n% threat here and there just feels forced.

 **Elemental shields.**
Shaman tanks, specially before raid gear are mostly forced inside water shield and use it 90%< of the time.
If we want to enable a higher threat output more naturally, *we should focus on how elemental shields work.*

It should be practically possible for shammie tanks to switch between the three elemental shields regularly.
Right now it is done in an extremely limited way.
 *Earth shield is barely used, lightning shield is usually kept for pulls, specially at bosses.*

Lightning shield is **threat** mode, specially with the way lightning strike is working in relation to that.
Earth shield is **defensive** mode, again, with the help of LS.
Water shield is **resource regeneration** mode.

Right now the devs want to raise the build's threat by granting free threat modifiers here and there.
Instead of enabling shamans to more confidently switch between these modes.

I'm telling with a high confidence that a tank shaman being realistically capable to spend 60% of fights in lightning shield would solve any threat problems.
No need to buff the totem talent, lightning shield orbs take care of the aoe threat to a degree, if used well alongside with the other abilities.

 *No need for the random threat modifiers.*
Lightning shield procs and mainly lightning strike while using lightning shield takes care of the threat problems.
This change would also open up earth shield which + LS is the closest thing to a defensive setup shamans have.

Making tweaks here instead of introducing random threat buffs would make the build much more interesting, the gameplay more rewarding, enabling shamans realistic and clever shield switches and would really open up the 'defensive mode' which is right now capped behind mana efficiency.

 **How to do that?**
I see four possible ways.
 *All four are buffs and if needed, I'm totally willing to accept nerfs elsewhere to keep up a balance.*

 1. Make passive water shield procs recharge more mana. Makes WS mode more efficient, allowing switches.
 2. Make lightning strike more effective in WS mode. Right now unless you are geared well, the strike in WS even consumes mana. It is true for 99% of the levelers.
 3. Make lightning shield and earth shield considerably cheaper to enable switches.
 4. Add a passive mana regen ability to the shamans. *I like this the least since the beauty of the elemental shields is solving the mana/threat/defense problem within themselves.*

 **What I'd recommend:**
 1. Let's reduce the number of elemental shield orbs from 9 to 6 to encourage frequent switching.
 2. Let the talent make elemental shields considerably cheaper.
 3. A slight tweak with water shield mana regen numbers.
 3. Lightning strike under water shield being more effective.

In exchange I can easily see and accept indirect nerfs for the build.
For example making Stable Shields talent cost 5 TP instead of 3.

 **TLDR:** The elemental shields solve threat, defenses and mana regen if done properly, no need for the random threat modifiers.
