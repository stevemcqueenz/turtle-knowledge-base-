# Improved Raid Markers

## Post 77677 by Queenoona (Barrens Chat Casualty) — 2023-11-16T16:42:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=77677#p77677 | page 1 | era: pre-1.18.1 -->

Howdy Folks, I'll keep it short!

Many guilds already use the existing raid marker items that can currently be obtained.
<https://database.turtlecraft.gg/?item=51412>
<https://database.turtlecraft.gg/?item=51411>
<https://database.turtlecraft.gg/?item=51410>

These allow the spot under the user to be marked with a colored rune, I think that while this is helpful it could be made better if instead of appearing under the user it gave you a ground targeting reticle and allowed you to choose where to place it.

 ***A seperate but tangentially related suggestion:***
An additional suggestion would be to add some items into the game that allow this to be done that are purchasable via a vendor (It could be a good gold sink) you would just want to make sure those versions were only usable inside of instances or certain zones to prevent people spamming them in cities. Some recolors of the spell effect from the Elune Stone would work great for this purpose.

Cheers, Happy Raiding
