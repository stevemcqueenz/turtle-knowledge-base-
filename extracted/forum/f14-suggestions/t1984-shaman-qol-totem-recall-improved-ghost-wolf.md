# [Shaman] QoL: Totem Recall + Improved Ghost Wolf

## Post 11802 by Rytz (Barrens Chat Casualty) — 2021-08-24T17:00:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=11802#p11802 | page 1 | era: pre-1.18.1 -->

Hi:

I'm new to private servers (Turtle is my first) so I'm not sure what the engineering/technical limitations are when making custom changes to the game.

That said, a couple of quality-of-life changes from TBC would greatly enhance the Shaman experience without creating balance turbulence are:

[1]: Improved Ghost Wolf: insta-cast at full rank (2/2).  Each point would reduce cast time by 1.5 secs instead of 1.  Since GW can't be used indoors, IGW (even with a 1 second cast) seems worthless after getting a mount.

[2]: Totemic Recall: ability to recall totems.  While getting some mana back would be nice from the recall, just being able to actually remove my own totems would be huge.  It always seemed like an oversight in vanilla.

I understand that these are from TBC and that this is Vanilla+ but these are (in my opinion) small things that really do make the class more enjoyable.

Thanks.
