# Rogue ability idea

## Post 90109 by Akos1896 (Grandmaster of Forum PvP) — 2024-03-13T19:15:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=90109#p90109 | page 1 | era: pre-1.18.1 -->

Hey!
I'm thinking about a rogue ability which adds some added raid utility for them, besides kicks but without pumping any numbers.
Base idea is an in-favor utility which doesn't affect combat.
I'd add rogues an enhanced lockpicking ability from a raid (like the way hunters received tranquil shot).
Let's say each raid has a chest which contains one trash drop. You can open this chest if 2-3 rogues have this ability and they use it together on the chest.
Would be in-flavor for those thieves, wouldn't make them stronger in the regular sense and would motivate guilds and PUGs to have at least 2-3 rogues in the roster for utility.
Some raids have really good trash, too. Imagine an extra shot for those boots of pure thoughts during a BWL progression run.
