# Naming Conventions Rule

## Post 10086 by Derikom — 2021-04-12T06:20:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=10086#p10086 | page 1 | era: pre-1.18.1 -->

There has recently been a situation wherein a benign but far from lore-friendly name has been set for a rename by a GM and a discussion cropped up around how fair this ruling was as there is currently no written rule at all for what names are and are not appropriate for the server (although there is a guideline requesting names be lore-abiding).

Blatantly offensive or otherwise inappropriate names are something I think any reasonable person can agree as something that needs to be reported and changed but when more benign edge cases occur and there is no true rule to point to there will always be room for interpretation and disagreement that could otherwise be avoided while simultaneously creating a better and more visibly “fair” environment for both role players and those who merely wish to play the game as a game.

My exact suggestions for what names should be added to a new, clear rule about what kinds of names should be disallowed are as follows:
 -Any name that violates the above mentioned topics listed under Chat Abuse
 -Any name blatantly or obviously referencing real world celebrities or public figures
 -Any name referencing real world or popular culture activities, places, groups, or things that is found to be jarringly discrepant with the Warcraft universe by the Turtle-WoW moderation team (examples: Wallstbets, Memeforceone, Ragingboner)
