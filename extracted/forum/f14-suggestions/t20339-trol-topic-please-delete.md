> **Cosmico wrote: Thu Jul 17, 2025 5:24 am**
> In this thread we're going to merge our previous discussions about classes in order to provide a sustainable, lore friendly and possible update for turtle wow.

Hate to break it to you, but none of this constitutes a "possible update".

What you're doing is armchair gamedev. It's a fun exercise but unless you're going to building these things yourself, it is pointless (and actually misleading) to present it as something that's possible. TWoW developers have their own plans and lack the resources to implement any of these large systems that you have in mind, or the sweeping changes to code that it requires, even if they wanted to implement any of these ideas.

If you want to do gamedev, start small. Pick one thing that's actually attainable (usually a variant on something already existing), and flesh it out properly. Then attempt to create it yourself, and you'll gain an appreciation for how hard even the small things can be to achieve. And hey, if you stick with it, and actually deliver a finished piece of work, you'll have achieved more than all the "ideas guys" in the world could.

Because the ideas spam you're doing isn't really going to go anywhere.
