# Bug Report Option

## Post 24178 by Bricius — 2022-09-01T18:52:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=24178#p24178 | page 1 | era: pre-1.18.1 -->

Im not sure about the flexibility and ability to modify the Escape/Help Options Menu, but if possible you should add a "Report Bug" feature that puts in a basic bug report for a file/system to categorize. This way bugs that are numerous and problematic can be seen with how many people report them, versus those that should just try and deleted their WDB Folder first and have it fixed that way. It would also cut down on duplicate forum posts and GM Tickets over stuff they already know about.
