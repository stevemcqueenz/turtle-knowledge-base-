# More Torch Varieties

## Post 10034 by Himyname — 2021-04-09T09:55:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=10034#p10034 | page 1 | era: pre-1.18.1 -->

The dark mod makes a lot of sense but it's actually very limiting when you play a class that uses an off-hand (Shield or off hand weapon) or a two-hand weapon. So there can be new torches made.

Torch Placement: Places a torch within the area. Cheap to make and can make many in a stack. When placed anywhere lights up that area.
