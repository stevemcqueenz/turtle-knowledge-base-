# Mind Flay should be able to crit like Arcane Missiles

## Post 52675 by Psychoticgamer1 — 2023-07-09T04:34:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=52675#p52675 | page 1 | era: pre-1.18.1 -->

Mind Flay should be able to crit like Arcane Missiles. This would also fix the issue with the Wrath of Cenarius not procing off of mind flay. Spriest already pays the hybrid tax by not having a talent that increases crit damage, it is simply bad design on blizzards part to have Mind Flay coded in such a way that it is the only spell that is unable to crit due to it being considered an Aura/Debuff that is a channeled spell. I am arguing that mind flay is more like Arcane Missiles than it is blizzard, as it is single target and not AoE, it should be able to crit. The DPS increase is so small from this change that it won't make Spriest stand out in any substantial way, but it would be a nice bone to have thrown toward the Spriests.
