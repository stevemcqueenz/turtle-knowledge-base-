Have you looked into the addon [Lore](https://github.com/seacrabsam/Lore)? It lets you speak Eredun.
For example, if you want to speak in demonic type /language Demonic

Command | Description Code: Select all

```
/lore -- Show help and commands
/language <lang> -- Change your current language
/lore cycle -- Cycle to next language on your tablet
/lore list -- List available languages
/lore tablet <lang> -- Add/remove language from tablet
/lore skill <0-100> -- Set language mastery level
/lore effect <type> -- Set speech effects (stutter, hiss, lisp, cut, growl)
/lore interpreter <name> -- Add/remove interpreter
/lore to <channel> -- Send translation to party/raid/guild/none
/lore self on/off -- Toggle translation to yourself
/lore auto on/off -- Enable/disable auto-translation
/lore hide/show -- Hide or show Lore button
/lore lock/unlock -- Lock or unlock Lore button
/lore position <corner> -- Change tablet position
/lore version -- Show current Lore version
/lore default -- Reset all settings
/lore reset -- Reset translation settings
```
