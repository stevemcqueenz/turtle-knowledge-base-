# BWL upgrade to crafted items

## Post 171619 by Bezawit — 2026-03-21T12:15:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=171619#p171619 | page 1 | era: post-1.18.1 -->

I LOVE the idea of being able to upgrade crafted items with the drops in BWL! That said, I think it's a little too specific. Right now the functionality seems to be you can update 1 specific item with a rare drop chance. For example, we had one of these improvement items drop specifically for Chromatic Cloak from Dragonscale Leatherworking.

How I think it should work:

A more generalized approach should be taken. Instead of only being able to upgrade Chromatic Cloak from Dragonscale Leatherworking, I think the item should allow you to update any item from Dragonscale Leatherworking.
