# Sugesstion: Swappable Tier bonus sets.

## Post 87589 by Raxk — 2024-02-12T08:40:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=87589#p87589 | page 1 | era: pre-1.18.1 -->

Hello all!

How fun would be it if we could swap Tier bonus set between sets? I don't think it would break the game and would give that extra incentive to collect Set Bonus.

Example, i got Tier3 on my priest but i so much prefer the tier 2 bonus set, or even the Tier 1. It would be amazing if by using a specific item we could change the bonus between sets.

This is an idea that could make the game more interesting and could even make some different builds and combinations work. As Turtle is moving forward from Classic with new content, i think changes like this would be awesome. You could only choose a specific bonus after collecting all the pieces that would give the bonus.

Thank you for reading.
