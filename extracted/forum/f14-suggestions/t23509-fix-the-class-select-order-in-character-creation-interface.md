# Fix the class select order in character creation interface

## Post 164501 by Niny — 2026-01-06T06:08:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=164501#p164501 | page 1 | era: 1.18.1-announced-pre-release -->

In the classic client, the class order on the character creation screen is warrior, paladin, hunter, rogue, priest, shaman, mage, warlock, and druid.
But in Turtle WoW, the new class/race combos are basically just shoved to the end of the list. At a glance, you can tell these are private server additions, and it slightly breaks immersion, especially for a somewhat OCD player like me.

For custom races like High Elves, having pally placed all the way at the end instead of right after warrior also feels weird. It just doesn’t look right compared to the original client.

Since Tauren Priest and Dwarf Warlock are being added next patch, this feels like a perfect chance to clean up the ordering of all the added class combos. That small change would honestly push the quality to near perfect, especially since the issue with custom races not having unique starting attributes has already been fixed.

Thanks for all the hard work!
