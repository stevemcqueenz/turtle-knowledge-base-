# Parachute Cloak - jump off from the fly-mount

## Post 106756 by Ahlen (Barrens Chat Casualty) — 2024-11-06T21:25:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=106756#p106756 | page 1 | era: pre-1.18.1 -->

An idea that came to my mind could be a nice perk for engineers wearing a Parachute Cloak
<https://database.turtlecraft.gg/?item=10518>

When using fly master AND wearing a Parachute Cloak, allow a character to jump off the mount mid-flight using the item active function. Once used your character would fall from the fly mount with the slow fall feature enabled for the entire duration of the fall. This perk would be unique only for engineers.

An example:
 1. I take a fly master from Orgrimmar to Thunder Bluff
 2. I can jump off the mount mid-flight and land somewhere in the Barrens (e.g. on top of Walling Caverns)
 3. When I jump the slow-fall effect is enabled for the duration of the entire fall so that character is not getting killed in the process
 4. The regular active of the item remains unchanged (10-sec duration) for regular usage e.g. jumping from high heights.

You need to get engineering skills up to 245 to use it so I think it could be a nice reward for engineers :)
