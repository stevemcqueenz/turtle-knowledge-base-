# Atiesh Class Restrictions

## Post 15884 by Bayanni (Patch Note Conspiracy Theorist) — 2022-01-16T03:01:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=15884#p15884 | page 1 | era: pre-1.18.1 -->

When looking at the staff and its current iterations, some of them would work better for other classes and specs than the one each caster is allotted. Mages and Warlocks might prefer each other's versions, boomkins would certainly want the mage one, and priests could make use of any of the different ones, really. The limitations by class, if lifted, could allow the one legendary item casters get to be something all of them would want to use rather than just some.

A few different ideas:
 1. Remove the class restrictions on the staff

 2. Allow swapping between different versions of Atiesh similar to the Signet Ring of the Bronze Dragonflight quest, something that costs Naxx-only items like 15 Frozen Runes and maybe some armor scraps or argent dawn tokens

 3. Open the ability for all current owners to swap as a one-time-for-free since they didn't get a choice initially. Since the number of players with a completed staff is very low, I don't think this would require an NPC or anything, just some GM powers

The idea is a bit rough, but the sentiment is there. Any thoughts?
