Right, Balake, the char creation screen will require some reworking, but besides that, there are a lot of things on the client side  that would need testing regarding the new race/class combo: NPC dialogues, class trainers not recognizing new races, class quests not working correctly, class and racial skills to work smoothly together etc etc... And every new change to the client is a headache, since there is no source code of the client, so modifying it is not a piece of cake. Plus, every modification or reverting will require to redistribute the client again, and there are still (after 2 months of expansion) new people on #suppport with "the server is offline?" every other day.
And the devs already had a full mouth with the v1.15 features (remember the flood of bug reports after the expansion?), so I think yet another headache was not what they wanted, and adding a new classes to the races that still had less than 6 was a smart move: to test how the new classes will affect the game, and if something goes wrong, it's easier to revert the changes (because the client was not modified for 7+ classes)

I'm still eager to see hunters of every race available, I'm sure it's possible technically and not controversial lore-wise, yet I doubt it will happen before parts 2&3 of expansion go live
