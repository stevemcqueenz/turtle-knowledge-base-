# Melee hunter is good design but needs more buff

## Post 110824 by Tokoerpaaisen — 2024-12-01T18:45:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=110824#p110824 | page 1 | era: pre-1.18.1 -->

Currently leveling a melee hunter as my first twow char, it is well designed and interesting to play, the skill of spell timing/ queuing is very fun to play.
Not sure how raid goes even tho the log chart didnt look so well. Still loving the class. However there are more things could be done.
 1. Add a raid utility buff. Mm got aspect of hawk for rap buff, + true shot. Melee should have something equivalent, wolf + one extra melee buff, to boost dps and be useful in raid.
 2. Make dw viable. An easy fix is melee spell deals total weapon dmg+ spell bonus. Don’t need to be worried about if dw will be op. It still has to deal with dw penalties. So if ppl cannot  handle all the misses, they can always go 2h.
 3. Make some melee pets, it’s a general hunter thing. That only few pets are used. One take is make wolves 1.1 dmg modifer, so that ppl can bring them in raid. Kind of solved issue 1 too. And if you ever decide to do so, please make ghost howl tamable, that’s dream ever since 2004.
 4. It’s personal, please remove raventusk rep gear class restriction. Hunter gears have way worse stats than rogues… that is just too sad.
