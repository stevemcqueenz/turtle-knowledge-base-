# Swim speed items stacking?

## Post 25756 by Imonobor (Bug Report Enthusiast) — 2022-09-22T16:09:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=25756#p25756 | page 1 | era: pre-1.18.1 -->

I foolishly collected 4 of the +15% swimming speed items, only to find out that they do not stack.

So my suggestion is to either allow them to stack (+75% swimming speed would make it slightly faster than running on ground - 117% of normal run speed, not that broken) or to add "Doesn't stack with other swimming speed increases" to inform people that collecting more than one of these is counterproductive.

If stacking 5 times 75% is too much, nerf some of the items to 10%.
The items in question are:

Deep Striders (rare boots from BFD)
Azure Silk Belt (craftable from tailoring)
Ice Pearl of Kaneq'nuun (trinket from darkshore quest chain)
Rethress Tide Crest (trinket from Azshara quest chain)
Captain's Overcoat (rare leather chestpiece from Revered Bloodsail Bucaneers rep)

Murloc Flippers (craftable boots from Survival 75, they give only +5% swim speed) - I'm not sure if these stack with the rest of the items, let me know if they do.

## Post 42591 by Imonobor (Bug Report Enthusiast) — 2023-04-22T16:09:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=42591#p42591 | page 1 | era: pre-1.18.1 -->

I'll necro my own post to inform everyone that I tested this again today, and they now DO stack.
Using the same 4 +15% speed items as before achieves 108% of normal run speed while swimming (so slightly faster than running or the same if using "minor speed increase" enchant on boots). I am a happy swimmer now.

On a somewhat related note, the +3% mount speed trinkets stack too, not sure if they did previously. So with gloves enchant, mithril spurs and two trinkets you can get up to 180% mount speed from 160% (rare mount). Gotta go fast.
