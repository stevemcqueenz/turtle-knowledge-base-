# Loot Distribution

## Post 23787 by Tedris — 2022-08-28T08:38:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=23787#p23787 | page 1 | era: pre-1.18.1 -->

Pre Raid BIS loot needs more distribution across all dungeons.

Some dungeons are just not attractive at all for certain classes and specs because nothing relevant drops there for them, while other dungeons are too attractive for some because 6 items are dropping there that are pre raid BIS.

At the same time, items exist on the loot tables that almost all the time get disenchanted.

My suggestion would be, that the "most wanted" items (preRaid BIS and T0) can drop in multiple dungeons so that in every dungeon there is a reason for every class and spec to run it.

I am very open for other ideas to balance this out ofc!
