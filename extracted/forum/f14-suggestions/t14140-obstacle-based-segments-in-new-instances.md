# Obstacle-based segments in new instances

## Post 96382 by Schwrop — 2024-06-05T12:04:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=96382#p96382 | page 1 | era: pre-1.18.1 -->

Suggesting to add obstacle mechanics in new instances. Existing examples would be: death-on-touch slimes on Patchwerk's path, erupting zones like in Heigan encounter, Suppression room in BWL, etc.

A few ideas:
- An encounter which would be solely based on mechanics. For example a sort of slowly accelerating orb that goes from closest target to closest target, instakilling and resetting speed. Maybe a possibility to place conducts for it to bounce off and get depleted bit by bit. Or lead it to a specific object to destroy it or activate a boss. Probably combine with a boss encounter or else fresh 60s could do it.
OR: The orb could have HP and be killable. Ranged dps would have to be the only ones hitting it, while melees run around, redirecting it in a convenient way for the ranged.

- The classic stuff. A tunnel with spikes/saws

- Room with erupting squares, switching in a pattern
