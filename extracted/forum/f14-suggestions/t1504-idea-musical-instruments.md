# Idea: Musical Instruments!

## Post 8954 by Wakodoodle — 2021-01-07T14:46:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=8954#p8954 | page 1 | era: pre-1.18.1 -->

What if Turtle wow had musical instruments that you could use to play notes and if you're creative: Music!

Idea on how they work:
You either equipped as a weapon or maybe its own secondary profession; where you'll get a new set of abilities (kinda of like when you stealth, which could borrow that code for tweaking if needed), of about 8-9 new skills per instrument.

Each skill is a 0 sec cooldown that plays a sound, the higher the number, the higher the pitch.

If you ever want to stop playing music simply unequip the musical instrument (or if we're going with the secondary profession, just press the profession skill again) and you're back to normal!

Some idea could be: Flute, Lute, Drums, Horn and Harp.

I'm curious on what you all think, do you like it, dislike the idea? Have a better way it could work or maybe you want to tweak the idea? Let me know below what you think; i'm always open to constructive criticism!
