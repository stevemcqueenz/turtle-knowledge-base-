Nordranar is an old server now and, once you hit 60, there's no reason why anyone should run older content. Hell, I noticed that many just boost their alt with level 60s on /follow from level 1.

There should be a challenge for people who enjoy taking it slow to bond together. A challenge that forces you to, for example, only run for T1 gear when you have T0.5 gear. Getting a full set of T0.5 gear might be too difficult for many, so maybe wearing half a set would work?

Hell, the challenge could extend all the way from the first dungeon. Players should only be able to progress past one dungeon if they have run the one before "sufficiently" (Alliance might have trouble doing this for RFC).

Overall it would be a fun thing to do and a continuation of Slow and Steady / Exhaustion challenges.
