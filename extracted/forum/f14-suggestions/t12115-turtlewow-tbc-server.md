I would like to suggest a separate TBC server hosted by the turtleWoW team in same vein as the vanilla wow server, I would not suggest that the team creates new content for it as it would likely take resources away from the main turtle vanilla server, but perhaps a few minimal changes such as the blood elf paladin seals for alliance and some minor QOL. There are no TBC private servers out right now that live up to the quality of the TurtleWoW server and it would be amazing to be able to copy our Turtle characters over to TBC to experience that expansion (perhaps at a cost if copying characters between servers is prohibitive for the turtle team), the only reason I can see why achieving this could be difficult would be because of the new content/items added into turtles vanilla server and them transferring over might not be possible, I however would be interested in a TurtleTBC realm even if transfers would not be possible.
