# Implementation of low lvl sets starting at lvl +25

## Post 11286 by Jombo (Barrens Chat Casualty) — 2021-07-17T15:37:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=11286#p11286 | page 1 | era: pre-1.18.1 -->

Hello again everyone

I think sets are one of the most exciting features in Wow in terms of itemisation and completionism. While there are a few low level sets, I feel like vanilla left a lot to be desired in this regard. Therefore I figured we could discuss some set ideas for lower levels.
If you take a look at mobs in Wow dungeons, there are often mob types with cool looking sets that you unfortunately can't obtain yourself.

My short brainstorm would be:
Garments of the Scarlet Crusade (items lvl 32-38)
<https://database.turtlecraft.gg/?npc=4300> - Scarlet Wizard set (could be 5 items set: robe, belt, boots, shoulders, gloves). To fit the elite mobs that were it, the set should be a fire damage based set based around the same lvls as the current Scarlet mail set.

Gnomeregan Full Body Armor (name could be changed) (items lvl 25-29)
<https://classicdb.ch/?npc=6223>. A tanky set for mail users.

Stockades:
Brigand's Leather Armor: (lvl 25-29)
<https://classicdb.ch/?npc=1663>
Dps, leather armor

Uldaman:
Firehammer's Arsenal: (lvl 41-45)
<https://classicdb.ch/?npc=7291>
A shadow cloth set for lock or shadow priest

Adventurer's Hide (lvl 41-44)
Leather set based on
<https://classicdb.ch/?npc=11073>
I'd say healer/magic dps set.

Adventurer's Outfit (lvl 41-44)
a recoloured cloth version of the above to look more clothesque. For magic dmg and healing.

Guardsman's Arsenal (25-29)
<https://classicdb.ch/?npc=4278>
Mail armor, tanky

These were just a few ideas.
