# Totemic Slam should always land

## Post 124722 by Taralej90 (Barrens Chat Casualty) — 2025-03-31T18:35:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=124722#p124722 | page 1 | era: pre-1.18.1 -->

Discussing the viability of shaman tank on the T-WoW discord, two main issues came up: mana sustain and the lack of def CD. And since the patch that is about to land tomorrow will already address the mana issues by adding SS and LS to Elemental Focus, my post will talk mainly about the lack of def CD.

I realized that shaman tanks actually **DO** have a def CD - you just need to be a tauren to have access to it.

Totemic Slam is on a 1.5min cd, does laughable damage, and reduces ONE enemy's attack/cast speed by 25% for 8 seconds. That's practically a def cd... with one huge problem - it can miss.

My suggestion is, therefore:
 - make it so Totemic Slam is always guaranteed to land;
 - more radically, rework Totemic Slam to Pulverize (it uses the same icon and animation anyway...) so that it affects all surrounding targets and becomes useful vs more than just bosses.

Totemic Slam being able to fail is like your warrior refusing to use Shield Wall just because. And since the damage of Totemic Slam is so hilarious, turning it into an AoE will have 0.01 effect on shaman balance. But it will improve shaman AoE tanking significantly.

PS - shaman tank is viable, I know. I just want to address some pain points about it.
