It's a block value enchant, and his complaint is that paladins don't get much block value and it's an important stat for aoe tanking. (he said block dmg but he meant block value). He didn't mean return damage.

In fact, it was possible to enchant other people on classic with their class zg enchant but that was hotfixed.

![Image](https://i.gyazo.com/28255a3124d3566434d72a6d56aa7d0b.png)

The paladin one is almost the same except instead of 15 block value, it's 24 healing, which is not useful when tanking, so the warrior enchant is much better. Especially since paladins get +30% block value but the problem is that the actual list of items that have block value that paladins can wear is only a quarter of what warriors can get.

It's a very important stat that's in very short supply because of the lack of paladin tank gear. And it makes sense that paladins should be the one to get the most block value, not warriors, since block value is a stat specific for aoe tanking, but 0 paladin tier items give block value.
