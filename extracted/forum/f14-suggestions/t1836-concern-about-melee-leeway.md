# Concern about Melee Leeway

## Post 10913 by Fizzles — 2021-06-16T00:59:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=10913#p10913 | page 1 | era: pre-1.18.1 -->

Hello, I would like to point out a recent change named "A minimum distance for the 'auto attack facing check' has been implemented." I don't think implementing this new change is good because it makes melee classes in PvP unable to hit any moving targets in melee range, especially when these targets are mounted. Specifically, players with high ping to the server can avoid even getting hit by melee classes due to this change. Because of this change, it may encourage players to exploit by throttling their internet connection(intentionally increasing their ping) to gain an advantage against melee classes in PvP when this change is discovered to have an drastic effect on melee classes. Although Turtle WoW will always have a core emphasis on PvE content, it should have a secondary focus on PvP content due to the recent merge, so it should try to also take care of PvP content when possible. I don't think this new change should stay, rather it should be removed in order to stop encouraging malicious intent within the playerbase.
