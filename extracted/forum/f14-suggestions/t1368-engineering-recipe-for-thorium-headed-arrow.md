# Engineering Recipe for Thorium Headed Arrow

## Post 8347 by Emmanamak — 2020-11-02T21:24:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=8347#p8347 | page 1 | era: pre-1.18.1 -->

As it currently stands, there is only one way to procure [Thorium Headed Arrows](https://database.turtlecraft.gg/?item=18042):
exchanging them via a quest giver in [Orgrimmar](https://database.turtlecraft.gg/?quest=7341) or [Ironforge](https://database.turtlecraft.gg/?quest=7342).

I suggest implementing a recipe for Engineers to create the arrows themselves.

Not sure if this can be implemented, or what the best way to do so would be, but it would be a nice change that I don't think would break the game.

Perhaps the recipe could be a boss-drop or a drop from [Knot Thimblejack's Cache](https://database.turtlecraft.gg/?object=179501).
