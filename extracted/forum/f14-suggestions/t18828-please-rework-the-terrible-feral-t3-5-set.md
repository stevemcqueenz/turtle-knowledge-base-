# Please rework the terrible feral t3.5 set

## Post 128132 by Noephix (Patch Note Conspiracy Theorist) — 2025-04-23T13:53:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=128132#p128132 | page 1 | era: pre-1.18.1 -->

The set is terrible in it's current state. Too much item budget is wasted on undesirable stats like intellect and attack speed (cat is the spec that relies the least on autoattacks among physical dps, which means that attack speed is way overpriced for us).

What cat needs is strength and agility. Meanwhile currently the highest stat on a cat set is... Intellect.
Yep, you heard that right. 6/6 feral t3.5 has 126 intellect, 110 strenght and 117 agi. If you don't count the neck (which is extremely hard to get since it's the best item for basically everyone) - you get 126 int vs 102 agi and 90 str. It feels like a bad joke, but unfortunately it isn't.

T2 set was a tank set. t2.5 set was very mediocre and geared towards bleed build. t3 set was a tank set with 0 items usable for cat. t3.5 is, once again, a very bad set with bad items and set bonuses that take forever to trigger (so you won't see them on most fights at all). And if the cycle continues as it is - t4 is going to be a bear set, which makes cat druids completely shafted gear-wise for ***5 whole raid tiers in a row***.

The only usable t3.5 set items currently are neck (moderate upgrade from Nefarian's neck, wow, finally) and boots (a very small upgrade from Wormscale stompers that we got back in AQ40). Chest is worse than Swift Execution (non-setAQ40 drop, bug trio). Shoulders have too much hit to be useful (we don't have what to replace hit items with, remember?), so worse than AQ40 non-set drop once again. Leggings have neither str nor agi, which makes them WAY worse for cat druid than it would be for any other spec (cat has the best str/agi conversion to DPS amongst all specs, so we avoid flat AP and crit as much as possible).

Cat isn't overperforming even on melee-friendly single-target fights, doing medium damage. No need to hamper the spec any further with troll items that underperform compared to AQ40 loot, while every other spec gets upgrades to their Naxx gear. Give us more STR and AGI, less INT, no flat AP or attack speed.
