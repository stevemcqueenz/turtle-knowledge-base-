# About mount names

## Post 168924 by Cutcutcut — 2026-02-19T18:23:00Z

Hello, sorry to take up your time reading this post.

A few days ago while playing, I accidentally bought a mount twice. Before purchasing, I had already checked my spellbook to make sure the name matched the one in the shop, but it didn’t help.

It turns out the display name of the item in the shop is different from the name in the spellbook.

I took a break from the game for about half a year, so I don’t have a precise memory of this mount. I could only check whether I already owned it by comparing the item name with my spellbook.

I hope no one else ends up buying a duplicate mount like I did. I also hope the developers can fix this small issue when they have time in the future.

Thank you.
