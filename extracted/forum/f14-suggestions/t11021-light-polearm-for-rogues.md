# Light polearm for rogues

## Post 72191 by Xudo (Grandmaster of Forum PvP) — 2023-10-19T18:11:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=72191#p72191 | page 1 | era: pre-1.18.1 -->

Currently rogues are supposed to use two one-handed weapons in PvP and PvE.
There was an idea to allow them to use polearms. But it could make them too powerful. You still wouldn't able to use ambush with twohanded. Thats why I propose special weapon type.

Proposal is: introduce special very fast twohanded weapons.
Why is it fast? Because it has blades at the both ends of the pole. You hit with one side and ready to hit by the other side.

Example weapon of t1 level.
two-handed 120-180 damage, 60 DPS, speed 2.5, some stats

Brutality blade for reference: [https://www.wowhead.com/classic/item=18 ... lity-blade](https://www.wowhead.com/classic/item=18832/brutality-blade)
one-handed 90-168 damage, 51.6 DPS, speed 2.5, some stats.
Shadowstrike for reference: <https://www.wowhead.com/classic/item=17074/shadowstrike>
two-handed 147-221 damage, 59.35 DPS, speed 3.10, proc on hit.

What is fun with that?
It will change gearing priorities. You don't need 24% hit. You only need 8% like other twohander wielders.
You still can use combat spec and stack more AP.

It don't have to be rogue-exclusive. But it should not be available to hunters.
