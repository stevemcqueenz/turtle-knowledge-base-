# Mak'gora

## Post 116579 by Wolfmanpaulx — 2025-01-13T13:38:00Z

**Mak'Gora Arena**: Using WSG, AB, Stranglethorn or Dire Maul arenas to compete.

 **Level Brackets**
Matches are divided into the following level brackets:
- 60 vs 60
- 55-59
- 50-54
- 45-49
- 40-44
- 35-39
- 30-34
- 25-29
- 20-24
- 15-19
 **Item Level Difference Rules**

 **Maximum Threshold:**
The total allowed difference (including item level and level disparity) is capped at 128 ilvl.

 **Level Disparity Contribution:**
For each level difference between the higher-level player and the lower-level player:
- Add 15 ilvl to the difference.
- This level-based contribution is counted as part of the 128 ilvl cap.
 **Remaining Item Level Gap:**
Subtract the level disparity contribution from the 128 ilvl cap to calculate the remaining item level difference allowed.

 **Final Formula**
- **Level-Based Contribution:** Code: Select all

```
Level Gap Contribution = 15 × Level Difference
```
- **Remaining Item Level Difference:** Code: Select all

```
Remaining Ilvl Difference = 128 − Level Gap Contribution
```
- **Per Slot Adjustment:**
Divide the Remaining Ilvl Difference by 16 usable slots to determine the allowed ilvl per slot.
- **Threshold Cap:**
If Code: Select all

```
Level Gap Contribution > 128
```

, the match is invalid, as the level difference alone exceeds the cap.
 **Team Size:** 1v1, 2v2, 3v3, 5v5.

 **Honor Price:** Code: Select all

```
1000 * lvl + 3000 * team size (1, 2, 3, 5)
```

 **Extra Prices:** Customization, titles, mounts, cosmetics, and so on.

 **Death Rules:** Matches are lethal to ensure hardcore rules.

 **Spectator Mode:** Add spectators to foster community and allow players to bet honor on outcomes. (If no honors won, bet = 1000; with honors won, bet = 2 * bet. Lose = no honor gain.)
