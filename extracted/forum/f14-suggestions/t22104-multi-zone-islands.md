# Multi-Zone Islands

## Post 153345 by Kanto123 (Patch Note Conspiracy Theorist) — 2025-09-26T15:07:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=153345#p153345 | page 1 | era: pre-1.18.1 -->

I believe that in the future, islands added to the game that are more lore significant should be multi-zone; meaning one larger island composed of 2 or 3 zones.  This way, we can add multiple biomes to a single island, can add more depth to the storylines by having them stretch across all zones, and make the island relevant to a larger span of levels.
As well, the map might start looking odd with so many small islands of the same size around the edge of each continent.

Having a single zone small island for lore significant places might be a bit underwhelming when we get to important things such as:
Kul'Tiras
Zandalar
Northrend
