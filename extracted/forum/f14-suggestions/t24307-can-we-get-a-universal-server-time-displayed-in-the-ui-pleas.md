# Can we get a universal server time displayed in the UI please?

## Post 170929 by Sylvestro1 (Barrens Chat Casualty) — 2026-03-16T02:22:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=170929#p170929 | page 1 | era: 1.18.1-announced-pre-release -->

First off, I am aware that you need to type ".s info" to get actual server time, but here's the thing: MOST PEOPLE AREN'T (probably because the game makes no mention of this anywhere!), and this causes endless confusion and miscommunication because the server time that the UI displays is actually not the correct server time, WHICH MAKES NO SENSE!

I also get that this was originally designed to be some kind of RP thing to simulate time zones between Kalimdor and the Eastern Kingdoms in-game, and that's cute and all, but the whole point of server time is to have a universal time that people from different time zones can use to orient themselves and this is a very important feature that is completely and pointlessly obscured in Turtle WoW.

Ideally, this RP time should be removed entirely and replaced with actual server time, but if you are dead set on keeping it, please rename it to something else, like "Game" time and add another time called "Server" time that displays the actual server time. I'm sorry, but having the UI display a "Server" time that is not actual server time is incredibly stupid and it blows my mind that this has been in place for so long now.
