Hey

Would like to suggest you make a npc so we can queue premade vs premade games. Which doesn't interract with the normal game cycle. This feature does not have to give any honor/marks at all. It's just so we can have a way to meet eachother in a team vs team scenario. Like if there is beef between 2 guilds, lets settle our differences in there.

This is some of the best content you can have in vanilla, and we do not have the option to do this atm. We are really missing out here imo.

Some other ideas I can think of:

 - Make the new Rated/BR thing crossfaction, so it doesn't die out!
 - Clean up sunnyglade and give this bg new rewards so its worth doing.
 - Adjust the pvp loot so it alligns with current patch Tier 3.5
 - Give back the normal cooldown on Orb of deception. It's really immersion breaking that this item can be spammed.

I won't get much into balance and class changes, but a small observation is that Shamans and Priest are bit overtuned. The hybrid classes in general seem very strong compared to some of the other classes. Can it be because of the updated tier3 / 3.5 sets?

Cheers,
