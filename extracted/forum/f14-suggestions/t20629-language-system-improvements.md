# Language System Improvements

## Post 142754 by Dracarusggotham (Grandmaster of Forum PvP) — 2025-08-02T16:08:00Z

Language System Improvements

As you know, WoW has languages, each race has its own:

Alliance
Humans: Common
Dwarves: Dwarf
Gnomes: Gnomish
Night Elves: Darnassian
High Elves: Thalassian

Horde
Orcs: Orcish
Undead: Gutterspeak
Tauren: Taur-ahe
Trolls: Zandali
Goblins: Goblin

And generally, the two factions have a common language:
The Alliance uses Common, and the Horde uses Orcish, which was fine, but I think this system could be more useful for role-playing.
Considering Crossfaction, I came up with the idea of leaving Common for the Alliance and Horde, and having the Alliance acquire a new Human language: Aratorian.
Where does it come from? Well, I don't know if the language issue was already established before World of Warcraft, but I think the fact that the human language is called "Common" seems...anticlimactic. Given that all races have their own language, it makes the human language...not very RPG-friendly.

Therefore, a language called "Common" should be spoken by all races that are politically part of the Alliance or the Horde. Considering that both factions literally have relationships, and that some opposing races speak to each other, it's logical to think that there must be some common language in Azeroth, similar to how Spanish or English are generally spoken almost everywhere in the world.

So I came up with this:

Alliance:
Human: Common, Aratorian
Dwarf: Common Aratorian, Dwarf
Gnome: Common, Aratorian, Gnomish
Night Elf: Common, Aratorian, Darnassian
High Elf: Common, Aratorian, Thalassian

Horde:
Orc: Common, Orc
Undead: Common, Orc, Gutterspeak
Tauren: Common, Orc, Taur-Ahe
Troll: Common, Orc, Zandali
Goblin: Common, Orc, Goblin

How does it work?
Simple, Common allows you to communicate generally between factions, Orc and Aratorian allow you to communicate only within your faction (perfect for PvP), and the unique racial language allows you to communicate only with members of your race.

This increases the tactical, role-playing, and general communication possibilities in the world, allowing Crossfaction to exist with a role-playing base in terms of language, since currently the races do not use a particular language to communicate.
