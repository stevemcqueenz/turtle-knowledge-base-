# Increase the Quest Number Cap

## Post 6359 by Xero — 2020-06-14T12:28:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=6359#p6359 | page 1 | era: pre-1.18.1 -->

Given Turtle Wow's focus on enjoying questing as part of the levelling experience, as well as our low but seemingly growing population, it would be great if we could **increase the current limit of active quests from 20 to say 30 or 40**.

 **Limitations** of the current quest cap include:
 - **It discourages swapping between different zones while levelling** (including when grouping opportunities arise), because it may not be worthwhile abandoning a number of quests you plan to run in your current zone just so you can pick up some different quests in the other zone.
 - **It makes dungeons serve as 'road blocks' to a character's advancement**, because the multiple quests for each instance block-out normal zone quest spots until a group can be formed to run each instance.
 - **It discourages the completion of fun but lower level quests**, as these can often be the first to be abandoned when the quest log fills up.

I'm sure this change would also be especially useful to Turtle's hardcore players, though I'm not one of those.

Would such a change be possible, ideally on the server side?
