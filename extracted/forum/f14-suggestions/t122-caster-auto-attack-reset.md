# Caster auto attack reset

## Post 689 by Easygoes — 2018-10-10T03:44:00Z

Greetings,

Normally, starting, interrupting/cancel or finishing a cast (provided it has a cast timer) will reset the auto attack timer- this should be true for NPCs as well. Currently, an NPC will be able to auto attack between spell casts, making them considerably more deadly than intended.

In addition, players can cancel a cast immediately into an auto attack. The auto attack should go on CD in this case as well for the player.
