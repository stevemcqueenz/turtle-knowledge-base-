# More Illumination for Darker Nights

## Post 19988 by Philandros — 2022-07-14T04:21:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=19988#p19988 | page 1 | era: pre-1.18.1 -->

Is it possible to create more sources of illumination for the darker nights addon, such as enchants and spells? Surely you would think fiery enchant and holy/fire spells would create sources of light, but they do not. This makes it more difficult to be swapping out weapons just to see. Especially melee classes.

Or add some kind of illumination pet like a firefly, or an armor socket that creates a light source, like a mining helm, etc.

Playing in a kind of "nightmare mode" with darker nights, no nameplates, and hardcore mode is a really fun experience, even fun after hitting 60, but would be so much better if there were more sources for illumination. <3
