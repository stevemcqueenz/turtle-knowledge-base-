# Suggestion: Adding the Tier 1 & 2 Raid Set Recolors from TBC??

## Post 33185 by Syrathegreat (Patch Note Conspiracy Theorist) — 2023-01-26T13:49:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=33185#p33185 | page 1 | era: pre-1.18.1 -->

In TBC Blizz added recolours of the Classic Tier 1 and 2 sets as dungeon and raid drops, some of which are really interesting and add new aesthetics for the sets (my personal favourite being the silver and red Dragonstalker set for Hunters).

My proposal would be for Turtle to add questlines to obtain these recolours inspired by the Tier 0.5/Dungeon Set 2 sets. This could just be just for cosmetic rewards but I think a more interesting option would be to do similar to the 0.5s and maybe use this to help boost the specs with less gear support?

Furthermore this could help make running the old raids for Bindings, DFT, etc more evergreen and fulfilling since there would be more horizontal gear incentives. Plus maybe the questlines could lead you around more of the new Turtle content as bonus incentive!

Some examples of the recolours for those unfamiliar:

![image](https://wow.zamimg.com/images/transmogsets/big/404.jpg)![image](https://wow.zamimg.com/images/transmogsets/big/396.jpg)![image](https://wow.zamimg.com/images/transmogsets/big/398.jpg)
![image](https://wow.zamimg.com/images/transmogsets/big/390.jpg)![image](https://wow.zamimg.com/images/transmogsets/big/394.jpg)![image](https://wow.zamimg.com/images/transmogsets/big/393.jpg)

I think it would be great to have access to these sets even if just for transmog - they by their very nature fit in with the world of Classic! Plus I think implementing them like 0.5 would be entirely Blizzlike and could be super interesting! The only issue I can see (other than the work of course) would be that Warlock Tier 1 does not have a recolour (at least not implemented anyways), however from my understanding, creating new recolours is not too difficult and may be worthwhile.

Anyways what do you guys think? What questlines do you reckon could by interesting to explore? What set bonuses could be interesting if non-cosmetic?
