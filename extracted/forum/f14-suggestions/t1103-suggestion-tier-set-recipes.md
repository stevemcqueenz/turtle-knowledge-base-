# Suggestion: Tier Set Recipes

## Post 6394 by Heroclastus (Barrens Chat Casualty) — 2020-06-17T10:36:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=6394#p6394 | page 1 | era: pre-1.18.1 -->

Hello everyone,

I'm not a raiding playe (atm) but from own experience and from what I read here on the forums there seems to quite some discontent/discussing going on regarding raid loot. In T1 and T2 escpecially the randomness of drops can be quite frustrating when some items seem to drop everytime and some other seemingly never

I have had this idea for quite some time, so here goes:
Tier Sets don't drop directly from bosses but as trade recipes

Specifics:

- If a boss dropped e.g. Shoulders of Might he now drops a Schoulders of Might recipe instead which is BOE and allows to craft a lesser/discharged blue version (at 70-80% strength) of the said item--> discharged Shoulders of Might. Set bonusses would stay the same similar to the rare and epic pvp sets sharing bonusses. Look would be the same as the epic version of the items perhaps with faded-out color

- These blue item version would be crafted by the appopriate trade skills, e.g. all cloth stuff by tailoring etc. and would require items from the corresponding instance to craft, e.g. discharged Nightslayer Shoulders need core hound leather and would be BOE too, so could be traded to non-raid players if they pay enough :)

- In order to charge the items you need a BOP item from the raid which also drops from the bosses (e.g. Molten Essence from MC for T1or Dragon Essence from BWL for T2) so you still have to participate in the raid in order to get the epic version of the items

- in order to accomodate for other specs instances like AQ20 and ZG could drop BOP essences too (Scarab Essence, Troll Essence or similar) which then could turn the blue crafted items into T1 items tailored towards other specs (like feral and balance druid or enhance shaman etc.)

- also a possibility would be to make the blue crafted T1 items tradeable with the T0 set items (bracer for bracer etc.) so you could complete these sets easier and perhaps even do the t0,5 quests which sadly are rarely done

- this would basically take away the randomness of tier drops at the cost of more resources invested and allow to equip all raid members quite quickly with at least the blue items. This would also make trash farming better as- as long as you have the recipe - you can craft blue items.

More coming   smiling_turtle_head
