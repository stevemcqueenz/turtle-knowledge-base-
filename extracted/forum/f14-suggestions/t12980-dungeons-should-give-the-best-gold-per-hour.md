# Dungeons should give the best gold per hour

## Post 86920 by Sovietpremier — 2024-02-04T14:35:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=86920#p86920 | page 1 | era: pre-1.18.1 -->

I have a suggestion:

Make running dungeons the best way to farm gold. For example, every boss you kill, you get a buff that will increase the gold from the next boss(this buff will have to be different for dungeons with more bosses). That will incentivize people running dungeons even if they need no gear or loot.

Lastly, the more dungeons you run a day, the more that rate will increase. We can call that buff "Dungeoneering"

This is an MMO, solo farming gold should not be the best option. The best option for gold per hour should be forming groups and running dungeons with players. This will also cut down on bots(they dont work well in a team based environment)
This also has a cumulative effect, the better geared you are, the faster you can blow through dungeons and get gold. So your gear progression will make a difference. It makes sense, getting better gear requires more game time invested which should allow an increase in gold.
