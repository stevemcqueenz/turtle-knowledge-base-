# Make Earthquake usable in PvP

## Post 148701 by ForumGentleman (Patch Note Conspiracy Theorist) — 2025-08-27T16:32:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=148701#p148701 | page 1 | era: pre-1.18.1 -->

First I would like to thank the team for implementing Earthquake as the last elemental talent for shaman.

Also grats on the spell animation.

I am one of the people that has asked for earthquake for months so I like to think you implemented it based on my repeated suggestions.

That being said, one important element to it, in my opinion, is that it should have some PVP usability so that full elemental becomes a credible alternative to elemental/heal hybrid spec.

One suggestion to make it usable in pvp:
 - add a 1,5sec knockback effect at the END of the effect if the enemy is still in the aoe area.
(You could use the effect of the MC mace that has the same effect)

I would also reduce dmg to 10-15% to make up for that.

If the target is not slowed, in most cases, he would have time to leave the aoe area in time and not get  the knockback, so it would require a good setup to be strong in pvp ( for example, frost shock beforehands. Since frost shock has reduced range, you won't be able to do that combo at full range which is balanced)

Any thought?
