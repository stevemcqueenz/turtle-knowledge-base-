# Prompt password when removing adding 2FA

## Post 105838 by Icekronikforums — 2024-11-01T20:25:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=105838#p105838 | page 1 | era: pre-1.18.1 -->

I noticed while removing and adding 2FA due to security upgrades that TWoW account management did not prompt for a password to confirm either action. While may seem dubious the idea here is to avoid critical account changes if for instance authentication token leaks but not the password. By prompting the password you verify that user has all the necessary credentials to perform such action.
