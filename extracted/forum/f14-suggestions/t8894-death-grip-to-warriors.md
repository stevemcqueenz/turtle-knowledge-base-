Currently prot warriors are not very strong in PvP.
Proposal is: add talent to last row which adds spell which works like [Death Grip](https://wowpedia.fandom.com/wiki/Death_Grip) of death knight in WoTLK. or like Meat Hook of Pudge in DoTA.
This skill will improve warriors CC utility in PvP. It will help to protect healer from attackers and pull enemies from safe places.

UPD:
Skill should be named "Grappling hook". It should have cast time of 1 second, require melee weapon and battle stance. It should be like physical missile, which can be dodged. Rage cost is 10. Distance is 8-25yd 15 seconds cooldown shared with intercept.
