# Re-introduce the Naxxramas invasion as a semi-regular event

## Post 23644 by Azeron — 2022-08-27T01:13:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=23644#p23644 | page 1 | era: pre-1.18.1 -->

The scourge invasion from the Naxxramas release was an iconic event for those that experienced it, I personally enjoyed special bosses added to all of the dungeons throughout the game so it was a shame this event was restricted to such a short period of time.

Considering Naxxramas is always floating over the world being regularly attacked, it makes sense that every now and then the floating fortress would go on the offensive again!

These attacks could either be through a more custom event tied to number Naxxramas clears, enough so that you'd still not exactly see the event often, but perhaps faster than the more simple option of having the event run annually on the anniversary of the lauch of the raid.

Minor tweaks could be made to the event of course, for example more custom bosses could be added which are tied specifically to the Naxx event when it's active, either in the new custom dungeons or the old ones that never got any love. Considering the very long-term nature of the server it would be a cool event for the veterens as well as a nice experience for newer players whom may never have taken part in it at all.
