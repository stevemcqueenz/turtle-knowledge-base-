# Suggestion about solving ninja chest problem

## Post 83277 by Konakamasaru — 2024-01-01T04:23:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=83277#p83277 | page 1 | era: pre-1.18.1 -->

Some dungeons in the game give high reward chest, e.g. Dire Maul tribute, Stormwind Vault.

When use Group finder to form a group, player cant really tell if the teammate is trustable. So a small part of the population cant really do the /roll procedure, they would ninja loot the chest as fast as they see anything they need. Its not about nation race, both World and China channel have similar report.

Could I submit a suggestion that making those high reward chest in dungeon **becoming a mob**?

Because a mob's loot would go through rolling system, while a real chest wont. I think a mob with 5 HP would be fine: 1 hit to open the chest. The mob's outfit could be a chest, so same vision experience, but need 1 more hit to open the chest.

I not sure if its hard to implement this. I know some programming either so if I could get some directional hint, I might be able to help on implementation either.
