# More engaging world: Animal lairs

## Post 70939 by Xudo (Grandmaster of Forum PvP) — 2023-10-15T13:16:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=70939#p70939 | page 1 | era: pre-1.18.1 -->

Currently all locations are divided to subzones. Subzones are filled with mobs. There is no additional structure in the world.
Also we have a lot of quests like The hunt begins [https://www.wowhead.com/classic/quest=7 ... unt-begins](https://www.wowhead.com/classic/quest=747/the-hunt-begins)
Player is ordered to kill multiple Plainstriders nearby to collect meat and feathers. It is typical "henocidal" quest which is quite common in vanilla wow. I think this type of quests can be greatly improved.

Idea is to add some structure and meaning to NPC actions. Simplest one is: Animals should have a lairs.

Lair is a point in the world where you can find birds eggs, wolfs puppies, lion kittens, boar piglets etc.
It should be guarded with some strong female animal - matriarch.
New animals should spawn near the lair if matriarch is alive and roam away from lair in all (predefined) directions.

If matriarch is killed, then druid and hunter classes can come and revive matriarch. (by interacting with lair object or casting some class spell). Doing this grant experience and little reputation (50) with faction capital.
Killing matriarch decreases reputation (for 100) with faction capital.
Matriarch respawns on its own, but very slowly.

Matriarch and child animals should never be subject of quest. Hunting quest description should have special note "don't kill matriarch".
