# Wpvp towers suggestion - make it like Gurubashi Arena

## Post 98529 by Bjorn88 (Patch Note Conspiracy Theorist) — 2024-07-04T18:22:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=98529#p98529 | page 1 | era: pre-1.18.1 -->

Greetings,

Tel'abim player here. Just had an idea about the upcoming world pvp towers. Specifically, how to make them attractive for pvpers and not just offer a minor zone-wide pve boost like the EPL and Silithus towers did in Classic.

The idea is to basically copy the Gurubashi event:
 -Have the tower situated in the middle of a small designated zone (like the arena).
 -Every 24th hour/whatever time a chest spawns on top of the tower. Inside is a token.
 -Turn in twelve/whatever number of tokens for a reward.

For the reward, I'm thinking it should be a trinket with good pvp utility to make it worth the grind - perhaps a copy of Tidal Charm.

I think this could be a fun, worthwhile objective which would see steady activity. The Tel'abim community is really looking forward to these towers and with the upcoming class changes the server has such great potential to become a top pvp server. Seize the opportunity!

Turtle devs announced world buffs in those towers. In think their idea already very good. Reward is strong, but can be lost by accident death. It can also expire, so you need to return to this place from time to time. It is useful only in open world grinding. It means it is valuable for 5ppl dungeons and leveling. There is no "only one winner", so all willing people can participate. It is not BiS, so twink owners won't hunt for it. Lvl 60 players also won't hunt for this buff because they can't really use it.

Gurubashi design led to situation when item is needed for low level for BiS item, but you can eliminate competition by high level characters. How many "normal" people have you seen there?
