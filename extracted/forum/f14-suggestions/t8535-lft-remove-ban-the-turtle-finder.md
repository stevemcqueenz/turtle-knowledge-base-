# LFT: Remove/Ban the Turtle Finder

## Post 54930 by Iceweb — 2023-07-28T11:16:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=54930#p54930 | page 1 | era: pre-1.18.1 -->

Despite it's best intentions, LFT is doing more harm than good:

- If a HC character uses LFT, it bugs it out for everyone else who waited 4+ hours and they all have to start over.

- If you don't update the LFT addon often, it bugs it out.

- If LFT matches you with someone who doesn't update it often, it bugs out.

- It even randomly bugs out for no reason.

- No incentives for Tanks/Healers to queue = 4+ hour queues for dps.

- Excessive non-guaranteed queue times = No one anywhere near dungeon = 30+ minutes extra wait time after party forms = "Please add Summoning Stones" spam on suggestion forums indefinitely.

- Can't form groups manually as easily because everyone uses buggy LFT.

In Vanilla (and in Classic) it was much easier (and faster!!) to form groups just using a text channel.
We could even have dedicated LFG channels for English, Russian, and Chinese languages.

If the addon is too buggy to be reliable and creates the need for summoning stones, it should just be removed completely.
