# Voting for a feature/talent for each release

## Post 81735 by Akos1896 (Grandmaster of Forum PvP) — 2023-12-19T14:24:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=81735#p81735 | page 1 | era: pre-1.18.1 -->

Hey!
Just a general idea. I think it'd be cool if the playerbase were somewhat added to the changes the new releases make.
Let's say you plan a new release with a given set of changes and you guys make a poll about some topics (like adding 1-2 talents to a class, itemization etc). And the option voted by the most players would be added with the new release.
F.ex. you decide to add a new shaman totem and you have 4 candidates for it and you make a pull for the next release.
Or you ask the playerbase what to add: fury warr utility, boomkin damage buff or arcane mage extra utility.
