Just a little detail to improve  immersiveness ;
I think there should be a way for a class like fire mage to create basic campfire without the need of flint and tinder.

## Post 8117 by Roxanneflowers (Patch Note Conspiracy Theorist) — 2020-10-12T03:56:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=8117#p8117 | page 1 | era: pre-1.18.1 -->

Basically copy [Bright Campfire](https://database.turtlecraft.gg/?spell=7361) and make a Mage Only version of the item/spell that only requires [Simple Wood](https://database.turtlecraft.gg/?item=4470#reagent-for) and no [Flint and Tinder](https://database.turtlecraft.gg/?item=4471).

Except ... the generic purpose of the skill (and the spell) is to learn how to start (Bright) Campfires WITHOUT resorting to the use of magic in order to do so.  It's all about the MUNDANE skill of fire building, not about how to make fires using magic.

As for being Mage only ... Warlocks also have fire magic spells (Immolate and Scorch being the obvious mentions).  Hunters have fire traps.  Shamans have fire totems.  So I'm not seeing a compelling reason to limit this notion to being Mage only.
