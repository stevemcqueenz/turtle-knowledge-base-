# More Illusions for Roleplay

## Post 99295 by Moongirl — 2024-07-12T15:52:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=99295#p99295 | page 1 | era: pre-1.18.1 -->

Hi everyone? Did you happen to see people walk around as a furbolg? Perhaps a pandaren? I sure have, and I can just think of the amazing **roleplaying opportunities with the illusions**!

If you have a look in the Turtle WoW Database, there is actually a lot of Illusions. However, over half of them don't say where you can get them! I used to see people with a Dryad Illusion, but it is not in the donation shop! I wrote this post for more illusion suggestions, and to bring some old ones back!

 **Dryad**: Maybe since I have been wanting to roleplay with Night Elves, I would really like to hop around as a Dryad! This can easily be added as a quest chain reward somewhere.

 **Flame Druid Forms**: Not really an Illusion. During the Midsummer Beach Bash, a night elf druid was pretending to be a Druid of the Flame! I thought it was so cool! If you can add a molten kind of color glyph to the bear and cat forms, it will make those Druids happy.

 **Female Pandaren**: I like pandaren, a lot actually. I like how Turtle WoW has added a Pandaren Illusion... but there isn't a girl one (That I know of) I don't expect you to bring over the model from MoP, but maybe if you are want to make Pandaria in the game eventually anyway, you can pre-make the model...? (I realize that is harder than it sounds) I'd also say the same with worgen.

 **Dragonkin**: Turtle WoW has added the Green Dragonkin model, which is very cool (I'm not sure how it looks like. If someone can post a picture, maybe I'll take the time to level a character and roleplay as one!  happy_turtle_head  ) How about the other dragons? One can easily be a blue dragonkin mage and roleplay like that. I'm pretty sure there are 6 dragonflights, (including infinite) so there is a lot of choices there.

I just like the thought of roleplaying as something you cannot usually be. I want to be more connected into roleplaying myself, so these additions will make me, and I'm sure others, happy! Thank you for reading, and good luck on your journey!   smiling_turtle_head
