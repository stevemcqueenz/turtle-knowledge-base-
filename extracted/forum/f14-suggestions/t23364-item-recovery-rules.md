# Item Recovery Rules

## Post 163471 by Gladeshadow (Patch Note Conspiracy Theorist) — 2025-12-21T22:53:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=163471#p163471 | page 1 | era: 1.18.1-announced-pre-release -->

Hello. I got a nice response from a GM about item recovery.
I had deleted a green quest reward that I hoped to get recovered. The GM replied that only quest rewards of blue or purple colors are recoverable.

I see that this is some kind of reasoning, but it also seems arbitrary. A lot of green are superior to blues; color doesn't inherently mean better. Also, the item was a quest reward. So it terms of rarity, the actual rarity is just one. This is the same regardless of color rating.

I hope the rules can be revisited in the future. Yes, I know I made a mistake by deleting the item in the first place. And the current rules help some players in some cases. But the current rules also lack some in game rather than color based logic. To clarify, I think quest rewards as a whole should be recoverable. Personally, I really hope to be able to get my item back sometime.
