Hi there! Let's break it down to fully understand what we're discussing. LFT is not actually a game mechanic, but rather an addon. In other words, it's a partial solution and not a complete, ready-made one. It's important to keep in mind that the client we're using is from 2006, which means there may be several issues with how addons work on it.

Now, should we disable it? Probably not, as you can simply turn off the addon in the start menu and choose not to use it. As for any bugs, the author is responsible for fixing them. You can find the author's GitHub page here: <https://github.com/CosminPOP/LFT>. By reporting the bug to the author on GitHub, there's a chance that it will be addressed and fixed. Unfortunately, reporting bugs on the forum is not the appropriate channel for this.
I understand that you're particularly interested in this addon, but you would like to see the bugs resolved. It would be greatly appreciated if you could submit a bug report on GitHub. Thank you for your attention!
