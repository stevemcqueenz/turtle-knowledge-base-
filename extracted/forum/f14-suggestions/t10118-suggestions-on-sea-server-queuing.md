# Suggestions on SEA server queuing

## Post 66224 by Hanjjj — 2023-09-21T13:17:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=66224#p66224 | page 1 | era: pre-1.18.1 -->

Hello, TWOW administrators, TWOW has been very popular in Asia recently. Currently, SEA servers need to queue for about 8,000 people during peak hours. Can I adjust the queuing policy? For example, according to the donation amount, you can enter the game stage in advance. For example, you can queue for 20 euros from 1,000. 30 euros can be queued from 800. Of course, this is just an example. After all, the increase of servers and daily maintenance cost a lot of time and money. If I were a donor, I would probably be AFK if I saw that I needed to queue up for more than 8000 people after work every day. Ordinary players can hardly stick to this situation. But if I am a donor, I can enter the game to enjoy the game in advance, then in the next journey, I will be very likely to continue to donate. The same donation can help you set up more servers so that more people can enjoy TWOW. In my opinion, this is a very healthy virtuous circle. The more donors, the more servers, the more players. Go on like this. In addition, there are also some suggestions for you in the game. Can the refresh speed of task monsters be accelerated at the beginning of server opening. Some tasks may not be completed in two hours, and too many players need to kill these monsters, but these monsters are too few or refresh too slowly.
