# Priest Battle Bishop Itemization

## Post 95731 by Bartabus — 2024-05-26T20:28:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=95731#p95731 | page 1 | era: pre-1.18.1 -->

My request is that some more cloth-melee items be added to the game so that we can truly explore the potential of a Priest Battle Bishop meme-spec. No class changes or anything like that, just some more cloth with AP, crit, hit, maybe haste, etc. Turtle has already made the decision to return attack power to the priest's Inner Fire spell, and bizarrely added a few cloth items with melee/tank stats (namely the Battle Bishop's Robes from Karazhan Crypt), so it only feels natural that we play this out a bit more and let the players have some fun with it.

I think keeping it hybrid focused by also having some caster stats like MP5, intellect, and spirit would keep the items from being rolled on by those greedy glass-cannon fury warriors and is on theme with the existing items and priest abilities.

I'm not asking for any crazy class overhaul or tier items, just like 2-5 more cloth pieces and perhaps a couple of staves that could help fill out the rest of the "Battle Bishop's Robes" potential.

Sincerely,
A priest with melee aspirations
