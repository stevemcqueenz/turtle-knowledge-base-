# All Shadowlands Customizations in Unreal

## Post 116297 by Dracarusggotham (Grandmaster of Forum PvP) — 2025-01-12T05:11:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=116297#p116297 | page 1 | era: pre-1.18.1 -->

As you may know, the Unreal client will come with HD Models by default that can be changed to the Legacy version.

It would be great to have all the customizations that were added starting in Shadowlands, including some of the allied races like Void Elves along with Blood Elves (Void Elves basically received High Elf customizations and Blood Elf customizations have been added to Turtle via patches), Orcs and Mag'har Orcs and all the other base races.

It would greatly expand the customization system and role in the game through all those customizations.
