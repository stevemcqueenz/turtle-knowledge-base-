## Post 8495 by Roxanneflowers (Patch Note Conspiracy Theorist) — 2020-11-19T16:50:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=8495#p8495 | page 1 | era: pre-1.18.1 -->

Changing the spells themselves ... is an incredibly BAD idea ...

Creating quest line(s) for Druids that offer them better itemization that is KEYED to different forms ... in theory that would be a better option (assuming you can get over the hurdle of HOW to implement such a thing).

Closest thing I can think of would be to in effect leverage the Leatherworking Armor Patch system that's already functional.  The way you could structure the entire thing is with a repeatable Weekly Quest (akin to how Children's Week works now on Turtle WoW).  One of the rewards is an Armor Patch that offers a different effect than just mere +Armor (so same core item but with a different applied effect).  You'd then be able to "tailor" the quest rewards to offer Armor Patches that are designed for different Forms that only "work" exclusively in a particular Form.
- Caster Form
- Bear Form/Dire Bear Form
- Aquatic Form
- Cat Form
- Travel Form
- Moonkin Form
Because there are 4 Armor slots that accept Armor Patches, you'd be able to mix 'n' match which weekly quest reward Armor Patches go on which items ... and you'd presumably want to run the quest more than 4 times (built in replay value) for alternate sets of gear.

The quest itself would simply be the enabler to access the Form specific Armor Patches that essentially offer alternative "enchantment bonus" slot yields.

Theoretically, such a thing ought to be possible to encode (easy would be a different question...) but deciding on the appropriate balancing for such repeatable rewards would be extremely finicky and tricky to settle upon.  So ... possible ... but fraught with challenges.
