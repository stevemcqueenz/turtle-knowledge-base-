# Feature request: Gear randomizer

## Post 16503 by Overi — 2022-01-30T19:37:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=16503#p16503 | page 1 | era: pre-1.18.1 -->

Hello everyone!
I have a feature request "Gear randomizer".
Exchange your gear item with another random item. Especially usefull for Hardcore Mode players, which can't use AH and trade is very limited. Many good items go to waste. Maybe implement it only for Hardcore Mode.
For example, I killed elite mob and got mail gloves, but Im rogue so have no use for it.

How it works:
You give a green/blue item and "Gear Token" to an NPC and it gives you back another random item.
Each rare and rare-elites and dungeon bosses will drop 1 Gear Token in addition for other drop. (Maybe bosses should drop 1 Token for each player)

New item will be:
 - Same quality as input item (i.e. green to green, blue to blue)
 - Preferable same level as input item. If there are no such items - lower lvl up to -5 levels
 - NOT an item that drops from dungeon, raid, crafted from profession or quest reward

Possible random modes:
 1) Change armor class without changing slot. Recieved armor class should be your class or player-picked armor class.
 2) Change slot without changing armor class
 3) Change weapon type (i.e. sword to maces, etc)
 4) Change random stats (i.e. "... of the Bear" +2str +2stam to "... of the eagle +2int +2stam)

Notes:
 - You can't randomize items of epic or legendary quality
 - You can't randomize items which require level 60 to use
 - You can't randomize consumables and other items which can not be equipped
 - Randomized item becomes soulbound
 - Randomized item should not be better to avoid powercreep, that's why levels restrictions
 - Tokens are needed to not allow randomizer to completely replace trading and social interactions. It's a pleasant bonus, not an alternative to gearing.

Discuss is welcomed!
