# Boosting RP with games

## Post 79080 by Murci (Barrens Chat Casualty) — 2023-11-28T13:41:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=79080#p79080 | page 1 | era: pre-1.18.1 -->

In roleplaying would be helpful if we would have some items, what can help to resolve different scenes.
For now you have to be in a party in order to see if someone rolls. Also there could be some yes/ no matter what could be solved with flipping a coin.

Therefore I would suggest to implement a few items, what can be found in later patches also and a few more:

- -**Worn Troll Dice:** Rolls 2x 6 sided dices - Can be used for gambling events

 -**Decahedral Dwarven Dice:** Rolls 1x 100 sided dice - Would be a Roll what can others outside of party could see

 -**A 20 sided dice**: For RP

 -**Titanium Seal of Dalaran:** for flipping a coin, (Tail/Head) in order to decide something, or just for gambling reasons.

 -**Blackjack Table/Set**: An item or an NPC what is programmed to make the blackjack game. It would be also useful in a gambling evening.
 *Let's say once could put down a deck, for that it needs to be set how many people wants to play. For that one need to use a pop up window to select players. Then a  deck appears. By clicking on the deck itself one would get 2 cards. You will see it in the pop up window, so no one else is knowing your cards. When everyone got their cards, then clicking again on the deck would come up a pop up window where one could choose to not take more card or to take one more card. Message will appear to everyone when they decide to pull one more card or they stop pulling. So the game is ending when someone is going over 21, or they click to stop pulling cards. If someone log our to DC, then it should automaticly out of the game, and also the dealer should have the option to restart the game if someone is going AFK. At the end the dealer would read the cards in an automated message like: John is having Ace of Spades, 8 of Hearts. John have 19. Rolf has Ace of Hearts, 7 of Hearts, and 6 of Spades. Rolf has 24. John WINS with 19.*

Probably there are many ideas, some might be easier to do some not, some will make it some not.

So there are some ideas, what would spice up Roleplayying and gaming in general in my point of view. 3 of them are already implemented in different patches. The last one needs some effort for sure, on the other hand maybe its managable in some way.    maintenance_turtle

 **If you have other simple game ideas for implement I'm totally curious about them, hopfully we can add to this server something.**  smiling_turtle
