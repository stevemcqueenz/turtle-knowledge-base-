# An idea for mounts, noncombat pets and transmog and WHERE to dump all this junk

## Post 7880 by Seelya — 2020-09-30T20:56:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=7880#p7880 | page 1 | era: pre-1.18.1 -->

Hellows peeps.

Seelya, The Silvered here.

I was thinking about this and talked to Dragunovi and we agreed on this idea, that it will be interesting and nice to all of us, then I brought it a bit more far.

Mounts could be converted in a spell in a proper spellbook tab. This way the player would only need to click the spell to summon and could drag and drop it in any action bar. With that everybody would be FREE from having to dump lots of mounts and pets at the bank and have more space for more important things. And this would be a bit similar to what blizz did to it on retail.

The same could be done to noncombat pets and maybe even the real combat pets for hunters. This way they all we collectors would be able to have our collection of pets, noncombat pets and mounts.

And finaly this could be done to transmog items. How? First the code would check if the item model being copied FROM is in the spellbook, if not then will add it, if yes no more adding. This way the next time the player want to transmog he could pick the model from the spellbook instead from the bag. This will save space too since peeps like me who use transmog wont need to keep an entire set of gear in the bank but each time the transmog is done it will use the coin anyway, so the server keeps giving the coins, the transmog quests keep being usefull and peeps will have even more free space in their banks.

In the worst scenario the item at the spellbook could make appear in the bag a ZERO coin value item when clicked that would be used for the transmog and then thrown away as trash, this way peeps wont get money from it but it will still give the desire effect.

Comments?

Hugs to all.
