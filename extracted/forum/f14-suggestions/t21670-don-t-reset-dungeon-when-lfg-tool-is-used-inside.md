# Don't reset dungeon when LFG tool is used inside

## Post 150135 by Reomc1 — 2025-09-04T04:16:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=150135#p150135 | page 1 | era: pre-1.18.1 -->

This has happened twice to me already. 5 people join a dungeon group and start clearing, when one person leaves or is kicked. We then used the LFG tool and found a new player. For those who don't know, the LFG tool assigns lead randomly when a new player joins, even if there's 4 people in a group already. If the new player gets lead, a new instance ID is created and everyone inside is teleported out and the dungeon is reset. This means if you're in the middle of a 3 hour dungeon you lose all progress - essentially, you're forced to not use LFG tool in this situation. I propose that either lead isn't assigned randomly if 4 people are in a group already or no new instance ID is created.

From my understanding though, it's not supposed to change lead if you're inside the instance when it pops, which is supposed to prevent your group ID from changing and thus mismatching with the instance ID. That is how it worked previously, but perhaps they broke the addon by accident.
