# Rogues need some love

## Post 106608 by Makipa — 2024-11-06T00:13:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=106608#p106608 | page 1 | era: pre-1.18.1 -->

An honest review of the patch for rogues:
Good:
 1. Trash DPS for combat spec is improved
 2. Subtlety is a refreshing alternative to normal DPS builds
 3. Small buffs here and there

Negatives:
 1. Taste for Blood is way too hard to keep up, between Slice and Dice and Envenom there aren't enough points for Rupture too
 2. Poisons don't do enough damage to justify skipping  strong talents like dual-wield spec and 5% dagger crit
 3. No party/raid utility if you don't go subtlety
 4. It's impossible to consistently keep up Tricks of the Trade, there isn't enough energy/combo points
 5. No alternative tier sets to make new specs work/reinvigorate old specs
 6. Surprise Attack's DPE is lower than SS's/Backstab's which is pretty bad for a talent 5 rows into a tree
 7. Serrated Blades are so strong that it forces even sword rogues to for it which is annoying since Opportunity does nothing for them
 8. Subtlety PvE spec has a lot of underwhelming filler talents
 9. Blade Flurry got nerfed for bosses

Proposed solutions:
 1. Double the duration of Taste for Blood talent, that should make it an interesting alternative to going deep combat and viable for hybrid specs/ alternatively change it to something different
 2. Add a slight chance to get a combo point on poison application, that should also help with issue 1
 3. Small party buffs/raid debuffs for combat and assassination would alleviate this ong standing pressure point
 4. This just needs to be finetuned
 5. When you have time, please consider some making some alternative sets for rogues too
 6. Make SA and instant attack that deals 40-50% weapon damage, that would make it fun to use and to see it proc
 7. Move serrated blades to combat/assa tree, can also move rupture bonus to other talents
 8. Add more damage related talents, one such thing might be bringing back improved kidney shot that'll work on bosses. Another - make garrote usable out of stealth, it synergises well with other talents in the tree
 9. Make Blade Flurry give 15% haste

I've made some changes to talent trees that should make them much more enjoyable for rogue, letting assassination take dw spec talent, making some finishers give party buffs/raid debuffs and other proposed solutions. I obviously don't expect them to be impemented, but if you take some expiration from them it would be great

Can any dev please take a look at this? Rogues definitely want some love from the devs. Most changes are interesting, but largely we're still locked into same old combat spec in PvE, at least for now. We've also got no alternative sets/changes to existing sets (except t2 shoudlers and boots), it would be nice if we got something else. Right now, it's kinda hard to be excited about cc2 when other classes got alternative gearing and meaningful mechanics and we're still doing what we've always done

We are not asking to be overpowered just for meaningful adjustments
