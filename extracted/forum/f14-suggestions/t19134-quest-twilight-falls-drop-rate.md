# Quest: Twilight Falls - Drop rate

## Post 130011 by Gladeshadow (Patch Note Conspiracy Theorist) — 2025-05-07T10:57:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=130011#p130011 | page 1 | era: pre-1.18.1 -->

The quest Twilight Falls (Alliance) <https://database.turtlecraft.gg/?quest=1199> has had the issue since retail classic that the mobs drop the required pendants at a rate of 80%, as seen here <https://database.turtlecraft.gg/?item=5879>. While this isn't so much a problem in a cross faction group on Nordanaar, it's still a hassle on Tel'Abim when the entire party is on the quest. Usually, the dungeon will end and a person has 8/10 required pendants, requiring running the dungeon again for this quest exclusively.

I suggest upping the drop rate of the pendants to 100% so that each mob is guaranteed to drop a pendant if anyone is on the quest, thereby stopping bad luck and predictable statistics from making the quest so frustrating.
