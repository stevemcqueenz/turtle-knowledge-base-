# Shaman change ideas (tank)

## Post 109725 by Akos1896 (Grandmaster of Forum PvP) — 2024-11-24T20:25:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=109725#p109725 | page 1 | era: pre-1.18.1 -->

Hey!

I've written a similar thing earlier but continued testing on my shaman tank to have a broader pov on the topic.
I'd propose some easy-to-implement changes (and some harder ones I guess - future me) which don't break the build in any way but make them more complete. Right now warden shaman feels really good - but you have to ignore some small pain points to really appreciate it.
My philosophy is NOT 'I like this class so make it super OP' - what I propose here are changes to make the build more coherent.
Honestly, wanted to have a wider overview of the classes by now but tank shaman was so much fun I neglected testing almost anything else, my other chars are still waiting.

So, the things I'd like to mention:
 1. LS-ing with Earth shield
While mana shield LS and lightning shield LS both have a well-defined use, earth shield seems to lag behind. You just need the resources and the threat more than an overpriced mini-healing.
What I advise is to change earth shield's LS effect. When an orb procs when LSing with an Earth shield, give us a mitigation buff for 10 seconds instead. It would give a well-defined use of LS+earth shock and in some fights it would be worth it to maintain that overpriced shield.
Personally I'd give it spell damage mitigation specifically since tank shaman has some gimmicks in that area. If we add a spell-damage reduction LS buff here, those gimmicks would become consistent enough that warden shaman would find a niche among tanks (the spell damage-specialist).

 2. + blocked amount in talents
Palas have holy shield, prot warriors have the new shield slam + the good old shield block. What I'm saying: since shamans have no way to temporarily raise block chance, the + blocked amount becomes an unreliable mitigation buff. Asking for a +block chance ability is too much in my opinion, the other option is simpler. Please replace +blocked amount bonuses from talents to +defense.
I'm not fully bis but I'm quite geared and even then my def. is 365 (sure, it would have been 378 if I had Styleen). What I'm saying is: with really high-end gear your defense is still kinda low, you could easily add some to the talents instead of the +blocked amount.

 3. Itemization
It is something I only heard about because I was lucky enough to just swap in a T2,5 set, equip some good old mail items, enchant them all and call it a day.
But people see way fewer shaman tanks than they could have. From raid PoV, they have no tanking set after late 50s blues until T2,5 so a shaman relies on random mail tanking drops. Problem is the number of such drops. WOW by default has plate and leather tanking items but barely any non-custom items for mail. To enable consistent gearing, many more mail tanking items are needed after lvl 40 and an earlier raid set which is tanking-centric. ZG, AQ20, T1, you name it.

 4. Defensive CD
This is big and it does indeed raise the power level of the build. But I gotta be honest.
Shaman tank with a defensive CD = a fully viable build, fully able to tank any content.
Shaman tank without a defensive CD = a desperate measure to solve the LFT problem which gets obsolete by the time you hit lvl 60.
The build is one weird shield wall clone away from not being meme anymore.
