<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=10891#p10891 | page 1 | era: pre-1.18.1 -->

I don't think it is necessary to start implementing changes on the QoL that existed on Turtle WoW because there is no need to do so. For example, mail between characters is now changed to have a 1 hour duration instead of instant mail. If there is a real need to do these changes due to technical or hardware issues, then it would be nice if devs elaborate further on why they implemented these changes on QoL. I don't think devs should've moved with these changes without asking the community first on why.
