# QoL Suggestion: Improve Ground Targeting for Abilities

## Post 119266 by Khold93 — 2025-02-07T17:46:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=119266#p119266 | page 1 | era: pre-1.18.1 -->

I’d love to see an improvement to how ground-targeted abilities like Blizzard, Flamestrike, etc., are placed. Right now, you have to stop moving before clicking the ability just to see the placement indicator. Since the targeting circle is already visible once the ability is selected, why not allow it to appear while moving as well?

It would make the gameplay feel much smoother and less clunky without changing how the ability functions. I get that some players might prefer the current system because it's more old school. I thought I would suggest it as It's a small, but quite annoying mechanic if you ask me.
