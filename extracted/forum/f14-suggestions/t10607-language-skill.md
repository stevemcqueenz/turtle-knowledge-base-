> **Xudo wrote: Fri Oct 06, 2023 11:39 am**
> I still don't get why Forsaken language differs from human language. All forsaken were humans afterall.

It's an ancient out-of-universe mechanic thing. Originally, Forsaken spoke Common instead of Gutterspeak back during the WoW beta. It was removed because people used it for, to put it mildly, pretty impolite discussion in-between both factions. So Common was removed from the Forsaken and Gutterspeak was implemented.

Given Turtle WoW's baseline implementation of cross-faction communication, it's a bit of a moot point on the server.
