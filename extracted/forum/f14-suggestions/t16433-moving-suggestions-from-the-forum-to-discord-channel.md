# Moving suggestions from the forum to Discord channel

## Post 112062 by Ahlen (Barrens Chat Casualty) — 2024-12-10T14:01:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=112062#p112062 | page 1 | era: pre-1.18.1 -->

How about moving Suggestions from the forum to the Discord dedicated channel supporting only Threads so that we can create dedicated Threads and vote for suggestions? Many games have such a channel and I think it works pretty well, but only if a channel follows proper structure.

I feel like majority of these ideas are ignored, not commented by TurtleWoW administration, cannot be voted and don't have any states like "Won't be implemented" ,"To be considered" etc.
