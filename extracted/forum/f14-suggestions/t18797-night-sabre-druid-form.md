Here I am to bump this topic and add a bit more to it.

There are actually a few really novel models for all the sabers out there some of which are in the game that all match the actual theme here and are still in the "Classic" art style. I do know their models are out there but without a working model viewer, I can't find them myself so I can't even begin to say how easy any of these would be to create a glyph of (their names in the files are actually their URLs). But these very much do exist and are "roleplaying friendly" type models to add as glyph options.

Despite the frostsaber, saber, and nightsaber divide, I categorized them by faction. Kudos to Petopia for having the file names and appearances and already on saber models:

 **Night Elf Variants**
[Duskfang, Dustwallow Marsh (Patch 4.0+), a black nightsaber.](https://www.wow-petopia.com/images/skin_pix/ridingtigerskinblacknosaddle.jpg)
[Duskstalker, Teldrassil (Patch 1.11+), a spotted white nightsaber.](https://www.wow-petopia.com/images/skin_pix/ridingtigerskinsnownosaddle.jpg)
[Frostsaber, Winterspring, (Patch 1.11+, Rev 4.1+), a white tiger frostsaber.](https://www.wow-petopia.com/images/skin_pix/ridingtigerskinwhitenosaddle.jpg)
[Frostsaber Huntress, Winterspring, (Patch 1.11+, Rev 4.1+), a solid white (*not* albino) frostsaber.](https://www.wow-petopia.com/images/skin_pix/ridingtigerskinnostripewhitenosaddle.jpg)
[Shadowclaw, Darkshore, (Patch 1.11+, Rev 4.0+), a traditional black, silver striped nightsaber.](https://www.wow-petopia.com/images/skin_pix/ridingtigerskindarknosaddle.jpg)
["Spotted Black", an unused traditional black, silver spotted nightsaber.](https://www.wow-petopia.com/images/skin_pix/tigerskinblackspotted-frostsabre.jpg)

 **Horde Variants**
[Dreadsaber, Sholazar Basin (Patch 3.0+), a yellow, spotted saber.](https://www.wow-petopia.com/images/skin_pix/ridingtigerskinyellownosaddle.jpg)
["Araga", Hillsbrad Foothills*, an unused tan lion-like saber using an error model that only appears on the rare spawn "Araga" but is a mismapped model.](https://www.wow-petopia.com/images/skin_pix/lionessskingold-frostsabre.jpg)
["Golden Tan", an unused saber model in the game.](https://www.wow-petopia.com/images/skin_pix/tigerskinbrown-frostsabre.jpg)
["Golden", an unused saber model in the game.](https://www.wow-petopia.com/images/skin_pix/ridingtigerskingoldnosaddle.jpg)
["Red Tan", an unused saber model in the game.](https://www.wow-petopia.com/images/skin_pix/ridingtigerskinbrownnosaddle.jpg)

 **Special**
["Albino", an unused saber model in the game with completely unique eyes.](https://www.wow-petopia.com/images/skin_pix/ridingtigerskinalbino.jpg)
["White Striped Black", an unused saber model in the game; arguably canon but you never see an actual nightsaber in this pattern but see saber cats in it.](https://www.wow-petopia.com/images/skin_pix/tigerskinblackstriped-frostsabre.jpg)

The "revs" are all the revisions from later patches, which seems to be when their models changed from the old "tiger" model to the saber model. However, from the look of it, all of these are skins mapped over the pre-existing models! Meaning that most if not all these skins exist in game as is!

I would love even a handful of these added and would happily donate for even one of them, even just a black one for night elves and one of the tan ones for tauren!
