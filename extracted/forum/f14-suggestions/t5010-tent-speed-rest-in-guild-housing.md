A great way to give the survival profession some more use would be to implement a system where a crafted consumable gives the guild house fast rest for a while. Much like tents, this consumable should have a crafting cd, but I think the consumable should last longer while also having a longer cd. It would attract those who aren't in the guild to hang out

you could make it look like you're tending to a hearth, survivalists throw a special object onto it to keep the flame going. A guild whose bonfire is never lit is one that's dead
