# Teaching Others [In-Game skills]

## Post 28548 by Breidr (Barrens Chat Casualty) — 2022-11-06T00:44:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=28548#p28548 | page 1 | era: pre-1.18.1 -->

I was having a discussion with friends because we like to muse about things.  We come from a lot of backgrounds, including MUDs.  There are various MUDs, and I think a game called "Dream" or something, a very early MMO, that had teaching mechanics.

It got me thinking, could some form of this be put into Turtle WoW.  It may not be worth the dev time, I admit, because it might not add a lot to the game, but I wanted to put it out there.  Could we possibly teach each other things like weapon skills, or other universal things?  Maybe have a targeted channel spell that increases the targets weapon skill number?

I know this a very abstract concept, but I was hoping to spark some sort of discussion.

There is enough things you can teach others using words in chat. You can teach when to use which skill. And it is good that we use words in chat to communicate and socialize.

Training skills for gold is supposed as gold sink in the game. If you want to teach others, then you should make it like another gold sink. For example you should buy "teaching license".
Also teaching is hard. Your first students inevitably fail your study.
Teaching is best to be expressed as "skill", which you improve every time you get money from student and NOT teaching him. And you shouldn't be able to teach this student again.
