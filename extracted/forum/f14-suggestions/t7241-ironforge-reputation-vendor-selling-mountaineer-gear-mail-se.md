# Ironforge reputation vendor selling mountaineer gear (mail set)

## Post 45860 by Jannus — 2023-05-14T19:28:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=45860#p45860 | page 1 | era: pre-1.18.1 -->

The Ironforge reputation vendor seems to be selling a leather set that gives strength, agility and stamina.

My proposal and request is - could we have them also sell a mail set for the warriors and paladins that gives strength, stamina and intellect, which is based off the Mountaineer gear that dwarven patrols/guards wear in Loch Modan? It's such a unique looking set that you cannot acquire through normal means:

![Image](https://files.catbox.moe/30gezz.png)

We've seen it's possible to make a set that was previously inaccessible to the player characters available with the addition of the Sentinel set, tied to Darnassus rep.

Please consider adding a similar, Moutaineer set for us dwarves, which can be used for both transmogrification reasons (both by the RP and regular community) or just as leveling gear you can acquire through rep.

Thank you for your consideration!
