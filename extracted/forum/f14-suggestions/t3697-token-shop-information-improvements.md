# Token Shop Information Improvements

## Post 22281 by Dangeraaron10 — 2022-08-14T10:36:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=22281#p22281 | page 1 | era: pre-1.18.1 -->

I've noticed a lot of people asking questions about items bought from the ingame token store.  Notably things like what races/genders would be able to use a given skin, what illusions can and can't do (such as being used in combat, being able to use mounts, what cooldown it might have, if any), whether mounts and pets are account bound or character bound (a player on the Discord recently mentioned that the mount is "added to the ***player's*** mount collection" which could be misconstrued as account bound vs. character bound).

I suggest a thorough pass through the Token Shop, clearing up a few things and adding some important info on each item being sold.  These can get pretty pricy and players should be able to make more informed decisions.

 -Expand information on each item, notably skin compatibility (list which gender is available for each skin, as some skins can be used on both genders, while some being either male or female locked)
 -Clarify what Illusions can and can't do
 -Clarify what items are account bound and what are character bound (if everything is character bound, it should be made apparent)
