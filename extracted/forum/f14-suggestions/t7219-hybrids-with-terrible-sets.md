And being a hybrid on TWow feels nice but we want to have tier sets too!

## Post 45778 by Bob022 (Barrens Chat Casualty) — 2023-05-13T18:39:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=45778#p45778 | page 1 | era: pre-1.18.1 -->

The horrible single-purpose class sets are a lingering holdover from the period where Blizzard decided that anyone who had a heal spell should only ever be a healer and nothing else.  Then and now that was always bad design, no point having multiple talent paths if you're not going to support it.  I'm not sure the extant class sets need to be changed, however, in a custom setting like T-wow:  Custom itemization and, longer term, entirely new content permits the introduction of new sets suited to other roles.  That's already been done to a certain extent, and I presume the main limitation is more a factor of time/manpower than intent.
