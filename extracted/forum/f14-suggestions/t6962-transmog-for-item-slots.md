# Transmog for Item Slots

## Post 44031 by Runningjohnny — 2023-05-01T20:03:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=44031#p44031 | page 1 | era: pre-1.18.1 -->

Just like Retail, Turtle utilizes a system that lets you transmog items. In practice, transmog is more accessible in Retail because the currency used there is more easily acquired.

What with Turtle being a server that focuses on RP and PvE, and the journey through the game being what entices a lot of people, the current system with transmog being very costly and impractical during leveling does seem to run counter to the server philosophy.

I've no idea if it's possible or practical to implement transmoggable slots, or maybe make the saved outfits for which you've already paid a fee once free to apply again (maybe add a cost to outfit slots?), but it is nevertheless a topic I'd like to bring some attention to.
