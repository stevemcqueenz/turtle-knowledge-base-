# Remove/Reduce "XP Nerf" When Running With A 60.

## Post 129799 by kibble42 — 2025-05-06T00:36:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=129799#p129799 | page 1 | era: pre-1.18.1 -->

I love how many new quests and dungeons there are to do in Turtle WoW: Mysteries of Azeroth. Unfortunately, I have found myself in the unfortunate position of not being able to run several of the dungeons, because I reached the level cap. I'd like to do all of the dungeons and quests to complete the Lorekeeper achievement, but this has been extremely difficult because of the 'XP nerf' that comes from having a level 60 in tow.

It goes something like this: I spend an hour queued for the dungeon, finally get a group, then one or more people in the group complain that they don't want to run with a level 60 because it will hurt their XP. As someone who is just playing for fun, this is very frustrating. It would be awesome to be able to queue up for a dungeon, and have a group that wants to actually run the dungeon, instead of being told to leave.

Thanks for all of your hard work on this WoW server & thanks for considering my suggestion. Have a great day :-)
