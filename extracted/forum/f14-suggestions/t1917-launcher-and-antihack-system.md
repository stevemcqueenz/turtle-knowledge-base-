# Launcher and Antihack System

## Post 11463 by Kiun — 2021-07-29T18:27:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=11463#p11463 | page 1 | era: pre-1.18.1 -->

I've been playing Turtle WoW the last month and I'm impressed with the server. I really enjoy the new content and I'm happy with the stability of the server and the community. But something that makes me feel bad about playing old WoW versions private servers is the lack of segurity against modern hack software.

Here are my suggestions to fix this problem that I would like to see in this server to make it grow:

Make a custom launcher that could be used for updating the game files for future versions. This custom launcher would remain in background and it would check any hack injected into WoW. The launcher could be updated to include protection against future cheating software. And, to avoid players opening game without the Launcher-antihacking program, the launcher could connect directly to the server and if the server detects one player running WoW without it then disconnect the player. Other workaround would be make the launcher change the realmlist to a new different one automatically, and change it again when closing WoW (this one would be easier to passthrough by players just opening realmlist while WoW is running).

I hope these ideas reach the developers and that they have the necessary time and motivation to polish and carry them out.
