# Fair Naxxramas Token Distribution

## Post 135446 by Overberk — 2025-06-12T10:33:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=135446#p135446 | page 1 | era: pre-1.18.1 -->

This suggestion addresses the issue of fair class distribution among tokens in Naxxramas, a problem we are currently facing and one that undeniably exists.

In my opinion, which is shared by others, this appears to be an oversight or mistake. When the new T3 gear sets were introduced, the distribution of classes across tokens may not have been adequately considered. Currently, the token for Paladins, Shamans, Druids, and Hunters includes 10 gear sets, while the token for Warriors and Rogues contains only 3 gear sets.

As a result, these classes often need to rely heavily on luck and spend significantly more time obtaining their gear, especially for off-spec (OS) items if they wish to collect them.

The proposed solution is to move Paladins to the token with Warriors and Rogues so that all tokens have a more balanced number of gear sets. For instance, the Priest, Warlock, and Mage token already contains 6 gear sets, making it more evenly distributed.
