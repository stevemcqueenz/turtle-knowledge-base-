## Post 42286 by Kashchei — 2023-04-20T04:34:00Z

I don't think Heroic dungeons have been brought up enough on here and I think they're a great way to add some variety to level 60 end game without having to put in a massive amount of dev time.

Doing a Scarley Monastary mega dungeon (as it was originally intended) could be a great way to set up for the Scarlet Citadel release.

All the rare mobs from Graveyard could be added as actual bosses, the scarlet chest and boots could be added as BOP items from bosses.

Suddenly we have another entire level 60 mail gear set, a cool as fuck scaled Ravager which could be a fantastic item for any number of classes to chase after and a bunch of additional caster gear to throw into the mix.
