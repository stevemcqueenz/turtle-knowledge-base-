# Website - update the "rules" section

## Post 110927 by Ahlen (Barrens Chat Casualty) — 2024-12-02T13:50:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=110927#p110927 | page 1 | era: pre-1.18.1 -->

I was looking for information about the differences between both servers and it was not intuitive for me to look for them in the "Rules" section on the website. I even made a thread on the forum where I ask for information.
[viewtopic.php?t=16188](https://forum.turtlecraft.gg/viewtopic.php?t=16188)

I would like to suggest the following modifications to improve the user experience, especially for newcomers who are looking for information. I've already met a a few people who were not aware that Tel'Abim is a PvP Server and what are the differences. In my opinion it should be very important information from the server advertisement point of view.

 1. Rename the tab on the website from "Rules" to **"Servers & Rules"**
 2. Remove the two buttons where one is for Nordannar and the second for Telabim, instead put everything in one place but make a proper distinction between information

The first Header could be - **Game rules applicable to all servers**
 ---------------------------------------------------------------------------------------
Here you would explain all general rules, anty-cheat policy, RP policy etc. which is applicable for all servers

Cheating, botting, modifications & third-party programs, bug & exploit abuse
Interactions with staff
Naming rules for a RP server like Turtle WoW
and so on

The second Header could be - **Nordannar PVE server specification**
 ---------------------------------------------------------------------------------------
Here you would list all parameters relevant to Nordannar server for example:

Cross faction: Enabled
Cross Auction House: Enabled
Multiboxing: Allowed (explain rules for that specific server)
Characters from both factions can be created on the same account: Yes
PvP Flag: Manual (always enabled when in WarMode)
Default experience rate: x1

The third header could be - **Tel'Abim PVP server specification**
 ---------------------------------------------------------------------------------------
Here you would list all parameters relevant to Tel'Abim server, exp rate, available glyphs, PvP policy, multi-boxing policy, is it cross-faction etc.

Cross faction enabled: No
Cross Auction House enabled: No
Multiboxing: Not allowed (only allowed for summoning purposes)
Characters from both factions can be created on the same account: Yes
PvP Flag: Always enabled
Default experience rate: x2

I can prepare you some more detailed draft if you wish to.
