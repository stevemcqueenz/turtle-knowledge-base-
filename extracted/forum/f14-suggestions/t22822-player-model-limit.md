# Player Model Limit

## Post 159167 by Mille — 2025-11-11T08:49:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=159167#p159167 | page 1 | era: 1.18.1-announced-pre-release -->

Could you please implement an option in the graphics or gameplay settings that allows the user to select how many nearby player costumes, customizations, or unique avatars are rendered in full detail? Any players beyond this limit should display with a default or simplified appearance (such as a basic model or muted costume) to optimize performance in crowded areas. This feature is commonly known as an avatar culling or character display limiter, and is especially helpful for visibility and framerate in large gatherings.
