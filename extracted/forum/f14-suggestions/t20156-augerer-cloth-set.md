# Augerer Cloth Set

## Post 138104 by Gladeshadow (Patch Note Conspiracy Theorist) — 2025-07-04T21:46:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=138104#p138104 | page 1 | era: pre-1.18.1 -->

Hi!
I see by looking at old posts that the augerer set made by tailors has gone through some changes over the years. Unfortunately, one thing that seems to remain is that it requires mageweave to create.
This is a mid-30s set. Silk is the cloth that is had at that level. And the set is *good*, as in a passable set of green gear, but by no means spectacular. However, it would still be a fun milestone as a tailor. The diviner set, which **also** uses mageweave and the pillager set which uses runecloth logically follow as milestones.
The augerer set should be updated to use silk rather than mageweave in its construction. That would help to make the set obtainable at the appropriate level range and not obsolete by the time it can it can be made, when even another tailor crafted set surpasses it.
