# Are Character Model Changes Realistic?

## Post 137786 by Junvahlok — 2025-07-02T00:12:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=137786#p137786 | page 1 | era: pre-1.18.1 -->

I am wondering if model changes for characters are something the Turtle Team would ever consider? I have seen a number of topics about this sort of thing, but I'm not sure if the possibility is "maybe" or "never." By model change I mean a donation store purchase similar to skins, but changing the model instead of the texture.

The two that are top of my list would be High Elves using the old vanilla models (reskinned Night Elves) and Undead using the High Elf Dark Ranger skin. I'm mainly curious if this is even possible. Both are of course acknowledged canon (there is a Night Elf model Highborne in Thalassian Highlands & there's a Dark Ranger in Brill), so it's mainly a matter of technology, I am thinking. We can change the textures of course, but we also have druid glyphs changing character models as well. But of course the druid forms aren't having to equip items either.
