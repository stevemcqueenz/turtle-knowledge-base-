The purpose of raidscaling is accessibility. On a casual server, it allows certain guilds to have a chance at attempting raids. It was probably added to TWoW years ago because the population was so low. But even with the recent population surge, raiding is still a niche thing for this server so raidscaling is absolutely critical for the existing small guilds that attempt this kind of content.

Do I think raidscaling breaks immersion? Yes, but I'd argue it is a necessary evil for this server.

For the 'tier' idea, I think it's both immersion breaking and unnecessary for this server.
