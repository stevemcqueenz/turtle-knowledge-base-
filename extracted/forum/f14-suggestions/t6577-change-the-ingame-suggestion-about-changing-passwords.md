Yeah for sure. Regular password changes do not help.

What does help is using a different password for every service. Use something like <https://keepassxc.org/> or Firefox's built in password manager, keep a database of your passwords, and when adding a new service, you will ask this tool to generate new passwords like k0bEP8uPs6tNpwdJ. Personally this is what i do for every single website and service I use. If one gets compromised, all my others are safe.

But then it comes time to log into wow. And nobody is gonna remember how to type out k0bEP8uPs6tNpwdJ by hand. To fix this, you can use <https://github.com/Haaxor1689/turtle-autologin> or <https://github.com/hannesmann/AutoLogin/> which will remember your wow password like your web browsers do. Not encrypted on your computer, but that's a low security risk.
