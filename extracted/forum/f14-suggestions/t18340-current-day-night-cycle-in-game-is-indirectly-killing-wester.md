## Post 125337 by Syrathegreat (Patch Note Conspiracy Theorist) — 2025-04-03T21:28:00Z

Some important context.

So this is something that Epoch has worked on (reducing down to a 3hr day/night cycle). However we know from them that rather than a simple change in the code, this was instead a massive undertaking because the cycle is linked to the calendar and actual server time, as well as there being a pile of scripted events that key off the cycle:

'Importantly however, everyone sees the same time. The actual Server Time used for Calendar events and scheduling raids with other players remains at a constant. This is a complete decoupling of the "Server Time" and "Client Time", and was a massive undertaking that no other private server has implemented before as far as we know.

Throughout Azeroth there are a variety of events that some simply may not have seen. The rams of Amberstill Ranch being put to bed, Pyrewood Village becoming a haven of the Worgen during night, and NPC's throughout the world donning torches to light their way. '

As such, although this would definitely be nice, it's been proven an enormous task, that likely isn't worth the resources on an already active server like Turtle - never say never though; they did divide the continent times after all.
