Servers with limited content released feels like more fun than joining server what is already capped max-level/releasing raids only.

We all know Turtle creators have the skill and got already amazing databases for it.
Im old fart i admit that and Tel'Abim is way too fast for me and players like me.

So why wont we get "side-project" server with brackets?
 1-25
 25-40
 40-55
 55-58
 58-60

All of these brackets does have:
 1. Dungeons to gear.
 2. "Endgame"-questing areas.
 3. Dungeon what is possible to convert raid.
 4. "Endgame gear"
 5. Skills unlocked to be able make everything what needed.

Basicly 3 and 4 part would be littlebit custom, but we all know its doable.
It would be slower progression than Tel'Abim where guilds finally got team to run current endgame, next raid was released...

Basicly brackets could be already 2-4 months (This is why i called this "Side-project" server) what would allow people explore all the areas of each bracket, find BiS items and create epic PvP scene too!

Endgame raids/Dungeons would be slower launched and reputations would be more needed for minmaxing.
