# 1v1 Arena Mode: for Practice, Fun & Spectators!

## Post 157794 by Thaladar (Patch Note Conspiracy Theorist) — 2025-10-30T09:08:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=157794#p157794 | page 1 | era: 1.18.1-announced-pre-release -->

Wouldn’t it be awesome to have a small-scale 1v1 Arena system purely for fun and training, no honor or ranking involved?

The idea:

• You can queue solo for random opponents or pair with someone specific to spar against
• All cooldowns reset at the start so you can properly test builds, gear setups, or matchups
• Optional spectator mode where friends or guildmates can watch the duel live, imagine people cheering you on or studying class matchups together
• Maybe even some fun environments like small ring arenas such as Gurubashi or snowy dueling circles in Dun Morogh

This would make it easier for people to practice PvP mechanics or just enjoy some chill competitive fun without the grind.

What do you guys think? Would you use something like this?
