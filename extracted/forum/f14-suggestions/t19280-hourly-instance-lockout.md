# Hourly Instance Lockout

## Post 130910 by striketitan — 2025-05-13T23:33:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=130910#p130910 | page 1 | era: pre-1.18.1 -->

The current instance lockout is at 5 dungeons per hour. Currently this lockout is shared account wide. This means if you lockout one character and then switch to another, that character will also be locked out of instances. I don't know if there is an objective in not letting people farm instances by locking the account but if this was the case, instead of several characters in the same account, people can just make new accounts. As so I believe the instance lockout should be bound to a character in order for the other characters to still be playable.
