# Add SP and HP bows

## Post 109654 by Ayesha (Barrens Chat Casualty) — 2024-11-24T12:32:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=109654#p109654 | page 1 | era: pre-1.18.1 -->

Hi!

Now since NE priests can wield bows, I think it's about time there could be spellpower and healing power bows added into the game. Maybe they should not be as powerful as wands. So my idea was to add:

a 31.2 dmg per second +11 spellpower bow that has a 5% drop chance to drop either:
 - in BRD from Emperor Dagran Thaurissian (to incentivize healers to come and join BRD);
 - in Dire Maul from Illyana Ravenoak or summonable East boss Isalien (to be more RP friendly);

I understand that the 11 SP is a bit high for that level of item, but it should be compensated by being a small percent drop. Especially it makes sense for the summonable boss, since there are items like Scepter of Intermineble Focus that drop from a summon boss and are useful up until AQ40.

## Post 109659 by Eeeeeeeeeee — 2024-11-24T13:18:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=109659#p109659 | page 1 | era: pre-1.18.1 -->

Something to this effect is appropriate. The usual complaint I've heard is that SP bows clog loot tables with an item that only niche builds want. To combat this, I think there's 2 main options:

 1. Add SP bows as choices to certain quests, or create some quests which feature them.

 2. Add SP scaling to some or all bow on-hit procs, similar to what we already have for melee weapons.

I personally prefer the second option, it's arguably easier for the devs, but there is a small risk that it over incentives Hunters to take SP items. I think this is very unlikely in the current version of the game tho, and scaling on-hits are very fun imo.

I don't see much of any downside in the first option mechanically, but it seems like more work.

Either way, have some kind of SP bows has always been appropriate lore wise, and now it's especially appropriate mechanics wise.
