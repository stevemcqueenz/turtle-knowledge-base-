# Allow enchants to be removed from whites and greys

## Post 87720 by Tekamthi (Barrens Chat Casualty) — 2024-02-13T20:05:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=87720#p87720 | page 1 | era: pre-1.18.1 -->

Recently started vagrant glyph character.  Had a white item on alt that could've been useful, but it was my enchanting alt so I had used it to level up enchanting profession, before I knew the particulars of vagrant glyph, and before I had really conceived of making such a character.

Anyway seems to me, given this glyph's existence on this server, would be nice QoL adjustment if using disenchant skill on white item was possible but only to remove any enchants, without getting any materials back or destroying the item.  Would have negligible effect to the mainstream playerbase, and only occasionally useful as there aren't too many players enchanting white items, but will make the odd time you encounter one as vagrant player more enjoyable
