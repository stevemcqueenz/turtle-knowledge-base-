# Hardcore mode

## Post 9662 by Valendor — 2021-03-05T15:46:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=9662#p9662 | page 1 | era: pre-1.18.1 -->

I would like to have an option where you play hardcore. Click it and the following rules apply:

 - Once you die, you can not resurrect your character.
So, no resurrection from a healer, no self-resurrection for a Shaman and no Soulstone use for/from a warlock.
 - No using the Auction House.
 - Grouping is allowed, but only with players that are tagged as hardcore.
 - Trading is allowed,  but only with players that are tagged as hardcore.
 - Mail box is allowed,  but only with players that are tagged as hardcore.
 - Once you are tagged as hardcore, you can not untag it.
 - No rested XP. Even if you are staying for some time in an area where you would get rested XP.
