# Improve Auction House Organization & Search

## Post 170983 by Nuninho32 — 2026-03-16T14:27:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=170983#p170983 | page 1 | era: 1.18.1-announced-pre-release -->

Hi everyone,
I’d like to bring up an issue that many players run into regularly: the Auction House feels like a big mess right now. Finding items can be frustrating, listings are often cluttered, and searching for specific things takes much longer than it should.

A few problems I’ve personally noticed:

 -Too many duplicate listings with inconsistent pricing.
 -Difficult to quickly find specific items or compare prices.
 -Some categories feel poorly organized or overloaded.
 -Searching often returns long lists that are hard to navigate.

Because of this, using the Auction House can become more time-consuming than it needs to be.

My opinion on what can improve:

 - Add better filters (level range, item type, stack size, etc.).
 - Improve category organization so items are easier to browse.
 - Add clearer sorting options (price per item, total price, newest listings).
 - Consider tools that reduce spam listings or excessive duplicates.

The Auction House is a core part of the game’s economy, so improving its usability would make trading much smoother for everyone.
This is my person opinion on this topic, what about you ? have you had similar experiences, or do you have other ideas for improving it?
