# Changing Captain's Overcoat to cloth from leather.

## Post 130733 by Drfaustmd — 2025-05-12T16:13:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=130733#p130733 | page 1 | era: pre-1.18.1 -->

This suggestion concerns the Captain's Overcoat item from the Bloodsail buccaneers Rep. The Captain's Overcoat is one of seven items that increase swim speed by 15% and is the only one of these items not available to all classes, I think this is a great disservice to cloth wearers. Collecting all these items has been extremely fun and so has using the bonus they provide, it has practical gameplay uses and is fun for RP. It is for these reasons i think the Captain's Overcoat should be made available to all classes in one of the following ways.

The first and simplest way would be to simply change the Captain's Overcoat from leather to cloth thus making it available to everyone.

The second solution would be to make make versions of the item in cloth mail and plate, the bloodsail faction already features a similar reward at exalted where the head piece is offered in each armor type.

Thank you for your time and consideration of this suggestion.
