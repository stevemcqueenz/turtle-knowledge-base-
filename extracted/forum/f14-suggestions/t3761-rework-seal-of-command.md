# Rework Seal of Command

## Post 22678 by Kwayver (Barrens Chat Casualty) — 2022-08-17T08:40:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=22678#p22678 | page 1 | era: pre-1.18.1 -->

Change seal of command to the following:

[Commanders weapon]
 100/120/140/160/180/200 mana
Instant cast

Imbue the paladin's weapon, giving it a chance to perform an extra attack as holy damage. The extra attack can activate seals and weapon effects. lasts 5/10/15/20/25/30 minutes.

So this would function more or less like a weapon stone/oil. It provides ret paladins with access to "windfury" but without the need for a shamen to be in group.
Sanctified command could award 10/20% base cost of Weapon Command as mana to the group when it procs.

Seal of Command is a mostly dead seal. This change not only solves the problem of it's redundancy when compared to Seal of Righteousness, but makes ret paladins less dependant on shamens to be viable in group settings. The change to Sanctified Command would improve the paladin oom situation by allowing the mana proc to activate without the need to spend mana in doing so.
