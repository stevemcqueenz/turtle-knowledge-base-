# Talent calculator - minor enhancements

## Post 106319 by Ahlen (Barrens Chat Casualty) — 2024-11-04T14:21:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=106319#p106319 | page 1 | era: pre-1.18.1 -->

Hello there,

I would like to suggest three little enhancements to the talent calculator <https://talents.turtlecraft.gg/>

- Add the information about character level which is required to use the talent tree

- Implement a feature to allow us to Shift + Click on talent to put all possible talent points so that we don't have to manually click 5 times on it if 5 talents can be used

- Don't make talents that we haven't selected active, instead leave them grey but highlight that they can be learned
I prepared a screenshot with visualization but I don't know how to upload an attachment here on the forum.

This TBC talent calculator is a great example of how it could work, it shows all the relevant information and presents selected talent visually in a very nice way (talents which were not picked up stay grey):
<https://calculators.iradei.eu/talents/paladin>
