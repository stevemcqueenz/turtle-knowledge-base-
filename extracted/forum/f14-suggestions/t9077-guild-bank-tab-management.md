# Guild Bank Tab Management

## Post 58898 by Lemonlime — 2023-08-24T16:26:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=58898#p58898 | page 1 | era: pre-1.18.1 -->

So my guild just unlocked guild bank and to be honest I'm really disappointed in the control options for access.

How it is currently if my tests are accurate:
Each tab has 2 options

 * minimum rank to access that controls both withdrawals and deposits

 * Maximum number of withdrawals per week

The biggest problem is if you are ABOVE the minimum rank to access, you automatically get unlimited full access to that tab. This is super super super bad. This means that if I have a tab for Members that has a 3 withdraw limit and a tab for core raiders that has a 3 withdraw limit, I have no choice but to allow core raiders full unrestricted access to the member tab.

My suggestion would be to implement these options per tab:

Minimum Withdraw Rank: (controls who is allowed to withdraw, limited by withdraw limit, including all ranks above this one)

Minimum Deposit Rank: (allows this rank and higher to deposit)

Weekly Withdraw limit: (a number or unlimited)

Minimum Admin Rank: (override for withdraw limit to allow admins to manage inventory)

It's just very bad that I can't have more than one rank in my guild that has bank restrictions. My suggestion is just one way to fix this. You could also have settings per rank per tab.  Either way it definitely is not good how it is.
