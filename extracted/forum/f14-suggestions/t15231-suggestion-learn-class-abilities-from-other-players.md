# [Suggestion] Learn class abilities from other players

## Post 103520 by HippoMilo — 2024-10-18T01:16:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=103520#p103520 | page 1 | era: pre-1.18.1 -->

2 parts to this idea. Basically, players can recieve trainings from other players, of the same class, that are higher level and have a high skill level on that ability.

Part one: When a player uses an ability, they get point in it the same way you get skills point in swords when using sword, or defense when being hit. This can also make that ability be more efficient to make the game play more emersive.

Part two: If a player is at least 10 levels above when that skill can be learned and has at least x number of skill points on that ability, For example Blessing of Might Rank 1 requires players to be level 4 when they can learn it from a training. So if a player is at least level 14 and has at least 100 skill points in that skill, they can teach rank 1 Blessing of might to other players.

The reason I think this could be good is it would encourage the player collaboration of the game and create more oppurtunities for players to interact with each other.

The player still pays to learn this skill, this time to the other player, and they can always go an learn it at the trainer as well.

One way to make it cooler, it's like a little mini game where you have to react and press a button or click at the right time, or like for mages, draw on the screen as if moving a wand. and going through 3 levels that get harder and harder to learn the skill... making skill learning a ton more fun... With the mini games, I'd only ask other players to teach me a skill and wouldn't go to trainer.

(Thoughts please!)
