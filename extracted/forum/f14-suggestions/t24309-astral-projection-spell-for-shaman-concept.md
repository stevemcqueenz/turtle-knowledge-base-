# Astral projection spell for Shaman concept

## Post 170936 by Argonianfly — 2026-03-16T06:11:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=170936#p170936 | page 1 | era: 1.18.1-announced-pre-release -->

I've thought of an interesting idea for a shaman spell, a totem that you place which allows you to astrally project. When you place the totem down, you would enter a realm like the spirit realm when you die, but you would be able to see npcs and move around to scout out areas. Only other people who are dead or astrally projecting would be able to see you.
I think it seems really cool thematically, it fits with the WC3 spiritwalker vibe. The only problem really is a suppose Far Sight already fits that bill, this would be more similar to a warlock's Eye of Kilrog ability, so there'd have to be something to differentiate it from Far Sight.
