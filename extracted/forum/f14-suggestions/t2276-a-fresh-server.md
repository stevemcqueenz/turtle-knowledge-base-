I recently heard about Turtle WoW and i'm very excited about all the cool changes and additions the team has made already.

Especially a lot of class changes coming soon - super impressive stuff.

My question/suggestion is whether it has ever been considered to make a new completely fresh server with all the existing changes and additions in play from the beginning?

It would be crazy cool to have all class changes and a fresh new realm coming together.

So new players dont necessarily wanna start on the server as they feel like they are very 'behind'

I don't like it either. Imo, the attraction of the MMORPG genre is to see a real community, like when you come to a new neighbourhood.
