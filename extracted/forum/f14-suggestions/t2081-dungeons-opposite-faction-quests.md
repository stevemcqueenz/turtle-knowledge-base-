# Dungeons: opposite faction quests

## Post 12637 by Merikkinon (Patch Note Conspiracy Theorist) — 2021-09-26T21:56:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=12637#p12637 | page 1 | era: pre-1.18.1 -->

So we have a few Alliance quests in Darkshore for WC. That's pretty cool. It becomes more than a Horde dungeon re: quests.

For the sake of expanding the game and especially player/party integration, what if we had a couple quests for RFC (for Alliance) and a couple in Deadmines (for Horde)?

While that might be a nice way to get a little XP and an item or two, what it would especially do it boost the numbers of players doing those dungeons overall.

It seems like it would be a win-win. I think it is possible to come up with storylines why each faction would be in one of the dungeons.
