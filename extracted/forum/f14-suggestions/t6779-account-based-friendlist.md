# Account Based Friendlist

## Post 42706 by Rahon — 2023-04-23T12:20:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=42706#p42706 | page 1 | era: pre-1.18.1 -->

Hello fellow Turtle WoW enthusiasts,

In recent weeks, our server has been bustling with daily active players. A significant portion of these players engage in the challenging hard mode. At the time of this post, we've observed approximately 1,100 concurrent players in the "Still Alive" guild. One aspect that sets Turtles hard mode apart from Retail hard mode is the allowance of grouping and trading, making socialization a key component of the hardcore experience.

To enhance this unique experience, I'd like to initiate a discussion on the possibility of implementing an account-based friend list, rather than the character-based friend list currently present in vanilla WoW. This change could be particularly beneficial for hard mode players, as the death of a character would no longer result in the loss of meaningful connections established between players. In classic WoW, the friend list is already tied to the account, which, in my opinion, only enriches each player's experience.

I assume that implementing such a change would require significant alterations to fundamental systems. It would be great if a developer could provide some insight into the feasibility of this proposed modification.

Kind regards,
Rahon
