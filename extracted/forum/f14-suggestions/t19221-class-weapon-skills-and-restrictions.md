# Class Weapon Skills and Restrictions

## Post 130614 by Exonhun — 2025-05-11T16:31:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=130614#p130614 | page 1 | era: pre-1.18.1 -->

Hey.

In my opinion if a race have a bonus on some kind of weapon skill, they should start with that weapon skill already learned. It's only logical in my opinion.
Example: an Orc Rogue should start with all their basic weapon skills and with one-handed axes already learned.

The other part of my suggestion is this:
I played the whole Alah'Thalas as a Nelf Priest.
I earned Friendly reputation, yet I couldn't purchase the "Well-balanced Short Bow" from the Quartermaster.
(Since Nelf Priests can use bows, I thought I would get a good bow)
The reason is, it is class restricted. I think this is dumb.

Same with an Orc Rogue.
Tried to purchase "Rockslicer" (one-handed axe) from the Revantusk Trolls Quartermaster, but it is locked for Warriors and Hunters.

It would be nice to let all these class restrictions go, since it only complicates future class weapon skill modifications and locks us away from good early game items.
To add to all that, class-locking weapons is unecessairy since your character's skill restricts the usage of said weapon.
I belive these changes wouldn't take to much time from the developers.
AND it wouldn't mess with game balance in any way.
