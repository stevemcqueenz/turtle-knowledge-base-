# Add more options for ranged weapon enchants

## Post 84846 by Syg — 2024-01-15T23:12:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=84846#p84846 | page 1 | era: pre-1.18.1 -->

With Hyjal release the weapon skill book for bows came along and made it so that a big chunk of hunters no longer needed Biznick's, leaving us with Sniper Scope as the next best ranged weapon enchant, a level 40 enchant that reads <Attaches a permanent scope to a bow or gun that increases its damage by 7.>.

Very underwhelming if you ask me, I'd like to see some other modifiers that also fellow warriors and rogues could use, like some extra attack power, maybe a crit (might be too strong) and haste. Maybe rAP or mAP if restricting to a certain class is necessary.

I'd also like to mention not only scopes but any modifier, feel free to play with the engineer flavor.
