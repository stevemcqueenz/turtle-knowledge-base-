# About the fashion coin quest

## Post 141050 by Cutcutcut — 2025-07-24T02:57:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=141050#p141050 | page 1 | era: pre-1.18.1 -->

Hello, I completed my HC mode challenge a few days ago. When checking my character, I found that a quest seems to have an unreasonable design. The name of the quest is "Fashion Demands Sacrifices". It was originally a quest that allows repeated acquisition of Fashion Coins by submitting materials. The items required for this quest dynamically change with the change of level. Therefore, subjectively speaking, it should be the same as ordinary repeatable quests—after you complete it for the first time, it will count as 1 quest completion, and subsequent completions will not be counted. However, in reality, this quest seems to be designed as 6 separate quests. They have the same quest name and the same quest description, but when you complete it for the first time at each different level stage, it can be counted as a quest completion.

The result of this is that after my character reached the maximum level, I directly missed the completion counts of the quest in the first 5 stages, and all this is easy to be overlooked. What's worse, I suspect that a character's quest completion record is calculated based on various quest numbers to determine whether the quest is completed. In this case, my character, without my knowledge, seems to have lost the possibility of completing these quests again.

The energy I've invested in this character has probably been the maximum I can afford recently, so it's unlikely for me to start over in the short term. I just hope that such quests can be optimized to minimize irreparable mistakes or omissions while characters are completing certain challenges.
