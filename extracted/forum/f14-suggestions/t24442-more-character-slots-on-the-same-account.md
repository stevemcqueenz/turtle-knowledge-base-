# More character slots on the SAME account

## Post 171935 by Nuninho32 — 2026-03-23T12:57:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=171935#p171935 | page 1 | era: post-1.18.1 -->

Hey everyone,
I wanted to bring up something that’s been bothering me lately — character slots, specifically on a single account.
I’m a huge altaholic. Turtle WoW makes it really hard not to be — there are so many classes, builds, professions, and RP ideas to try out. The custom content just makes it worse (in a good way). I constantly get new ideas for characters I want to create.

The problem is: I’ve already hit the character limit.
And before anyone suggests it — I don’t want to create another account just to make more characters. I’d really prefer to keep everything on one account.
Right now it feels like I’m being forced to either, delete characters I’ve invested time into, or
stop creating new ones entirely.
Neither option feels great.

Would it be possible to increase the base number of character slots per account ?

I feel like this would really help players who enjoy exploring everything the server has to offer without fragmenting their characters across multiple accounts.
Any other altaholics out there feeling this pain? ![😄](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f604.svg)
