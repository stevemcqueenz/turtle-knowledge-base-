# Make Chastise off gcd

## Post 110475 by Erousagi — 2024-11-29T09:26:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=110475#p110475 | page 1 | era: pre-1.18.1 -->

As the new 31-capstone spell in the Disc tree, Chastise is in a very bad state right now in both PVP and PVE after the last nerf.

In PVP, it only CCs the target for 2 seconds, leaving only 0.5 seconds for the priest to cast something, which makes it basically unusable to set up any meaningful follow-up. It can still be used as an interrupt, but together with the range nerf, it's over-nerfed and needs some help.

In PVE, the haste buff is too insignificant and too short. Using it on a friendly target in most cases cannot make up for the 1.5 GCD cost unless it crits or the priest is wearing 3 pieces of T2.5. It becomes a toy to funnel the priest's DPS into one selected parser without increasing raid DPS.

Thus, I propose to make it an off-GCD spell like Judgement or Counterspell. This would solve both problems for PVP and PVE without changing any values. As an off-GCD spell, the priest can use the entire 2-second CC time to set up a follow-up. This is much fairer than the 0.5-second nonsense or the 5-second overpowered issue. Also, when used as an interrupt, it's much more flexible since it won't be locked by the GCD. For PVE, the priest no longer has the dilemma of sacrificing their own DPS or not. It can be weaved between casts or with an instant cast without losing a GCD, and can be used as a burst if you want to be selfish. The damage of it can be tuned down a little if it's too strong, but it's already low enough in my opinion.
