# Request for Full Resolution Support for Vertical Monitors (1080x1920 and others)

## Post 126418 by Tettr — 2025-04-11T08:32:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=126418#p126418 | page 1 | era: pre-1.18.1 -->

Hello Turtle WoW team and fellow adventurers!

I'd like to suggest adding proper support for vertical monitor resolutions, such as 1080x1920.

The Issue:
When I connect a second monitor in vertical (portrait) mode, the game limits the available resolutions — even for my main horizontal monitor. For example, my main monitor supports 1920x1080, but when a vertical one is connected, the highest option becomes 1600x1200.

This seems to happen because the game pulls supported resolutions from all connected displays, and vertical ones can interfere with proper detection.

Why It Matters:
Some players use vertical monitors for browsing, chat, or second-screen apps.

Others (like me) simply enjoy playing on unique setups or multitasking.

Streamers and creators often use multiple monitors in mixed orientations.

Suggestion:
Please consider improving how Turtle WoW detects and lists available screen resolutions — especially when vertical monitors are connected. Even a config file workaround or command line argument would be a huge help!

Thanks for your time and for keeping Turtle WoW alive and growing!
