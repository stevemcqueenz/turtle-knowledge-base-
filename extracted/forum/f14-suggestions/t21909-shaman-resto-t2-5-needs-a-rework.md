# Shaman Resto T2.5 needs a rework

## Post 151769 by Pikestain — 2025-09-15T07:40:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=151769#p151769 | page 1 | era: pre-1.18.1 -->

T2.5 resto shaman set bonuses are very underwhelming and underpowered compared to all other T2.5 set bonuses:

 3 set res on ankh with more mana - potentially useful once per hour (or perhaps 40mins if wasting talent points on ankh...) - not worth choosing set over off pieces

 5 set bonus further 5% redistributed damage from spirit link - potentially useful just 6 times per hour maximum - this isn't the worst for progression but very situational and I'd argue better as the 3 set bonus not the full 5 set bonus but also not worth choosing set bonus over off pieces

Suggestions that would be more useful and balanced compared to other T2.5 classes:

 -holy pala has 15% mana regen continued while casting maybe add some MP5 or the same regen as a set bonus
 -holy pala chance at increasing +healing on healing spells - maybe add the same for shaman but could make this specific to single target heals as I know there is appetite to encourage options other than chain heal
 -resto druid has healing touch cast time reduced - reducing healing wave cast time would be an idea
 -resto druid has a healing way like effect - maybe a 'increases the bonus of healing way by X% would be good'
 -holy priest has light well benefits - arguably worse than resto druid and holy pala by a long way but at least both set bonuses useable 6 times an hour (though I think probably still deserves a re-work if holy priests agree?)

Thank you for taking the time to read and everything you are doing with Turtle!
