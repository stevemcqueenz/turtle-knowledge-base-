# Dungeon-Set/Tier Token Rework

## Post 166023 by Azinforum — 2026-01-23T05:53:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=166023#p166023 | page 1 | era: 1.18.1-announced-pre-release -->

Please consider reworking the way players experience progression for gear that has, almost ubiquitously, been agreed as the best method. Tokenization.
If you, as the TWoW team, didn't agree with this, K40 would have individual class drops, not a token system.

 **Dungeon-set/Tier1/Tier2**
There is a lot of really cool gear that you never get to use or experience, because you simply never see it. 20 MC runs and no Hunter Chest. 15 BWL and no Rogue Shoulders. 25 Strat UD and no Lightforge pants. This is not a fun or engaging form of experiencing the game. By the time you receive this gear you will have completely and utterly surpassed it.
- Rework Dungeon-set/T1/T2 to use the same token split as AQ40 Tokens

- Make Dungeon Sets use Skin of Shadow, Frayed Abomination, etc to craft

- Make Tier1/Tier2 use Fiery Core, Lava Core, etc to fix the damage that Molten Caches have done

This would make running Dungeons/MC/BWL *feel* good.
Running MC with 30 people to DE a double warlock drop for the one T2 warlock in your raid feels really bad.

 **Naxxramas**
As highlighted here, please redo the distribution of tokens
[viewtopic.php?t=23575](https://forum.turtlecraft.gg/viewtopic.php?t=23575)
- Warrior/Rogue > Warrior/Rogue/Paladin
