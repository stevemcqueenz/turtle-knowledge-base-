# Hardcore Shadowforge Key

## Post 126197 by Goldenspatula — 2025-04-09T18:25:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=126197#p126197 | page 1 | era: pre-1.18.1 -->

Hello,
as you know, there's a quest called [Dark Iron Legacy](https://database.turtlecraft.gg/?quest=3801url) from [Franclorn Forgewright](https://database.turtlecraft.gg/?npc=8888url) which grants you access to the [Shadowforge Key](https://database.turtlecraft.gg/?item=11000url). This key is very nice for those doing several runs and allows for a nice skip (given the absurd size of the dungeon, this is very welcome.) However, HC players are locked out from it since you need to be in ghost form (dead=bad) to interact with this NPC.

My suggestion would be to either make the NPC permanently visible to all, or add the additional step of using the T.0 item ([Extra-Dimensional Ghost Revealer](https://database.turtlecraft.gg/?item=22115url)) to see him while still being alive. Please, add this! If you agree, give this post some visibility as I believe this could be added in a weekly patch without much fuss.

EDIT: To make it more fun, you could make it visible with: Ghost Revealer and/or the [Detect Greater Invisibility](https://database.turtlecraft.gg/?spell=11743) spell for flavor, and this could apply to normie too.
