# Request: Upgrade Path from 28-Slot to 36-Slot Bags in the donation Store

## Post 146697 by Chunjied — 2025-08-18T07:59:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=146697#p146697 | page 1 | era: pre-1.18.1 -->

Could you please add an in-store “upgrade” option that lets us turn an existing 28-slot bag into a 36-slot bag by paying the difference, instead of having to trash the old one?
I’m a Paladin who loves the class precisely because I can fill any role—tank, healer, DPS, fire-res tank, etc. Unfortunately, that also means I carry a mountain of gear. I already bought the Mobile Banking perk and unlocked every single bank slot. My current setup is five 36-slot bags and five 28-slot bags, but I’m still running out of space.
The problem is that my 28-slot bags are now past the refund window. If I simply buy new 36-slot bags, those 28-slotters become vendor trash. An upgrade service—paying just the difference in price—would solve this neatly.
Every hybrid I know—especially Druids and Paladins—is in the same boat. We’d really appreciate it if the donation Store could offer this small but meaningful quality-of-life feature.If this feature were added, I’m sure many of us would jump at the chance to purchase it.
Thank you for considering it!
