# QOlL change Suggestion: increased buff durations for certain classes

## Post 23621 by Snoodydood (Patch Note Conspiracy Theorist) — 2022-08-26T22:21:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=23621#p23621 | page 1 | era: pre-1.18.1 -->

I think it would be a overall good idea to increase certain buff durations that were extremely short in vanilla just because people often forget to rebuff while in groups or while distracted while questing.
I don't think think it would have any negative impact toward the game as a whole and would just be a small convenient change. The abilities in particular I'm talking about are; Shouts for warriors, which only last a measly 2 minutes. weapon enchants for shamans which are a longer 5 minutes, but still inconvenient to remember re-casting while in instances and raids. and Paladin blessings for the same reason. This is just a small QOL idea that's not even going as far as some other minor changes already in this client so I think it's fair to consider.
