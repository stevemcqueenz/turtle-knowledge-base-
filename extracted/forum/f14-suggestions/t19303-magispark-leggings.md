# Magispark Leggings

## Post 131139 by Tess322 — 2025-05-14T23:51:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=131139#p131139 | page 1 | era: pre-1.18.1 -->

I would like to make a suggestion regarding the Magispark Leggings item.

As it stands the item is pretty much usable only in AoE sets for Mages and Priest, you could maybe make an argument for SpellRet.

To expand the usage of the item there could be a small change made to accommodate Disc priest.

From second hand testing the item seems to only trigger the spell power effect when the character is moving without any grace period. If the buff would persist for 0.5/1s it would allow Disc priests to utilize Searing Light procs with some consistency - cast smite move slightly and cast instant smite if triggered.

Currently it is possible to do so however it is greatly affected by lag, this small adjustment would make it more reliable and would not affect any other spec.

You could probably make an argument of a bad gameplay but I would say the Pandoras box has already been opened and this would make it less frustrating to play with.
