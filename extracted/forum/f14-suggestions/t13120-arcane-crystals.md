# Arcane Crystals

## Post 87974 by Thoriamuss — 2024-02-16T19:26:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=87974#p87974 | page 1 | era: pre-1.18.1 -->

Food for thought:  Each Thorium node small and rich drop 1 thorium dust per node.  After you gather x10 thorium dust you can have an alchemist combine it with x20 Golden Sansam to create a thorium gem.  With the thorium gem you can have a tailor combine it with x10 bolts of runecloth to create a thorium crystal.  Then have a blacksmith combine it with x10 Iron and x20 Truesilver to create an arcane bar.  Then as a miner you take the arcane bar and combine it with x20 thorium ore to create x1 arcane crystal.

This creates a need for Gold SanSam which is desperately needed.  And creates a path to obtain an arcane crystal without having to rely only on RNG with every single node.

Something similar can be done with Black Lotus to help increase it's obtainability w/o worrying about flooding the market.
