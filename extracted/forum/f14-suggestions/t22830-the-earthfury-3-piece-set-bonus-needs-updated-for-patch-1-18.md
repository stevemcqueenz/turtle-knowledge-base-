# The Earthfury 3-piece Set Bonus Needs Updated for Patch 1.18

## Post 159206 by dioaffo1 — 2025-11-11T16:27:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=159206#p159206 | page 1 | era: 1.18.1-announced-pre-release -->

The 3-piece shaman healing set bonus for The Earthfury is still, "(3) Set: The radius of your totems that affect friendly targets is increased to 30 yd."

As of Patch 1.18, the baseline radius of all totems affecting friendly targets has been expanded to 30 yards. There was a redundant talent in the Restoration tree that was reworked to account for this, but the Tier 1 set bonus has not been updated yet. Please consider updating this set in a future patch or itemization update.
