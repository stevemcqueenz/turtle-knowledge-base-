Yeah for World PvP : raid on a capital, kill the leader with a timer. With the pve system it is really chill : the "attacked" faction can spectate the event in game without danger.

Or : plan an AV event (just needs scheduling and communication). I'm sure it would attract a lot of players, because this BG is very uncommon on the server.

Strat UD is perhaps the best bet to organize a dungeon speedrun race event. Because it is very quick and already has an ingame timer (45min) : it has been designed as a speedrunable content by the devs.
Quick run (less than 1 hour) means more teams can participate and it is more digestable for the audience spectating the event.

For raid, the same logic means BWL is more interesting than MC, because it can be speedrunned quicker. BWL all time record is under 20min. It was quite usual on classic to see it under 1h, 1h30 max, even with pug groups.
