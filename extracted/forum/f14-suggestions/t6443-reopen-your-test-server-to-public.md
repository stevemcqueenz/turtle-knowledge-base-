# Reopen your Test Server to Public

## Post 40608 by Fizzler (Patch Note Conspiracy Theorist) — 2023-04-07T00:50:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=40608#p40608 | page 1 | era: pre-1.18.1 -->

I remember that there was a test server back then open to test certain features to fine tune them, like certain custom boss encounters. It is locked from public view, but I want devs to reconsider this since it will help them find problems with their boss encounters and other new content released. This also will help devs fine tune class balance by enabling players to test certain abilities before launch. I do not think immersion in "hiding" new features from other players is important when future custom content is shown to be broken at launch, such as when mobs have no loot tables in Black Morass or when fishing pools do not exist in certain custom islands.

Thanks
