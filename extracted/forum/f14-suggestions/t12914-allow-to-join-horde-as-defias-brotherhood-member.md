# Allow to join Horde as Defias Brotherhood member

## Post 86221 by Xudo (Grandmaster of Forum PvP) — 2024-01-29T08:03:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=86221#p86221 | page 1 | era: pre-1.18.1 -->

Idea is to allow human players to choose alternative storyline in starting locations.
One important difference from regular humans is that Defias players don't follow quest to kill other Defias. Defias questline should end by joining the Horde.
Paladins can't betray Alliance. This questline should not be available to them.
If player completes any quest related to killing Defias, then he is banned from this questline.
Players still can do all those Gnoll/Kobold/Murlock/Beasts henocide and civilian quests to collect wood and stuff.
There should be special NPC in Northshire Vineyards, which turn all Defias mobs neutral and allow to pick quests from them. There is also Jerod's Landing which can be used as quest hub.

Players like to play pretty human-like characters. Blizzard mercilassly bend the lore to allow Blood Elves to join Horde. How about using existing natural conflict to lead some outcasts to horde? This feature also reuse existing starting location. Racials and available classes will be same as for humans.
