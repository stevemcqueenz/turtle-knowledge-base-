On official servers, they have this thing called the "Breaking News" window.  It's located on the screen where one types in their account name and password.  As the name implies, it would give players the latest game-related news, such as the weekly reminder of Tuesday maintenance, and the like.  It's a very handy feature and very useful for keeping players in the know.

So naturally, *Turtle WoW* turned it into a nag notification to always clear your game cache.  |:

Supposedly, it's incredibly difficulty or otherwise not worth the effort to redirect the Breaking News window to a server other than Blizzard's official *World of Warcraft* server news.  Something about modifying the EXE, or modifying vital operating system files on the player's computers?  I don't recall.  It wouldn't surprise me if that stupid, static notification were burned into a file somewhere in the modified client, then linked to in the modified EXE file.

Anyway, it's surprising that a server like this still doesn't have a "server status" page of some kind.  Less populated servers do, so why not this one?  It shouldn't be that hard to make a little thing to push updates and news on the website, or add a status bar to the forum software, or something.
