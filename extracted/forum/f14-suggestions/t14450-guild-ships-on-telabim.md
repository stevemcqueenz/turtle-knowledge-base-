# Guild ships on Telabim

## Post 98398 by Deeno (Barrens Chat Casualty) — 2024-07-02T20:53:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=98398#p98398 | page 1 | era: pre-1.18.1 -->

I would like to propose an idea for the Telabim realm: implementing guild ships as an alternative to the original guild houses:

 - Each guild would be able to own a ship, which would function similarly to a guild house but with simpler, more manageable customization options.

 - These ships could be all anchored near Telabim Island or the STV islands, as the tension is increasing between the Alliance and Horde.

 - Guild ships could be targets for minor raids, adding a dynamic and engaging element to the game.
