# Tiger's Fury

## Post 56643 by Jammyxx (Patch Note Conspiracy Theorist) — 2023-08-10T08:00:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=56643#p56643 | page 1 | era: pre-1.18.1 -->

The rework to Tiger's fury for druid was really nice, having that double duration makes the ability worth using while soloing or leveling if you activate it before a pull and the added +12% attack speed was okish.

The problem is this nice change is almost never used in raids or pvp other than once for an opener, and even then it doesn't make a huge difference.

The main reason is because it doesn't work with powershifting, Tiger's fury is removed upon dropping cat form, although you do keep the +12% atk speed.

The way to fix this would be to let Tiger's Fury +40 dmg buff persist throughout it's duration even if Cat Form is dropped (like the Blood Frenzy buff) but dropped if you enter Bear Form, (Like Berserk is).

This little change will help feral and make use of the class changes the Devs made so that we can actually have another ability useable in end game raids.

I'd also suggest increasing the attack speed bonus of Blood Frenzy to 20-30% and maybe this would alleviate the need for cat using MCP,  along with us now having newly added  FAP weps.
