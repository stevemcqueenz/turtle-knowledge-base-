# Artisan Challange Fix

## Post 106018 by Aubrea — 2024-11-02T19:25:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=106018#p106018 | page 1 | era: pre-1.18.1 -->

I find the Artisan Challenge odd, I really like the idea of it but find it very flawed with 1 of 2 very easy possible fixes.

First of all I need blacksmithing to be able to get any weapon and armor upgrades, that's perfectly fine.

Next I need tailoring to be able to equip any bags, but I also need mining to acquire the materials for blacksmithing, but I can't do both. So I need to either forgo storage, make an alt to mine materials for my Artisan character, or farm insane amounts of gold to buy bars for blacksmithing, Which isn't incredibly doable at low levels, I need gear to farm gold reliably and I need gold to get gear.

I see 2 simple possible fixes, either allow people who undertake this challenge to pick up a third profession, or don't include bags to have to be crafted in order to equip.

I understand its an optional challenge. but the current limitations are bordering on making it unfun, I don't want to drop the challenge because I love the idea of the self sufficiency, but find it too limiting. I really think that only being able to equip stuff you craft should not apply to bags, but at least having 3 professions would make up for that. I don't feel like a challenge should require having another character, and I don't see having limited storage as a reasonable intended side effect of this challenge.
