# On Making Flying Mounts Better

## Post 95735 by Jaeger3791 — 2024-05-26T20:40:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=95735#p95735 | page 1 | era: pre-1.18.1 -->

I think flying mounts on TWoW being ground locked is pretty lame, especially considering how much of a grind some of them are.
I think one option to make them much more interesting would be to be able to set a mount to replace the default flight path model. For example, a flight master dialouge option could be added to select a mount currently in your bags, and when using the taxi service that mount's model would be used instead of the default gryphon.

There are other ways of going about it but I just think that the current flying mounts don't make much sense.
