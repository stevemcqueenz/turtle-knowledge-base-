# Shop items as custom spells or commands

## Post 5932 by Emmiasilk — 2020-05-12T00:28:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=5932#p5932 | page 1 | era: pre-1.18.1 -->

I finally bought my first shop item today, and I was a little disappointed to see that my new [Illusion: Banshee] transformation appears as an item in my inventory. While this is in no way game-breaking, I plan on buying a few of these, so it would have been really nice if it didn't take up a slot in my rather paltry inventory. I'm also scared of the possiblity of accidentally losing one by selling it or destroying it when clearing out my inventory. So here are two ideas that might make these items more convenient for their users:

 **Idea 1**: Make shop items like these into custom spells. When we buy these items in the shop, it teaches our character a new spell in the General tab that allows us to use the transformation/mount/whatever. Any existing shop items that have a spell equivalent would now teach us the spell and then destroy themselves.
 **Possible issues with this idea that I can think of**:
- It might be impossible. I've been told that it's very difficult to add custom learnable spells in this game, but I'm also aware your team has done some custom client-side editing, so it might not be out of the realm of possibility
 **Idea 2**: When someone buys a shop item, they gain access to a command, such as `.illusion succubus`, which triggers the desired effect. Like the previous idea, the existing items could be changed so that they trigger the learning of the command.
 **Possible issues with this idea that I can think of**:
- It may require programming in an entirely new system, server-side
- It might be confusing to new players having to type in a command
I can understand if neither of these systems can be implemented, or if there is any other kind of problem that makes change unlikely, but thankyou for reading my suggestion! I really appreciate it.

## Post 5933 by Torta (Turtle WoW Team) [STAFF] — 2020-05-12T01:42:00Z

Hello!

Implementing custom spell without having client-modifications is not the option, at least right now. We are not resorting to mandatory client updates yet! Currently Illusions are bond to a Dummy Spell which has no proper description or name and can't be placed in the spell book as it is.

Commands are easy but immersion-breaking. Wouldn't go for it.

If you ever delete your items by an accident, make a ticket, we'll restore it for you :)

What I could suggest as an alternative:

 1. Having this item equipable  (as shirt, maybe).
 2. Making them indestructible or higher quality, to prevent accident vendoring.
