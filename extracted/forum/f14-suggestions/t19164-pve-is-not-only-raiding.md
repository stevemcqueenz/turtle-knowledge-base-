# Pve is not only raiding

## Post 130184 by Caos (Barrens Chat Casualty) — 2025-05-08T12:03:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=130184#p130184 | page 1 | era: pre-1.18.1 -->

There is some common misconception between many players on this server that seem to think that Pve and raiding are the same thing and constantly argue that devs should focus on Pve balance and content because that's what most of the playerbase is playing when in reality the changes they want and some that have been applied are only relevant on raiding.
Most CC and survivavility (if you are a dps or heal) in raiding is completely useless while these things are very important while leveling and even if you play dungeons.

Haven't seen the stats but I highly doubt that most of the playerbase is raiding naxx and even a part of those that play these raids only do it because the items are fucking broken. Probably most raiders here don't give a fuck about these stupid parsing and dpsmeters, in ZG, AQ20 or MC I have never seen anyone mentioning them, so I don't think there is really a need for all classes to deal the same damage.

All the buffs applied to rading items and some of the class changes have really made the game worse leveling and dungeons. Leveling on the open world and dungeons have become easier which is not that of a big deal but still it was better before, but every dungeon above level 50 has degenerate into a dumb steamroll from the moment any player with raiding gear joins the group.
And don't make some stupid argument about not being forced to play with them, if you have been waiting for a dungeon for long you are not gonna leave because there is some OP player or tell them to leave. Its preferable making some steamroll trough the dungeon than waiting again in queue but it would be wait better if this dumb streamroll wasn't posible.

Regarding PvP don't even need to mention how bad has become.
