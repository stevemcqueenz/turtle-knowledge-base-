I'd also love to see a /who filter specifically to include or exclude hardcore players.  We can already use existing /who chat commands like c-"Class" and z-"Zone" and g-"Guild" so adding in a hc command such as /who hc-"No" would filter out all hardcore players while "Yes" would ONLY show hardcore players.

This kind of change doesn't require GUI modifications and could likely be added in to either the who interface or alternatively added to the already-existing custom server commands like .server info and so on.  So something like .hcplayer show or .hcplayer hide would respectively show ONLY hardcore players in /who or show ZERO hardcore players in /who queries.
