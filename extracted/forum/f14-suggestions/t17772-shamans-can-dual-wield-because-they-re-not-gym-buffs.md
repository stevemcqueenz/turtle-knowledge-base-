<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=121172#p121172 | page 1 | era: pre-1.18.1 -->

This topic is advised frequently.
There are some things though which have to be considered regarding this.

Vanilla - This is a Vanilla+ (more or less) server. In Vanilla shaman's identity was 2handers, not dw. You can argue that it's too big of a change to switch this in a Vanilla+ environment, private servers from later releases exist after all.

Windfury - Sure, one handers hit smaller but if shamans ever go dw, windfury would need a rework and it would mean meddling with two core design elements in a Vanilla-like environment. Post cc2 windfury only affects main hand weapon, sure. But that's the totem. Since shamans can't dw at the moment, it is not defined how weapon imbues would work (and wf imbue gives 2 extra hits, not one). Being able to WF imbue both weapons? Too much. Being able to only imbue your mh weapon as an enhancement shaman? Would feel lame.

Loot - The game has to keep a balance between 2h and dw so both kind of loot would be useful for a wide playerbase. Putting a build from one category to another would switch up things.
Sure, tanks only use one-handers but if we only check DPS now:
arms, ret, enh and (mostly) survival hunter are the 2h ones.
fury, rogues (combat, sub) go for DW.
Sure, there are more DW user builds but I skipped tanks here and ignored how well builds are represented in raids (arms or even survival hunters are really rare). That highly affects the distribution.

Work - If you add DW to enh, you create a bunch of added work, having to rebalance things. Should the melee proc rate of clearcasting be lowered because you're punching with two weapons? Giving the shaman an offhand hit chance talent while the tree is already filled, trying to support both enh DPS and tank. The question of weapon imbues. Shamans losing their only legendary, Sulfuras. A bunch of added work which could be used to solve existing issues like rogues, cats, trivialized dungeons, you name it.
