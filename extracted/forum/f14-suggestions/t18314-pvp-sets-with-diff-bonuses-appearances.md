# PvP sets with diff bonuses/appearances

## Post 124991 by Deuce — 2025-04-01T21:25:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=124991#p124991 | page 1 | era: pre-1.18.1 -->

Turtle has done a lot to make the less viable, viable.

One thing that stands out is the pvp armor for some classes being superior.

Others have appearances that seem a little off for the class, like alliance warlock.

Perhaps some switched up color schemes and particle effects could spruce things up a bit.  Or set bonuses matching specs that aren't quite as viable.

Id leave it to the geniuses that be in design here, and by making this thread open it up for discussion.

It seems like a great idea to incentivize people showing up to the BGs again even if only to get some new transmog looks.

Oh - I also considered some kind of tokens dropping from 1v1 kills in world as an alternative to honor grinding.  There was an effort to make some kind of towers or something to fight over and maybe that reward didn't quite line up enough.  Only downside is I could see people griefing by tagging ppl to prevent said token from dropping.  These would probably be one offs and a number of solo kills per week could rank you in the lone wolf club.
