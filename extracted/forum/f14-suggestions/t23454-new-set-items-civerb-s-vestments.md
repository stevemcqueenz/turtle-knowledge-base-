# New Set/Items: Civerb's Vestments

## Post 164102 by Zashferret — 2025-12-31T04:45:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=164102#p164102 | page 1 | era: 1.18.1-announced-pre-release -->

In line with [this](https://forum.turtlecraft.gg/viewtopic.php?t=23453) post, I have the following idea for a Diablo 2 set converted into something for Turtlecraft.

"Civerb's Vestments" would be a 3-piece Uncommon set made up of a 1-handed Mace, a Necklace and a Shield. Each piece requires level 18 or 19 to use.

"Civerb's Cudgel": 1h  Main Hand Mace, 24-45 damage with a 2.30 Attack speed (for a 15.0 dps), and give +10 Attack Power.

"Civerb's Ward": A shield That has 478 Armor, base block value of 9, and give +1% chance to block and +3 Defense

"Civerb's Icon": Necklace that grants 4 Health per 5 seconds and 4 Mana per 5 seconds.

It could have a (2) and (3) set bonus:

(2) +10 Strength
(3) +10 Fire Resist and +10 Nature Resist

Once again, just an idea for an early set that more benefits shamans, paladins and warriors but the mace and necklace could be used by priests and druids
