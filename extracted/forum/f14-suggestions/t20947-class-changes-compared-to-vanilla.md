## Post 145706 by Eskayrogue (Barrens Chat Casualty) — 2025-08-15T14:26:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=145706#p145706 | page 1 | era: pre-1.18.1 -->

To explain, it would be really nice to have a place on the main website that shows class changes and ability changes compared to their orignals, or show what's new, similar to what is on the Project Epoch Website. This would also make it possible to see a linked ability to know what it does. This would also just be quite nice if you cannot remember what the vanilla ability is.

Also it would make it so you wouldn't have to scroll through all the class change updates and find them on the forum to know what is different, this would be a huge QoL change for new players.
