# Suggestion: "Recreate Character" Button for Dead Hardcore Characters

## Post 140214 by Kottenpicker — 2025-07-18T04:29:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=140214#p140214 | page 1 | era: pre-1.18.1 -->

Feature Overview:
Add a "Recreate Character" button visible on the character select screen only for dead Hardcore characters. Pressing it would:

Automatically create a new Level 1 character
With the same name
And same appearance, race, and class

Why It’s Useful:
Hardcore players retry often. This reduces friction and keeps momentum going.
Saves time reselecting appearance/class manually.
Makes the Hardcore experience smoother without reducing difficulty.
Respects the permadeath nature — no data recovery, just faster restarting.

Example:
You die at level 25. On the char select screen, your character is grayed out as usual.
Now, there’s a “Recreate Character” button.
Click it, and boom: new char with same look/class, name reused if possible.
You’re back at level 1 and ready to go.
