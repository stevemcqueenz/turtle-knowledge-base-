# Please Fix this repeatable quest!!!

## Post 134315 by Constantinecn — 2025-06-04T22:04:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=134315#p134315 | page 1 | era: pre-1.18.1 -->

In Wintersping the is a repeatable quest off Salfa called "A Warm Feeling". After first completion this quest is repeatable, however it does not follow the same rules as other repeatable quests. You have to go back to Salfa and pick up the quest for EACH hand in. Additionally before the mobs will drop the Tea Leaves the quest needs to be picked up. Is it possible to change this quest to a Blue hand in quest, and add the Tea Leaves as a drop to the normal loot table of the 3 NPC's that drop the item. This would align with the rest of the repeatable quests in the game! Not being able to pick up more than the quest requires for hand in makes it extremely tedious for a repeatable quest.

I would like to see the quest giver being a hand in point (blue question mark, like ALL other repeatable quests), and the Winterspring Tea leaves be added to the loot table for the 3 NPC's as currently the leaves are only added to the loot table if you hold the quest.
