# Update Suggestions , Heroics, Professions, Class + Race combos

## Post 40617 by Kashchei — 2023-04-07T03:32:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=40617#p40617 | page 1 | era: pre-1.18.1 -->

I've just started playing TW in the last week or so and found that I'm loving the teams version of classic+.

Here's some thoughts on additional changes I think are worth considering (please bare in mind I haven't seen end game yet so I apologise if something I suggest is already implemented)

Heroic Dungeons;
I think everything from RFC onwards can warrant a heroic version with scaled loot. Imagine being able to put together a level 60 sul'thraze or a lvl 60 Dragon's Call / Ironfoe.
Another fun idea would be to add BOE levelling gear (blues and epics) as scaled BOP items to the loot tables.

More Class Changes
I can't speak too much on this topic but I'd love to see Shamans get access to polearms (I mean come on they are basically spears) It would also be great to see Stormstrike updated to either increase the effect of the next shock you cast OR gain a unique effect based on whichever weapon enhancement you have on.

Class Crafting
More class crafting would also be amazing, I never quite understood why hunters didn't craft their own ammo / traps not dissimilar to how rogues make their own poisons.

Racial Rebalance
While I understand that weapon expertise is great to have when it works for your class , it feels pointless when you can't use guns / bows / axes on a certain class.
I think the BEST possible change to racials would be to put more flavour into class / race combination spells, adding these variations to shamans was a 10/10 idea and I think every class should have them.

Class + Race Combo's
The team has done a great job pumping out more class race combos and it's been done in a lore friendly way. Undead pally's + Troll druids and idk maybe Dwarf shamans could be the play.

Professions
I would absolutely LOVE to see jewel crafting and inscription implemented for TW, the 1-300 work has already been done for both and while I understand glyphs are a contentious topic it could be well worth (especially for JC)

Additionally I think every profession should have 1 or more features / items that're locked to having skill in that profession (to prevent engineering being as dominant as it's always been).

Please share all opinions you have, I love a good discourse. If you have any reasons you think any of these are terrible please let me know as well.
