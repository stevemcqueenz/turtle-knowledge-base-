# Some races which have already been added.

## Post 33359 by Jongyi (Barrens Chat Casualty) — 2023-01-28T15:41:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=33359#p33359 | page 1 | era: pre-1.18.1 -->

Playable races are hot issues lately during the threads.
I would like to point out some of the races have been already added to playable race sections

Forest Troll
Forest trolls of Amani (and Raventusk) have already rejoined the Horde. You can already play as forest trolls!
You can create forest troll through troll customization and RP as forest trolls of Amani

Wildhammer Dwarves
Wildhammer have rejoined their ironforge kins. You can create wildhammer dwarves via dwarf customization and RP as wildhammer dwarves!

Blood Elf?
While there is no solid concrete evidence and it is only my assumption, i noticed we can start to select new high elf skin tone through customization and also saw pairs of blue-green eyes in the latest updates. These options were previously unavailable and now you can create looks as closely possible as to blood elf. My guess is that at some point, some of the blood elves will rejoin their high elven brethren and these new customization indicated that.

These customizations are neat and clever way of putting new playable races without having devs to spend resources for entire new races. Would love more customizations on later updates.
