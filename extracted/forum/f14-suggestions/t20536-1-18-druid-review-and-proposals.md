Talk about the underlaying issues and proposals.

We have couple of idols, some of them are really good, some of them are for very niche purposes but there is no point to gather all of them if there are a GCD and a GCD retrigger if swapped while the first GCD was counting down. In worst case scenario the total GCD time can be 3.9 seconds. That is unacceptable both for PvE and PvP purposes. Currently what is implied to get the most powerful one and stick to it.

Feral:
- Bear have only 3 offensive button (4 with Faery). Maul replacing autoattacks so it is delayed. Swipe is not good on single target and when on low rage.

- Bears should have more and interactive abilities. 95% of the time is just pressing Maul.

- Cat gear with haste is garbage since 40% of auto attacks are glanced off. It is a total waste stat on cat gear and should have something better.

- There is no talent in the feral Tree that help occasional healing like AP to Healing power conversion.

- There are no Cat - Bear synergy abilities only exception that Tiger’s Fury Haste stay when switched out of cat form.

- There can be spells/talents that promotes more form to form changes to gain some benefits.

- Feral Tier sets are highly specialized and clashes with druid class fantasy and hybrid gameplay. For example a T3 which is a tank set with tank set bonuses there can be a secondary set bonuses that affect cat abilities.
Altogether the specialized Tier system T2.5 cat 100% T3 Bear 100% Bear should be reworked like T2.5 80% cat effects 20% Bear and T3 80% Bear effects and 20% cat.

- With the new talent rework still there are not enough points in the tree to have all the bleed and powershifting talents for cat gameplay. If Furor going into replace Nature’s Grasp in the Balance tree then the issue can be solved because ferals going there anyway to pick up Omen.
Balance

- There is no talent that can reduce Rebirth cooldown.

- T3 Gear having haste on it while druid have only 2 abilities that can be affected by and 2 instants which can be not while still spell hit/crit starved.

Restoration

- There is no (raid exclusive) resurrection spell for druid.

- There are no purge resistance on hots spell in the talent tree.

- There is no fail safe mechanism if Tranquility got interrupted very early due to a fear or stun. Wasting a 30 minute spell for having 1 or 2 seconds of it is terrible.

- Healing Touch build improvements are nice but if the goal to be a tank healer then need something beneficial secondary effect on it that good for tanks.

- There is no strong Reju build support talent like for Regrowth there is Preservation for HT there is Aessina’s Bloom. Reju support talent can give purge resistance, lowered GCD on it, first tick is instant for each cast for a set period.

- Tree of Life Form is still a 99.99% a pve talent. While having some armor that is good against ranged physical shoots but with low mobility will be avoided to talent for it like a plague in Arena and other 10-15 player battlegrounds. Solution can be: remove the move penalty, enable to cast Entangling Roots while in tree form and melee attacks against it auto grasp the attacker (cooldown on it)
Efflorescence does not solve the issue that more Resto druids in the raid the worse experience for them because their toolkit not synergizes with more than 1 or 2 in the raid.  The current solution is to limit their resto spells out of 3 (RG,Reju,HT) to use one for each druid  to avoid greefing. 1 Reju druid, 1 RG, 1 HT. All of them are restricted to use just 1/3 of their healing toolkit. That is not a good solution. The most conflict between the 2 hots Reju and RG styles. Current Efflo does a little to solve the conflict.

There are several proposals to fix this. Efflo should not be Tree exclusive rather should it be baseline. The more Druid in the raid they should amplify each other.
New tooltip for Efflo: Current effect + upon removal the original caster of the hot gets refunded 20% of the spell cost and additionally Increases healing power and mana regen while casting by 2% for each Resto druid in the raid. Max 6% (20 points spent in resto game count you as one)

Atiesh 2% casting speed is only good for Ferals. Maybe add 2% mana regen for the group as well? Same problem occurring again like before thinking druid is a 100% specialized class.
