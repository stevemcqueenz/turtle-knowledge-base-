What about the fact that the warlock could transfer their health not only to the demon, but also to other players? For example, using [Health Funnel].
And what if the skill of [curse of rechesness] acted not only on enemies, but also on group members, like a kind of buff?

Well, we can always use more healers (or people willing to actually play one), so the first idea is actually quite interesting. Now imagine an overhaul of voidwalkers so that they can function as a health reservoir for the group. Toss in some fast heal using "remote healthstones" and we might just come up with a completely new healer class if we pursued this thought further.
