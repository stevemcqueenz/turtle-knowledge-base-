# change ZG head/legs enchants to be class-agnostic

## Post 169170 by Aegle47 — 2026-02-22T06:46:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=169170#p169170 | page 1 | era: 1.18.1-announced-pre-release -->

Hi Turtle Team and fellow turtles,

I would like to suggest a potential adjustment to the Zul’Gurub head and leg enchantments — specifically, making them class-agnostic instead of class-restricted.

Currently, all of the Head and Leg enchants from Zul'Gurub are tied strictly to specific classes. While this is how it was originally designed in Vanilla, it limits hybrid experimentation, discourages creative or off-meta builds, and mainly encourages the rigid "intended" class paths.

On a server like TurtleWoW, which embraces custom content and alternative playstyles, this feels like an area with **big potential.**

Proposal:
Make all Zul’Gurub class-specific head/leg enchants usable by **any class**. Nothing changes with the required class voodoo dolls. Think of the class labeled on the item more like a suggestion instead of a hard requirement.

For example:
A Survival Hunter could use the rogue's enchant "Death's Embrace" to gain more AP for his melee hits
A Mage could use the warlock's enchant "Hoodoo Hex" instead of their class specific enchant to opt for more Stamina for PVP instead of going with 1% SP Hit.
An Enhancement Shaman tank can use the warrior's enchant "Presence of Might" to build Stamina, Defense and block.

Why This Is Good for TurtleWoW?
 1. Encourages Build Diversity
This server thrives on custom specs and creative theorycrafting. Removing class restrictions empowers players to being able to fine-tune for their specific spec, not just their class label.

 2. Supports Hybrid Identity
Vanilla’s class design often punished hybrids by locking them into “approved” roles. Class-agnostic enchants would reinforce TurtleWoW’s more flexible philosophy.

 3. Increases ZG Longevity
More players farming Zul’Gurub for different enchants = longer raid relevance and more economic activity.

 4. Low Risk, High Reward Change
This wouldnt introduce new power. only redistribute existing stats more freely. It promotes choice, not power creep.

TurtleWoW has already shown it’s willing to evolve beyond strict 2004 design where it benefits the game. Making Zul’Gurub enchants class-agnostic feels like a very “Turtle” change:

More creativity.
More theorycrafting.
More player expression.

Curious to hear what others think — especially from hybrid mains    happy_turtle_head

Thanks for reading!
