## Post 47938 by Bob022 (Barrens Chat Casualty) — 2023-05-29T11:25:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=47938#p47938 | page 1 | era: pre-1.18.1 -->

Yes, your first suggestion--merchants re-selling items other players sold--is technically possible as proven by that feature's existence in some other games of this type.  It appears unsupported by Warcraft's client, hence implementation here would presumably require a lot of work, probably so much so as to make it impractical here.

The second suggestion--selling items only to merchants interested in that specific item type--has been done in a much smaller number of games.  Again, nothing stopping it.  It runs into a serious quality-of-life problem where most players don't want to have to run to a dozen different vendors every time they want to sell their bag full of junk.
