# General suggestions

## Post 82573 by Kevinflynn — 2023-12-24T13:49:00Z

Hi there ! I have the following suggestions to improve the server.

 1. Current server economy is broken. At the moment, there is a problem with the fact that if you make a mistake in choosing a profession, then you will not be able to make a profit in terms of gold. For example, I have skinning and it didn’t make much difference to sell skins to a vendor or to auction, with alchemy it turns out that the grass is at the same price as pots on auction, you can only make a profit from flasks, tailoring is a dead profession now, the profit from it is minimal and the clothes are outdated.
A proposal to solve the problem - we need a person who would monitor prices on auction and somehow regulate the situation with prices, or automatic purchasing according to specified parameters so as not to have to do this manually.

 2. Ticketing system. We need a person who would adequately respond to people’s tickets, could immediately check some bugs and independently post the problem to GitHub.
The current paste is so that people go to GitHub, fight there and figure out what’s what, this is some kind of cringe, as for me. I sent about 15 tickets with serious bugs and received the same message for all of them, by the way I didn’t notice right away because I accidentally deleted the letter from my email - go to github or clear ur WTB folder.

 3. I leveled my warrior in warmod mode and was constantly ganked, dying 50 times from the maximum levels in each possible zone. Think about what can be done about this, as for me, it might be worth limiting the possibility of killing a character if you are more than 10 levels from the character you attacked, or another option is to make it so that a high-level killer receives a "deadly mark" - this is a title that will appear above character, saying that he will now be hunted by a special patrol from several very strong NPCs and they will not calm down until they kill the target with the mark (they can hunt the target anywhere except dungeons and raids).

 4. Increased quest log, in practice I was faced with the fact that I constantly had to delete some quests. I understand that the limitation may encourage some players to complete additional quests to undefined Don’t drop them, but increasing the quest log by at least 5 slots would be a very good solution.

 5. Problem with receiving mail. The character cannot receive messages; when a certain number of messages is reached, an error is displayed and the mail has to be cleared. I believe that at the moment the number of messages stored in the mail is not enough for a comfortable game, so it is worth increasing the possible number of messages/items stored in the mail.

 6. Addons and client tweaking - I spent about a week to get everything +- working adequately for me and I could play the game without suffering from the fact that, for example, when I turned the camera, my mouse was not constantly jumping on the screen. Setting up addons also took a lot of time. The solution to the problem is to download the client from an official webpage that already has the option of automatically looting things from mobs, fixing the mouse jumping around the screen and increased camera distance.
Create an official macro guide for each class may help a lot to people, since it is old game client that not support new macroses that u can search in many web resources.

 7. Attitude of developers towards players. Here I want to point out undefined the negative attitude I faced. The bug with the flipper boss in Karazhan existed from the very beginning and was not fixed very soon (several months or something like that) I understand that fixing bugs is not so easy, but why should people waste their time killing the boss 3 times and wiping who knows how many times over the course of several months, temporarily removing this boss would be the best solution until the bug is fixed or do his usual mob. Once I sent a ticket, other players also encountered this and um came and just looked at it all, instead of, for example, checking the logs to make sure that we killed him, just destroy the boss so that people could finally get loot from the boss. It so happened that at this time the restart also happened to be two hours long.. I would also recommend setting a specific time for the respawn of the Snowman in the current event, people stand there for hours and wait. Somehow it doesn’t work out very well, in my opinion. For me personally as a player, undefined The attitude of the administration towards the players is important, I think for many it’s the same.

 8. Server restart. If possible, restart the server at a certain time so that people know what time it will be and make a notification about the restart in the middle of the screen so that everyone can pay attention to it.

 9. Different difficulty levels for every new raids (for casual players and players who love difficulties). There are differences in mechanics for bosses; for hard mode there are more interesting, unique mechanics.

 10. Adding a hard difficulty level to the current lower Karazhan (add a difficult level, leave existed one as it is for casuals) and add unique mechanics to bosses for hard mode. Add some gold drop from the enemies or anyelse, its very expensive raid if you using consumes and especially if u wipe.

 11. Black Morass increasing the amount of reputation gained from mobs by 2 times will not be amiss and a possible expansion of goods in the store, for a magician, for example, I didn’t see anything interesting there, I was only interested in bags.

 12. I recommend that you be more careful when adding new items, so that the old dungeons do not die because of the new items have been overbuffed and it’s as if there’s no point to go old dangeons for treasured items that everyone used to hunt for.

 13. If some update is released, some fixes for example, then be sure to post a link to the post with updates in the discord, for example, due to the fact that there was no link to the update in the discord, many players for a long time did not know that there was a bug with Moroe's was fixed.

 14. Return the newcomers guild. I believe that this guild is needed so that people can share their experiences and answer questions of new players, because there is a lot of custom content on this server and not everything is obvious the first time.
In order to have less unnecessary conversations in the guild, you can do this - The guild consists only of GM's and characters up to level 60. Everyone who starts the game is automatically in it until level 60; as soon as level 60 is reached, the person receives some title, for example, “Expirienced Turtle” and he is than automatically removed from the guild. Those who are already level 60 will receive the title aswell.

 15. Battlegrounds. I'm new to pvp especially BG's, so we need others' opinions on this matter, but it seems to me that 2 hours + of fighting is to much and It is worth reducing the amount of time per match, and also giving not a large amount of gold for a victory, and a little less gold for a defeat, so that you can recoup some consumables.

 16. Suggestions for the site:
 1) Redesign the main database page - <https://database.turtlecraft.gg/> making it more user friendly, adding search options.
 2) There is a problem with logging into the forum, make possibility that when you log into your account at <https://turtlecraft.gg/#/home> and then going to the “forums” tab, the account was saved and there was no need to log in again to post on forums.

Best regards,
your   smiling_turtle  Kevin Flynn
