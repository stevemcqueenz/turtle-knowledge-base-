## Post 45968 by Ishilu (Patch Note Conspiracy Theorist) — 2023-05-15T18:00:00Z

Encebe, we are partly on the same page here.

Let's consider multispeccing:
I strongly reject the idea to give this away cheap or early in the game. This would only lead to a meta where even in leveling dungeons only prot warriors tank, only holy priests heal etc.. While encountering such tanks and healers in the early game is sometimes quite nice, it relieves players from the need to simply play the game well. So, multispec below lvl 60 gets a big no from me. However, I fully agree that multispec is a great addition for the endgame, especially for hybrid players who want to effectively use the full toolkits of their chosen classes and not reduce their classes to a single role. The best way to implement it should be discussed elsewehere.

Changing Classes:
Fact is, people will always be stupid enough to come up with a meta and other people will be stupid enough to follow it, and even worse, expect others to do the same, draining a lot of fun out of the game in the process. There are several ways to deal with this:
a) accept the meta as it is and follow it.
b) put in a lot of work to change it (mind that we can only discuss things and do the corresponding boring middle-school-level math, the real work of implementing it would fall to the devs). I doubt that a perfect balance can be achieved while keeping the game in a fun and playable state. So, "spec A deals 5% less damage in a raid than spec B" can't be a good reason for changing the game.
> players should adapt to the game and not the game to players

, right?
c) happily poop on the meta, play as we like and put world chat theorycrafters on our ignore list. That's what I do most of the time.

If we change the classes, it gets tricky. I think there are 4 points where changes can be discussed.

 1) Itemization: It's broken for some specs and needs fixing. Exhibit A: the Crowd Pummeler. Case rested.

 2) Changing numbers, like scaling spell X up by Y%, reducing mana/rage/energy cost by Z%. I really don't care as long as you folks don't overdo it and it's only for balancing out classes and specs, not for an overall higher power level. The math is simple enough. This doesn't change the actual gameplay.
Just don't make my game too easy, ok? I'd hate to only play 5-man dungeons where all mobs fall so easily and deal so little damage that everybody can just turn off their brains and spam AE. There's always WotLK if people want this kind of gameplay.

 3) changing talent trees, adding spells:
Now it gets tricky because this can significantly change the gameplay of a spec. I think utterly removing core talents like wyvern sting or premeditation would be wrong. Buffs can - in some cases - be discussed, but again, please do this stuff only for balancing, not "because the game is too hard". It's not.
I like how many talent trees were fixed in TBC, however. I won't call for deeper talent trees, but stuff like manareg for ele shamans were a good idea. If we want to look for good talent changes and spell additions, that's where we should start looking, in my opinion.
Note that there are private servers where you can create your own classes from scratch. Still, I have good reasons for playing on turtle and not on that one  happy_turtle_head  .

Regarding a lack of AE for some classes: I'd rather have the turtle devs tune mobs so that we need less AE and more CC, see my "turn off their brains" rant higher up.

 4) Changing basic class mechanics:
Dead zone and pet loyalty for hunters, Combo points, rage mechanics, 30-minute-druid ress and many more:
Yes, this stuff can be annoying, but this really, really should not be touched because learning to deal with that stuff is a part of mastering the classes and, ironically is a key to having fun in the game.
Again, if people don't want to play with "bad core mechanics", there are later WoW patches where just that is offered. For example, "combo points on the rogue and not on the mob" are a retail thing. In my opinion, coming to a vanilla server and asking for changes to make the game more like retail is a bit like going to a steak house and demanding a bigger vegan menu.

Finally, we should keep in mind that different classes need a different amount of love from our dev team. Forcing shaman and druid players to dress up in priest robes and only heal in endgame content was not cool. If the class description says "class X can heal or melee dps or caster dps", then this class should get the opportunity do do all these things in the endgame. "Forcing" pure dps classes into specific specs for specific content isn't a great thing either, but not as problematic as forcing shamans into priest dresses.
