# More tameable pet types

## Post 25994 by Chillblains — 2022-09-24T00:15:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=25994#p25994 | page 1 | era: pre-1.18.1 -->

I've always been a bit underwhelmed by the options available to hunters when it comes to taming pets. The decision to have some types of beasts be tameable while others aren't has always felt arbitrary. I think that it would be cool to tame kodos, or deer, or thunder lizards, or wyverns or any other beast that can't be tamed already. Even if it would ultimately be a cosmetic choice, it should still be considered, for variety's sake if nothing else.

## Post 25995 by Shamma (Bug Report Enthusiast) — 2022-09-24T00:26:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=25995#p25995 | page 1 | era: pre-1.18.1 -->

There are pet families and abilities these families can learn.

Adding new pets to existing families is easy. Turtle has done it by adding e.g. eagles to carrion birds family and foxes to wolves family.

Adding new pet families on the other hand - that would be a lot more work. What you are asking is adding a lot more pet families not simple pets. And if these pet families would have special abilities only available to them, then high lvl animals of said family will be needed for the hunter to learn these abilities. But none exist. So even more work to add them and zones where they fit in. It is a deep rabbit hole this one.

I can bet they have discussed it and decided against it and added the eagles and foxes instead.
