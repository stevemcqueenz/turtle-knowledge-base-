# Make twow team obligated to answer on each suggestion

## Post 90833 by Melg — 2024-03-20T02:23:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=90833#p90833 | page 1 | era: pre-1.18.1 -->

As of today it seems suggestions on this forum is more like graveyard of ideas, where you can type some words, maybe find few people who think same way, and thats it. It has 119 pages already. People wrote something, to never see any resolution. I suggest to implement workflow on which each of new suggestions (after this rule is introduced) should be reviewed by team member and get one of few resolutions: accepted as suggested, accepted with changed details, rejected with reason of rejection. This way we can have base of accepted suggestions, we can have base of rejected suggestions, which should be searchable. And we would have clear result on each of them, so people won't try to push idea forward anymore if it's know to be rejected because of X, and Y reasons. And we also would see real time from suggestion to response, and from idea acceptance till implementation. I think current system is missing valuable feedback from developers, although i understand that it would take some time and some human resources to implement such workflow.
