# A solution to node camping

## Post 84281 by Scelus12 (Barrens Chat Casualty) — 2024-01-11T04:36:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=84281#p84281 | page 1 | era: pre-1.18.1 -->

At this point everyone, everyday, sees a dozen players seemingly afk in the world camping herbs/ore nodes.

Why not increase the number of nodes by 5x, but still keep the overall number of spawned herb/ore the same?

Basically make it much less rewarding to sit on a node, and more rewarding to be in the world running around.

Might be too much work, but I think it would be worth while.
