# Cross-Server Matchmaking Battlegrounds

## Post 118511 by 987004590 (Barrens Chat Casualty) — 2025-01-31T05:57:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=118511#p118511 | page 1 | era: pre-1.18.1 -->

The most important issue in PVP right now is simply this: the player base is small. The imbalance in classes and equipment is a facade; in a small player base battlefield, the main factors contributing to the imbalance are the uneven team compositions and individual skill disparities. Only by expanding the base can one qualify to discuss imbalances.

Therefore, I suggest cross-server matching, noting that it is cross-server matching, not cross-server queuing.

This means that each faction is still composed of players from the same server, which avoids many potential issues. It also fosters a competitive mindset between servers, benefiting PVP development, and is simple to implement without introducing any bugs.
