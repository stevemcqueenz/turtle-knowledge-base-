# [Suggestion] Cross-Server Bgs

## Post 102995 by Maaliss — 2024-10-13T04:43:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=102995#p102995 | page 1 | era: pre-1.18.1 -->

I know fourms are never a great way to get a feel for ingame reality but two things seem relatively clear.

 1: Both Tel'Abim and Nordanaar residents are very set in their playstyle and never the twain shall meet.

 2: Population levels between both servers are vastly different (which in itself is not a problem) and as a result BGs Tel'Abim hardly ping, particularly AV which never pings.

Playstyle differences aside, I'm sure the one thing we can all agree on, is we enjoy TurtleWoW and want others to enjoy it.

So that all can enjoy all aspects of this game, is there a chance to allow Crossserver BGs? Blizzard has done it and their player numbers are higher than here. I'm sure it would work here.

Ps. Plus it would be fun to see the possible outcomes between premade Nordanaar vs premade Tel'Abim AV fights would go.
