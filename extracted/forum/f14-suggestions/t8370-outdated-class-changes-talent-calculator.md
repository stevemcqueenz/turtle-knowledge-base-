Theres been many changes over the months yet these pages were never updated.
For example:
'Bloodlust' talent says increases by 10%' on the current Calculator but it is in fact 15% in-game.
'Spirit Wolf' racial says 5 min cooldown on the 'Class Changes' page but it is actually 4 min CD in-game.

I'm sure there are many more examples to be found.

This is problematic because people base their choices on the advertised info.
Like if I had known 10 min CD on Spirit Link was actually 20 sec in-game I would have become a Tauren.

I'd suggest updating these old outdated pages to display accurate numbers/cooldowns/effects etc.
