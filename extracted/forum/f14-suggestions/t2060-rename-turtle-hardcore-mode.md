I know it's unlikely and would probably lead to (initial) confusion - especially since Turtle Mode was already named Hardcore Mode before.

Anyways, here I go:

I'm currently playing both a char in Turtle Mode (slow & steady) and one in Hardcore Mode.

To be honest: I think Turtle Mode is harder (more hardcore) than Hardcore Mode (Hardcore Mode is hard only once, while Turtle Mode is hard all the time).

That's why I suggest:

Rename Turtle Mode back to "Hardcore Mode".
Rename Hardcore Mode to "Heroic Mode" (because these guys are true heroes, risking their - one - life).

If someone does both modes at the same time s/he does it "hard & heroic" - rolls off the tongue easily, right?
