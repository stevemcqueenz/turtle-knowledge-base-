# Affliction Warlock 3.5 Tier Set

## Post 171690 by Bebblock — 2026-03-21T21:15:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=171690#p171690 | page 1 | era: post-1.18.1 -->

Hey!

The Affliction Warlock tier 3.5 (3) set received a double nerf, although I don't know if this was intentional. Because of this, the 3.5 (3) set is almost no longer worth playing, and you would almost go back to the AQ40 2.5 set (1 tier set back!).

The patch notes did the following:
Amount of mana and health gained from health drained by Siphon Life reduced from 50% to 25%.

This is a double nerf on the mana gain, which is perhaps heavily unnecessary and makes Affliction Warlock play very differently now because you have to tap life much more.
The set caused an extra 50% health drain, and you received 50% of the health drain back as mana. This means you had 150% health drain and 75% (50% of 150%) mana drain. Because you now only get an extra 25%, and 25% of that results in a health drain of only 125%, which is 31.25% (25% of 125%). So you are already losing 33.75% due to the double nerf. I will calculate it in numbers below:

Previously, if you drained 1000, you would get an additional 50%, bringing you to 1500 (1000 x 1.5). Of this, you received 50% = 1500 / 2 = 750 mana back.

In the new situation: If you drained 1000, you would now get 1250 (1000 x 1.25), and of that, you would receive 25% = 1250 / 4 = 312.5 mana.

This is 41.66% of the mana you received before the patch. 58% is, of course, a gigantic nerf. Would you please take a look at this, because as far as I'm concerned, this is a bit excessive.

Kind regards,

The affliction warlocks from Twow
