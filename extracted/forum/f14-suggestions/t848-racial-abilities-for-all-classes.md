I like the idea of race specific abilities for each class. Things to consider:

 1.) The actual spell
— Balance (Big issue): How does this effect gameplay? If too much, it is inbalanced. If too little, then it is trivial.
 2.) Implementation
— Creating a quest to obtain the spell.
— Creating the spell (code, dbc work, serverside work)

A quest for each class for each race is quite a lot of quests. If we were to make them chain quests then that would make this even more work.
