# Herbalist's New Gloves

## Post 94062 by Zvyrhol (Grandmaster of Forum PvP) — 2024-05-04T19:50:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=94062#p94062 | page 1 | era: pre-1.18.1 -->

[Herbalist's Gloves](https://database.turtlecraft.gg/?item=7349) is the only item in Turtle WoW that increases Herbalism skill by +5. The problem is type of Gloves which is Leather. That means classes that only can wear Cloth type of armor are not able to equip this item. In Vanilla this item was restricted to Alliance (only one vendor sells the recipe) because Horde had Taurens with +15 Herbalism skill. So in original Vanilla the Horde was not able to get these Gloves. This has changed in Turtle WoW because we have cross-faction AH meaning that these gloves can be easily acquired by everyone even already skilled Taurens.

I suggest adding new cloth gloves that give bonus herbalism or changing current Gloves to cloth so every class can equip them. Herbalism skill is important because even if you have 300 Herbalism, you can fail gathering Black Lotus which costs 40g by the way. Herbalism skill is essential if you are competing against other herbalists in AV. In my opinion being Tauren shouldn't determine if you have 100% chance to gather Black Lotus. Non-Tauren-Clothie can have maximum 305 Herbalism skill which doesn't guarantee successful harvest of BL.
