# Improving the Transmogrification System

## Post 154020 by Wyrdo (Barrens Chat Casualty) — 2025-10-02T10:44:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=154020#p154020 | page 1 | era: pre-1.18.1 -->

Hello again Turtle WoW team,

I’d like to suggest a few improvements to the transmogrification system, which would make it much clearer and more user-friendly:

Clearer display of transmogged items
– On retail WoW, you can easily see both the base item and the transmog appearance. On Turtle, it’s not always clear what someone is actually wearing. Making this distinction more visible would improve clarity a lot.

Unlock appearances from loot, not only from equipped items
– It would be a big Quality of Life improvement if looted items could be added to the collection automatically, instead of requiring players to equip them. This would reward exploration and farming without forcing players to constantly swap gear.

Independent shoulder transmog
– On retail, you can transmog shoulders separately (left/right). This would allow for more creativity and variety in character looks, without being game-breaking.

Thanks for considering this suggestion !
