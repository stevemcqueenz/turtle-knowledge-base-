# Give a reward for Hakkar hardmode

## Post 127410 by Suspicious — 2025-04-18T23:46:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=127410#p127410 | page 1 | era: pre-1.18.1 -->

My suggestion is to add a reward - possibly an extra chest of loot - for killing Hakkar first.

Hakkar is a pretty straightforward boss the way most people run ZG (kill all the troll bosses, then kill Hakkar). Deal with Corrupted Blood, position properly for the poison mechanic, CC mind-controlled tanks, collect loot.

However, Hakkar also has several other mechanics that he only uses when pulled before any of the bosses die. It would make a pretty challenging and rewarding hardmode, requiring tank swaps, more involved healing, maybe even tranq shot.

It would make a great 'T1.5' boss.
