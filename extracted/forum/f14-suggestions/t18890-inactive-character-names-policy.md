Revisiting this.
I know the policy isn't being followed, despite some official responses on discord saying contrary, because I myself have level 1 characters that never logged in for well over 6 months while I've been away from the game. These characters haven't had their names taken away. It would be great if the official people gave factual answers, but that simply isn't happening in this case.
It's great for me that the names weren't taken, and I don't in any way mind. However, I think there should still be some policy in place. I personally favor individual names being made available if a person requests that specific name and the name is being held by an inactive character for some specified amount of time. It's kind of the best of both worlds since people can get an inactive name if they want it and it also allows for extended breaks. The only small piece of work is that a GM would look to see if the name has been inactive. Like I said, this is a small amount of work. It's also what used to be done for inactive names.
