# Designate an English SEA Server

## Post 125927 by Sturmfaust — 2025-04-08T01:41:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=125927#p125927 | page 1 | era: pre-1.18.1 -->

My guild has recently started up on Turtle WoW for the first time. We're mostly Aus/NZ players so english speaking.
We initially rolled on Tel'Abim but found the high ping was pretty noticeable at times (>350ms), so moved over to SEA-Blood Ring, which is consistently 160ms. The trade off is obviously that all public channels and 99% of the players are Chinese, and we still haven't figured out how to get their names to display, let alone talk to them.

The language barrier isn't itself a completely gamebreaking issue as we can get dungeon groups going with our numbers and can probably eventually convince 20 of our number to come over for raids but, having spent a bit of time looking around reddit, discord, forums, etc for information about where OCE players are, it seems there's a bit of a gap in the official info.

Obviously OCE doesn't represent a huge number of players so we can't expect a dedicated server (although that would be great), but it would be good if Turtle WoW could designate one of the SEA Servers as "the OCE server" so that at least all the english speaking OCE players are funneled to the same place.
It would also be helpful if there was an english version of the SEA sign up page that appeared when accessed from the english client...Not sure how that would work exactly but we went around in circles a few times before realising we had to create a separate account on the Chinese page to be able to login to SEA.
