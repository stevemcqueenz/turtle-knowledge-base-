# Main/Sub Class Pattern

## Post 43927 by Dauntedpony — 2023-04-30T18:05:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=43927#p43927 | page 1 | era: pre-1.18.1 -->

Classes may unlock a sub-class that uses alternative mechanics provided by adding, modifying, and removing spells and abilities. Sub-classes are generally unlocked around levels 10-35 through a chain class quest. The character can switch between their main class and any sub-class and back by talking to the class trainer for that sub-class or main class.

When in this other class, the character has its own XP (level) that is not connected to the character's main class level. Sub-classes are not selectable via character creation and start with XP which makes them a starting level of 8.

Sub-classes do not alter the role of a given class but instead, provide alternative mechanics by which to fulfill it. Sub-class design should also focus on the verb "Trade" and "Specialize" and avoid "Add" or "Extend" as core elements.

Sub Class candidates:
- Warrior: Barbarian
- Warlock: Fel Sworn
- Mage: Arcanist
P.S. I'll expand these sub-class candidates' ideas in other posts, but this is a framework for how a sub-class could be added to the game.

## Post 44150 by Dauntedpony — 2023-05-02T18:06:00Z

This whole sub-class system could be implemented in a no-new UI or no-new code sort of way. But I would discourage that approach. This mostly comes down to the allure of "new". It gives Turtle a way to attract more players with something that feels fresh and exciting without the burden of creating a whole new class.

The depth of a sub-class could be simply trading one ability for another that mixes up the gameplay. Or as complicated as a whole new talent tree and set of abilities. Regardless of the final implementation, this novel system could be used to great effect to tell the stories of Azeroth and its people.

I think sub-classes should be different than added normal content. A sub-class should always use the verb "**trade**" in how it interacts with the main class.

 **Trade**, why? Because it is difficult to compare multiple mutually exclusive actions so it should be less likely to damage/invalidate a class's kit. It also enables bold changes which are meaningful to the player's actions and choices.

I think this difference also plays a role in why your sub-class may start at a lower level. This further makes them incomparable (numerically) as your character may not meet all level requirements for your normal gear.

For all of these reasons, I think that the implementation of sub-class should be a "first-class" feature.
