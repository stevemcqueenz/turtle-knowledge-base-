# Suggestion for Class specific items (looks) for RP

## Post 6275 by Sylph — 2020-06-08T17:09:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=6275#p6275 | page 1 | era: pre-1.18.1 -->

I'm not an expert coder, or know even remotely how it works to import items and so on.

BUT what I do like it looking cool and finding items that would go well with a set. So the suggestion I would like to make is to maybe add class specific items (that are not raid drops) to some endgame dungeon bosses that don't see alot of love?

As an example the Soulforge Paladin set looks pretty cool but it is of course only for paladins! So it would be cool if those items (the models, not necessary the same item) would be able to be obtained by non paladin classes!

This counts for any of the class specific items, I just gave this one as an example.

That being said I have no idea how other people view this or if it even would be wanted but I would love to see people make more RP sets if some items would not be locked for specific classes. I do want to stress that I don't want the items themselves to be available to other classes, just the models!
