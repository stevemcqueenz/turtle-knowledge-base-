# Quiver overhaul

## Post 173852 by Ffnabep (Barrens Chat Casualty) — 2026-04-03T09:24:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=173852#p173852 | page 1 | era: post-1.18.1 -->

Quivers are no longer equipped in the bag frame but instead in offhand. Ammo is still kept in bags but the quiver now gives the increased attack speed + stats equivalent to off-hand weapons.

This is mostly a style change and it would take a fair amount of work developing custom quivers for all level ranges as well as end game, but something about the current design of quivers rubs the wrong way. What about you? Peace.
