I currently use *[Lore](https://www.curseforge.com/wow/addons/lore/files)* to emulate this, but that requires a Chat Channel – and other players using it – to "work properly".  Even so, it's kind of fun to run around and speak languages I shouldn't know.  Like… [Nerglish](https://wowpedia.fandom.com/wiki/Nerglish).

Anyway, it *would* be kind of nice to implement this in some official capacity.  It shouldn't be that hard, either.  Titan, Demonic, and Kalimag ("elemental") are already part of the game, as is "Thelassian" [sic], and other languages could be added, if need be.  For example…

Druid -> "Feral" (custom language), Moonkin (Retail 7.x / 8.1?)
Shaman -> [Kalimag](https://wowpedia.fandom.com/wiki/Kalimag) ("elemental")
Rogue -> [Gutterspeak](https://wowpedia.fandom.com/wiki/Gutterspeak) / "High Sign"
Warlock -> [Eredun](https://wowpedia.fandom.com/wiki/Eredun) ("demonic")

Just some thoughts~
