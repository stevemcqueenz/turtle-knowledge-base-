# Devs - I think it's time.

## Post 56698 by Jammyxx (Patch Note Conspiracy Theorist) — 2023-08-10T15:03:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=56698#p56698 | page 1 | era: pre-1.18.1 -->

We're at 2200+ in queue right now, and thats without the new patch dropping yet. I can imagine when the patch drops it'll be a 6k+ queue. The server will keep growing. At some point the Devs are gonna have to suck up their pride about only having one server  and open a seperate HC server.

It's the only way at this point to ensure the server runs optimally and everyone can play without these extortionate queues.

I've seen so many complaining about the inferno quest to get level 60, and levelers complaining about the HC and normal imbalance for quests and tags etc.

At 6-7k pop I was against having a Seperate HC server because I liked leveling alongside the rest of the community as my hardcore and I'd buff and help hardcores as my normal character... But things have just gotten out of hand now with these queues, and even the Chinese server at this point will only help for so long.

Hardcore levelers make up atleast 25% of the population, it would make most sense to open another server for them with an optional transfer to normal server at 60 and gain the immortal title.

Think about it, the hardcore people can't even interact with the normies, and the world isn't going to exactly feel dead with 3k+ as hardcore on their own server in their own community.

They bring nothing by being on the same server with the current population, they can't trade, group, raid, party, or even use the same auction house as the normal community.

If things die down in the future you can always bring them back onto the original server anyway.
