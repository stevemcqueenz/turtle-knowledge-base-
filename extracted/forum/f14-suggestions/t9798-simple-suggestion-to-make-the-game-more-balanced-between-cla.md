# Simple suggestion to make the game more balanced between classes

## Post 63968 by Blackduck (Barrens Chat Casualty) — 2023-09-14T12:40:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=63968#p63968 | page 1 | era: pre-1.18.1 -->

Make it so you can choose whichever ZG helm/leg enchant you want regardless of class.

None of these enchants have anything that make them class specific. They just add hit/crit/spell damage/healing/etc. So there's nothing game breaking about letting people choose which enchant they want.  It would fix some of the end game raiding issues that a lot of classes/specs have by letting them focus on enchants with spell hit/spell damage if they're a moonkin for example or maybe they want the one that gives more crit that warlocks get if they're already hit capped.
