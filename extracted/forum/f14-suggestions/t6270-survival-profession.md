# Survival Profession

## Post 39510 by Warpath626 — 2023-03-28T22:32:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=39510#p39510 | page 1 | era: pre-1.18.1 -->

It would be cool and useful I feel if the survival profession would be able to allow your character to craft arrows like engineer does bullets or create throwables for rogues, warriors, and hunters. Additionally, I think it'd be cool if we had a 'butcher' option, which could carve meat from animals we kill like skinning, which can help the cooking profession. Maybe we could also create torches just for aesthetic value. Maybe something similar to 'armor' kits that could increase either our fire or frost resistance (you know, like surviving cold or hot temperatures). Or some things that could increase your run speed passively like a wilderness stalker, or create some discount version of camoflage like a ghillie suit. Just some ideas.
