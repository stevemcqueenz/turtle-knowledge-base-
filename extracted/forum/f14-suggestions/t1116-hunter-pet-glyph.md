# Hunter Pet Glyph

## Post 6496 by Naturemage — 2020-06-22T03:12:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=6496#p6496 | page 1 | era: pre-1.18.1 -->

With the transmog system in place for druid forms, I wonder if this would be possible for hunter pets as well? My idea is basically to have a Glyph of the Exotic Beast that changed pet families into a different pet. This would be strictly cosmetic, of course, and the pet would continue to behave exactly like the original animal.

If the Glyph of the Exotic Beast is on your keyring, your summoned pet will appear to be a beast from a new unique family.
- Bat >> Wyvern
- Bear >> Zhevra
- Boar >> Stag
- Carrion Bird >> Hippogryph
- Cat >> Aqua or Lavender saber cat (unused look)
- Crab >> ???
- Crocolisk >> Basilisk
- Gorilla >> Stegodon
- Hyena >> Diemetradon
- Owl >> Gryphon
- Raptor >> Devilsaur
- Scorpid >> Serpent
- Spider >> Kodo
- Tallstrider >> Giraffe
- Turtle >> Beetle
- Wind Serpent >> Faerie Dragon (or thunder lizard)
- Wolf >> Spectral Wolf (unused look)
These family transmogs were chosen based on if the "new" pet would make sense using the old pet's skills.
