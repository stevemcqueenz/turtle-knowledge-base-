# Visual distinction for upgraded items on the auction house

## Post 174496 by Alexianon — 2026-04-08T20:05:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=174496#p174496 | page 1 | era: post-1.18.1 -->

Currently, the auction house displays upgraded items (enchanted, socketed, etc.) exactly the same as ordinary ones in the search list. Sellers undercut each other by a single copper, while items with real added value are ignored simply because they are not visible at first glance.

Suggestion:
Modify the server so that upgraded items receive a visual marker in the standard auction house list. For example: a different text color, small icon or special frame or border.

Buyers can instantly see which items have real improvements, crafters and enchanters gain a fair advantage for their work. This encourages crafting and adds value to the economy.

This is not about adding complex filters or changing how the auction works. Just a visual hint.

Sincerely

Yeah, it's honestly a shame on both ends. As a seller, you get no benefit from selling upgraded items because you have to compete with the lowest prices. As a buyer, it's too much of a hassle to go looking through every single listing to see if any have an upgrade on them. A special frame – and maybe even the option to filter by enchanted/unenchanted – would be a great help for everyone, I think.
