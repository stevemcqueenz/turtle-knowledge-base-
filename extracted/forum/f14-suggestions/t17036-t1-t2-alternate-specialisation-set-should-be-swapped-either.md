# T1 & T2 alternate specialisation set should be swapped either way.

## Post 116180 by Twospooky — 2025-01-11T02:56:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=116180#p116180 | page 1 | era: pre-1.18.1 -->

Currently if you swap a T1 or T2 piece for the alternate set, it is one way only and if you want to use the original set you have to get the item to drop again.

Example: Warrior T1. You can swap a tank set for a dps set but you cannot swap a dps set for a tank set. If you want to tank again you have to re-farm Molten Core for the tank set which could take months.

T2.5 and T3 can be swapped both ways. You can swap warrior tank set for dps set and you can swap the dps set for the tank set.  Why is this inconsistent between tiers? It's faster to re-farm Naxxramas tier sets too, it drops from more than 1 boss and at a much higher rate.

Futhermore the tier sets are swapped at the same NPC and the quest to do it only appears if you have the required item.
All the quests should appear on the NPC so the gear is sorted into an orderly list a which prevents the player from accidentally swapping the wrong item and is what prompted me to post this. It also allows the player to inspect the items without the use of a third party addon.
