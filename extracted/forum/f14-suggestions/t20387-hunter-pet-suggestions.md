Here are some Thoughts about how Pets work together, so Hunter can talk what kind of pet everyone uses.

| **Hunter Pet Synergy – How Pets Support Each Other** |
|---|
| **Damage Buff + Armor Reduction** • **Wolf (Howl)** → Damage/Crit buff for the team • **Owl/Carrion Bird (Screech)** → AoE Armor debuff • **Raptor (Bone Crusher)** → Single-target Armor reduction → Perfect for Raids/Bossfights |
| **CC-Lock Chain** • **Spider (Web)** → Root • **Wyvern (Wyvern Sting)** → Sleep • **Basilisk (Petrifying Gaze)** → Petrify → Up to 12 sec control chain in PvP |
| **Tank + Support** • **Bear/Turtle** → Taunt + Shell Shield for tanking • **Owl/Bat** → Screech reduces enemy physical damage • **Spirit Wolf** → AoE Fear for adds → Ideal for Dungeon groups |
| **Bleed + Poison + Armor Break** • **Cat/Raptor** → Bleed DoT • **Scorpid/Wyvern** → Poison DoT • **Devilsaur** → Monstrous Bite for Armor Break → Maximum sustained damage |
| **PvP Zerg Combo** • **Hyena** → Healing Debuff • **Wind Serpent** → Magic damage bypasses armor • **Devilsaur** → AoE Fear → Lock down healers & crush enemy teams |
| **Support + Defensive** • **Moth** → Healing Aura • **Hippogryph** → Wind Barrier (Projectile reduction) • **Thunder Lizard** → Thunder Stomp (AoE stun) → Long sustain in PvE & PvP |
| **Recommended Setups** • **2 Hunters:** Wolf + Owl → Buff + Debuff → best for Raids • **3 Hunters:** Bear + Wolf + Owl → Tank + Buff + Debuff • **4 Hunters:** Devilsaur + Wyvern + Basilisk + Owl → CC + AoE Damage + Fear |
