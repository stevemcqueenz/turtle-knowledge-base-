# Judgment of Wisdom and mana using melees

## Post 151560 by Akos1896 (Grandmaster of Forum PvP) — 2025-09-13T12:15:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=151560#p151560 | page 1 | era: pre-1.18.1 -->

Hey!

This is not strictly a suggestion, just an observation.
I noticed that mana-using, non-pala melees have mana problems if JoW is not available.
Meaning survival hunter and enh shaman.
A part of me would suggest a better mana regen system for them but JoW has to be kept in mind, since at raiding, it is expected to be applied, and mana has to be a finite resource.

I'm not talking about buffing those 2 builds or nerfing JoW, just stating that expecting one class' debuff on a target for two other classes to function properly resource management-wise is weird design.
