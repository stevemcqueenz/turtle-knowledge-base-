# Fallen Prophet set + T2,5 tank set (shaman)

## Post 106713 by Akos1896 (Grandmaster of Forum PvP) — 2024-11-06T14:50:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=106713#p106713 | page 1 | era: pre-1.18.1 -->

Hey!

I'd suggest to re-itemize mantle of the fallen prophet into a bracer and boots of the fallen prophet into a waist item.

Why?
Fallen prophet set is a unique 3-pieces set from AQ40 made for shaman tanking, having multiple relevant and interesting item bonuses.
In the meanwhile one of the T2,5 shaman sets has become a tanking one. I really like the option.

But.

T2,5 is a 5 item-set, meaning that there is a place for a 3item-bonus outside of the set while wearing it. While the fallen prophet set is fun, it is no challenger of the T2,5 set.
If mantle of the fallen prophet becomes a wrist item and boots of the fallen prophet becomes a waist item then you can wear both, adding +12 defense and 2% haste to your shaman via set bonuses.

I suggest this since:
 1. Shaman tanks are still memes outside of dungeons, this change wouldn't overpower them in any way.
 2. Fallen prophet was a very niche but unique set at AQ40 which now becomes totally irrelevant very soon since you get a better set while farming AQ40.

You could in theory say that T2 or T3 enh DPS items can be used on those slots but this change would enable a survival-based item bonus for the remaining slots. Our friends wear mail after all.
