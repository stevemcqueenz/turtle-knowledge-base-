# Is it possible to add an additional CAPTCHA in to login procedural, please?

## Post 63214 by Konakamasaru — 2023-09-12T13:36:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=63214#p63214 | page 1 | era: pre-1.18.1 -->

As the subject. Excuse me if I'm wrong about something.

I mean AFTER username/password, but BEFORE the queuing, could we add an additional captcha so we could make sure it is a human who is trying to queue.

Now turtle wow needs no captcha at all, so in theory the registration and login procedural could be done automatically.

However, it is already quite some time since the registration is open to everyone, so adding a captcha at registration would be inefficient, as there could already be enough backup account be prepared for bots.

I see that there is a patch file that add the "saving username/password" function to the client: [https://turtle-wow.fandom.com/wiki/Clie ... #AutoLogin](https://turtle-wow.fandom.com/wiki/Client_Fixes_and_Tweaks#AutoLogin)

It is possible to add additional UI elements to the client.
So this captcha idea comes to me. It require building a new UI frame for the client and some tweak on the server so the captcha could be generated and be verified.

I don`t know much about WoW programming, nor I know nothing about the actual server states. However current queue length is somewhat  provoking me to think maybe a captcha is necessary.

Just  suggestion.  Thanks for your time.
