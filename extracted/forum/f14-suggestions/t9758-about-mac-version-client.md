I used to play in a old mac
I used the program WINE

It was confusing at first  but in fact is pretty easy once you know how

Just open wine and write /wine with the .exe directory

Like
/wine /programdirectory/wow.exe

Never add spaces is something i learned. So dont rename any folder with spaces. only add a space after /wine
