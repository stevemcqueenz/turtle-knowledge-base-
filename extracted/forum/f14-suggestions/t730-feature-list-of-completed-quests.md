# [Feature] List of Completed Quests

## Post 3760 by Face — 2019-08-20T00:54:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=3760#p3760 | page 1 | era: pre-1.18.1 -->

In vanilla there is no way to know how many quests the character has completed unless someone keeps note of every single one. Since many people are in this server to enjoy questing, I thought it would be a nice feature to have.

This became possible after an API call was introduced in WotLK, I think it was GetQuestsCompleted()

Now I'd like to know if such a thing would be possible in 1.12 and if anybody thinks it would disrupt the vanilla experience.

Personally I would use it for making personal backups of characters or for restoring my questing addon if I need to reinstall.

Thanks for your attention, keep your opinions coming!
