# Account Freeze mechanism

## Post 59623 by Mina — 2023-08-28T20:58:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=59623#p59623 | page 1 | era: pre-1.18.1 -->

With the increasing popularity of the server, the odds of someone inputting their password somewhere other than the password field (for example discord server that they just chatted) keeps their account at risk.

So currently the only way to "save" such account, is to inform the "owner" to change it ASAP or try to get in yourself and change the password and send to "owner".

So instead of waiting for response from the "owner" or attempting to change the password myself, I would suggest to add "freeze account" functionality, that invalidates current password and login attempts, preferably checks if any character is online during that moment and "freezes" them or something until they verify that they are legitimate owner. This verification could be done by sending a code or url link via email.

Might need a lot of thinking, so it doesnt result in people spamming it. Or maybe instead of manual "freeze" it could be done automatically if several people are attempting to log in from different IP addresses.
