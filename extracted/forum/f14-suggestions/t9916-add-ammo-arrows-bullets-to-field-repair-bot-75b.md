Hi, as a hunter it can be frustrating to run out of ammo in the middle of a dungeon or raid. All other classes are able to save on bag space and quickly reload on their critical reagents by using the donation reward Field Repair Bot 75B.

Would it be possible to add some ammo (even if it's not the max level stuff) to the repair bot's vendor list so that hunters can have the same benefit?
