## Post 8724 by Roxanneflowers (Patch Note Conspiracy Theorist) — 2020-12-17T13:51:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=8724#p8724 | page 1 | era: pre-1.18.1 -->

Actually, the simplest way to rig this kind of thing would be to do a Spurs of [Levitation](https://database.turtlecraft.gg/?spell=6492) item that can be enchanted/equipped onto Boots.

Basically take the Priest [Levitate](https://database.turtlecraft.gg/?spell=6492) spell and modify it to only be active while mounted, so your mount "walks on air" all the time.  As soon as you dismount, the [Levitate](https://database.turtlecraft.gg/?spell=6492) spell effect terminates.  The item confers no speed bonuses, merely a way to "walk on water" (by hovering in the air above it), that activates only when mounted, no cooldown.

Instead of Blacksmithing, I would make the creation require Engineering skill to create and equip, but Engineering skill is not required to use the effect (so Engineers make it, but non-Engineers can use it).

Following the precedent of Tents for Survival skill, you'd need to Use an item to create the Spurs of Levitation using materials in your inventory.

Crafting Item (used from inventory) Requires:
- Engineering (250)
- [Truesilver Bar](https://database.turtlecraft.gg/?item=6037) (8)
- [Enchanted Thorium Bar](https://database.turtlecraft.gg/?item=12655) (2)
- [Light Feather](https://database.turtlecraft.gg/?item=17056) (20)
- [Crystal Force](https://database.turtlecraft.gg/?item=11563) (2)
- [Essence of Air](https://database.turtlecraft.gg/?item=7082) (4)
Crafts:
Spurs of Levitation
Use (on Boots only): [Levitation](https://database.turtlecraft.gg/?spell=6492) spell effect only while mounted.
