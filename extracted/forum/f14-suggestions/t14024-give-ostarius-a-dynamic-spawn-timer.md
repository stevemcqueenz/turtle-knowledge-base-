# Give ostarius a dynamic spawn timer

## Post 95504 by Ploxion — 2024-05-23T14:44:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=95504#p95504 | page 1 | era: pre-1.18.1 -->

So currently ostarius is programmed to spawn from a quest, that quest gets locked after he's killed and are then available again after a server crash/restart. It has been beneficial with the high amount of crashes lately. I personally don't consider this to be vanillalike.
Instead I'd suggest to give him a dynamic spawntimer, make the quest repeatable so everyone can spawn him if they've done the questline. But to eliminate the need to have a designated scouter check for him I'd also suggest to have a zonewide/regionwide announcement made about him being summonable
