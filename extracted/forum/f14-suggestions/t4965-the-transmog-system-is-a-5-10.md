lemme first of say that the armor saving on equip for later use is a big plus.
but there are other features that hinder/ are redundant :

 -transmoging to gear bound ; it sucks because it means you have to re-do transmog everytime you switch gear, creating another issue
 -transmog is neadlesly expensive ; the fact you need to gather fashion tokens is extremely redundant and a huge time sink/waister, i wanna play and have fun, not running back and getting fashion tokens everytime i wanna save my appearance.
 - sometimes the system flukes and you end up semi naked (?) it needs some fixing fer sure.
 - there are already solid transmog systems out there, not gonna server name drop or compare, but really go out there and you can find easily impactfull transmog systems done.
so please, make the transmog system so it can be done on a wim, and doesn't hinder gameplay or rp or w/e.
help the class fantasy feel of it, cuz it adds alot to the game.
