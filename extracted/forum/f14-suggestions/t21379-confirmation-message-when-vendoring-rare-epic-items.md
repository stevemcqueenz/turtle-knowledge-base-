# Confirmation message when vendoring rare/epic items.

## Post 148176 by Tarkz — 2025-08-25T14:14:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=148176#p148176 | page 1 | era: pre-1.18.1 -->

Being able to accidentally sell your gear so easily with no confirmation message is currently a MAJOR problem that needs to be addressed. Especially considering how easy it is to sell part of your main gear by mistake via a macro or add-on that switches your gear while having a vendor open. The fact that most have/have access to a vendor bot makes this issue even more severe.
I've heard of countless people having sold gear by mistake, gear that they raided/grinded/farmed sometimes for months to obtain and I'm sure a simple confirmation message would save players a lot of grief and GMs a lot of tickets.
In order to make this easier for people that just want to vendor random blues without having to click on a confirmation message for every item, maybe a requirement for the message to pop would be for the item to be soulbound.

If the confirmation message is something that cannot be done due to whatever reason, maybe consider at least letting players buy that gear back via the Ratchet NPC the same way it is for quest items.
Please and thank you   smiling_turtle_head
