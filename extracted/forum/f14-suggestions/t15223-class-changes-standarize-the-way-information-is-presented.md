# Class Changes - standarize the way information is presented

## Post 103382 by Ahlen (Barrens Chat Casualty) — 2024-10-17T13:28:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=103382#p103382 | page 1 | era: pre-1.18.1 -->

Hello,

As a new joiner to the server I have a suggestion to provide more information on the website where you explain all changes applied for each class Learn More --> Class Changes. I would like to see there a list of all class and race specific abilities and racials, including their description, required level, mana cost etc. Some sort of database displayed in a very nice way so that it's easy to go through and learn what changes you have implemented for specific classes. Another thing is that not all information is presented in the standarized way, some information from one Class will have information when an ability becomes available while leveling, while other Class will not have such information.

For example Druid Savage Bait has the information when it can be learnt, while Decesive Strike from Warrior toolkit does not have such information provided.

When I was searching through Turtle WoW database I found a lot of "uncategorized spells" mixed with other spells not really beloning to a class. It seems that database is not well organized or I am not able to search through it properly. Anyway, I believe that providing more information in the Class specific changes on the website could be a good way of advertisement of the server and for analysis of which class I would like to start playing with. This is what people are usually intrested with when they land on your website.

To summarise, Learn More --> Class Changes should be more standarized and should present all changes applicable for a particular class. We should see changes to the talents and abilities which we can learn through leveling or which are learnable through other sources.
