# Allow to select 2 icons for macroses

<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=150346#p150346 | page 1 | era: pre-1.18.1 -->

Sometimes, I use macroses to decide, which ability I should use. For example: if target is friend, then Heal else Wrath.
Or if I far, then Charge else Hamstring.

In those cases, it will be cool to see Charge/Hamstring icon in the same time. Like top-left half is from Charge, bottom-right half is from Hamstring.

It will change icons depending on my selected target. I know this doesnt help you but just thought ide throw it out there.
