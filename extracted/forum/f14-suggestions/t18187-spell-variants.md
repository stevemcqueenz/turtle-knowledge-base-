# Spell Variants

## Post 123898 by Dannyp92 (Barrens Chat Casualty) — 2025-03-26T09:41:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=123898#p123898 | page 1 | era: pre-1.18.1 -->

This is probably very hard to implement, and probably impossible to do as of now. But it would be very cool to be able to switch between "variants" of spells. So for instance, you could change Conflagrate to work as it did prior to CC2, where it consumes the Immolate-spell, so you can follow up with Soothing Kiss (which would break otherwise, see the old Drakedog-build). This example would work better for PvP, while the current version is better for PvE. This could perhaps also be used for a future possible Necromancer-spec, where you can "morph" the Summon Imp spell to instead summon a Skeletal Mage.
