# Troublemaker achievement for PvP realm

## Post 79404 by Xudo (Grandmaster of Forum PvP) — 2023-11-30T14:56:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=79404#p79404 | page 1 | era: pre-1.18.1 -->

Currently PvP server does not offer any custom challenges, so I thought what could be done there?
This new challenge should obviously be related to PvP.
It should be about fair pvp of players with similar level.
It should take some intentional effort to achieve.
It should be done in open world. Because PvP server is about world-pvp, not about 3 battlegrounds in a endless loop.

On PvE server some horde players of lvl 19 camped Moonbrook and killed careless warmode players. I think this is kind of PvP to be encouraged on new server.

So proposal is: add achievement "troublemaker".
Player get this achievement and title for killing 500 enemy players which yield honor in each contested territory.
When player get 150 kills, then everyone should see yellow message in general chat telling "Player <name> killed 150 enemies in <zone>. Beware, he is going to kill even more!".
When player gets 500 kills, then everyone should see yellow message like "<name> has finished his slaughter in <zone>. Where he will go next?"

Assuming that you need to get honor from kills, you would not be able to level to 60 first. You will need to do get this achievement during your leveling. I expect that people will tend to populate low level world doing this challenge.

Some locations are contested, but with little horde/alliance presence. Like Wetlands or Redridge. Though if there will be some horde guy attempting to do this challenge, then alliance players will get some targets to kill even there.
