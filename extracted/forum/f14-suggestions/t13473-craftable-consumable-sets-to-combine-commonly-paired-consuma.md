# craftable Consumable Sets to combine commonly paired consumables

## Post 91040 by Ghostlights — 2024-03-21T10:31:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=91040#p91040 | page 1 | era: pre-1.18.1 -->

Whenever a warrior/paladin/shaman uses Elixir of the Mongoose, they use an Elixir of Giants immediately afterwards, right? So how about the ability to combine them into a single item that applies both buffs when used?

For example:

Gladiator's Potion Set: Mongoose + Giants
Juggernaut's Potion Set: Elixir of Superior Defense + Elixir of Fortitude + Major Troll's Blood Potion
Conjurer's Potion Set: Greater Arcane Elixir + Mageblood Elixir
Shadowcaster's Potion Set: Elixir of Shadow Power + Greater Arcane Elixir + Mageblood Elixir
Pyromancer's Potion Set: Elixir of Greater Firepower + Greater Arcane Elixir + Mageblood Elixir
Starcaller's Potion Set: Elixir of Greater Nature Power + Greater Arcane Elixir + Mageblood Elixir

It could include blasted lands buffs, too

Berserker's set: Mongoose + Giants + ROIDs
Headhunter's Set: Mongoose + Giants + Scorpok Assay

Potentially even hyper-specialized sets like:

Crusader's Potion Set: Applies Mongoose + Giants + Greater Arcane Elixir
Hellcaller's Potion Set: Shadow Power + Greater Firepower + Greater Arcane Elixir

I think it would work best as part of the Survival skill so that each player can combine their own consumables, but it could be part of alchemy too I guess.

Thematically, I think it works best with survival since you're just putting multiple potions in the same box as a form of efficient organization
