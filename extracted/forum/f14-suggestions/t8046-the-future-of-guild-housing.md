# The future of Guild Housing

## Post 51730 by Lemonlime — 2023-06-29T03:31:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=51730#p51730 | page 1 | era: pre-1.18.1 -->

Guild housing is a very highly desired feature in a guild. Since individual guild houses take a lot of manual dev work, and we're unlikely to be able to continue having custom builds for every guild at the rate twow is growing, I thought I'd share a few thoughts I've had about scaling this feature up without gating it behind manual dev work.

Create a handful of generic guild houses around the world with unlockable NPCs that function similarly to the guild bank npc - you can only access this feature if your guild pays x amount of gold, turns in x amount of mats etc. Guild Masters would have to visit the house in game and talk to the npc to unlock the specific feature, which could include guild tabard teleport, flight path, vendors, bank, auction house, mailbox etc etc. Each feature would have a set of requirements the guild would need to work on to unlock. Of course each guild would only be allowed to select one guild house at a time.

Think Skyrim houses - they are in predetermined locations, but you can still upgrade them based on whatever your guild decides is most important for them. This would take dev work for each new location, but then these locations could be used by any number of guilds. Ideally this would be able to be instanced so that I only see my own guild members while I am in my guild house, but I imagine that would be exponentially more complex from a development perspective.

Obviously it's not the same or as special as having your very own custom designed guild house, but it's a heck of a lot better than not having the option at all if your guild isn't old enough or whathaveyou. I would rather see small guilds be able to thrive too instead of having every single player funnel into the few guilds that have houses so they can use their tabard teleports.

On a side note, guild bank is too dang expensive for something that is a pretty fundamental guild feature. That cost needs to come way down.
