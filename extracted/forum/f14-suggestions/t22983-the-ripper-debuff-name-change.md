# The Ripper debuff name change

## Post 160400 by Marrep — 2025-11-23T12:33:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=160400#p160400 | page 1 | era: 1.18.1-announced-pre-release -->

Debuff that reduces armor, applied by The Ripper (<https://database.turtlecraft.gg/?item=60422>) is named exactly the same as a rank 1 Corrosive Poison from a rogue - "Corrosive Poison".
If you could change the name of the debuff from The Ripper to something else, or change rogue poison debuff name to "Corrosive Poison I" instead of just "Corrosive Poison", it would make it possible, for example, to modify aDF addon to track The Ripper debuff and not get confused by the rogue-applied poison.
Thanks in advance.
