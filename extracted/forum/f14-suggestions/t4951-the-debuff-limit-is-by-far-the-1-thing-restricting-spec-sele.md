# The debuff limit is by far the #1 thing restricting spec selection

## Post 29882 by Ukkoso — 2022-11-26T18:05:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=29882#p29882 | page 1 | era: pre-1.18.1 -->

In the 3 minutes since I've written this post, it's been brought to my attention that this is already something that is being discussed by the team, which is great! I'm going to leave this post up though in order to voice my support. Thank you all for the work you do! This server is amazing.

Every vanilla server out there runs into the same issue. There are only 2 or 3 truly viable  DPS specs for raiding, and 80% of all specs are watered down to 1 or 2 abilities because of the debuff limitation. There is no amount of "buffing" other classes that is going to solve this problem because none of those abilities are actually usable in a 40-man raid.

As a disclaimer, I am not an expert in all classes. I'm probably about to mislabel some abilities.

The problem that this server seems to keep running into is that you can't just keep giving these other classes more damage abilities without drastically effecting PvP. This can be addressed by just making the abilities that they already have actually usable in PvE! There is already so... much... variety... between classes in this game, 80% of it is just unusable because of this 1 effect. Yes this is an oversimplification. No it won't solve all PvE problems, but most of these tools are already built into the classes, they just aren't allowed to use them in raids.

We all know the list, and this isn't even the full one:

Affliction Warlocks: No amount of buffing DoTs will ever make them usable when there isn't a slot for them. This is now a 1 button class.

Destruction Warlocks: Fire abilities aren't usable when there isn't a slot for immolate. This is now a 1-button class.

Retribution Paladin: No amount of reworking Crusader Strike will make this more than an auto-attack class. No, you can't use judgements either. This is at worst a 0-button auto-attack class, maybe a 1-button class.

Feral Druid: An entire spec based around bleeds that isn't allowed to use any bleed effects.

Balance Druid: No moonfire or insect swarm, 1-button class.

Enhancement Shaman: Only real offensive ability isn't usable, no amount of buffing will change this core problem. This is an auto-attack class with a single shock every few seconds (maybe).

Shadow Priest: Addressing the mana problems is good, but it's still a 2-button class (if they're even allowed to use mind-flay) because you can't waste a debuff slot on a DoT.

Hunter: Giving this class another direct damage ability helps them scale, but one of their unique abilities is already unusable. This is now a 2 or 3 button class that sort of scales better?

Rogue: Only 1 poison option because we can't use a debuff slot for something like deadly. Yes this is already a top spec, but even the pure dps classes are watered down by this limitation.

The debuff limit is far and away the number 1 thing holding back Vanilla Wow PvE. People have said for 15 years that "you just need to learn your class, they're all viable" which is very clearly not true. 15+ years later the majority of the classes listed above are either just not allowed in raid or are a 1-off brought for a buff, which is then relegated to a 1-button spam. This is a core problem with the game and is not addressable by continuing to add more damage abilities to these classes. They already have damage abilities, they just aren't allowed to use them.

Thank you for coming to my Turtle Talk.
