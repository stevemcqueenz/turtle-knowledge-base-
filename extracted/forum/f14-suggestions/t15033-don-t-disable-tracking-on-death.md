I have for my paladin one button tanking macros, where I check if Righteous Fury enabled, remove Salvation if buffed and so on.
You can write macros, that will check if Cat form enabled , than cast Track humanoid and after cast some Cat spells, Claw or Prowl, for example. And put it instead Claw or Prowl on panel.
Something like this:
/script if buffed("Cat Form") then if not buffed("Track Humanoids") then CastSpellByName("Track Humanoids") end end
/script CastSpellByName("Claw")
