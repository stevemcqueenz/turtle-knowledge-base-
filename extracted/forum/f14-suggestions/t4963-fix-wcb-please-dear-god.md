# Fix WCB Please dear god

## Post 29966 by Ugoboom (Bug Report Enthusiast) — 2022-11-28T18:27:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=29966#p29966 | page 1 | era: pre-1.18.1 -->

For now, wbuffs are still a thing. While they are still a thing, can we get WCB to not be literally cancer for alliance to obtain?

This is an insanely important wbuff, without it meele lose about 10% of their DPS, and even more for 2h enjoyers including ret paladins. This is really not optional for the numerous naxx teams on this server. You don't get it? You do worse on dps and get lesser prio on gear unfairly. This is not fun.

To get this buff, we have to stand around in org or crossroads as the enemy faction, paying attention to the screen to see when a new drop occurs, then be mind controlled for the event. This is awful.

Also, the WCB buff has a 3 hour cooldown, making it the only wbuff that has impossible logistics as randoms can ruin any scheduled buff drops. Please remove this cooldown like it has been done for the ony and nef heads (which was a fantastic QOL change y'all made!)

As for getting WCB as alliance...

The quick fix is to adjust buffs in cities to apply to both factions, without the need for mind control, so at least we can AFK in crossroads in a safespot from guards and get it easy. I will settle for this easy fix, though its not super thematic.

The ideal change, albiet more dev work, is that we could use an alliance equivalent quest, perhaps involving one of the new dungeons, giving an identical buff but with alliance theming.

Both suggestions can be done at the same time as well, they're both good changes I think should make it in eventually, to give players more option to their way of experiencing the game.

Thank you.
