# Druid Starfire is so slow now post-change to "Balance in all Things"

## Post 175415 by Halfgeek9 (Barrens Chat Casualty) — 2026-04-16T05:09:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=175415#p175415 | page 1 | era: post-1.18.1 -->

The old talent was far more interesting and useful for Balance spec Druids, having that -0.5s cast time to Starfire make the spec more mobile and "boomy" dps.

Now stuck at 3s cast time for a mediocre nuke just feels bad in both PvE & PvP. Balance druid are also bottom tier DPS by far.

Suggest buff to talent "Improved Starfire".

From current 0.2/0.3/0.5s reduction to Starfire -> 0.3/0.6/1.0s reduction.

A boost to DPS output (much needed) and less static hard casting a slow nuke in PvP (also much needed for the weakest class).
