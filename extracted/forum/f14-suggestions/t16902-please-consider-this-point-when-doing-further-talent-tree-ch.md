# please consider this point when doing further talent tree changes

## Post 115442 by sandronecrophos — 2025-01-04T22:54:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=115442#p115442 | page 1 | era: pre-1.18.1 -->

Hi Turtle WOW creators,

I'm a 20 years WOW player, only play mage. So far I'm playing a mage again in the PVE server and really enjoys the content you created.

However the recent talent changes concerns me for further direction of this server's development.

By the way I only play mage PVE, not PVP or any other classes.

For me the best time of the mage talent tree design in WOW history is on TBC. The best talent tree mage players ever created is the arcane/frost 40/21.

![Image](https://i.gyazo.com/0dd4ca2991812b43f123dbd4932a7db5.jpg)

The reason is not about what talent is overwhelmingly strong or not, the reason is this talent distribution is mained on arcane, however function as a frost mage. It reaches the extra crit rate, crit damage and extra spell power in deep arcane tree, but used all the core talents in upper frost tree including the extra damage, crit damage, hit rate, temporary casting speed enhancement, then combined all above into a well-functioning talent. Whoever created this talent distribution is really a PVE genius.

BUT what I want to say by above story is, the talent tree design should focus on encourage player's creativity to make up new stuff, develop new way to play a class or a spec, rather than making some talent super strong then force all good players to choose it.

THIS is exactly what is happening on the new mage talent design. I don't know other classes changes but I believe more or less it's the same situation if developers follow the same principle.

I understand that developers want to spice things up so enhance the previous comparably "weak" arcane talents, but what happens is the changes all focus on enhancing arcane skills, rather than anything else. The good talents only benefit arcane missile/blast/rapture/whatever arcane, but no effect work on frost or fire skills. Then how can players be creative and research new ways to play? The possible imaginations are all blocked. We have to put 48 points to arcane talent if we want to perform well in raid, then where is the creativeness? Remove 1-3 points on arcane hit rate base on gear? That's not creative, that's boring.

So, if you ever wants to change the talent trees again, please consider more on how to combine different trees benefit together, instead of just develop some strong but boring talents. Stimulating players creativity is much more important than if certain spec is popular or not. Forcing everyone to choose the same talent is not fun. I believe turtle wow wants to create fun, so think about it.
