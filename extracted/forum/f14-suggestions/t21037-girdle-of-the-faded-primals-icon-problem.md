# Girdle of the Faded Primals - Icon problem

## Post 146303 by Jc473 (Patch Note Conspiracy Theorist) — 2025-08-16T23:22:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=146303#p146303 | page 1 | era: pre-1.18.1 -->

This new item from Sanv Tas'dal (kara40 boss) drops a belt with a proc chance to summon a spirit protector which provides a buff to your party called Primals' Blessing. Unfortunately, this buff shares the same icon as the Regrowth ability from Druids. This makes it harder to heal certain groups as a Druid.

I use PFUI and I don't think there's a way to hide this buff because the addon detects the Regrowth icon and assumes it should be included when you select the option "Show Hots indicators". Surely, people using the other UI addons will also have this problem?

So, is it possible for the art team to come up with a new icon for Primal's Blessing please?
