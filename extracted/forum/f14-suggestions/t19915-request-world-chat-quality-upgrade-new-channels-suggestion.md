# Request: World Chat Quality Upgrade + New channels suggestion

## Post 135965 by Wez0 (Patch Note Conspiracy Theorist) — 2025-06-16T17:00:00Z

**World Channel Rules & Updates** ![🌍](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f30d.svg)

![Image](https://via.placeholder.com/150x50/FF0000/FFFFFF?text=View+Rules)  **General Rules** ![📜](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f4dc.svg):
- **No spamming items or memes** ![🚫](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f6ab.svg) (e.g., dirge jokes). Nostalgia’s cool, but brainrot clogs the chat! ![😵](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f635.svg)
- **No racism or hate speech** ![🚫](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f6ab.svg) in-game. Respect all players! ![🤝](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f91d.svg)
- **No guild recruitment** ![🏰](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f3f0.svg) in World Channel. Use the guild channel instead.
- **No trading** ![💰](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f4b0.svg) in World Channel. Head to the trade channel for deals.
- **No LFG posts** ![👥](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f465.svg). Use the LFG channel for group finding.
 **Channel Updates** ![🔧](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f527.svg):
- **Guild Recruitment Channel** ![🗣️](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f5e3.svg): Auto-invite guildless players to */guildrecruitment* on login. Include a welcome message with exit instructions:
> “Welcome to /guildrecruitment! ![🏰](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f3f0.svg) Find a guild or type Code: Select all
>
> ```
> /leave guildrecruitment
> ```
>
>  to opt out.”
- **Trade Channel** ![💸](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f4b8.svg): Create a single */worldtrade* channel for all trading to cut spam and keep it simple. (Note: */worldtrade* beats */trade* for clarity! ![✅](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/2705.svg))
- **Profession Channels** ![⚒️](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/2692.svg): Add dedicated channels like */enchanting*, */tailoring*, */blacksmithing*. Less spam, easier to find buyers/sellers! ![🛠️](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f6e0.svg)
- **LFG Channel** ![👥](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f465.svg): Launch a */lfg* channel for all group-finding needs, keeping World Channel chill. ![😎](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f60e.svg)
 **Config Updates** ![⚙️](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/2699.svg):
- **Channel Join Message Toggle** ![📢](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f4e2.svg): Let players enable/disable join messages in settings to reduce clutter. ![🔔](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f514.svg)
- **Permanent Channel Ownership** ![🔒](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f512.svg): Allow players to buy or earn a permanent channel slot (no annoying ownership change spam, e.g., yellow text). ![🏆](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f3c6.svg)
 **Extra Suggestions** ![💡](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f4a1.svg):
- **Moderation Tools** ![🛡️](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f6e1.svg): Use automated filters for spam or off-topic posts, with warnings for players. ![🚨](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f6a8.svg)
- **Channel Directory** ![📜](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f4dc.svg): Add a Code: Select all

```
/channels
```

command to list all channels with descriptions and join/leave instructions. ![📋](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f4cb.svg)
- **Rate Limits** ![⏲️](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/23f2.svg): Add a 10-second cooldown for posts in busy channels like World or Trade to curb spam. ![⏳](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/23f3.svg)
This keeps the chat clean and fun! ![🎮](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f3ae.svg) Let me know your thoughts! ![😄](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f604.svg)
