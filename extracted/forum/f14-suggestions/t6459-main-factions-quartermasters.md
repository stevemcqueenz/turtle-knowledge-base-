# Main Factions Quartermasters

## Post 40690 by Keldiskeris — 2023-04-07T17:20:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=40690#p40690 | page 1 | era: pre-1.18.1 -->

Hello Turtle WoWTeam, Forum dwellers.

Hope this post will reach you well.

Could we get some proper quartermaster rewards? In this post [viewtopic.php?t=728](https://forum.turtlecraft.gg/viewtopic.php?t=728) under New Factions and Reputation Rewards you mention new items to be available.

You got me quite interested but unfortunately from what I've seen, items sold at most Quartermasters are lackluster and irrelevant, in some cases, there are absolutely no items that seem rewarding at the point you actually reach the required reputation, only Raventusk Trolls <https://database.turtlecraft.gg/?npc=80807#sells> & Silvermoon Remanat <https://database.turtlecraft.gg/?npc=80459> have received some love and seem to be at least somewhat relevant.

I suggest adding thematic armor sets for each type (cloth, leather, mail, plate) and some weapons for every Main Faction.
These would be underpowered at required levels, like not on par with dung drops. Still, it would provide some RP and cosmetics for those that want them. Something like heirloom armor in retail but in the spirit of Vanilla.
HC characters would be maybe restricted from this until lvl 60?

The brackets could be as follows
Honored - req lvl 25 -green ilvl 25, No set bonus
Revered - req lvl 45 -green ilvl 45, 5 set armor with 3 or 5 set bonus to make it a bit more viable, but still underpowered
Exalted - req lvl 60 -blue ilvl 65, 5 Set armor with some nice set bonus to make it feel like a reward for getting exalted but worse than PVP or pre-raid BIS gear.
Items bind on pickup and could be class restricted.

Weapons would follow the same brackets and power level mentality as armor with some twists like Darnassus QM won't be selling maces, but fist weapons. Ironforge guns but no bows. Orgrimmar only axes and etc. Basically, each faction would have some lore-friendly weapons.

Any feedback is appreciated.

Thank you!
