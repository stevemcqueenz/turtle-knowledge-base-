A toy with a cooldown that plays a horn sound (e.g., Gondor horn) and can just trigger the /roar animation.

/rasp has a sound: it makes a farting noise. Add this effect to /fart as well.

Add the Groove Warden mount to the store. Hit me up if you want a the .m2 file. I have it retroported and working in my own modded patch.

 4. **MoP Challengemode armor sets**
Make the Challenge Mode gear sets available in the shop (retroported files ready if needed).

 5. **Druid forms /roar**
Make /roar use appropriate sounds for each druid form (e.g., bear growl, moonkin roar).
