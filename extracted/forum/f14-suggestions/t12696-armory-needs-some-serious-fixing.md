# Armory needs some serious fixing

## Post 84579 by Imonobor (Bug Report Enthusiast) — 2024-01-13T20:53:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=84579#p84579 | page 1 | era: pre-1.18.1 -->

It seems the armory (<https://armory.turtlecraft.gg/>) has been abandoned. Its current state is very broken. Here are the problems with it:

 -You can only search characters from the main realm (Nordanaar).
 -Item tooltips are broken and don't load (it seems the API is attempting to call Wowhead instead of the TWoW DB)
 -Model previews don't load at all. (not a critical problem)
 -Clicking on a character's talents again links to Wowhead and breaks, because TWoW talents are not the same as Classic. It should link to <https://talents.turtlecraft.gg/>

I understand that it's not a very important tool, but at the very least item tooltips should be fixed, because currently it is frankly useless.
