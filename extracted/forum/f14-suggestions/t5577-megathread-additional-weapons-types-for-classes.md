# MEGATHREAD: Additional Weapons Types for Classes

## Post 34495 by Syrathegreat (Patch Note Conspiracy Theorist) — 2023-02-10T16:33:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=34495#p34495 | page 1 | era: pre-1.18.1 -->

A couple weeks ago I posted in General chatting about [new weapon skills for classes](https://forum.turtlecraft.gg/viewtopic.php?t=5433) which had a number of interesting points brought up. Since then,  [this post](https://forum.turtlecraft.gg/viewtopic.php?f=14&t=1896) about polearms for druids has been necroed, plus I've seen and had a number of conversations in-game and in Discord about the topic.

As such I've decided to make a megathread of all these ideas in a formal suggestion for the devs. Many of these don't necessarily have any meta items for the classes, but are more about flavour and opening up variety, especially while levelling. Furthermore it would add more options for transmog - fashion is the true endgame after all!

 **The goal is to create a one-stop-shop for the arguments for and against the addition of different weapon types to classes, since it seems a popular topic of discussion here.**

Please post any more suggestions and I'll edit the list accordingly. Similarly if you have any strong feelings against any of these additions, please voice them too.

 *Note 1*: Recommendations for the addition of ranged weapons to classes that currently use relics in that slot all have the additional issue that they may have implementation problems due to these using the same part of the UI. *(Credit: Xudo)*

 *Note 2*: To clarify, not all of these are things I would personally advocate for. I just want to get all the arguments either way in one place.

 **Druid**
- *Polearms* - as heavily discussed [here](https://forum.turtlecraft.gg/viewtopic.php?f=14&t=1896), Druids were originally supposed to be able to use polearms to the point of being listed as such in the original manual, however this was removed in Beta. This was re-added in retail and fits well within class fantasy so there should be no reason why not to add this. ***[GETTING ADDED IN 1.16.6!](https://forum.turtlecraft.gg/viewtopic.php?f=70&t=8230)***  turtle_in_love

- *Axes* - would just add more variety for gearing and make almost more sense in lore than maces and daggers since we have Broxigar's [Axe of Cenarius](https://wowpedia.fandom.com/wiki/Axe_of_Cenarius) - druids obviously have no aversion to axes since this was crafted by Malfurion under the direction of Cenarius using druidic magic. It was actually considered for Arms Warriors as their Artifact Weapon in Legion but was deemed too druid-y and nature themed for the class.

- *Wands* - would add another piece to their toolkit, especially if you want to be more more of a caster while levelling, and would make sense since they're mostly sticks and some of them even have nature damage such as [Stormrager](https://www.wowhead.com/classic/item=16997/stormrager). I am not very experienced with Balance so please correct me if I'm wrong, but I can imagine this could help with the mana issues Boomkin has, especially since Moonkin form has access to its weapons.

- *Shields* - fits well within class fantasy and would provide more use for caster and healing shields. It might be extremely powerful especially for Feral tanks, but with them already hitting armour cap in the likes of BWL gear, should be fine, it may however trivialise gearing as now even Resto druids could be close to hitting armour cap with a single item. Additionally Moonkin boosting armour values could be an issue in PvP to make them extremely tanky. *(Credit for counterpoints: Ravenstone)*
 **Hunter**
- *Maces* - why not? They get every other weapon and I see no reason why specifically to exclude maces. One possible issue could be that Hunters might be able to exploit Manual Crowd Pummeler to increase attack speeds with ranged weapons, depending on if the effect would work that way. *(Credit for counterpoint: Ravenstone)* Edit: testing with [Fishliver Oil](https://database.turtlecraft.gg/?item=1322), which has the same effect as MCP at reduced potency, confirms that the attack speed increase is only on melee swings and therefore not an issue.

- *Shields* - like Rogues, Hunters were originally supposed to have access to bucklers back before shields and bucklers were consolidated into a single weapon class. Restoring this would add more variety and could create some interesting melee hunter builds. It would fit the class fantasy with many archer units in history carrying backup shields such as Byzantine cataphracts and Mongolian horse archers. The concern would be that in PvP hunters could equip a shield to get extra passive armour against anyone who closed the gap with them. *(Credit for counterpoint: Ravenstone)*
 **Mage**
- *One-Handed Axes* and *Maces* - with Dwarf, Orc, and Troll mages, it makes little sense that they can't use weapons more synonymous with their culture. It could be argued that this is homogenisation of the caster classes but I would say that the class abilities and tier sets are far more intrinsic to class identity, especially with everyone often using staves. The main issue with Maces is that it would cause issues with gearing Elemental Shamans and Shadow Priests as the likes of Lok'amir and End of Dreams would become Mage and Warlock priority further making it difficult for these less-meta specs. *(Credit for counterpoint: Xudo and Snakeman)*
 **Paladin**
- *Staves* - with Paladins having a Holy spec, having staves would lean into the warrior cleric archetype and could make for more variety in gearing.

- *Bows* (and/or *Crossbows*/*Guns*) - one of the things stacked against Prot Pally tanks is that they haven't a way to range pull and LoS. Sure this would mean giving up their Libram, but many times not having a ranged option just hampers them too much. Plus, there are many holy archer archetypes in fiction as well as in Warcraft like with Priestesses of the Moon *(Night Elf Paladins when??)*. Paladins shouldn't have to rely on Kobold Magic Candles forever. Bows would be ideal but I can see Guns working for dwarf paladins due to being more culturally appropriate. *(Credit: Kefke)*

- *Fist Weapons* - it would be good to see some sort of pseudo-"monk" who uses divine magic and fist weapons like the pacifist monks of fiction. Priests would be ideal however they are in no position to melee so Paladins would be the next best option. However the lack of dual wield would limit this aesthetic somewhat - perhaps just with an offhand? *(Credit: Etarpylon)*
 **Priest**
- *One-Handed Axes*, *One-Handed Swords*, *Fist Weapons* - *Same argument as for Mages*. Additionally we see sword-wielding priests in later versions of Warcraft with Anduin being a high-profile example. I'm a bit more leery about Fist Weapons, however there are certainly more examples of unarmed punching priests (and especially monks) in fiction so out of the casters they're probably the most reasonable one for these weapons.
 **Rogue**
- *One-Handed Axes* - this is probably one of the most requested additions by far (along with druid polearms) and was actually added in retail too. It would open up many more gearing options to rogues, would just require some talent adjustments to accommodate.

- *Shields* - *Same argument as for Hunters*. I appreciate the class fantasy would more be parrying daggers as opposed to greatshields, but I'd rather we have the option, especially with the transmog system. *(Credit: Xudo)*
 **Shaman**
- *Polearms* - I kind of like the distinction that Shamans can't use Swords, however I don't see much reason why they don't have access to polearms, especially with the underutilisation of polearms, as well as warrior having classed them with axes in the poleaxe talent.

- *Wands* - *Same argument as for Druids*. *(Credit: Andromath)*
 **Warlock**
- *One-Handed Axes* and *Maces* - *Same argument as for Mages*.
 **Warrior**
- *Wands* - warriors are by far the weakest caster class so this would go some way towards helping them be more viable  wary_turtle_head

- Remove *Staves* - staves really don't fit warrior class fantasy and create a strange counter-intuitive weapon progression path while levelling that many people don't enjoy. *(Credit: Gantulga)*

Please let me know if there's anything I've missed or if there's anything else you'd like to see - or not see for that matter.
