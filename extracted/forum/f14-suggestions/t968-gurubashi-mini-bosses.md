# Gurubashi Mini Bosses

## Post 5495 by Kazgrim (Patch Note Conspiracy Theorist) — 2020-03-24T04:08:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=5495#p5495 | page 1 | era: pre-1.18.1 -->

It would be a neat feature to add mini bosses that would spawn every X hours, containing level-appropriate gear reflecting the difficulty of the boss.

In some very old wow trailers you can see players fighting bosses in gurubashi arena, which is what inspired me to write this suggestion!

This is already a feature in the Dire Maul arena. Mini bosses spawn there in the center of the arena for players to fight, however it is so far out of the way that not many people do. Since gurubashi arena is relatively easy to get to, I think mini-bosses here would make for an interesting addition!
