# Warlock Demons Should Get a New Name After Death

## Post 161223 by Rhagoz — 2025-12-01T14:11:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=161223#p161223 | page 1 | era: 1.18.1-announced-pre-release -->

Right now, when a Warlock demon dies and is resummoned, it keeps the same randomly-generated name forever. But lore-wise, this doesn’t really make sense. While demons don’t truly die, as their bodies are destroyed, and their essence returns to the Twisting Nether to reform over time - there is a certain down-time to that whole process. Therefore, while that original demon is regenerating, the Warlock would logically be summoning a different demon of the same type, not the same individual.

 ***If the minion is a new demon, it should naturally have its own demonic name.***

This small change would make Warlock summoning feel more authentic to Warcraft cosmology while adding some flavor and variety to the class. It wouldn’t affect gameplay at all, as it is just a fun, lore-friendly enhancement. I also think that it would be fun to see all the different names you get.

If anybody likes the name of their demons and wants to keep them forever, I guess you could add a "Tome of Permanent Binding" or something?

(In truth, I am simply mad that my Imp has a stupid name and I want to be able to change that!)
