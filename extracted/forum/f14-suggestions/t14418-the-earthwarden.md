# The Earthwarden

## Post 98134 by Euromind — 2024-06-29T08:24:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=98134#p98134 | page 1 | era: pre-1.18.1 -->

Greetings travelers

I have an idea since this is a cross-faction and roleplay server. Some of us like the roleplay and PvE content a lot more than PvP.

Would it be possible to make a faction/reputation quest line that made you an Earthwarden, friendly to both factions. You are considered a peacekeeper towards the people of Azeroth and can now enter both Alliance and Horde cities, but you can never do PvP again or use PvP items. So make sure peace is truely in your heart. If you have any honorable kills then these must also be reconciled through some tokens/donations of some sort.

This could be a start and see how this works. Perhaps in a later stage some items or abilities could be implemented to only be used by Earthwarden charecters to avoid "broken" abilities in PvP. But that's secondary.
