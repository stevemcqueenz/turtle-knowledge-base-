# Rogue class fantasy changes

## Post 40049 by Bambooozaler — 2023-04-02T23:19:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=40049#p40049 | page 1 | era: pre-1.18.1 -->

Here are some suggestions to rogues for class fantasy that are based more on world building/cosmetics.

Ravenholdt Reputation

Ravenholdt is underwhelming and I thought it would be different in classic plus but it seems to be the same.

Here are some suggestions for reputation tiers

- Teach a spell to pickpocket other players for currency (scales with level, and with limitations)
- A spell that allows players to copy another players appearance
- Pet that stealths with the rogue as he stealths, panther/crow/wolf
- Ravenlord mount that is black instead of blue, same model.
- Ravenholdt Tmog set
Stealth

Allow the sub rogue talent camouflage to remove all movement restrictions. Leaving the rogue in walking speed once stealthed. This is to empower the class fantasy of sub rogues. As the speed benefit still feels lacking, cats can stealth faster than rogues, it's quite sad.

PickLocking

Make picklocking interesting by creating special lockboxes that can only drop AND only be looted by Rogues. These lockboxes will be high level and still have a chance of failure. Upon failure the rogue will be given one of various debuffs.

Debuffs

- Turned to rat - rat trap from ratchet
- Ice block - hunter trap
- Thrown in the air - onyxia tail swipe
- Death - engineering trinket
- Drunk - I don't know which effect causes the most drunkenness'
The rewards could be some of the following.

- Pet rat - dalaran sewer rat pet
- Special Tmog sets, recolor shadowcraft, T1, etc.
- Ton of Reagents, or reagent that are unlimited
- Special rogue trinkets
- More disguises?
- Mount - mekgineers motorcycle from wotlk
These lockboxes would be rare, and also all the items would be BOP. Making this a rogue class fantasy improvement. Finding treasures but only applicable to the rogue.

Disguises

Disguises were scrapped content that was brought back. But unfortunately it kept all the flaws and none of the benefit. The amount of disguises were low, they required reagents, and they break in combat AND while talking to NPCS. I propose to remove all reagents, allow these disguises to be used in combat, and to add much more diversity to the disguises.

Conclusion

These are the changes I propose to give a bit more class fantasy for the rogue class which seems to not have much love. I understand most of this is cosmetic or world building, but I know rogue is in a tough spot when it comes to making changes as they can get scary quickly. Please let me know what you think about the suggestions.
