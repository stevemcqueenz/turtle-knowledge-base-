## Post 108052 by Murci (Barrens Chat Casualty) — 2024-11-15T21:03:00Z

Gryphons, Hippogryps, Wyverns, and Dragonhawks are core parts in order to get from one place to another.
The idea is simple:

 **It would be nice to make them tameable for hunters.**

One can make it for all, list it in the shop or it need to be dependent on some task:
 *"When someone reaches exalted with the Wildhammers, then one could buy a tome and would be able to tame Wild Gryphons"* From roleplay perspective it can benefit Wildhammer roleplayers, the Kaldorei and many from the Horde. One can be a flightmaster or a rider of the sky.

 **Grim Batol is around, so Gryphons would fit to that patch also.**

I hope you find this post useful.
