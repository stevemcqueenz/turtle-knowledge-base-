# Increase the minimum level for HC system messages

## Post 48633 by Nerat — 2023-06-03T03:10:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=48633#p48633 | page 1 | era: pre-1.18.1 -->

As it stands, with every HC character death above level 9 spamming the chat, I've noticed that it annoys a lot of the newcomers to the server and is, imo, detrimental to the HC community (from the unintentional backlash from the non-HCs as well as from adding a lot of needless spam in guild chat). The messages might have been ok to be this low when the population was 10 times smaller, but now it's gotten to be more annoying than interesting to see a death, especially since most shown are below 20.
Also, even if there is a command to hide these messages, most don't know about it and won't go looking for it if they don't even know it's possible.

My suggestion is to increase the default minimum level required for a death system message to 20 (from 10). The level-up message can be left as it is.
