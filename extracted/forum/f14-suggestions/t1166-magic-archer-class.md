Its only a joke, but let me introduce you

Magic Archer
(that is only basic logic)

Equipment: Only Cloth
Character strength: Magic Power, based on int for crits and dmg(not agility)
Damage is based on skill level + magic damage up + int

Basic elemental range skills:
Fire arrow – basic fire damage (dmg= skill lv + magic dmg up + int + wpn dmg), no sub effects
Ice arrow - basic water damage (dmg= skill lv + magic dmg up + int + wpn dmg), no sub effects
Holy arrow - basic holy damage (dmg= skill lv + magic dmg up + int + wpn dmg), no sub effects
Shadow arrow - basic shadow damage (dmg= skill lv + magic dmg up + int + wpn dmg), no sub effects
Natural arrow - basic natural damage (dmg= skill lv + magic dmg up + int + wpn dmg), no sub effects
Arcane arrow - basic arcane damage (dmg= skill lv + magic dmg up + int + wpn dmg), no sub effects

Sub elemental range skills:
Flame shot – target is set on fire (flame dot) (like explosive trap)
Ice shot – slows the target for set time (like a frost trap, like mage frost bolt slow effect)
Holy shot – lowers target magical resistance
Shadow shot – lowers target magical power
Natural shot – poison the target (like serpent sting)
Arcane shot – lowers target hit rate by %

Mele skills
Fire strike – basic fire damage (dmg= skill lv + magic dmg up + int + wpn dmg), no sub effects
Ice strike - basic water damage (dmg= skill lv + magic dmg up + int + wpn dmg), no sub effects
Holy strike - basic holy damage (dmg= skill lv + magic dmg up + int + wpn dmg), no sub effects
Shadow strike - basic shadow damage (dmg= skill lv + magic dmg up + int + wpn dmg), no sub effects
Natural strike - basic natural damage (dmg= skill lv + magic dmg up + int + wpn dmg), no sub effects
Arcane strike - basic arcane damage (dmg= skill lv + magic dmg up + int + wpn dmg), no sub effects

Pets:
Pets are like warlock pets, not like hunters. no feeding, they are like spirit wolf or alike. Magic archer learns pet skills from books like warlock. Spirit bear - tank, Spirit wolf - mele dps, ..........., no more than 6 pets
