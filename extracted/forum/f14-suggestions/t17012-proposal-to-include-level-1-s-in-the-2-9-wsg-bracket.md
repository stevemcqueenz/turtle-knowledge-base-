# Proposal to include Level 1's in the 2-9 WSG Bracket

## Post 116088 by Boomerbob9000 — 2025-01-10T07:56:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=116088#p116088 | page 1 | era: pre-1.18.1 -->

I think we should add level 1's to the 2-9 level bracket. This would allow level 1 players to earn reputation with WSG and provide level 1 twinks with more opportunities to earn honor kills, rather than just farming starter zones. The number of players queuing for WSG at this level is already low, so combining the groups would help make the 2-9 WSG scene much more active. It would also make the "level 1 lunatic" challenge more appealing to a lot of players.
