Is there a possibilty to make a prompt when entering a saved raid ID so you can avoid getting into a cleared id without knowing?
I've entered several raids where the raid leader remembered his raid days wrong or just simply made a mistake, so upon entering we all got into his saved ID.
this is completely unavoidable and really disheartening to lose an entire week of an entire raid without even having done anything wrong.
On official servers you get a prompt when you enter a cleared/saved ID asking you if you are sure you want to enter this saved ID or not. If not you click no and get ported back out without getting the ID attached to your character. This would honestly save a lot of frustration
