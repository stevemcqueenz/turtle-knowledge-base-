# SUGGESTION : More balance in Arena = more active players

## Post 152499 by Maoeu — 2025-09-20T21:18:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=152499#p152499 | page 1 | era: pre-1.18.1 -->

Hello,
To improve the arena experience and encourage more players to join, I believe it would be worth adjusting some of the current rules:

– The felguard (15 min CD) should not be available. All other cooldowns over 10 minutes are already banned, so allowing this one feels inconsistent and creates imbalance.
– Similarly, powerful consumables (LIP, potions, etc.) as well as engineering gadgets should be banned too. This would keep arena focused on skill and strategy, just like in TBC/wotlk,etc arena, instead of turning it into an item race.

These changes would make matches more balanced and more fun, making arenas much more appealing for the community. In the long run, more players would be motivated to participate, and overall PvP activity on the server would grow stronger.

Thank you for considering this suggestion to give everyone a healthier and more enjoyable PvP experience :)
