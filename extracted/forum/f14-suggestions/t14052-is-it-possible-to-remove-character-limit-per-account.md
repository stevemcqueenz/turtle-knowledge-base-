# Is it possible to remove character limit per account?

## Post 95721 by Allwynd01 (Bug Report Enthusiast) — 2024-05-26T16:57:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=95721#p95721 | page 1 | era: pre-1.18.1 -->

As I understand, each account can have no more than 10 characters, if you want to have more, you have two options:

a) delete existing characters to make room for new ones
b) create a new account

From what I remember, when people asked for Human Hunter, Turtle WoW staff responded that "it was hardcoded into the game and impossible to add more classes", but now we have Human Hunters.

So I'm curious if this character limitation per account still exists and if it's possible to remove it somehow? I think I've seen on newer versions of WoW, if you have 10+ characters, there are some arrows that allow you to scroll up and down since not all characters are visible at the same time. Maybe a similar method can be implemented? Maybe not?

I'd appreciate if anyone who has good technical understanding can clarify this a bit more.

The trouble with having all your characters on one account is that you can't multibox to trade and enchant your alt's gear (until they add enchanting vellums that can be mailed, fingers crossed)

Having a separate account for each character (with different pasawors!) is also more secure against hacking, but if you don't reuse account names and passwords from elsewhere, it doesn't matter that much.

I have all my characters in separate accounts and I use the login patch to remember their credentials (although that's probably a bad idea security-wise, since it probably stores them unencrypted in a plain text file lol)

Still, it'd be nice to be able to have more than 10 characters on one account for those who need it, but I'd guess it's hardcoded. So just create a second account :)
