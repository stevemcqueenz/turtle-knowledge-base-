# Make Shield Warriors Great Again

## Post 108850 by Neechy (Patch Note Conspiracy Theorist) — 2024-11-20T05:32:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=108850#p108850 | page 1 | era: pre-1.18.1 -->

Were they ever great in vanilla? Not really, but the title is catchy.

Point is, even with recent class changes the player consensus seems to be that Deep Prot is still not that great in PvE.

 **Request to devs: Please make sword and board playstyle more viable for tanking.** A heavy armored warrior with a shield is like the class fantasy prototype. IMO this seems like the type of character you would want protecting you when going up against a powerful raid boss or being swarmed by multiple enemies.. So the fact that DW warriors continues to be the meta for tanking is disappointing to say the least. I mean the very idea that a warrior swinging two weapons around crazily would somehow provide better protection than a dude with a bigass shield seems pretty bizarre.

And I think the devs' idea with these class changes was to make deep prot more enticing, but with all the player complaints, it seems that the goal has fallen short...

I'm not sure exactly what it would take in order for shield prot to be a more optimal tank so I am interested to hear from others.

One possible suggestion:
New talent: 'Damage Shield'
 - Deep in the Protection Tree to advocate for shield specialization
 - **2 talent points: On a successful block, you reflect [10/20]% of the enemy's damage back to them. This damage deals a high amount of threat.**
 - The idea is that by using a shield you could start doing more comparable damage and threat as DW warriors, thereby reducing the need for tanks to go the DW rout
 - Example scenario: A raid boss hits you for 5000 damage and receives 1000 damage back (assuming 0 armor). May not seem like a lot but it adds up the higher your block %.
 - And because it is based only on successful blocks and only on the damage of the enemy, it is a very PvE focused talent that shouldn't be OP in PvP against other players.

And yes I realize this is a WOTLK talent and I would generally never advocate for going that rout on a Vanilla+ server, however this is a pretty benign talent (compared to a lot of CC2 changes) that actually feels pretty vanilla friendly. And there is the option to make this identical to the WOTLK talent where it does damage based on the warrior's block %, but that may be too weak.

Interested to hear thoughts!

There are two very separate issues with Warrior tanking now, each of which needs a different solution;

 1. As an MT
It is specifically threat from the normal Deep-Prot rotation when compared to the other tanks (Druid/Pally/Shaman) that needs an update. A solution that would fit into the tanking style of Deep-Prot would be to have the effect from Reprisal (Row 5) reset the CD of Shield-Slam and make it cost 5 rage (rather than 20). This would encourage the intended play-style.

 2. As an OT
This one is much more difficult as the other tanks (Druid/Pally/Shaman/FProt) have a reasonably stable method of generating threat without taking dmg. The solution for this needs to be very far down the Prot tree (possibly capstone) so that it does not impact other warrior DPS builds (including FProt). On the basis that a 1H+Shield OT is not generating a lot of rage the solution would need to allow threat for little/zero cost so that it could sustain reasonable threat generation while not actively tanking. As much as I disliked it, after trying many times, Blizzard themselves determined that Vigilance was mathematically good enough as a solution.

The TWow version ("Beware the old soldier") would need to also work with the updated play-style from (1) above. One possible version, working similar to the Paladin Hand of Sacrifice)  could transfer a fixed % (1-2%) of dmg done from the target (MT) to the Warrior. This would help generate an acceptable amount of rage that the Deep-Prot war could then use their normal play-style, benefiting from (1) above.
