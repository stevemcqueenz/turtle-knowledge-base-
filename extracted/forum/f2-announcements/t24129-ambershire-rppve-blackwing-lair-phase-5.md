# Ambershire (RPPvE) Blackwing Lair & Phase 5

## Post 169691 by Torta (Turtle WoW Team) [STAFF] — 2026-03-01T21:56:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=169691#p169691 | page 1 | era: 1.18.1-announced-pre-release -->

Hey everyone!

I'd like to reiterate the current state of Ambershire Phase releases:

In the next Patch 1.18.1 we have new content for BWL, a new boss, zone extension, and some layout changes!

We didn't want to release BWL without it on a fresh realm where guilds are still competing in the raiding scene for the first kill the old version of the dungeon.

Initially, Phase 5 was scheduled to release on February 27 which would include Zul'Gurub and Emerald Sanctum.

After a poll was held on Ambershire, the winner by popular vote would push back BWL release to Patch 1.18.1 and move the release of Zul'Gurub up to Phase 4. This is the current Phase we're in.

Phase 5 will be released upon release of Patch 1.18.1 somewhere in **March**. This phase will unlock the updated Blackwing Lair and Emerald Sanctum.
