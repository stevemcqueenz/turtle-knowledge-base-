# Turtle WoW Launcher

## Post 108794 by Torta (Turtle WoW Team) [STAFF] — 2024-11-20T01:28:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=108794#p108794 | page 1 | era: pre-1.18.1 -->

We're very excited to announce the initial release of the Turtle WoW Launcher! This launcher has been in development for a while now, and will allow us to push updates much easier, while also enabling players to manage their installation with ease. The launcher will be distributed alongside this patch automatically, and you will be able to use it to launch Turtle WoW going forward!

The full list of features includes:
- Server news and changelog panels

- Multilingual support

- Automated WDB clearing

- Game Settings (VanillaTweaks)

- Addon Management (One-button updates!)

- Default support for VanillaFixes, Nampower, and DXVK.

- Custom Mod support & toggles
Download it [here](https://launcher.turtlecraft.gg/api/launcher/TurtleWoW.exe?download&mirror=en1).

Curious to see how the launcher works? Watch this rundown by Vrograg:

FYI for Linux users, I was *unable* to get Wine(Bottles) to run the launcher. Crashed every time, which was weird, as I was able to run the WoW.exe from the same bottle/wine just fine.

However, I *was* able to add the launcher to Steam as a "Non-Steam Game", using the experimental version of Proton ('Compatibility' setting).

Once the launcher would start, it tried to do an update of the WoW client, but that failed (it complained about not being in 'admin' mode). I also had to make sure the "TARGET" and "START IN" Steam properties for the launcher were pointing to the right place/directory/location where Turtle WoW was installed. When the launcher was first added to my Steam library those two settings were set to a link/shortcut for the location. I had to change it to use the actual directory/location itself, and not the shortcut.

Finally, after all of that, the launcher wanted to update itself, and it did, but after restart of itself it wanted to do an update again. And again. And again. I fixed this by just downloading the launcher from the link at the top of this topic, and manually copying the exe into the turtle wow directory.
