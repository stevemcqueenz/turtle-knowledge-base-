## Post 11291 by Allwynd01 (Bug Report Enthusiast) — 2021-07-17T17:07:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=11291#p11291 | page 1 | era: pre-1.18.1 -->

I think increased FOV will create the illusion that the character is moving faster, which I think is a good thing to have. I think since WoTLK, the game's base FOV became increased. I believe this was a discussion on the official WoW Classic forums back in 2019 and that's where I learned about this.

So yes, that will be a good thing to have, if possible FOV should be increased as much as possible without warping the side view too much. Even better - it would be nice to have it as a console/macro command in-game so players can change it at will and if they don't like this, they can revert it back to normal.

On the same topic, I would like to suggest (and also inquire if it's possible) to allow players to use commands to boost the game's draw distance, world render distance and grass/object/mob draw distance.

For WoTLK WoW, there was a tool called WoW Machinima Tool, which allowed you to increase these draw/render distances beyond the limits as well as detach the camera from your character and adjust its speed so you could visit places in the game that were never meant to be seen. I've heard some argument where people say it's impossible, because the game has some limitations that can't be bypassed, but if this tool can bypass them, then it should be possible.

Things WoW Machinima Tool allowed to set:

 - FOV
 - draw/render distance
 - show or hide trees and other objects
 - detached floating (ghost) camera
 - time of day
 - time speed
 - cloud density
 - environment colors (fog, sky, water, etc) <https://i.ytimg.com/vi/6Abge3eSp0E/maxresdefault.jpg>

I think it should be an optional patch. The FOV is a huge deal for how players experience the game world. By making it larger, it creates the illusion that everything is smaller and less vast in scale. It makes the character feel like it's moving faster, and thus has a subtle effect on how players psychologically act while playing. It makes the game more like retail where the gameplay is about speed and less about slowly experiencing a vast world. I think it should be an option for players that want it, but it should be an exception, not the default. This is Turtle WoW after all.

For those anxiously waiting for this, you can make the modification yourself using a hex editor such as HxD. Simply open Wow.exe in a hex editor, use the search function to look for **DB 0F C9 3F E6 F1 47 40 00 00** and replace it with **66 66 F6 3F E6 F1 47 40 00 00**. Make sure to back the exe up first in case you mess up.
