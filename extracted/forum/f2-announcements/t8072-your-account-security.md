# Your Account Security

## Post 51917 by Torta (Turtle WoW Team) [STAFF] — 2023-06-30T15:03:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=51917#p51917 | page 1 | era: pre-1.18.1 -->

Hello, everyone! I just wanted to give you a heads up about some recent server issues we have been facing. We have noticed an increase in attacks, and one is happening right now.

As we work on mitigating these attacks, we strongly urge everyone to exercise extra caution regarding the security of your accounts. These attacks specifically target our authentication server.

Therefore, we kindly request that you review your account password today, especially if it is too simple or if you have used this password for any other online service. Please change it if necessary. The attackers use leaked data from all over the internet in attempts to guess your logins, supported by botnets that use unique IP addresses for every login attempt.
Code: Select all

```
Please use the account management panel on our website or utilize the following command in-game:
.account password old_password new_password new_password
```

Keep in mind that 90% of those attacks are executed by the gold-sellers. Please, don't support individuals who are actively harming our server.

Thank you for your attention, and stay safe!
