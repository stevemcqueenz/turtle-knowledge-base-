# Character Name Cleanup (Ambershire)

## Post 158031 by Torta (Turtle WoW Team) [STAFF] — 2025-11-01T11:00:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=158031#p158031 | page 1 | era: 1.18.1-announced-pre-release -->

Hello, everyone!

During the upcoming maintenance on **November 5** we'll clean up inactive character names on the **Ambershire RPPvE** realm: names that were reserved during the pre‑launch event but never actually used.

Any character that hasn't reached **Level 2** and hasn't logged in since**September 1** (two weeks after launch) will have its name released.

We're looking into freeing up roughly 100k character names!
