# Mystic class

## Post 148374 by Cheruscan (Bug Report Enthusiast) — 2025-08-26T10:03:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=148374#p148374 | page 1 | era: pre-1.18.1 -->

I want to brainstorm a possible new class that would first and foremost fit lorewise into the game, but also help with bringing more needed options into the game.

The Mystic

A caster class that wears leather/cloth and wields staves, daggers, maces, fistweapons, non shield off hands and wands

Speccs would be; one focusing on support, one on caster dps and finally a healer specc

Damage types of the spells would be nature and shadow

We need more healer options and both shadow and nature dmg are underutilised currently (Nature especially)

Lorewise Mystics would bridge the gap between mages and druids/priests.

An arcane scholar that tries to understand the natural world, someone who doesnt scoff at old wifes tales about curses and spirits.

I think the Witch of Northwind is a good starting point for the class fantasy.

Does anybody have suggestions for a class like this?

How would we fit it in the Lore?

Which races should be eligible?
