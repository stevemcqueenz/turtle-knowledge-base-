# Power word : shield and rage

## Post 153168 by Menelluin — 2025-09-25T16:20:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=153168#p153168 | page 1 | era: pre-1.18.1 -->

Hello, I would like to clarify something about the priest's shield on this server.
The other day, another priest player told me that several players on the server had given him a bit of grief because he was using his shield on a warrior tank and that it was hurting his aggro.
I've played on many private servers, and it turns out that on one of them, this was indeed the case, so I'm not surprised by this comment. However, I've been playing this class for a long time and I still play it on the official server, where this is NOT the case, as the log shows. The priest's shield does not normally prevent warriors or druids transformed into bears from generating rage. So my question is simple: “When people claim this here, is it an urban legend based on false memories, or is it actually a specific property of this server?”

## Post 153172 by Azcron (Patch Note Conspiracy Theorist) — 2025-09-25T16:33:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=153172#p153172 | page 1 | era: pre-1.18.1 -->

This actually comes down to which client you’re playing on. Back in 1.12 Vanilla, warriors and bears only generated rage when they actually took damage, so if you put Power Word: Shield on them it would absorb the hit completely and deny them rage, which is why people complained that shielding tanks hurt their threat. That mechanic stayed in place until patch 2.0.1 (the pre–Burning Crusade patch), when Blizzard changed it so that rage was calculated based on damage before absorption, meaning tanks still got their rage even if the shield ate the hit. From that point onward, including retail today and most private servers that use updated clients, shielding no longer interferes with rage generation. So if you’re on a true 1.12 emulation server, like Turtle, the complaints are real and not an urban legend, but if you’re on retail or a server running newer mechanics, shielding is perfectly safe and doesn’t block rage at all.
