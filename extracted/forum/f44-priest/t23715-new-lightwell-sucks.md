# New Lightwell Sucks

## Post 166149 by Zvyrhol (Grandmaster of Forum PvP) — 2026-01-23T22:06:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=166149#p166149 | page 1 | era: 1.18.1-announced-pre-release -->

I miss old Lightwell, it was very good spell in PvP. Placing it in the tunnel in WSG was great for whole team. Health regeneration that works in combat was massive. It was useful for all Priest's specs, not only for healing one. Smite and Shadow Priests used them effectively. Even in raids it was worth using it sometimes, for example before boss fights. As a baseline spell, it was absolutely based. Only healers complained...

Now it's more like version lobbied specifically for healers in raiding environment.
Note that Lightwell still is a baseline spell even though only healers will benefit from it. Shadow and Disc specs can't make effective use of Lightwell anymore because it requires Priest to cast healing spells.
