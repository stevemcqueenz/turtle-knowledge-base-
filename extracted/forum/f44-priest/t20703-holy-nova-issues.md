# Holy Nova issues.

## Post 143389 by Itsbacon — 2025-08-06T14:31:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=143389#p143389 | page 1 | era: pre-1.18.1 -->

Looking for some input from others on some possible Holy Nova changes.

First, what I'm trying to address really boils down to three key points.
- They have made Holy Nova usable in shadowform, but I feel the burden to acquire the skill is incredibly high for shadow priests.

- As a heal it is generally useless in anything outside of 5 player content due to the party restriction (though efficiency issues make it mostly useless in 5 mans too).

- The skill is incredibly inefficient to use.
To address the first issue, I'd like to see Holy Nova be made a base skill learnable by all priest regardless of spec. For holy and disc builds that previously opted for the talent, this doesn't skew the build all that much, since it was only 1 point and both builds were generally going to be building past it in the tree anyway. But it greatly reduces the burden on shadow priests, allowing them to still reach down into the disc tree for improved fort, more threat reduction, imp inner fire, and some points in meditation or shield.

To address issue 2. I want to make holy nova target castable so if you cast it on a friendly target, the nova is centered on that target and all healing done is applied to members of that targets party. So if the priest is in group 1, and targets a melee dps in group 2 the nova can heal all melee dps within group 2's party that are in range. I'm not sure if holy nova is restricted to the priests party because of engine limitations, or if its simply to balance out how OP it could be having a priest holy nova and heal 40 people at once in a raid that are stacked. But I know the game would support this proposed logic as it's already implemented for prayer of spells, and maintains the balance of only being effective for healing on a max of 5 players at once. I think this functionality should be achieved through a talent, in the holy tree (replacing the 1 point previously used to acquire holy nova).

I believe the skill is so inefficient to cast as a balancing choice to account for the fact it does damage and healing at the same time. To address this I would like to see the mana costs reduced for the target cast holy nova, but have the healing and damage for the targeted version of the spell separated based on the active target. So if you cast the spell on a hostile target, the skill only does damage but if you cast it on a friendly target it only does healing.

 **Questions for the community.**

- Do you think any of the issues I have brought up are actually things that need to be addressed?

- Do you think any of my proposed solutions are reasonable to address the listed issues?

- If you like the idea of the target castable holy nova, do you think it should be implemented as a talent that changes the behavior or holy nova? Or a new skill that provides the proposed ability changes, while retaining holy nova as a separate spell?

- Where in the tree do you think this new talent if implemented should be? High up and easily accessible? Replace Holy Novas current spot? Deeper in the tree?
