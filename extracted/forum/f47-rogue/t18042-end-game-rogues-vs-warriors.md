# End Game Rogues vs Warriors

## Post 122845 by Bigbosc — 2025-03-18T03:43:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=122845#p122845 | page 1 | era: pre-1.18.1 -->

Currently end game Rogue is simply outclassed by DPS Warrior.  This kinda sucks for a few reasons.

First if we compare the DPS on both several cleave friendly fights like Anubrekhan, and on single target fights like patchwerk we can see around an 18% DPS difference with Warriors beating Rogues at all tiers of play.  I compared the number 1 warrior to the number 1 rogue, the same for number 20, number 50, and number 100 where applicable, over the last few months of logs from top guilds.

In all these cases the figure is at or close to 18%.  That sucks.

Please nerf warrior a bit and please buff Rogue a bit.  Maybe start with some simple numbers changes, like increase backstab, and sinister strike AP coefficient by 5% and nerf the coefficient on some warrior button, maybe execute?

DPS warrior is very similar in role in a raid to a rogue.  We are both physical dps who can field a number of useful armor debuffs, and other buffs (if rogue is sub anyway).  And we both offer mana free cleave damage, and strong single target damage.  We both offer solid interupts to enemy cast.  Finally we each have some unique abilities to help a raid, Warriors have some nice long cooldowns like Recklessness, Shield Wall, AOE taunt, etc.  Where rogue can help with some skips by using distract, or we can access 4 trinkets on a fight with vanish, or avoid certain mechanics like Webspray on Maexxna.

So the classes are pretty similar, and an 18% difference in output in every type of fight just sucks.  Thanks devs, I think Rogue is actually very fun right now and the designs are dope, but this difference needs some more numbers adjustments when possible.
