I can't tell you for sure if it's possible. The game uses a custom client that is English-only. I'm using some addons like "PF Quest" which I think are allowing the option to translate quest text into some popular languages, including German. But I think when I tried it on a few custom Turtle WoW quests, that don't exist in the normal game, the quest translation didn't work.

So to my understanding, to play Turtle WoW in German would mean to have the client UI in English, having the custom Turtle WoW quests also in English and only to have the original quests in German. It's far from ideal.

I think this is partly because maintaining one client (English) is far easier for a private server team than multiple different clients as it seems unfeasible. Also the custom quests have to be manually translated to every language as the translation tool for the original quests is most likely pulling data from the original quest text in different supported languages for the game.
