# Cower is being parried!

## Post 3107 by Skullmiser (Barrens Chat Casualty) — 2019-06-08T03:42:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=3107#p3107 | page 1 | era: pre-1.18.1 -->

The Druid ability "Cower" is presently able to be blocked/dodged/parried.. and it is possible to "Miss."
That's not how this ability is supposed to function. It should only be able to be "resisted."
This bug is especially bad, as being blocked or parried makes it much more difficult to use if you're in danger.  You can't get behind an enemy nearly as well if you have their attention.

Taunt/growl can be resisted, and are working normally.   Somebody check "feint" for me. The Rogue skill.
