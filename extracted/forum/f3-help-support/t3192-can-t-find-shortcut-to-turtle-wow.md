Do you mean that you extracted the exe file into a folder or are you opening the file directly from the zip folder (which I didn't even know was possible if that's the case)?
You should be able to right click the exe file, select 'create shortcut' and drag the new shortcut over to your desktop.
You likely need to have all your files in the zip folder extracted (right click) into a new folder first.
