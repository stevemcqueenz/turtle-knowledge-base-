Lore-friendly names aren't… as strictly enforced as you'd think.  And though the server is labeled as "RP", that's not enforced, either.  So long as you're not intentionally interrupting roleplayers, you're good!

If you're worried about your name for role-playing reasons, you can always donate for a rename token or remake your character.  Also, you can talk and use chat-related AddOns at Level 5.  It *was* Level 10 for a short while, but they reversed that decision almost as quickly.

Cheers!  And welcome to *Turtle WoW*!

 **Edit:**
Oh, and if you're stuck for a name, you can always try Emily's *[Fantasy Name Generators](https://www.fantasynamegenerators.com/)* site!
It's usually good for any and all types of fantasy names *and* even has generators specifically for *[Warcraft](https://www.google.com/search?q=site%3Awww.fantasynamegenerators.com%2F+%22Warcraft%22)*!

These are the naming rules on Turtle, copied from the rules here on the Forum:

> Naming rules for a RP server like Turtle WoW
>
>  We do not force our players to use RP-friendly names, but we would be grateful if you contribute to the immersion by using a good fantasy name. However, some name type are forbidden and players will be requested to changed it:
>
>  It is forbidden to use names that reference well known people: politicians, social activists, religious figures, culprits, actors, celebrities, etc.
>
>  It is forbidden to use names political, religious or controversial connotations
>
>  It is forbidden to use names which are referencing inappropriate explicit matters: extremism, sexism, racism, mocking certain groups of the people.
>
>  It is forbidden to use names which are overly vulgar and sexual.
>
>  It is forbidden to use names created to mimic any staff name.
>
>  It is forbidden to use real-world country names in your guild names.

The rp community will very much appreciate, if you pick a fantasy name instead of something else on top of these rules. If you can't even talk yet, which means you are not even level 5, I would just delete my character and make a new one with another name.

Have fun on Turtle!
