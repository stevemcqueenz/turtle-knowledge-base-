Greetings!

To find out your account name you can use the following options :

 1. Check your email and look for the account registration email. It will contain the login account name.

 2. If you have not deleted the game client, you can find out the account name in the WTF folder.
Path: Game client folder -> WTF -> Accounts -> ...

 3. If you have a **keyword**, you can request for access restoration on our e-mail [[email protected]](https://forum.turtlecraft.gg/cdn-cgi/l/email-protection#d7beb9b1b897a3a2a5a3bbb2b4a5b6b1a3f9b0b0).
In the e-mail, please provide all the data that you have + the **keyword**.

Please note that such requests are not processed without the **keyword**.

I hope I was helpful in answering your questions.
