I changed my password here on the forum, but my in-game password is still the old one.

Where do I change my in-game password?

## Post 2301 by Zefugi — 2019-03-11T21:10:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=2301#p2301 | page 1 | era: pre-1.18.1 -->

If anyone from the future use search and find this question, here is the answer:

You have to change game password in-game. You do it in the in-game chat by typing:
.account password OLD NEW NEW
So if you wanted to change password 'myoldpass' to 'mynewpass', you'de type:
.account password myoldpass mynewpass mynewpass

This only works if you have your old password.
