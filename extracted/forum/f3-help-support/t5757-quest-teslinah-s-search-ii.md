## Post 36124 by Mac (Bug Report Enthusiast) — 2023-02-26T03:35:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=36124#p36124 | page 1 | era: pre-1.18.1 -->

That orphan can be real picky sometimes about which exact pixel you need to stand on for it to count as exploring that area.  Usually exiting the area (such that the name on the minimap changes) and re-entering helps.  If you're mounted, you can try dismounting.  Sometimes stopping in random spots helps.  It can be a bit annoying, especially if you haven't done the quests and aren't entirely sure if you're in the right spot, but the quests do work when they feel like it.

For the park, I believe the moonwell area is where I've gotten it several times in the past, around where the class trainers are.
