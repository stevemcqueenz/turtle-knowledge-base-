Greetings!
In most cases such problems occur with some providers .
If you are not using the current version of the game 1.17.0 then download the update or already updated client here : [https://discord.com/channels/4666224558 ... 8302398485](https://discord.com/channels/466622455805378571/747135466192633906/1158513058302398485).
If you are using the current client, the following options may help you :
 1. VPN - Use any VPN. If you are able to enter then the problem is in your ISP and you can only wait.
 2. Reboot your router - sometimes the problem is really in your router.
 3. IP - Try changing the IP in your router.
 4. change the connection type to hotspot or wifi
 5. Download a new client.
