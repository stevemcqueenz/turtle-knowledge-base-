What are your PC hardware specifications?

If you are changing programs and it affects performance, it makes me think you have a very weak computer.

My first PC from 2005 was old even by that time's standards - some Sempron 1.6GHz CPU and 256 MB RAM, some integrated SiS 64MB GPU and WoW ran at probably 20-30 FPS on lowest, but it was one of the best games that ever graced that PC.

I remember I had some stuttering/freezing and at the time I was using Winamp, but after I switched to foobar2000, that problem went away.

Browser memory consumption these days should be almost equal, but when you have an average/above average PC, you can't really notice, maybe if your PC is really slow and old it's noticeable, so it will be best to list your specifications so people know how to help you better.

But if that's your problem, closing as many programs as possible will be the best way. Also, when I was on my first PC, doing Windows XP reinstalls every few months kind of helped a bit, after all, the PC was so slow that all kinds of pointless things (now) seemed to work wonders, especially employing the help of 5-6 different junk cleaners, it would speed the computer up for a few days and then it would become slow again.
