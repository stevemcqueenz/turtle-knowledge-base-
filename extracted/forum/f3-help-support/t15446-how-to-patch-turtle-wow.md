Right-click on the desktop shortcut (assuming you have one) and check the file path. It should look something like this:

- C:\TurtleWoW\WoW_tweaked.exe
or

If it’s the first one, you just need to reapply the tweak by dragging the new WoW.exe onto vanilla-tweaks.exe (you probably did it long ago).
