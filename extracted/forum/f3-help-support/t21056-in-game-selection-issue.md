## Post 152458 by Mrnatural48 — 2025-09-20T11:07:00Z

Fixed it!

In the turtle wow launcher, there is the mods section of the window. And inside there are a set of 6 different fixes.
It's the vulcan mod that is causing the issue. Disable it and it should solve the selection issues.
I have the first 3 selected - which were on by default - and the next 3 unselected.

The vulcan one is the dxvk v2.5.3 mod. Hope this helps.
