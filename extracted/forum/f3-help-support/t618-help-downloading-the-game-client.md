## Post 3168 by Musse (Barrens Chat Casualty) — 2019-06-16T16:31:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=3168#p3168 | page 1 | era: pre-1.18.1 -->

1. Put the contence of the Zip in a folder you create. This could be e.g. C:\Games\TurtleWoW (or whatever you prefer).

In the folder you created:

 2. Make sure the file realmlist.wtf contains this line (and only this):
set realmlist logon.turtlecraft.gg

 3. Launch the game with WoW.exe (not Launcher.exe).

Optional:

Create a shortcut to WoW.exe and put the shortcut where you prefer to have it. Can e.g. be your desktop or Windows Start Menu. Not going into how-to here, since this depends totaly on your OS (Windows version).

In other words:

There is no "setup" you need to run, you can just copy the whole contence anywhere and run it from there. You can also copy all to your other machines according to your needs.
