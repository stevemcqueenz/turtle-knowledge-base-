I am not experienced with macOS to be honest, but I got the Windows version of Turtle Wow running on my Ubuntu Laptop.

How you might ask..

For Linux and macOS exists an application called Wine (or WineBottler on macOS), which is capable of running Windows programs on Linux and macOS.

So I would suggest, that you use the WoW download provided by Turtle WoW and try to run it with WineBottler.
