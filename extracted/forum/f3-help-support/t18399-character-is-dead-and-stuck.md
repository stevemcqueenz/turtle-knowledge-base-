Try reducing your render distance to 777. That should resolve the issue ![🙂](//cdn.jsdelivr.net/gh/twitter/twemoji@latest/assets/svg/1f642.svg)

You can do this by navigating to the Turtle WoW main folder > WTF > Config.wtf
Then edit the line:
SET farclip "777"
