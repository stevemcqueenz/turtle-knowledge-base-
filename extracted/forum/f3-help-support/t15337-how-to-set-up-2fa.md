# How to set up 2FA ?

## Post 104692 by Pepesmite (Turtle WoW Team) [STAFF] — 2024-10-24T14:14:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=104692#p104692 | page 1 | era: pre-1.18.1 -->

![Image](https://i.ibb.co/GJCmb62/2024-10-24-17-06-26.png)

Hello, everyone!

This guide will help you install and use two-factor authentication (2FA).

Let’s get started!

First, you need an active account on Turtle WoW.

If you don’t have an account yet, you can create one by following this link: <https://turtlecraft.gg/>

If you already have an account, please follow these steps:

- Go to the official Turtle WoW website: <https://turtlecraft.gg/>

- Log in to your account using your username and password.

- Locate the **“Security”** tab and click on it.
![Image](https://i.ibb.co/88yVPMw/2024-10-24-15-58-01.png)

In the Security tab, you will see two sections: **“Change Password”** and **“2FA Authentication.”**
To enable 2FA, find the “**Enable 2FA”** button in the **“2FA Authentication”** section. ![Image](https://i.ibb.co/NyQtJcf/2024-10-24-16-00-04.png)

Once you click the **“Enable 2FA”** button, you will be provided with a QR code to scan in your 2FA application, along with a secret code. ![Image](https://i.ibb.co/XSshnFZ/2024-10-24-16-00-44.png)

You can use either Google Authenticator or Authy to scan the QR code.

[Google Authenticator how to use ?](https://support.google.com/accounts/answer/1066447?hl=en&co=GENIE.Platform%3DAndroid)
[Authy how to use?](https://authy.com/guides/)

The Secret code is required to manually activate two-factor authentication (2FA).

If you are unable to scan the QR code, you can select the “manual” option for adding an account in your 2FA application and enter the secret code located directly below the QR code.

After completing these steps, an account will be created in your app that generates a unique one-time code every 30 seconds.

You will need to enter this one-time code into the input field and press the “Submit” button. ![Image](https://i.ibb.co/sb1232M/2024-10-24-16-46-02.png)

Once you do this, two-factor authentication (2FA) will be enabled for your account.

You will also see a code to restore 2FA, which you should save. ![Image](https://i.ibb.co/gRyQMQ8/2024-10-24-16-47-04.png)

This code will be necessary if you lose access to your 2FA application.

That's it, folks!
