Hello!
Here are options for solutions:
 1.VPN
 2.Change connection type wired/WiFi/hotspot
 3.Reboot the router
 4.change the IP address in the router
 5.Reboot the PC several times.
 6.Reinstall the client.

babble-zone 2.2.0 - it's an error caused by one of your addons. Disable addons and check if the error persists.
If the error is gone, you need to turn on addons one by one to determine which addon is generating the error.
Usually it is a wrong version of cartographer or atlas
