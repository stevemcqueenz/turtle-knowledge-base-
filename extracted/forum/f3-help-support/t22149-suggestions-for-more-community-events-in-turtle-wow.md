## Post 153613 by michaelarrington — 2025-09-29T02:27:00Z

Hi everyone,

I've been on Turtle WoW for a while now, but I'm really impressed with the friendly atmosphere and the slow, "vanilla" style of play that the server offers.

One of my favorite things is the community events organized by both GMs and players, such as races, treasure hunts, or small roleplay events. This makes the server more lively and different from other private servers.

I want to ask everyone:

Should we have more weekly or monthly events to connect the community more?

Do you have any suggestions for new, fun events that fit the Turtle WoW style (e.g., PvP mini-tournaments, career events, or Azeroth travel events)?

I'd love to hear more from you so that we can make Turtle WoW more interesting together! [Retro Bowl 26](https://retrobowl26.org)
