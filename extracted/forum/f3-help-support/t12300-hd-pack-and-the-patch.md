# HD pack and the Patch.

## Post 81889 by Spot (Barrens Chat Casualty) — 2023-12-20T07:07:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=81889#p81889 | page 1 | era: pre-1.18.1 -->

If you are having trouble downloading and/or installing the new patch, it may be your HD pack if you have it installed.  I couldn't get my game to run properly after the implementation of the patch until I removed the HD files from the Data folder.  I also deleted the WDB folder and moved all my addons to another folder until I could get into the game again.  I also unpinned "WoW_tweaked.exe" from start and pinned "WoW.exe" to start.  Use that.

I'm back in the game now thankfully.  It was a rough day.  I need my TWoW fix.

Don't know if reinstalling the HD pack will mess things up and I'm gonna hold off.  I like the original look to the game just the same.  The HD pack just mixed things up for a wile.  I just thought I'd post this here because I know a few players that also use this mod.

I don't want to see them frustratingly locked out and not figure out why.  Some of them are new to moving files around outside the addons folder.

> **Spot wrote: Wed Dec 20, 2023 12:54 pm**
> The game starts to re-upload the patch, tells me to restart the game, and then I got that failed to patch message.

Yes, this is exactly what will happen if you run **wow_tweaked.exe** without running **vanilla-tweaks** before. Because what happens is **wow_tweaked.exe** is the old client executable, therefore it will try to apply the patch again and again without success. After you run **vanilla-tweaks**, everything will be fine again   happy_turtle_head
