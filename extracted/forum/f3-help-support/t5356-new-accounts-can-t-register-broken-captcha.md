## Post 32601 by Rumblin — 2023-01-15T21:47:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=32601#p32601 | page 1 | era: pre-1.18.1 -->

Had this issue with a friend yesterday. The CAPTCHA breaks if any error occurs on submit (ie. invalid username/password, username already in use, etc.). You need to refresh the page entirely (and fill out the form again from scratch) in order to get the CAPTCHA working. You'll know it 'worked' when you hit the submit button and no error message appears. The form won't close, though, so it will look like nothing happened; but the verification email will still be sent and the account created. Use Chrome (or at least a chromium-based browser like Edge) just to be sure.

I tested a minute ago and the above still holds true. Some things to keep in mind is that usernames (both account and forum names) can only be 15 characters long, and special characters like dashes (-) are not valid.

TL;DR If you get an error refresh the page
