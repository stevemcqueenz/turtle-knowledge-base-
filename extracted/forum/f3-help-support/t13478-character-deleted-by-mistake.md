Greetings!

Please make a ticket in the game from the account on which you deleted the character. Also provide the name of the character.

> **How to contact a GM and get help in-game?**
>
>  Near your key ring there is a red question mark, press it to send an in-game ticket.Also you can enter the command /gm in the game chat.
>
>  You don't need to be online for tickets to be solved. Support will respond via in-game mail.

Please note that for almost any in-game issue please create a ticket in game. The forum is intended for communication between players.
