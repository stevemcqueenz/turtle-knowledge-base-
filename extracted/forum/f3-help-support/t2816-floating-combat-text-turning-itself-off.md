Looks like you use your Wow.exe file right out of a zip archive instead of unpacked folder. Please make sure you have your game unpacked and placed somewhere on your C drive within its own folder for example Code: Select all

```
C:\Game\TurtleWoW\Wow.exe
```

If you have it done correctly then make sure you have your WTF or perhaps whole WoW folder's settings never set to Read only option. Those are most common mistakes which could lead to such a bug-like behaviour of your game.
