Authy is a bad insecure example.  Not only is it proprietary but [Authy has recently been hacked](https://www.securityweek.com/twilio-confirms-data-breach-after-hackers-leak-33m-authy-user-phone-numbers/) exposing user information to cybercriminals.  If you said something like Google Authenticator I wouldn't have needed to post this.

Furthermore, according to [their own help page](https://help.twilio.com/articles/22771146070299), Authy lacks a simple 'export' feature meaning you'd need to manually re-add every single authenticator to a competing service if you wanted to switch (aka 'vendor lock-in') which is not only bad for security but also portability and competitiveness in the 2FA space.
