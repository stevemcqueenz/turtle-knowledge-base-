There are macro threads in most class channels.  I can't speak for all of them but I know there are druid and warrior ones.  The advanced search feature might be a powerful tool here.

If you have a specific macro question, I recommend using the search function first.  If that doesn't yield results, make a post in the class channel you're looking for macros for.  I also suggest downloading super macros or roid macros from the add-ons wiki.<https://turtle-wow.fandom.com/wiki/Addons>
