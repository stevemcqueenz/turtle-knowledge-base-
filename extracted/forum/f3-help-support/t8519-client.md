There is no link. Here you are guide how to patch :

∙ Make sure your game isn't saved in a write-protected directory such as Program Files, Downloads, Documents etc. The best place to save your game would be `C:\Games\WoW`.
∙ Make sure that your app binary is named `WoW.exe` and not something else. Patcher is looking for a file with this name.
∙ Disable Antivirus or Windows Defender.
∙ Start WoW.exe as Administrator: right click on the icon and pick this option in the cont4ext menu.
∙ Try to run `TWPatcher.exe` with administrative permissions as well.

If the issue persists, please DM me screenshots of your **Data** and **WoW** folders.
