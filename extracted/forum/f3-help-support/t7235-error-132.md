Have you tried downloading the client from the official torrent instead of a hosting site?  That seems to work for a lot of people.

You could also try installing a Vanilla client from disc and adding or replacing these lines in your *WTF/Config.wtf* file: Code: Select all

```
SET realmList "logon.turtlecraft.gg"
SET patchlist "logon.turtlecraft.gg"
```

More information can be found [at this official thread](https://forum.turtlecraft.gg/viewtopic.php?t=5143).  Hope this helps!
