## Post 32512 by Torta (Turtle WoW Team) [STAFF] — 2023-01-13T00:20:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=32512#p32512 | page 1 | era: pre-1.18.1 -->

Please try one of the following options:

∙ Enable Vertext Animation Shaders in WoW Video settings.
∙ If you want to set your framerate higher than 60/75 to 144/240 please edit the game config: WTF > Config.wtf > SET gxRefresh "240"
∙ Try using DXVK to replace the DirectX 9 renderer with Vulkan. This should solve most of the graphical glitches. Download it from here and place the 32 bit dll files in the game folder: <https://github.com/doitsujin/dxvk/releases/tag/v1.10.3>
∙ Try switching between the graphic API as described here: [https://www.mmo-champion.com/threads/68 ... vs-DirectX](https://www.mmo-champion.com/threads/687894-OpenGL-vs-DirectX)
∙ Try using this third-party modification created to eliminate stutter and animation lag: <https://github.com/hannesmann/vanillafixes>

Hey I didn't bother to read all the reply so sorry if it's been mentioned, but in my case I was getting low FPS because wowpov.exe was not recognized by my laptop's graphics driver and therefor my system was running the game on integrated CPU graphics instead of allocating its process to my GPU which is only turned on for some processes to save battery at the system level. It is a simple fix to go into Nvidia Control Panel (right click on desktop), going to program settings, adding the turtle wow executable, and selecting "high performance nvidia processor" in the dropdown.
