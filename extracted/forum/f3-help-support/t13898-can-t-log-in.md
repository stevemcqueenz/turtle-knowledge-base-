It sounds like you're having a pretty frustrating time with this issue. Windows Defender might have deleted the binaries, you can whitelist our binary files to prevent this. Here are a few steps you can try to resolve the login problem:

 1. Wait at least one hour before you try to log in again if you get the "too many login attempts" error message. Keep in mind that another failed login will trigger a ban for another hour.

 2. Create a new account if you don’t own any characters yet.

 3. Delete the WDB cache folder from your client (Keep the WTF folder!)

 4. Check if you have 2FA enabled, and disable it temporarily if necessary.

 5. Check if your firewall or any third-party software is blocking the network access of the client.

 **If none of these steps help, log in to our Discord and use the #support channel.** You will get a reply within 30 minutes. In-game tickets (if you are able to log in) are answered 24/7 within 2 minutes.

Another way to contact us is via email at: m a i l @ (our website domain), email replies take up to 24 hours.

As you know there are many changes in our game client. These changes modify the game files including “exe” files.

Many protection programs when analyzing think that this is a violation and delete important files from the folder with the game client.

To prevent this from happening to you, you need to add the folder with the game client to the exceptions of your antivirus and protection systems.
