Hey there!

Please make sure you’re using the correct realmlist. Are you trying to access the EU server or the South American server? The realmlist will be different for each.

For the EU server, your realmlist file should look like this:
set realmlist logon.turtlecraft.gg
set patchlist logon.turtlecraft.gg

Also, it's important to note that your forum account and in-game account are separate.

Lastly, if you created an account on the EU website but are trying to access the South American network, it won’t work. You’ll need to create a separate account on their site:
