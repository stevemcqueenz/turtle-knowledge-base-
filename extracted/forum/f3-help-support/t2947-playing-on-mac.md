## Post 18370 by Allwynd01 (Bug Report Enthusiast) — 2022-04-26T09:50:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=18370#p18370 | page 1 | era: pre-1.18.1 -->

You probably can't patch because you're on Mac. I don't know if Linux users experience the same thing.

You should probably ask someone to upload you an up-to-date client from a Windows machine, but when another patch is issued, you will probably run into the same problem and have to ask someone to upload you another up-to-date client from a Windows machine.

Best case scenario would be to run Windows in a virtual machine and play Turtle WoW from there.

Once I tried playing on Linux, but I don't think I had the correct drivers and the game ran at about 30 FPS and there were many other hoops so I gave up. My personal opinion is that Windows is the way to go hassle-free for gaming, every other OS requires a lot of headaches and workarounds that just aren't worth it.
