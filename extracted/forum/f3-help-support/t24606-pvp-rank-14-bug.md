## Post 173181 by Xudo (Grandmaster of Forum PvP) — 2026-03-30T12:02:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=173181#p173181 | page 1 | era: post-1.18.1 -->

It is happening most likely due to integer overflow.
Honor is probably stored in unsigned 4 byte integer field, which can hold values from 0 to 4,294,967,295 (which is 2^32 - 1).
When you have 0 honor and do dishonorable kill, you get negative honor values and then integer overflow happens. Computer performs "wrap around" and negative value become very large positive one.

Judging by initial post, it seems that devs know about that problem. Topic started probably had rank 0, did civilian kill, got rank 14. Then devs nullified this "cheated" rank. Thats why Darkconfidant is complaining.

I think it will be fixed soon. Typical release day problems.
