# Visual bug with Silk Skirts, and also Krampu's little helper suit

## Post 163907 by Lunarose — 2025-12-28T11:00:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=163907#p163907 | page 1 | era: 1.18.1-announced-pre-release -->

Hello, I think I'm in the right place for bug reports.

I've been encountering a visual bug with the two following items:
[Black Silk Skirt]
[Krampus's Little Helper Suit]

The skirt, as shown, seems to be picking up textures from whatever is underneath it, textures of the skin underneath or whatever boots are being worn. I got a friend to check to see if it was my HD mod's fault but it was not.

![Image](https://imgur.com/a/bOvsD1Y)
(not sure if I am doing image embed correctly so here: <https://imgur.com/a/bOvsD1Y> )

This does not happen with the other color of silk skirts from the same vendor.

Whereas the Little Helper suit is visible on top of the skirt, or any leg item equipped.

I got really excited to make a new mog with my fancy new crown but I was met with the horrifying skin skirt D:

It would be lovely if these items were fixed, especially considering one of them is a special new winter veil reward.   scared_turtle_head
