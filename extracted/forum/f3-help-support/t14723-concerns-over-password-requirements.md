# Concerns over password requirements

## Post 100387 by karosien — 2024-08-29T22:58:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=100387#p100387 | page 1 | era: pre-1.18.1 -->

Hiya! I'm extremely new to Turtle WoW, but I  have  concerns about your password requirements.

 1) You have a maximum limit of 15 characters.
 2) You **ONLY** allow alphanumeric characters.
 3) Once logged in, your password change form says you can have up to 16 characters and include some special characters. However, you get an error message if you use 16 characters and try to use the special characters stated.

Now, I realize that you do offer 2FA, which is wonderful and is a must-have for security these days. The problem that I have is that you limit the length of your passwords AND you limit it even further by preventing the use of any special characters. This is a huge security issue. You can easily crack a password with those requirements with modern hardware.

Back in the day, requirements like these were required because of storage limitations and the lack of proper security practices. This is no longer the case. There are many resources about password security and I recommend you check out [https://cheatsheetseries.owasp.org/chea ... Sheet.html](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)  about these issues. They go into great detail and are the standards for authentication security.

The main takeaway here though is that if you are hashing your passwords (and you should absolutely be doing that), then there is no reason to restrict the length to less than 64 characters, not to mention there shouldn't be a restriction on the type of characters you can use.

Anyway, I do like what I see of your server so far, really seems like a passion for your team and I wanted to provide my knowledge to help you improve further. I've been in the cyber security field for a while now and like to help out when I can.
