Good day.
Shift-left click should be it, and if it works while buying stuff then it might be either an add-on problem or it might be an e.g. a sticky key problem.
For the add-ons, try disabling all of them and check if it works. If it does work, then enable you add-ons one by one to see which one is the culprit.
If it is working sometimes and not working other times, then my guess would be a sticky key problem. Do you Alt-Tab while playing? Alt keys have the tendency to get stuck and lead to hotkey problems. Press Alt a few times to get it unstuck and try again.
