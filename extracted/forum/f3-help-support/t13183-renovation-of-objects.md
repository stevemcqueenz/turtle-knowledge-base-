> I sold the items out of stupidity and a lot of time has passed for redemption, is there any possibility of recovery?

Greetings!
Mistakenly sold items can be purchased from vendors in the buyback section. If a lot of time has passed, unfortunately you can't restore items.
However, if you have sold some unique item that is a reward for a quest, you can submit a tick in the game to recover the item.

[How to contact a GM and get help in-game]

Near your key ring there is a red question mark, press it to send an in-game ticket.Also you can enter the command /gm in the game chat.
You don't need to be online for tickets to be solved. Support will respond via in-game mail.
