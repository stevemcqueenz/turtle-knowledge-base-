# Rogue Blind Changed to Physical in Latest Patch – HoP Doesn’t Remove It

## Post 147269 by Thaladar (Patch Note Conspiracy Theorist) — 2025-08-20T13:53:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=147269#p147269 | page 1 | era: pre-1.18.1 -->

In the latest PvP patch, Rogue’s Blind was changed to a physical effect. After testing this in arena, I noticed that Paladin’s Hand of Protection does not remove Blind, even though HoP should clear physical debuffs.

This feels like the change isn’t working as intended. If Blind is going to stay physical, it should interact properly with abilities like HoP. Otherwise, it ends up much stronger than before, since it can’t be dispelled as poison anymore and isn’t cleared by physical immunity either.

Could the team confirm if this is a bug, or if Blind is really supposed to ignore HoP?

Here's the patchnotes for the blind change and the comments about it being physical:

> **Jamey wrote: Fri Jul 25, 2025 1:32 am**
> **UPDATES | Dated: TBD (1.18.0) 2025**
> > **REVISION | Dated: 14 August 2025**
> >
> >  **Blind:** Debuff is now considered a Physical effect instead of a Poison.
> >
> >  *Developer Comment: With the introduction of Insignias that remove all crowd control effects Blind has been struggling even more than before to stay on targets, so we're changing its effect type to Physical so that it isn't easily cleansable by potions and class specific spells.*
