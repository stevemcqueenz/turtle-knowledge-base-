I had the same issue, this is what fixed it for me.
Closed the game - disabled 1 of my 2 monitors - restarted my computer ( when my computer loaded up, it only had 1 monitor active) - Relaunched the game - now I was able to select my correct resolution of 2560 x 1440 wide.

Side note - AFTER the game is up and running on my 1 monitor at correct resolution, I enabled my 2nd monitor. But any restart of the game or closing and opening of the game brought the issue back. Had to redo the above fix and it works again.
