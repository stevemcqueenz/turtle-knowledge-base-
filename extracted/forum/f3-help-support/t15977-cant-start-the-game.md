> **Bravery wrote: Wed Nov 20, 2024 3:45 pm**
> ...error says procedure entry point DiscardVirtualMemory could not be located.

To my knowledge, this issue is caused by using Windows 7 or earlier. Programs designed for later operating systems assume you're running such a system and throw up their errors in protest when they find you're still using, shall we say, Windows Classic.

I find ending the "rundll32.exe* process directly from the Task Manager causes the updater to wake up, wipe my add-ons, and extract the patch from the main directory (where it downloads to) to the Data folder (where it's supposed to go).
This process persists even after WoW has been closed, for me, and I have to close it manually every time.

If no rundll32.exe appears in the Task Manager when you try to start Turtle WoW, I would avoid ending it without knowing what it's actually for.
