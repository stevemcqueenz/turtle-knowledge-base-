## Post 149231 by Anadelonbrin — 2025-08-29T21:19:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=149231#p149231 | page 1 | era: pre-1.18.1 -->

Hello there,

I'm not entirely tech minded but setting up the launcher and getting the game running was pretty straightforward. I have messed around and have a few lower level characters on Nordanaar, and even made some placeholders on Ambershire. I've since tried to go to Tel'abim and during the handshaking processs it disconnects me and sends me back to the login screen.

For a while I was struggling to connect at all because it would default to Tel'abim and would then disconnect me immediately. Since then I've found that cancelling the handshaking process it at least gives me the option to be assigned a server and so I can then reconnect to both the PVE ones again.

Asked for some assistance on Discord and recommended deleting the WDB folder, which I did, and disabling addons but the problem still persists. Seems odd to me that I cannot log into one server but the other two are fine.

Would appreciate any suggestions and/or assistance. Thanks!

## Post 149416 by Anadelonbrin — 2025-08-30T18:59:00Z

Problem fixed from assistance on Discord. Apparently Malwarebytes can interfere with logging into the one server, but not the others. Removing this fixed the issue for anyone with a similar issue. Thanks!
