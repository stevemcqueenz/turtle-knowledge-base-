# Covert Ops

## Post 2276 by Peeves — 2019-03-08T09:23:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=2276#p2276 | page 1 | era: pre-1.18.1 -->

The quests "**Covert Ops - Alpha**" and "**Covert Ops - Beta**" give you a *Covert Ops Pack* that should contain all of the following items:

 *Covert Ops Plans: Alpha & Beta*
 *Remote Detonator (Red)*
 *NG-5 Explosives (Red)*
Remote Detonator (Blue)
NG-5 Explosives (Blue)

Consecutive tests showed that not all of those items are 100% drop rate from the *Covert Ops Pack*. I am unsure if this should be the case.

Anyways, the explosives themselves seem to work on placement, but seem unable to be triggered by the Detonators. Quite an interesting mechanic for Vanilla WoW, possibly hard to fix. The quests are both still managable without those items, so no rush.
