Hello!
Because of the sheer number of downloads and installs of the new Patch 1.17.0 some popular Antivirus programs have flagged our client download or WoW.exe as malicious / trojan. This is done in error and the only reason for this is because lots of players all at the same time are using the new client.
This might cause issues with downloads or installs and we recommend that you make an exception for the new client folder to prevent running into additional issues.
