# Raptor Strike ability cooldown increased by ping

## Post 147217 by Atlatrozius — 2025-08-20T09:51:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=147217#p147217 | page 1 | era: pre-1.18.1 -->

Raptor Strike has a 5s cooldown (with talents) that starts from when the Raptor Strike melee attack is made (not when the ability is cast). Because of how this is tracked, a user with 200ms ping actually has a 5.2s CD on Raptor Strike.

While ordinarily being unimpactful, the small increase in cooldown on Raptor Strike from ping can cause weapons close to a divisable attack speed breakpoint to go from using Raptor Strike every 2nd attack to every 3rd attack. This can represent an non-insignificant damage loss, and likely should be looked into if resources allow.
