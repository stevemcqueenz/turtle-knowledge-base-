All you need are proper drivers for your graphics card and install Wine. I currently play Turtle WoW on Linux Mint on a system made out of old PC parts I had. lol AMD 860k quadcore 8GB DDR3-1600 and a GTX 660 2GB.

Valve has already stated the Steam Deck is a PC and is open to installing other operating systems such as Windows and Linux Distros. I don't think the default SteamOS  will run 3rd party games that are not supported by Steam. You will have to install Linux and run it with Wine or install Windows to run it as a native app.
