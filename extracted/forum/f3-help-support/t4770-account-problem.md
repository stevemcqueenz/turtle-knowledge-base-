Hello

Please open an in game ticket with full details:

Character name

Lost gear name

Date when the event happened.

Event explained with details.

We won't be able to help with "Something happened to my character, go check logs and fix it" type of tickets.

How to open a ticket:

Near your key ring there is a red question mark, press it to send an in game ticket. If you have pfUI and you don't have the micro bar enabled, you can type /gm to open the interface. You don't need to be online for tickets to be solved. Support answers by in game mail.
