## Post 163058 by Theexpell — 2025-12-18T08:48:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=163058#p163058 | page 1 | era: 1.18.1-announced-pre-release -->

You can’t block or intercept the sound directly (I’ve tried), but if it bothers you enough there is a workaround. You can go into the sound patch files, locate the sound file used by Omen of Clarity, and replace it with an empty (silent) file.

The game doesn’t care what sound it plays, as long as a file exists - so if the replacement is silent, it will simply play nothing.

Just keep in mind that anything else using that same sound file will also become silent, not just Omen of Clarity. That said, I can’t think of many other things that use that particular sound?
