Having problems connecting?
Check your Launcher Version (Bottom right of launcher screen):
 - if it is less than 2.2.8, download the newest launcher from:
 - Windows: [https://launcher.turtlecraft.gg/api/lau ... load=bunny](https://launcher.turtlecraft.gg/api/launcher/TurtleWoW.exe?download=bunny)
 - Linux (Beta):[https://launcher.turtlecraft.gg/api/lau ... load=bunny](https://launcher.turtlecraft.gg/api/launcher/TurtleWoW.AppImage?download=bunny)

Edit your `realmlist.wtf` file to contain the following:

SET realmList "logon.turtle-server-eu.kz"
SET patchList "logon.turtle-server-eu.kz"

Still Can't Connect?
Try the steps in this pinned message: [https://discord.com/channels/4666224558 ... 9886474351](https://discord.com/channels/466622455805378571/691438750185553950/1421754489886474351)

If all that still fails, please pull your launcher log file (Open Cog Menu, click Open Log file) and post in [launcher-support](https://discord.com/channels/466622455805378571/13092390460269527959)
