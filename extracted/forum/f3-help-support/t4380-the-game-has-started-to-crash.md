Verify game files: Verify the integrity of the game files through the game launcher. This process may take some time to complete, but it can fix any corrupted game files that may be causing the crashes.

Lower graphics settings: Lower the graphics settings within the game to see if it improves stability. This may help to reduce the strain on your computer and prevent crashes.

Close other applications: Close any other applications or programs running in the background. This can free up resources for the game and help to prevent crashes.
