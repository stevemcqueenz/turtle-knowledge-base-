Greetings!
If you have difficulty with a quest in the game, you can always make a ticket. The gm will help you figure it out.
 **How to file a ticket :**
Near your key ring there is a red question mark, press it to send an in-game ticket.
If you have pfUI and you don't have the micro-bar enabled, you can type /gm to open the interface.
You don't need to be online for tickets to be solved. Support will respond via in-game mail.
If you are sure that you have discovered a bug, you can also bypass the ticket system and file a bug report.
 **How to make a bug report:**
Please, make a bug report on our tracker: <https://github.com/slowtorta/turtlewow-bug-tracker>.
It's easier for the team to document and investigate issues if they're reported on Github.
