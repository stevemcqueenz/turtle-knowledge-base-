Unfortunately, Ratchet's Flight Path is bugged when flying longer distances.
For Alliance trying to fly north from Ratchet, you need to fly to the flight path in Azshara (really simple to pick up at a low level since it's right by the border with Ashenvale), and from there you can fly anywhere you want. I also believe Alliance can fly to Theramore from Ratchet as well, and from there fly anywhere, but I'm not sure about that. Theramore's flight path should be easy for low levels to pick up as well because of boats from Eastern Kingdoms to Kalimdor.

For Horde, it's best to fly from Ratchet to the Cross Roads.

The cause of the issue is known and it has already been stated that it will be fixed in the next patch. The issue is the client files that determine flightpaths say you can go certain routes (that were lifted from TBC) but the server does not have those routes programmed, thus the error is received. This issue should be resolved already and applied with 1.16.1.
