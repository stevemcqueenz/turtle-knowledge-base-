Hello, community!

I know that the issue is old, but maybe you can provide me a stable solution for it. I have two monitors connected. The main one is connected via DisplayPort, the additional one is via HDMI.

The game client doesn't really work on the display port, everything is flattened and smeared, I can't change resolution, list of resolution settings is extremely short, I can't change details, distance or anything else. Any attempts to adjust setting sooner or later end up with a black screen.

Every time to play, I have to disconnect the second monitor, swap cables, and that's the only way the client starts proprly.  (No, I can't change the configuration, because I'm limited by the ports on a monitors and graphics card)

Is there any addon or patch that would solve this problem? Maybe some kind of software or drivers?

Thank you in advance.

Hi!

Addons do not affect the game client only the UI so I will say no.

No patches either.

There are a few options to solve this problem but maybe they will not be permanent.

You can try using these modifications: [https://turtle-wow.fandom.com/wiki/Clie ... and_Tweaks](https://turtle-wow.fandom.com/wiki/Client_Fixes_and_Tweaks).
They fix some graphical problems but not all.

There is also a way to disable one monitor before starting the game client.  You turn off the monitor, turn on the game and then turn on the second monitor.

If you have an Nvidia video card, you can set game specific settings in the Nvidia panel.

Also you can go to our [discord](https://discord.gg/qmaEYFNm), support channel and using a search engine by pressing ctrl+f enter a phrase or words on your problem for example: "display port" or "two monitors".

hey buddy, I had a same issue, it took me 2 days to sort it out.
here is what I did and it worked.
install wowtweaks, its easy to do just read trough.
then delete the whole folder that is above WTF folder(can't remember the name its also three letter combo)
then unplug 2nd monitor and this is very important ( unplug from the pc not from display) in my case my main monitor is hdmi and 2nd is display port, so I unplugged display port
then restart pc and run the game from wowtweaks.exe
it magically fixed the issue and I could even plug back 2nd monitor without any issues, its like the game sorted it self out
good luck
