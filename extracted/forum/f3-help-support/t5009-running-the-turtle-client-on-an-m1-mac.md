## Post 30574 by Akamizu — 2022-12-13T05:12:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=30574#p30574 | page 1 | era: pre-1.18.1 -->

It kinda works on Parallels, but it's very inefficient due to virtualizing a whole Windows system and using Window's x86 to ARM translation.

Only if the Turtle-Wow team decides to make the client 64-bit, we would be able to play with Crossover.
 32-bit translation is still very buggy with Rosetta 2. Crossover currently only works on WoW Cataclysm (64-bit) clients or later.

So unfortunately all we can do is hope and wait.
