## Post 74080 by Rellelol — 2023-10-27T01:43:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=74080#p74080 | page 1 | era: pre-1.18.1 -->

If you are getting disconnected upon login. On login screen look to the bottom right under Credits, If it says Tel'abim then you need to go to your turtle wow install location, open WTF folder and open up config. Look for SET realmName "Tel'Abim" and remove that line. Save changes and try login again. You should be able to select the realm again.
