Hi,

Ive just recently found out about this server and am really enjoying it, especially the concept to HC.

Unfortunately i cant seem to get the game to run smoothly like normal WOW. I am experiencing a kind of micro stuttering in game. When im moving, the camera is not flowing 100% smoothly so to speak. Also, the animations are not 100% fluid.
The game is playable but the micro stuttering is really bothering me.

I cam running regular wow on high settings without any issue.

I have tried alot of the things ive read online and applied the changes that people have suggested in game:

- Vsync on/off

- Full Screen/Windowed Mode

- Hardware cursor on/off

- Setting refresh rate to 64Hz in Nvidia Control Panel

- Compatibility mode windows XP/Windows 7
None of it seems to fix the problem.

One thing i wasnt able to try so far is to activate tripple buffering since my game crashes when trying to apply it in game. Does anybody know the config command to activate it?

## Post 16857 by Allwynd01 (Bug Report Enthusiast) — 2022-02-08T14:12:00Z

I haven't had this problem with WoW or Turtle WoW for that matter, but I had a similar problem recently with The Elder Scrolls 3 Morrowind. I tried all kinds of things, but nothing worked, I searched for it on the internet and found one solution.

You turn off VSync in the game and open nVidia Control Panel and then go to 3D settings and locate **wow.exe** and from there you turn VSync on inside nVidia Control Panel specifically for **wow.exe** and nothing else. At least that helped me fix the problem in Morrowind.
