I haven't played Turtle WoW since late last year, so I decided to fire her up and check out the latest changes. I clicked on my Wow.exe, which is dated 10-03-23. The WoW signon screen comes up, and it knows me. I click on the red Login button. It authenticates me, and then a separate screen comes up that says "*Downloading update*". It slowly counts up from 1% to 100%. Then a message is displayed that says

"Download successful.
The update was successfully downloaded.
Press the restart button below to restart World of Warcraft."

I press the red Restart button, and that screen goes away and we go back to Windows desktop, where a panel comes up that says "Turtle WoW Patcher". It shows an empty bar that says "*Installing...*" below the bar.

That's it. Nothing else ever happens. I have let it sit there for hours. I have run this several times with the same result, so I am at a brick wall as to what to do.
 ---------------
FYI: a glance at my Turtle WoW directory shows three new files with the timestamp of the download today.
They are *TWPatcher.exe*, *tw_update.log*, and *wow-patch.mpq*.

The *tw_update.log* file contains a single line:

"*Log file created. WoW process is not finished yet, waiting for exit*"

After I give up and abort the Patcher's install process, this is added to the

"*Update is complete, starting the game...*"

Turtle WoW then runs again. As soon as I click the login button, the entire download runs again, then back to Windows to the Patcher which once again never does anything.
