## Post 35280 by Rukopashka — 2023-02-19T21:45:00Z

If you're seeing an error message indicating that your game files are corrupted when trying to enter World of Warcraft, deleting the "Interface\FrameXL" folder as the error message suggests may help resolve the issue.

Here are the steps you can take:

 -Close the game launcher and any other programs related to World of Warcraft.
 -Navigate to the World of Warcraft installation folder on your computer.
 -Locate the "Interface\FrameXL" folder within the World of Warcraft folder.
 -Right-click on the "FrameXL" folder and select "Delete".
 -Confirm that you want to delete the folder by clicking "Yes" when prompted.
 -Restart the World of Warcraft launcher and attempt to log in again.
If the issue persists after deleting the "FrameXL" folder, you may need to try repairing your game files or reinstalling the game.

Hello.

There is no auto repair feature for our client.

The described solution for the error <you game files are corrupted. Please delete Interface\FrameXL Folder>  it won't fix the issue if you delete the blizzard addons  interface folder cause they won't auto replace.

If you encounter this issue please get a new client and don't merge it with your old one. Make sure your game isn't saved in a write-protected directory such as Program Files, Downloads, Documents etc. The best place to save your game would be C:\Games\WoW .
