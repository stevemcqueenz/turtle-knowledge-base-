## Post 8639 by Roxanneflowers (Patch Note Conspiracy Theorist) — 2020-12-06T12:54:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=8639#p8639 | page 1 | era: pre-1.18.1 -->

Orange creation = 100% chance for +1 Skill
Yellow creation = 50% chance for +1 Skill
Green creation = 25% chance for +1 Skill
Grey creation = 0% chance for +1 Skill

As you can see, if you're not crafting Orange labeled items, you don't have a 100% chance of skill up.  That means that if you're crafting Yellow labeled items, not only is the skill up chance not 100% ... it's also perfectly possible to have a run of Bad Luck™ where you keep not getting skill ups even though you are crafting Yellow labeled items.
