Necroing that post for whoever will end up here with that same issue in the last two months before i post this :

If you have this error with nearly EVERY DLL that's at the root of your turtle wow folder, disable "Smart App Control" in windows defender. That shit got added recently and it stops the dll from even reaching quarantine, so you won't see them added there at all, and you'll have an error for each and every dll present.

Once disabled, never enable it again, as it's straight up garbage and doesn't do anything better than what og defender did. Enjoy playing now. Took me a while to figure out.
