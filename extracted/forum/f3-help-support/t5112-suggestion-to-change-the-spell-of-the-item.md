## Post 30935 by Everjunior — 2022-12-18T16:57:00Z

Greetings, dear and respected Turtle Wow team. I'm writing to express my indignation at the fact that some spells of the items  have the same spell ID as certain class spells. I was very disappointed to learn that the [Horn of Engryss] ( <https://database.turtlecraft.gg/?item=83224> ) trinket has an attached spell with the same ID as druid's Thorns ( <https://database.turtlecraft.gg/?spell=1075> ), and therefore cannot be used at the same time. I express my sincere hope and ask you to correct this mistake by making it possible for the druid to use both the item and the spell on himself at the same time.

Thank you
