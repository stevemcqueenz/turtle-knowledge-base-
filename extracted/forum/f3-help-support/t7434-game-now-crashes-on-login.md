## Post 47367 by Allwynd01 (Bug Report Enthusiast) — 2023-05-25T10:22:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=47367#p47367 | page 1 | era: pre-1.18.1 -->

Out of the addons you use, the only ones I use are:

 - Cartographer
 - pfQuest + pfQuestTurtle

and I haven't experienced crashing. I remember some years ago on a different server with Cartographer, I had issues where there were so many markers on the map that I had FPS drops only in Stranglethorn Vale and nowhere else. If I left STV, the FPS would improve, if I go back in, it would go bad again, if I disabled the addon, no FPS drops.

I think I was also getting some message about "out of memory" and after some fiddling, I noticed that on the addon manager, there is a text box where you can specify how much memory is given to addons. I think it was then that I realized the highest amount you can input is 999 (limited to 3 digits for some reason) and after doing that, the message for "out of memory" disappeared and my FPS improved until I cleared most of my quests in Stranglethorn Vale.

You can try dedicating more memory to your addons, if that doesn't help delete all of them and reinstall them one by one until it works again. I'm under the impression that too many addons make people really dependent and also cause issues so the less addons you use, the less headaches you will have.

Those who say you can't play the game properly without addons X, Y and Z are just playing the game the wrong way. All people need is Cartographer for the windowed map and pfQuest for faster questing when you have already played through WoW without a quest helper several times and you already know the quest's story just by reading the name.
