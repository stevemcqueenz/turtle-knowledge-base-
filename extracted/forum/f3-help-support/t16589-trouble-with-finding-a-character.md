Greetings!

Please make a ticket in game from the account where the character is missing.

[How to contact a GM and get help in-game]

Near your key ring there is a red question mark, press it to send an in-game ticket.Also you can enter the command /gm in the game chat.

You don't need to be online for tickets to be solved. Support will respond via in-game mail.
