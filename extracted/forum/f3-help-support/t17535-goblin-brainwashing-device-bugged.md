As I received from another Forum member (Griefmaker), here is a soluntion for the time being:

Save one spec, then wait for the CD to finish and then use the goblin brainwashing device you can then save the second spec. Repeat for a third or fourth if you have it.

Basically:
- Use GBWD and save a spec

- Wait for 10 minute CD

- Use GBWD a second time to save a second spec

- Wait for 10 minute CD

- continue for any remaining specs (note there is a respec fee for each initial respec)
