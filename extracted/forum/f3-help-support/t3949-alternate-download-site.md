## Post 23989 by Allwynd01 (Bug Report Enthusiast) — 2022-08-30T11:03:00Z

Just use some 3rd party downloader client like:

 - Neat Downloader
 - Free Download Manager
 - Internet Download Manager

Browsers by default are set to respect the traffic cap of each server, so even if your internet speed is fast, if the server has set a cap to something like 200kb/s, the browser will just respect it and download at that speed.

Download managers, which were popular in 2000 - 2009 and after that faded into obscurity do not respect the server's traffic cap and will download at the highest possible speed that your internet connection allows.

Personally I don't have this problem with downloading Turtle WoW slow through my browser, but then again I use Brave, which is a Chromium-based browser and it's by default superior than the outdated and archaic Firefox, which only has a new skin every 12 months, but deep underneath there is outdated code from like 2002, it's just a bad browser.
