Sharing my "solution" here in case anyone else ever runs into the same issue. In addition to my problem above, I noticed each time I launched client ("WoWFoV"), I had to select my realm and then adjust all my settings again (resolution, graphic options, etc.). I was searching for how to fix that issue and came across a thread that said not to install Turtle WoW into a folder like Program Files.

I moved the folder to D:\TurtleWoW and fired it back up. I had the same problems as before when I first launched the client again, but after I saved them and restarted everything worked perfectly. Now I can get back to questing!
