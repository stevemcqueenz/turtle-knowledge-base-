I was reading over the forums and noticed that there was a lot of changes over the years to the rules of multi boxing so I just wanted to make sure that I understood the current ruleset completely.

> Multiboxing
>
>  Multiboxing is the act of controlling multiple WoW clients simultaneously. This can entail having multiple clients open on a single machine or utilizing multiple machines to control the actions of both accounts at the same time for combat or moving. At our server, we permit the use of a maximum of two accounts at a time, with the following exceptions:
>
>  It is strictly forbidden to multibox if either of your characters is undergoing a Hardcore challenge.
>
>  It is strictly forbidden to multibox if either of your characters is flagged for PvP or is assisting others in PvP. This includes Warmode.

So in the current ruleset so this means that we -are- allowed to use 3rd party software like auto hot key? Since it does ont currently mention the use of software as being not allowed or are we not allowed to use it currently?

Per (what I believe is) the most recent rules update on this ([viewtopic.php?t=5438&hilit=multiboxing](https://forum.turtlecraft.gg/viewtopic.php?t=5438&hilit=multiboxing))  "Examples of actions that are strictly forbidden under any circumstances while controlling multiple clients:
Using any third party software to control your characters while multi-boxing.
Multi-box in any PvP situation."
So third party software is still strictly forbidden.  That part has been in the rules since the beginning, I would honestly expect to see something clarifying that it is allowed if it was going to change.
