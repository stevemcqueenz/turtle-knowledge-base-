Where do you copy the folder on your hard drive? Make sure it is not one of those pesky write-protected folders, like \Program files\ and the like. C:\Games\Wow\ or something similar tends to work just fine. Also check if the other topics with the same problem (as in black screen) help you, there are tons of them.
Quote from Torta:
"Please find the config located in your game folder: WoW/WTF/Config.wtf
Open it and add the following lines: SET gxWindow "1" SET gxMaximize "1"
Save it and close it."
