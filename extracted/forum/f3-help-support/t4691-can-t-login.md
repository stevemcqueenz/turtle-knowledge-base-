## Post 28076 by Fin (Patch Note Conspiracy Theorist) — 2022-10-28T07:09:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=28076#p28076 | page 1 | era: pre-1.18.1 -->

You can update the client with incorrect information. If you information is wrong too many times  you get locked out for 15 minutes when you try to log in.

Please try to reset password:
[viewtopic.php?p=12891#p12891](https://forum.turtlecraft.gg/viewtopic.php?p=12891#p12891)
After:

Use the following command in game to change it to a custom password.
.account password old new new
