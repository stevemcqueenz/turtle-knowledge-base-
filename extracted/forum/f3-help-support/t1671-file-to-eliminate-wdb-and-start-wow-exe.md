# File to eliminate WDB and start WoW.exe

## Post 9850 by Merikkinon (Patch Note Conspiracy Theorist) — 2021-03-22T20:40:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=9850#p9850 | page 1 | era: pre-1.18.1 -->

Got this from my time on Kronos (props for the Dead):

 1) Write this into a text file and rename to **.bat** format

 2) text:

@echo off
rd /s /Q “WDB”
start WoW.exe
exit

 3) Make sure to put the .bat file in the main WoW directory with the wow.exe file (you can make a shortcut to the .bat file itself)

 3) when starting the game, simply click on this .bat file (name whatever) and it will delete the WDB folder and then start wow.exe
