# Skybox Visual Glitch / Streaks When Looking Up at High Render Distance

## Post 163848 by Teovald — 2025-12-27T11:43:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=163848#p163848 | page 1 | era: 1.18.1-announced-pre-release -->

Hey all,

I’ve encountered a visual glitch in the skybox when playing outdoors with a high render distance setting. Basically, when I look up at the sky with farclip set around 1500, I get horizontal streaks and visual artifacts across the sky.

Steps to reproduce:

Set render distance (farclip) to a high value (e.g., 1500).

Go to any outdoor area with sky visible.

Look up toward the sky.

You should see horizontal streaks or glitch lines in the skybox.

Observed behavior:
Skybox shows streak-like artifacts when looking upward at high render distances.

Expected behavior:
Skybox should render cleanly without streaks regardless of farclip.

Fixes/workarounds attempted:

Removed the HD Patch — did not fix the issue.

Reduced render distance to vanilla Classic max (777) — this removes the glitch entirely.

So far it seems tied to the higher farclip value — lowering it fixes the visual glitch, but I’d like to keep a higher view distance if possible.

Questions/Info:
Is there a way to maintain 1500 render distance without triggering this sky glitch?
Any known config settings, tweaks, or console flags that help?
