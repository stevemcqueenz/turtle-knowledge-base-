## Post 10290 by Vetoblade — 2021-04-28T17:51:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=10290#p10290 | page 1 | era: pre-1.18.1 -->

The game by default is not designed for a higher resolution, so you have to set it manually. You have to go to the game data, and find a map, I forgot how it's called, but you can find some information about this on google. There you will be able to change the resolution settings, and choose what you prefer. When I got a new monitor from [how2pc](https://www.how2pc.com/best-gaming-monitor-under-200-144hz/), it was also at a high resolution, too good for the game, and I had to put the resolution by myself in the game settings, and now it looks very clean and smooth on my new monitor.
