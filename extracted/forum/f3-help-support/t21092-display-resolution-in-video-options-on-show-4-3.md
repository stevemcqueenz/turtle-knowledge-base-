I don't use Windows anymore, but I remember when I used it, there was a thing if the game is installed on the C drive where Windows is, you don't get as many permissions about read/write like if it's on the D drive or another drive.

Are you sure your game is not installed on the C drive? I always found it stupid if a Windows PC has only a C drive instead of a C and D drive. For Linux this makes no difference, because read/write permissions are different so you can only have one drive and that doesn't affect anything.

I've seen many people complain about such problems when they installed games on their C drive. Look into that if it applies to you.
