Hey there!

Our launcher is temporarily disabled. Please use the WoW.exe file from your main folder to manually launch Turtle-WoW.

Additionally, check your realmlist file in the main WoW folder to make sure it's set correctly for the server you want to connect to.

You can manually download the EU client using the following link:
<https://sadl.b-cdn.net/twmoa_1172_eu.zip>

You can manually download the SA (Spanish) client using this link:
<https://sadl.turtlecraft.gg/twmoa_1172_es.zip>

For players trying to access the SA realms with the EU client, make sure your realmlist is set to :
SET realmList "salogon.turtlecraft.gg"
SET patchList "salogon.turtlecraft.gg"
