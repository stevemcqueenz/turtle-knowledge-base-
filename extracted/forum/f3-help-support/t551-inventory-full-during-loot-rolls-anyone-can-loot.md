# Inventory Full during Loot Rolls --> Anyone can loot!

## Post 2875 by Bishoor — 2019-05-16T01:05:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=2875#p2875 | page 1 | era: pre-1.18.1 -->

Hi Team,

Allow me to preface this post by saying I wholly appreciate everything the devs do to make this server great.  I love the tight-knit community we have here, and you guys have created a beautiful home for us players to enjoy.

That being said, I have one piece of feedback.
So I issued a ticket yesterday regarding this loot issue:
When using Group Loot, if an item drops, and everyone in the group Greed rolls (or Need rolls, I suppose) and the winner of the roll happens to have their inventory full, that item on the corpse can then be picked up by **any** member of the party.  It is fully up for grabs as if the loot option were set to Free-for-all.

I received a prompt response to the ticket, saying that after investigating it, it's working as intended since this is the way it was in vanilla.  I must mention, I played Vanilla from 2005 on, from patch 1.5 to 1.12, and at no point did I experience this.  What I remember is, if someone has their inventory full, other members of the party can of course see the item on the corpse, but **cannot** pick it up, as they did not win the roll.  *Only the winner of the roll is able to pick up the item.*

Even if this did exist at some point in vanilla prior to patch 1.5, in my humble opinion this mechanic needs to be adjusted.  I've already been in groups where someone has accidentally looted bind on pickup items, which causes tension between players.  In a close community like this, this could easily damage someone's reputation due to ninja looting accusations, based on an honest mistake from preemptive clicking.  On every other private server I've played on, only the winner of the roll is able to pick up the item.

Like I said, even if this did exist in Vanilla at some point, I think it's worth it to correct it.  Turtle WoW has cross-faction grouping, gnomes riding wolves, and purchasable cosmetic mounts at level 1, which are all things that give this server flavor and make it a nice place to play on, even though none of these things existed in Vanilla.

I think this is an adjustment worth making, and would improve the experience for all players.  Group Loot should be fair, and measures should be taken to avoid unnecessary conflict between players.

To the devs: Thank you again for all that you do, and I do hope you consider this change.

Humbly,
Avarice / Bishoor
