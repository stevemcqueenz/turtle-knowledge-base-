Hello there!
Don't worry, this is topic is not for asking if/when is this possible, but rather showing how it can be! I got it working with stable 50fps on my macbook   satisfied_turtle
All thanks to the new version of vmware Fusion:[https://blogs.vmware.com/teamfusion/202 ... eview.html](https://blogs.vmware.com/teamfusion/2023/07/vmware-fusion-2023-tech-preview.html) which is free   satisfied_turtle_head

So, what we need is the vmware Fusion version, which can be downloaded from [https://customerconnect.vmware.com/down ... FUS-TP2023](https://customerconnect.vmware.com/downloads/get-download?downloadGroup=FUS-TP2023), as well as a Windows 11 ARM release iso, which can be downloaded from here [https://communities.vmware.com/t5/VMwar ... -p/2957381](https://communities.vmware.com/t5/VMware-Fusion-Documents/w11arm-esd2iso-a-utility-to-create-Windows-11-ARM-ISOs-from/ta-p/2957381)

Then it is as easy as creating the Windows VM and setting it up. For that I recommend this video guide: [https://www.youtube.com/watch?v=Mqn1yoV ... B2bQ%3D%3D](https://www.youtube.com/watch?v=Mqn1yoV_OW4&pp=ygUQbWFjb3Mgd2luZG93cyB2bQ%3D%3D)

Afterwards all we need to do is download the latest client and run it.

A demo presentation will be available here: <https://youtu.be/MF_Uk93wr5c>

Cheers!
