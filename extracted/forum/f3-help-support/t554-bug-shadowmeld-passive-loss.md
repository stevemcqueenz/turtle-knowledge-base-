# Bug:  Shadowmeld Passive loss

## Post 2883 by Skullmiser (Barrens Chat Casualty) — 2019-05-16T13:17:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=2883#p2883 | page 1 | era: pre-1.18.1 -->

Nightelves passively have a stealth/prowl buff, making them harder to be detected while stealthed or prowling, however using the active ability "Shadowmeld" will remove the passive ability until relogging.
