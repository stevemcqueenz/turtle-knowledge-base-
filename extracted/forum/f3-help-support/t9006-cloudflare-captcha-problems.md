## Post 58565 by Allwynd01 (Bug Report Enthusiast) — 2023-08-23T08:17:00Z

I use Brave, sometimes some websites act up, because I have Brave's built-in content blockers as well as uBlock Origin, in those cases, I have to disable either or both for the websites to work.

Check if you have some content blockers preventing Cloudflare from working properly, if you don't have any, then it's either your ISP doing something or your computer has some specific hosts file changes or some firewall or antivirus is causing problems.

It should work, if it doesn't the problem must be on your end.
