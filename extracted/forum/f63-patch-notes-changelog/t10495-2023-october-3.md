## Post 68406 by Torta (Turtle WoW Team) [STAFF] — 2023-10-03T13:13:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=68406#p68406 | page 1 | era: pre-1.18.1 -->

- Cooldown for Flourish has been fixed.

- Replaced the spell list for Venomlash Chimera.

- The Binding of Xanthar can now function as group loot.

- Rank of Glanthas the Ancient has been fixed.

- Loot chances for Genn have been fixed.

- Respawn timers for Gilneas Dungeon have been fixed.

- Item parameters for Dark Iron Reaver, Edgemaster's Handguards, Theramore Tome, and Stonard Tome have been fixed.

- The Still Alive title is now granted to the previously created HC.

- Broken Graveyard for Gilneas City and Gilneas has been fixed.

- New script implemented for the quest Ammo for Rumbleshot.
