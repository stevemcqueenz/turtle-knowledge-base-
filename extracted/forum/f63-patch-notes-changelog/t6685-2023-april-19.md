# 2023 — April 19

## Post 42070 by Torta (Turtle WoW Team) [STAFF] — 2023-04-18T21:01:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=42070#p42070 | page 1 | era: pre-1.18.1 -->

- Gor'dosh Firethrower will now cast Fireball.

- Spellshock Leggings can now drop from all mobs in Zul'Farrak.

- Fixed issue with quest Drifting Across the Sand.

- Corrected wrong factions used for various mobs across the world.

- Tempest's Rage's effect will now only apply to the player as intended.

- Added new gossip options to Glyph Masters that explain the different challenges.

- Tabetha should hopefully no longer get stuck in a non interactable state.

- Improved scripting for quest Sacred Waters of Eldre'thalas.

- The Defias Traitor is now immune to players.

- Study to Survive is now shareable.

- Work for Food is now shareable.

- Durotar Scouring  is now shareable.

- Corrected reputation gains and losses from killing some NPCs from the Magram and Gelkis factions.

- Fixed a bug that caused the new revamped crafting items to bind on pickup instead of the intended bind on equip.
