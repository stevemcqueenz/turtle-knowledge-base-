## Post 151050 by Jamey (Turtle WoW Team) [STAFF] — 2025-09-09T23:23:00Z

![Image](https://turtlecraft.gg/images/changelog/Changelog-2025-09-10-ENG.jpg)

- **Weekly quests** should now resest with the weekly server maintenance, as intended.

- Fixed an issue where weekly quests would be missing from a Player's Quest Log.

- Fixed display ID of **Murloc Fin**.

- Lowered respawn time of **Undermine Shipment**.

- **Dragonfire Bomb** will no longer be able to be resisted.

- Fixed skinning loot of various creatures.

- **Concoction of the Dreamwater** and **Juju Might** no longer stack.

- **Groldan's Stash** is no longer lootable by Horde players.

- Implemented numerous **performance improvements**.
