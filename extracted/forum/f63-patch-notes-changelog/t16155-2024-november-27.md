# 2024 — November 27

## Post 110047 by Reynolds (Turtle WoW Team) [STAFF] — 2024-11-26T19:48:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=110047#p110047 | page 1 | era: pre-1.18.1 -->

![Changelog_2024-11-27_3.jpg](./download/file.php?id=85) <dd>Changelog_2024-11-27_3.jpg (66.41 KiB) Viewed 20500 times</dd>

- Rank 1 through 3 of lightning strike had their partinioning fixed and now properly scale to reflect previous patch's power level:
 - Rank 1 (Level 20/Talent): 20% Weapon Physical + 10% Weapon Nature

 - Rank 2 (Level 38/NEW): 40% Weapon Physical + 15% Weapon Nature

 - Rank 3 (Level 56/NEW): 60% Weapon Physical + 20% Weapon Nature

- Tranquility will no longer get cancelled when a single player leaves its radius.

- Minor tooltip adjustments to Totem of Crackling Thunder and Totem of the Stonebreaker.

- Lightning Strike's nature damage portion no-longer double dips into damage modifiers.

- Lightning Strike's nature damage portion now succesfully casts even when silenced.

- Nerfed Lawbringer's (Paladin Tier 1 8 Set Bonus) proc chance from 30% to 12%.

- Quickness (Racial Passive) will now increase ranged attack speed as well, as intended.

- The Distracting Jarven quest is now repeatable, which eliminates players' softlocks if they haven't had time to interact with the keg while he's away.

- Enabled Druids to use Great Rage Potion and Rage Potion.

- Corrected class of Desecrated Tokens to allow their disenchantment.

- Corrected NPC Yox Rackgadget' name typo.

- Fixed toy object not being summoned by Goblin Radio KABOOM-Box X23B76 spell.

- Fixed /shoo emote non-working on Baby Sharks required for completion of Sharks Are Friends, Not Food.

- Cleaned up spawns from events that should no longer be active.

- You can now use big mounts inside cities again.

- Holy Strike is now affected by Judgement of the Crusader.

- Fixed conditions for disabling War Mode.

- Fixed a bug that could cause players to be permanently saved to a non raid instance.

- Fixed Arlokk not being attackable after leaving stealth.

- Added a few new extra displays to Illusion:Dryad for both male and female models.

- Fixed an issue where Avoidance would not be learnt by every Pet.

- Fixed Tome of Tactical Escape cooldown issues.

- Fixed an issue where Improved Water Shield did not provide the expected bonus to Mana regeneration while casting.

- Fixed an issue where Judgement of Command could be parried, blocked, or dodged.

- Fixed an issue where Arcane Power did not reduce mana gain from all sources by 75%.

- All Demonic Sacrifice buffs should now be removed after a respec.

- Damage from Flametongue Totem should no longer trigger Windfury.

- The healing effect of Holy Strike should no longer trigger Corrupted Mind.

- The T3 Elemental 8 piece set bonus should no longer trigger if you don't have the Electrify talent.

- Fixed T3 Restoration 8 piece set bonus.

- Fixed several item enchantments to correctly require a specific item level, as intended.

- Fixed looting issues with Fragment of the Nightmare's Corruption.

- Shaman and Paladin items should no longer drop for the wrong faction on PvP realms.

- Fixed not being able to enchant Cuffs of Evocation.

- Temporarily reverted the fix for Heavy and Solid Gritted Paper cloth requirement, allowing them to be crafted again. This issue will be fixed with the next client update.
