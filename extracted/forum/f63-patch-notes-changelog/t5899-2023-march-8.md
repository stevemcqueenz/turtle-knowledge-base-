# 2023 — March 8

## Post 37124 by Jamey (Turtle WoW Team) [STAFF] — 2023-03-08T00:24:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=37124#p37124 | page 1 | era: pre-1.18.1 -->

- Various performance improvements throughout the core.

- Revamped all Runed Pedestal to be more Blizzlike.

- Revamped a lot of quests in Tel'Abim to give proper money rewards upon completing them at level 60.

- Fixed quest The Harvest Golem Mystery.

- Fixed an exploit that allowed stacking weapon stats through disarm effects.

- World buffs are now correctly removed from pets as well in end-game instances.

- Fixed the Eranikus Moonglade quest event.

- Assigned missing sell price to beach event items.

- Fixed an issue where The Unsent Letter was lootable by both factions.

- Updated the script event list for NPCs Silithid Creeper and Swarmer to be more Blizzlike.

- Fixed multiple NPCs targeting dead players for some spell casts.

- The Rat Trap in Stormwind Vaults is no longer avoidable once triggered.

- Some big mounts have been disabled in capital cities.

- Fixed an exploit that allowed players to stack ranged attack speed through quivers.

- Corrected Zone description for some Sparkwater quests.

- Corrected the displays for some Theramore Sentry NPCs.

- Corrected Zone description for quest Stealing a Core.

- Corrected grammar in various quests.

- Added missing armor values to Withered Quilguards.

- Fixed an invalid faction for NPC Joseph Dalton.

- Restored target dummy loot as was previously removed erroneously.

- Hillsbrad Human Skulls now stack up to 30 per bag slot.

- Removed Pet Avoidance from some players who got it erroneously.

- Gave a lot of custom quests proper max level money rewards.

- Set all Idol drop chances from 0.4% to 1.0%.

- Modified Pet AI to be more natural when attacking multiple NPCs.
