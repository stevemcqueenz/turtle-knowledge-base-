# 2023 — January 11

## Post 32417 by Torta (Turtle WoW Team) [STAFF] — 2023-01-10T22:31:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=32417#p32417 | page 1 | era: pre-1.18.1 -->

- Grammar fixes for ~20 quests and NPC texts.

- Increased Shellcoin promoter yell cooldown.

- Various fixes for missing XP reward for new quests.

- Turned Venture Camp's escape route into actual flight path.

- Fixed some inconsistencies with the CLUCK quest.

- Removed wrongly-assigned reward from Gorras Thorncrusher quest.

- Added a loot-table for Disturbed Earth Elemental.

- Disabled HC gravestones for players below level 10.

- Assigned spells and loot from Greater Fleshripper to Plateau Fleshripper.

- Fixed script for Carver Molsen.

- Added new script for Bloodscalp Witch Doctor.

- Fixed Scarlet Cleric casting Mind Blast on himself.

- Leech effects will not trigger threat for healing part.

- Disabled Call for Help for Rajaxx wave mobs (double-spawn issue).

- Lowered respawn time of Sceptic Peon.
PvP-related:

- Removed duplicate Stormpike Mine Layer in AV.
