# 2025 — February 05

## Post 118948 by Reynolds (Turtle WoW Team) [STAFF] — 2025-02-04T21:15:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=118948#p118948 | page 1 | era: pre-1.18.1 -->

![Changelog_2025-02-05.jpg](./download/file.php?id=117) <dd>Changelog_2025-02-05.jpg (518.76 KiB) Viewed 20446 times</dd>

- The quest to slay **Omen** is no longer auto completed on pickup.

- Fixed an issue where **Insignia** briefly made the user immune to spells and effects.

- Lower Karazhan Halls: **Skitterweb Eggs** are now immune to all crowd control effects.

- Fixed an issue where **Engineering Target Dummies** appeared hostile to their owner.

- The spell **Turn Undead** is now considered a Holy spell rather than Nature.

- **Elune's Blessing** quest should now be completed when **Omen** dies.

- The quest **Reverence To The Ancestors** for the Lunar Festival event is now classified as a RAID quest.

- Fixed an issue where the power type for distant group members was displayed incorrectly.

- Ranged attack power now contributes to Priests' bow attacks as expected. (<https://turtlecraft.gg/bug-report?id=11484>)

- Fixed an issue where Warlock minions would be resummoned if the Warlock died while under the effect of **Eye of Kilrogg**. (<https://turtlecraft.gg/bug-report?id=11387>)

- **Immolation Trap** will now correctly work with the **Stinging Nettle** talent once again.

- You can no longer set your guild house location at **Volatala Zilmbu**.

- Fixed not being able to enchant **Red Defias Mask**.

- Fixed **Solnius** adds not always staying in combat with players.

- Fixed not being able to interrupt **Encasing Webs**.

- **Scarlet Spellbinders** should no longer fall below the tower.

- Ranged shots should no longer be affected by spell pushback.
