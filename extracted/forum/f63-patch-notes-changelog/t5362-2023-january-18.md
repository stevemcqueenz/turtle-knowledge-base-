## Post 32681 by Torta (Turtle WoW Team) [STAFF] — 2023-01-17T20:07:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=32681#p32681 | page 1 | era: pre-1.18.1 -->

- Grammar fixes for ~20 quests and NPC texts.

- Various fixes for missing XP reward for new quests.

- Fixed Shoot cast delay for Shadowforge Wyrm Hunter.

- Fixed Undead class quests restrictions.

- Removed call for help from boars in area with bugged mmaps.

- Fixed Yesu'gei not being interactable.

- Assignd emote states to new Shadowforge Excavators.

- More quality fixes for Catographer exploration.

- Assigned graveyard to Scarlet Enclave.

- Removed hunter spells from non-hunters with bugged quest.

- Fixed startzone creature fire ressistance.

- Fixed DisplayID for Voryn Skywalker.

- Fixed spawntime on startzone mobs.

- Fall damage will tick from a coordinate where Slowfall stops.

- Re-enabled Alliance SC attunement quest chain.

- Removed The Black Morass from cartographer requirement.

- Fixed quest The Sleeper Has Awakened.

- Allowing clearcasting on Savage Bite.

- Fixed Sorcerer Ashcrombe & Deathstalker Adamant attacking players.

- Restored missing graveayrds for Naxxramas and AQ40.

- Removed The Scarlet Basilica from Cartographer requirement.

- Removed race restrictions from Razor-sharp Blade quest.

- Fixed issues The Harvest Golem Mystery chain.

- Arcane Missiles will not be interrupted by somebody casting different rank.

- Added missing spawns for Ashmane Boars and Hellboars.

- Corrected gameobject interaction distances.

- Preventing casting on dead unit target if spell does not allow it.

- Fixed Brilliance Aura exploit: [https://github.com/slowtorta/turtlewow- ... ssues/2706](https://github.com/slowtorta/turtlewow-bug-tracker/issues/2706)
