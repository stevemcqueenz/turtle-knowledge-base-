# 2026 — April 22

## Post 176101 by Torta (Turtle WoW Team) [STAFF] — 2026-04-21T20:52:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=176101#p176101 | page 1 | era: post-1.18.1 -->

![Image](https://turtlecraft.gg/images/changelog/Changelog-2026-04-22-ENG.jpg)

- **Raid Scaling** is now active on all raids.

- All 20-player raids now have a minimum scaling threshold of 8 players (down from 12).

- All 40-player raids now have a minimum scaling threshold of 16 players (down from 20).

- Summoned **World Bosses** will no longer have proximity aggro enabled.

- Fixed an issue where **Sand Breath** was not removed by **Blessing of Freedom**.

- **Emerald Dream Welcome** now grants immunity to the **Intruder of the Dream** debuff during the **Kronn** encounter.

- Fixed an issue causing **Small Pearl Ring** to not appear in the profession window (requires client update).

- Fixed an issue where some recipes were not consumed upon learning.

- Increased the armor of **Timbermaw Defenders**.

- Fixed an issue preventing Hardcore players from using **Demonic Sacrifice**.

- **Corrupted Hide of Ursol** will now drop for only one player.

- **Uldaman** is no longer required for the **Cartographer** title.

- **Ancient Power Module** will now drop from **Uldaman** as intended.
