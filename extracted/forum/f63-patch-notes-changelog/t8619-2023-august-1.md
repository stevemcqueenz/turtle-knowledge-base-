# 2023 — August 1

## Post 55525 by Akalix (Turtle WoW Team) [STAFF] — 2023-08-02T00:20:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=55525#p55525 | page 1 | era: pre-1.18.1 -->

- Fixed issues with disappearing transports.

- Disabled dynamic respawns for some creatures that are mostly found in caves.

- Fixed Enchant Gloves - Minor Haste not giving spell haste.

- Fixed equip effect of Bloody Gladiator's Circlet.

- Added Champion's Grace to priest trainers.

- You will no longer see hardcore messages about players below level 40, unless you opt in using the .hcmessages command.

- Fixed Dra'lox Felstar not using threat list.

- Various fixes to the towers PvP event in Eastern Plaguelands.

- Lady Katrana Prestor will now respawn when Highlord Bolvar Fordragon leaves combat.

- Added protection for Hardcore players when the server is overloaded.

- More core stability and performance improvements.

- Fixed an issue with Baxxil not despawning.

- Changed names of Power Mushrooms to not have duplicate naming.

- Fixed an issue with Bloody Gladiator's Circlet not proccing.
