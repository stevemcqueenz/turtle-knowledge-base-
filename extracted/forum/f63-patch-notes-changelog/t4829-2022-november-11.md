# 2022 — November 11

## Post 28982 by Torta (Turtle WoW Team) [STAFF] — 2022-11-11T16:30:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=28982#p28982 | page 1 | era: pre-1.18.1 -->

- Turtle mount swimming speed is no longer affected by riding skills. It's half of the mount speed by level.

- It's no longer possible to remain in the cart while teleported to the Battleground from the Mirage Raceway.

- Fixed a bug so that Charge gets you in combat right away.

- Server info now shows server time without any continent bias.

- Dorius Stonetender should not drop his letter before he dies.

- Added missing skinning loot to the following creatures: Deathmaw NPC, Lurking Feral Scar, Deatheye.

- Joe Fishface will now teach you Fishing.

- Heart Candies from the Raceway reward box are edible now.
PvP-related:

- Removed buy and sell price from Armor Scraps.
