# 2023 — March 15

## Post 37776 by Torta (Turtle WoW Team) [STAFF] — 2023-03-14T22:26:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=37776#p37776 | page 1 | era: pre-1.18.1 -->

- Lowered respawn time of almost all high-competition quest objectives in level 1-20 zones.

- Working on a general server performance :)

- Added script to Bubble Fissures.

- Fixed an issue with quest objects not re-stocking on quest items.

- Removed announcement about HC death from level 10 bracket.

- Added loot tables to Earthen Curators, Earthen Rockshapers, and Orthal the Steward.

- Various grammar fixes.

- Added Darnassus reputation reward for Silmaron's quests.

- New script for The Stones That Bind Us quest.

- Prevented goblin radio from aggroing guards.

- Removed Copper, Tin, and Silver Veins from Desolace.

- Attempted to fix not being rezzed issue in AV.

- Earthen Arise: preventing to summon of more than one Goggeroc, also check if the player has a quest before summoning.
