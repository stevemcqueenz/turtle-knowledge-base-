# 2026 — February 18

## Post 168652 by Torta (Turtle WoW Team) [STAFF] — 2026-02-17T21:01:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=168652#p168652 | page 1 | era: 1.18.1-announced-pre-release -->

![Image](https://turtlecraft.gg/images/changelog/IMG_20260217_144142_397.jpg)

- **Crystal Charge** now works on stun‑immune targets.

- Several spell‑damage‑increasing auras now properly stack with each other.

- **Cleaning Job** quest now only requires a Neutral standing with the **Syndicate** faction to be accepted.

- **Nat Pagle, Murloc Expert** quest now correctly starts at **Agnar Beasttamer** again.

- Drop chance of **Gorishi Sting** for the quest **Bloodpetal Poison** has been increased.

- **Dusksteel Throwing Blade** has been moved to vendor **John Smith** in **Ravenholdt Manor** and is no longer disenchantable.

- Fixed an issue causing **Alchemy** concoctions to not stack correctly.

- Added new abilities to the **Nordanaar Guardian** to prevent griefing.

- Fixed an issue causing **Efflorescence** to heal excessive amounts when used in quick succession.

- **Healing Touch**, **Lesser Healing Wave** & **Lesser Heal (Rank 1)** now generate less threat when you have the **Lunatic Challenge** active.

- Players who assist others through healing or buffing will now leave combat faster after no threats remain in dungeons and raids.

- Fixed an issue causing fishing in **Icepoint Rock** to occasionally yield no fish.

- **Shadow of Death** should no longer fail to proc occasionally.
