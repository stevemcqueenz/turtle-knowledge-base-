## Post 37283 by Torta (Turtle WoW Team) [STAFF] — 2023-03-10T08:22:00Z

- Reduced respawn timer for various popular quest objects.

- Changed model for Otherwordly Robe.

- Various grammar edits from QA and players.

- Allowed party loot for Azure Agate.

- Yet another fix for The Sleeper Has Awakened quest.

- Restored Uldum Pedestal in Tanaris.

- Changed On Use spell on Dark Iron Desecrator item.

- Holy Protection potions will now stack to 10 in a batch.

- New script for The Tome of Valor quest.

- Fixed a few possible crashes.

- New script for Breaking The Felstar quest.

- Removed skinning ability for some NPCs that shouldn't have it.

- Fixed random movement type wandering for bears and cubs in Tirisfal Uplands.

- Fixed interrupt flags for Consume Shadows.

- Fixed Sunnyglade graveyards.
