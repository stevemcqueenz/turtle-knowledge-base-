# 2024 — August 28

## Post 100299 by Torta (Turtle WoW Team) [STAFF] — 2024-08-27T16:27:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=100299#p100299 | page 1 | era: pre-1.18.1 -->

![Image](https://turtlecraft.gg/images/changelog/changelog_280824.jpeg)

- Corrected the quest chain order leading to the Changing Paths quest.

- Totemic Recall will now correctly refund the mana cost of every totem. Additionally, the refunded amount will be displayed in the combat log.

- Fixed a crash in the Deadmines instance script.

- Lucidity Potion no longer dispels effects that are already active, ensuring it now works like the Free Action Potion.

- Fixed an issue where players were not receiving credit for the quest "Bolstering Our Defense" when capturing towers.

- Limited Invulnerability Potion no longer removes negative physical auras, such as Death Wish, when used.

- It is no longer possible to unequip weapons while disarmed.

- Fixed an issue where Baron Geddon would sometimes continue to follow his waypoints after entering combat, instead of engaging the players.

- Fixed the issue where the Scarlet Monastery Cathedral instance state was not being saved properly, causing the bosses to respawn.

- Fixed an exploit with Tree of Life.

- Corrected the flavor text for Skull of Grarr and Evershifting Stone.

- Added a new command .skip2faip to require a 2FA PIN even when connecting from the same IP as last time.

- Fixed various performance and memory issues.
 *The current changelog includes entries from previous weeks while our forums were down.*
