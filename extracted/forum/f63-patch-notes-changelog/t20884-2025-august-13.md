# 2025 — August 13

## Post 145131 by Torta (Turtle WoW Team) [STAFF] — 2025-08-13T16:46:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=145131#p145131 | page 1 | era: pre-1.18.1 -->

![Image](https://turtlecraft.gg/images/changelog/Changelog%202025-08-13_ENG.jpg)

 *The changes listed in this changelog will be applied during the maintenance window on August 15.*

- **Mother Smolderweb** will now summon spiderlings on death instead of during combat.

- **Trashtalon** is now sheathed correctly.

- Fixed flight paths for **Pridewing Wyverns** in **Stonetalon Mountains**.

- Added missing **Noble's Pendant** drop to **Gilneas City**.

- Fixed a regression where guild rosters did not respond to guild events as expected.

- Removed the level requirement from **Chronoboon Displacer**.

- **Darnassus Sentinel Glaive** and **Sentinel's Glaive** can now only be equipped in the main hand.

- **Elder Growlheart** now properly drops loot.

- Added **Voltage-Neutralizing Nature Reflector** and **Giga-Charged Arcane Reflector** recipes.

- Removed the temporary workaround preventing **Scarlet Spellbinders** from following pathfinding.

- Fixed an issue where **Malfunctioning Servitor** dropped higher-level trash loot than intended.

- Fixed **Chain Lightning** sound effects.

- Removed on-kill XP from **Onyxia Whelps**.

- **Tower of Karazhan**:
 - Slightly increased the health of summoned creatures in the **Sanv Tas'dal** fight.

 - Modified the damage and frequency of certain **Rupturan** spells.

 - Added a new mechanic that rewards keeping **Felheart** intact during the **Rupturan** fight.

 - Fixed exploits on **Kruul**.

- Several dungeons now award reputation for their associated factions when slaying various enemies within. Dungeons already awarding reputation have had their reputation gains slightly increased:
 - **Dire Maul** → **Shen'dralar**

 - **Scholomance** and **Stratholme** → **Argent Dawn**

 - **Caverns of Time: Black Morass** → **Wardens of Time**

 - **Blackrock Depths** → **Thorium Brotherhood**

- The master loot list is now sorted by class instead of group number.

- Added visual feedback for **Hunter Volley**.

- Reduced the cooldown of **Eternal Dreamstone Shard** to 3 days.

- Updated the description of the **Feral Combat** Tier 2.5 set 5-piece bonus to accurately reflect its effect.

- Updated and added several game tips.

- **Shadeflayer Trolls, Trappers, Shamans, Shadowhunters, Goliaths and Berserkers** no longer drop **Misthoof Hide** and can now be pickpocketed.

- Added loot to **Warlord Hanzento** and significantly reduced his health and armor.

- **Groundskeeper Jacoby** and **Captain Rothynn** now drop loot.

- Fixed an issue with **Groundskeeper Jacoby** and **Captain Rothynn** leashing earlier than normal.

- **Mana Stalkers** can now be skinned.

- **Into the Dream III** is now properly classified as a Dungeon quest.

- **Into the Dream VI** is now properly classified as an Group quest.

- **The Runestone Scepter** is now properly classified as an Group quest.

- **Enthelar Valebranch** now has loot.

- **Hyjalroot** is now classified as a Herb, meaning it can be tracked by Herbalists.

- **Shadeflayer Tribal Bracelet** are now Bind on Pickup similiarly to other Hyjal quest items.

- **Saving the Shadowtooth** quest now only requires level 55 instead of level 60 to put it more in line with other Hyjal quests and now has a new item reward.

- Increased the drop chance of the rods needed for the quest **The Clutch of Atherelex** from 11% to 35%.

- **Wormscale Stompers:** Merged Spell and Physical Hit effects.

- **Gardening Planters** can now be placed anywhere in the wilds, and it's no longer possible to loot someone else's crops.
