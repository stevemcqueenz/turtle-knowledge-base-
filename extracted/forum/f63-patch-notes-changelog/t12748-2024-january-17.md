# 2024 — January 17

## Post 84934 by Torta (Turtle WoW Team) [STAFF] — 2024-01-16T21:04:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=84934#p84934 | page 1 | era: pre-1.18.1 -->

![Image](https://turtlecraft.gg/images/changelog/changelog_jan17.png)

- Karazhan bosses can no longer be kited and will leash if brought too far away.

- Nerfed the spell power scaling of Barnacle Targe.

- Added waypoints to Greater Firebird and Murderous Blisterpaw.

- Removed Mazra'alor from cartographer requirement.

- Idol of the Emerald Rot will no longer reset combo points when equipped.

- Added missing spawns for the quest "In Search of the Owner."

- Fixed an <error> message randomly appearing in the chat.

- Fixed Brainwashing Machine lasting only 2 minutes instead of 5.

- Added fishing loot tables to Blackstone Island.

- Fixed a typo in the "Under the Sea" quest.

- Added fishing loot tables to Thalassian Highlands.

- Added skinning loot to Bramblethorn Boar.

- The quest "In Eranikus' Own Words" is now accessible for Goblins.

- Corrected Marlos Catos' /yell text.

- Mudsprocket Spirit Healer location will now properly operate as a graveyard for Horde players.

- Added a missing campfire to one of the murloc camps in Dustwallow Marsh.

- Fixed Rod of Resuscitation being upside-down when equipped.

- Fixed several minor bugs with Felwood Corrupted Plants, including incorrect quest IDs and a missing node along the north road of Felwood.

- Reworked the Mirage Raceway script to allow doing the Test race solo.

- The item Minion's Scourgestone has been added to NPCs: Overzealous Student, Bonereaver Sentinel, Failed Student Experiment.

- Changed broken sheathing for Ley-Technician Staff.

- Attempted a fix on the PPM for the following weapons: Flurry Axe, Bashguuder, Dark Edge of Insanity, Sulfuras, Hand of Ragnaros.

- Satyr Claw is now properly hidden when sheathed.

- Bruiser's Chainmail now properly has armor.

- Signet of Themar is now properly a ring instead of a robe.

- Rustgate's Water Shipment and Temporal Anomaly's icons have been fixed.

- Rakklan's Targe is now properly a shield.

- Formal Purple Waistcoat's first word is now uppercase, like other fashionwear found in the vendor.

- Chromatic Gauntlets now properly have a 1% physical hit chance instead of a 1% spell critical chance as listed in the 1.17.0 changelog.

- Razor-Sharp Knife now requires level 30 to use, as the quest it provides also requires level 30 to accept. It is also no longer race-locked on the item.

- Wildfeather Bracers now properly make leather noises when the item is moved inside the inventory.

- All the snapjaw eggs that rarely drop from turtles are now unique.

- Drape of Nordrassil can now be enchanted.

- Fixed grammar in Femur Staff's description.

- Ebonmere Bracers now properly have an icon and a model.

- Spicy Beef Burrito no longer puts food into a minute-long cooldown.

- Fiery Chain Girdle and Shoulders no longer require Armorsmithing as listed in the 1.17.0 changelog.

- Temple of Ahn'Qiraj's Gloves of the Redeemed Prophecy and Gloves of the Fallen Prophet no longer have a class restriction as they're part of a set with two other unrestricted items.

- Waters of Vision now puts the user on a 30-second cooldown on equip, like other On-Use items.

- Scythe of the Harvest and Halberd of Smiting should now face their blades upwards when sheathed.

- Manual: Intervene is now properly consumed on use.

- Fixed the range to summon Lord Valthalak being too short, requiring you to stand on the exact spot.

- Removed duplicate intellect from Mantle of the Fallen Prophet.

- Updated ZG entrance message to reflect the new level requirement.

- Increased Ogre Warbeads drop chance inside Dire Maul to 25%.

- Idol of Evergrowth will now work on other players too.

- Added daily quests to kill the players with the most HKs and DKs during the past day.

- There is now a stacking debuff inside AV for players that have not entered combat for longer than 5 minutes. If you get 3 stacks, you will be removed from the battleground.
