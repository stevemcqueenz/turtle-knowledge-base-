# 2023 — April 3

## Post 40087 by Torta (Turtle WoW Team) [STAFF] — 2023-04-03T09:21:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=40087#p40087 | page 1 | era: pre-1.18.1 -->

- Changed respawn delay of Chief Murgut.

- Fixed gaps in waypoints for Twilight Prophet.

- Reduced resistances of AQ mobs.

- Changed entry of Lordaeron Soldier.

- Increased nightmare dragons despawn delay.

- Fixed issues with Skeletal Remains of Kariel Winthalus.

- Fixed issues with reputation gains on kill displayed incorrectly.

- Added quest requirements to NPC Seril Scourgebane gossip option.

- Fixed requirements for the quest The Seeker's Demise.

- Made 383 new quests shareable.

- Deleted low lvl loot from NPC Surf Glider.

- Added missing reward for the quest Lofty Height.

- Set respawn timer of Carver Molson to 5 minutes.

- Various fixes for grammars, loot and NPCs from QA and bug tracker.

- Improvements for dynamic respawn system.

- Fixed combat timer for pets vs mobs.

- Corrected model ID for Diathorus' Claw.

- Assigned skinning loot to NPC Jade.

- Added armor values to NPC Sewer Beast.

- Fixed guardians not being flagged for pvp.

- Added Fashion Coins to drop from more dungeon bosses.

- Additionally, Fashion Coins are now available as a donation reward.

- Essence of Eranikus will drop with 100% chance now.
