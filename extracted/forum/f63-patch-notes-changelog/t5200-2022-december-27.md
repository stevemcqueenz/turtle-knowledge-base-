# 2022 — December 27

## Post 31601 by Torta (Turtle WoW Team) [STAFF] — 2022-12-26T19:21:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=31601#p31601 | page 1 | era: pre-1.18.1 -->

- Temporary restored Revantusk/Silvermoon reputation rewards. Please be aware that rewards in their current state will be gone some time during the January once we have new rewards ready.

- Fixed King Morogo Thunderfoot! wrong quest zone.

- Fixed reputation gain for Gusting Vortex's quest.

- Fixed Brackenwall Longbow.

- Lowered Carus' Gift respawn timer.

- Misc. grammar fixes.

- Changed some of new quest objectives to require less mob kills.

- Rewamped Triage quest script.

- Earthbind and Magma Totems will not set you in combat if there're no enemies around.

- Fixed Young and Foolish quest menu bug.

- Earthbind Totem should will not remove Stealth.

- Changed Thorns spell for Horn of Engryss item.

- Fixed Mandokir not being able to attack.

- Fixed Arc'Tiras adds aggro'ing.

- Fully disabled LFT for Hardcore players.

- Fixed Temukar's attackability.

- Removed corrupted reward for Earth Rumble quest.

- Fixed Silvermane Pelt drop from SIlvermane wolves.

- Changed respawn timer of Oilmaster Higgle Wirefuse to 5 mins.

- Snowball respawn timer is set to 14-20 hours now.

- Fixed new brace enchants: Enchant Bracer - Greater Agility, Enchant Bracer - Spell Power.

- Quest Back on Track should be started by Gizzin Wildbucket.

- Far Sight/Mind Vision will not reset after multiple casts.

- Adjusted Naxxramas Shaman/Paladin loot-tables to work better in cross-faction raids.

- Fixed Azotha summon on Ancient Dirt Mound quest.

- Set Zul'jin respawn time to be same as Thrall.

- Fixed Dark Ranger skin token (use on it again to get the right look)
PvP-related:

- It's no longer possible to kite Korrak to friendly NPCs.
