# 2023 — June 7

## Post 49087 by Torta (Turtle WoW Team) [STAFF] — 2023-06-06T18:45:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=49087#p49087 | page 1 | era: pre-1.18.1 -->

- Added missing spells to the warrior trainer, Ilsa Corbin.

- Limited Invulnerability Potion will no longer disable the Improved Starfire talent.

- Removed incorrect spawns of Half-Buried Bottles.

- Added a limit to the number of letters you can send per hour.

- Changed the quality of Ring of Darlthos and Signet of Darlthos to Uncommon.

- Fixed some Ghost Mushrooms respawning too quickly in Gilijim's Isle.

- Warlock's Demonic Sacrifice auras are now removed upon talent specialization.

- Removed EXP and money rewards from Race Against Time.

- Fixed Salve quests given by Maybess Riverbreeze and Arathandris Silversky.

- Spirit Armor calculations now use floating point numbers instead of whole integers, and the bonus will be rounded up instead of down.

- Reduced the chance for Judgement of the Crusader to activate Slow effects.

- Fixed the Scarlet Diversions quest.

- Fixed too-short respawn timers for some Small Thorium Vein and Truesilver Deposit nodes.

- Removed ownership from the /join welt channel.

- Removed the race requirement from the Wasteland quest.

- Removed the invisible campfire from Forest Song Inn.

- Mug O'Hurt's slow proc has been changed to properly interact with slow removing effects.

- Fixed wrong disenchant loot from many custom high level blues.

- Fixed all Tallstrider mounts to behave like normal mounts.

- Removed faction requirements from raid loot that only caused issues.

- Added new scripted sequence for Melris Malagan to reflect the current reality in the shellcoin investment world.

- New item: Skin Change Token - Demon Hunter (for Night Elves, male & female).

- New item: Skin Change Token - Necromancer (for Night Elves, male only).

- New item: Skin Change Token - Demon Form (for Night Elves, male only).
