# 2025 — January 7

## Post 115795 by Jamey (Turtle WoW Team) [STAFF] — 2025-01-07T22:32:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=115795#p115795 | page 1 | era: pre-1.18.1 -->

![Changelog_2025-01-07_2.jpg](./download/file.php?id=109) <dd>Changelog_2025-01-07_2.jpg (344.68 KiB) Viewed 23065 times</dd>

- **Greater Blessing of Light** will now correctly increase healing of **Holy Shock**.

- Fixed **Onyxia** dropping too much loot.

- It is now possible to use externally acquired bags and fishing poles while participating in the **Artisan's Challenge**.

- **Flight Masters** will now grow stronger each time they die and respawn to discourage extended farming/camping.

- Fixed **Slam Rank 1**'s training cost.

- **Totem of Static Charge** no longer scales with spell bonus damage.

- The Hunter T2.5 3-piece set bonus will now trigger on periodic damage from **Serpent Sting**.

- Fixed an issue where the **Arcane Infused Gem** was not functioning as expected.

- Corrected the bonus healing amount provided by **(Greater) Blessing of Light**.

- Corrected the bonus healing provided by **Daybreak**.

- Fixed an issue where **Holy Radiance** was unable to trigger **Vengeance**.

- Fixed an issue where **Kidney Shot** was unable to trigger **Tricks of the Trade**.

- Fixed an issue where **Fire Rune** caused **Elemental Focus** to stop functioning correctly.

- Fixed getting stuck in root if you enter indoors right as you are afflicted by **Entangling Roots**.

- Finishing moves that don’t affect the target no longer cause mobs to aggro if you have the **Ruthlessness** talent.

- **Elemental Sharpening Stones** now work while shapeshifted.

- Fixed **Korgan** becoming unselectable in certain situations.

- Wrapped gifts can no longer be placed into the guild bank.

- Fixed effects that reduce mana cost with charges being consumed incorrectly.

- Increased the level requirement of the quest **Sharks Are Friends, Not Food**.

- **Corrupt Dream Shards** now stack up to 8.

- Fixed an issue where the effect of **Righteous Defense** could stack.

- Greatly reduced **Winter Grell Trickster** and **Winter Grell Schemer** respawn timers.

- A number of items, such as the **Zandalarian Hero Charm** and **Talisman of Ephemeral Power**, have their shared cooldown restored.

- Removed vendor prices and level requirements from some shop items in the Fashion category.

- **The Greatest Wizzard Hat** is now bound on pickup but no longer has a level requirement.

- Added **City Guard** transmogs to the Fasion category of the donation shop.

- Items and auras providing reduced critical strike damage will now work as intended for melee auto-attacks as well.
