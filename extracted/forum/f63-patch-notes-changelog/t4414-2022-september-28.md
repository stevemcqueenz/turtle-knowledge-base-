# 2022 — September 28

## Post 26292 by Torta (Turtle WoW Team) [STAFF] — 2022-09-27T23:00:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=26292#p26292 | page 1 | era: pre-1.18.1 -->

Please read the changelog for the upcoming server update and the maintenance:

- Fixed Mana Sprite and Ley Sprite using wrong spell instead of Detonate on death.

- Pets are no longer allowed on transports to avoid possible issues.

- Enemy civilians will no longer summon guards when a hardcore player approaches them.

- The proc rate of Omen of Clarity has been increased as it was lower than intended in practice.

- Whip of Encouragement will increase casting speed as well.

- Dream's Herald has durability now.

- Added variety to Booty Bay fishing schools and equalized respawn times for all spots.

- Fixed a typo in the description of quest Finding Akh Z'ador.

- Agitating Poison can finally be applied on weapons, but it will still not work correctly until the next client patch.

- Removed a wrong spell used by Entropic Horror.

- The Stormwind Vault Rat Trap should no longer get stuck if a player enters and leaves too fast.

- Fixed some position desync issues with creatures.

- The daze effect from Aspect of the Cheetah will no longer trigger from periodic spells.

- Multiple database fixes for quests, items, and creatures from our bug tracker.
