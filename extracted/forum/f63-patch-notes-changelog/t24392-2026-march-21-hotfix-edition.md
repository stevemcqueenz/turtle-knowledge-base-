# 2026 — March 21 [Hotfix Edition]

## Post 171608 by Torta (Turtle WoW Team) [STAFF] — 2026-03-21T11:04:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=171608#p171608 | page 1 | era: post-1.18.1 -->

![Image](https://turtlecraft.gg/images/changelog/Changelog-2026-03-21-ENG.jpg)

Below are hotfixes implemented during patch release day, or scheduled for implementation during the weekend.

- Removed debug chat output from various places. Bad habits die hard...

- Fixed Enhancement Tier 2.5 changes not being applied.

- Fixed an issue causing already completed quests to not reward reputation for the **Draenei Exiles** faction.

- Adjusted respawn timers for **Black Lotus** in **Moonwhisper Coast**.

- Adjusted respawn timers of **Blackwing Alchemists**.

- You can no longer gain rested XP while dead.

- **Lothos Riftwalker** will correctly give access to the **Attunement to the Core** quest.

- You can mount in the **Temple of Ahn'Qiraj** raid dungeon again.

- Fixed an issue where **Idol of Equilibrium** was missing from one of **Broodcommander Axelus**'s loot tables.

- **Crusader** and **Holy Strike** now properly grant their benefits even if the attack is missed.

- **Holy Strike** no longer heals more targets than intended.

- Fixed the server clock to reflect real time.

- **Void Zones** should no longer chase players.

- **Fang of Alichos** is now usable in shapeshift forms.

- **Flurry** will now properly be consumed when attacking.

- Fixed **Pearl of Kaneq'nuum** icon.

- Fixed **Dragon's Touch** haste spell to be On Equip.

- **Apprentice Survival** is now correctly available at level 1 again.

- Fixed an issue where **Blackwing Alchemists** respawned shortly after dying.

- Added 224 Feral Attack Power to **Yoxtez**.

- Removed wrongly assigned **Find Fish** from players that haven't completed the quest.

- **Blackwing Riflemen** will now spawn at a random balcony.

- Fixed Druid flight masters in **Moonglade**.

- **Grobbulus**' Poison Cloud no longer damages far‑away players.

- Adjusted the respawn time of **Tablet of Kaz'gan** for the quest **A Grave Misunderstanding!**

- **The Fallen Ones** are attacking **Moro'gai Village** not as aggressively anymore.

- Added missing Honor gains at the end of the **Thorn Gorge** battleground.

- Fixed the orientation of the Horde gate in the **Thorn Gorge** battleground.

- Fixed a teleporting issue when touching the Alliance gate in **Thorn Gorge**.

- Both **Spirit Guides** on **Thorn Gorge** will no longer spawn when the capture point was controlled.

- Improved the **.cartographer** command to also include zone name.

- Fixed the Tauren priest quest **Garments of the Three Siblings**.

- **Blackroot Brew** now correctly doesn't stack with **Juju Might**.

- **The Coil of the Hydra Set** and **Bulwark of Unshaken Earth** are now correctly **Bind on Equip**.

- **Archaeologist's Lantern** is now correctly categorized as an off-hand frill.

- Corrected the categorization of several cloaks to make them enchantable.

- Renamed **Plump Country Pumpkin** to **Hearty Country Pumpkin** to avoid confusion.

- Fixed an issue where players could not turn in the quest **Dirge's Kickin' Chimaerok Chops**.

- Fixed an issue where players were unable to dismount from the gryphon taxi at **Talrendis Point** in **Azshara**.

- Added a level requirement to the **Scaleshield of Obsidian Flight**.

- **Pollen Burst** healing now scales with 25% of the **Pet's** attack power.

- **Moro'gai Defenders** now properly attack players engaging in PvP.

- **Relic of Elunaris** can no longer be looted from **Nendis Memento**.

- Increased the drop chance of **Foulheart Horn** for the quest **Horns of their Allies**.

- Corrected creature typing for **Moonwhisper Coast** satyrs.

Issues that require a client update (spells being misplaced in the wrong spellbook tabs etc.) will be fixed with the small patch delivered via the [Launcher](https://launcher.turtlecraft.gg/api/launcher/TurtleWoW.exe?download=bunny):

- Moved **Famoust Fashionista** companion back to the companion tab.

- Fixed several class & collection spells being listed under the General tab of the spell book.

- Players will once again be able to **Blink** in **Onyxia's Lair**.

- Fixed the **Moonwhisper Coast** world map highlight.

- Updated talent inspect data.

- Added missing icon for **Ice Pearl of Kaneq'nuun**.

- Fixed an area where players could get stuck in **Thorn Gorge**.

- Fixed the **Timbermaw Hold** entrance map not showing up correctly.

- Reduced the range of skill levels gained by crafting **Dim Torch**.

- Updated minimaps around the **Timbermaw Hold** entrance and **Ironforge** entrance.

- Fixed multiple issues with the **Blackwing Lair** raid model: fixed a possible crash spot in **Nefarian's** room, fixed missing collision on barriers (now properly blocking players from falling down from **Nefarian's** balcony), fixed alpha on banners, and fixed some lighting errors.

- Fixed map icons for the **Thorn Gorge** battleground.

- Fixed the use animation for picking up the flag in **Thorn Gorge**.

- Added map icons for the **Tarren Mill** vs **Southshore** world PvP event.

..to be continued.
