# 2023 — March 1

## Post 36539 by Torta (Turtle WoW Team) [STAFF] — 2023-03-01T19:46:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=36539#p36539 | page 1 | era: pre-1.18.1 -->

- Talent-based auras will be removed by using Brainwashing Machine.

- Fixed auto-completion of Harvest Golem quest.

- Assigned level 60 money rewards for Tel'Abim quests.

- Added blizzlike script for Runed Pedestal.

- Yes another fix for Attack on the Tower.

- Removed loot ID from target dummies.

- Corrected combat reach and bounding radius for fox pets.

- It's now possible to complete the quest chain: Magical Fortifications.

- Reduced respawn timer for Continuing Ceremonies quest objects.

- Fixed Jubjub not running to Morja when Dark Iron Ale is placed.

- Made Remnants Sentry aggressive.

- Made Grim Reach increase the range of Drain Soul.

- Fixes for The Tome of Valor quest.

- New script for The Sleeper Has Awakened.

- World Buffs will be removed from hunter's pets upon entering raids.
