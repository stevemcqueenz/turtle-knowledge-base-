# 2019 — Match 11

## Post 9734 by Torta (Turtle WoW Team) [STAFF] — 2021-03-11T19:53:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=9734#p9734 | page 1 | era: pre-1.18.1 -->

We will temporarily shutdown the server for an extended maintenance on Monday, March 15th (10:00 server time) to release a new client update 1.15.1. This patch will include the following fixes:

• Fixes for missing icons and textures for certain item models.
• Fixes for bugged maps.
• Fixes for missing flight paths and graveyards.
• Distant portraits for the new races.
• Background for the new races when previewing outfits.
• Fixes for visual spell problems.
• New camera for introduction cinematics.
• Fixes for CPU spikes caused by DiscordOverlay.dll.
• Added new music to Steamwheedle Port and Mudsprocket.
• Removed unused tabs from Goblins in the character creation screen.
• Character creation: new Forest Troll skins.
• Character creation: new Wildhammer Dwarf skins.
• Character creation: new Orc faces.
• Character creation: new Night Elf beards and eyebrows.
• Character creation: new Dwarf beards.
• Character creation: new Goblin faces & beards.
• Passive spells for Hardcore mode.
• Fixes for  a bug with Scarlet Crusade faction.
• Fixes for going At War with your own faction.
• Misc. graphic and sound assets for future content.

Earlier promised new Goblin animations won't be part of this update. We had to commission this work on a freelance and still waiting for an artist to complete this part, but we can no longer delay other fixes from doing live. Please, stay patient, broken models will be fixed, but good things take time. This is something what we can not do ourselves and have no other choice but to wait.

If you experience problems updating the game, please ensure that your antivirus or Windows Defender is not blocking the following files: TWPatcher.exe, DiscordOverlay.dll or WoW.exe. Open Window Security in your right bottom taskbar, go to Virus & Scan protection > Allowed Threats > Protected Threats and select the files and click the Restore option.

If you're a Mac user or having issues updating the game, you can download the patch manually. Apply it only on 1.15.0 client. Patch 1.15.0 › 1.15.1:  [https://www.mediafire.com/file/nt1mjeur ... h.zip/file](https://www.mediafire.com/file/nt1mjeur9715zn8/turtle_wow_1.15.0-1.15.1_patch.zip/file)
