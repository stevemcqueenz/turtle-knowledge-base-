# 2025 — August 15 [Build 2778]

## Post 145822 by Torta (Turtle WoW Team) [STAFF] — 2025-08-15T17:15:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=145822#p145822 | page 1 | era: pre-1.18.1 -->

![Image](https://turtlecraft.gg/images/changelog/Changelog_Hotfix_2025-08-17_ENG.png)

This thread will be updated over the next 24 hours with quick hotfixes for issues reported on the patch release day. The changes listed will be implemented during planned restarts performed within this timeframe.

- Fixed the faction of **Bristlewhisker Slave**.

- Fixed respawn times for certain trash mobs in **Dragonmaw Retreat**.

- **Stone Golem** no longer drops **Mutton Chop**.

- **Raised Skeleton** can no longer be distracted.

- Fixed **Pet Command: Take Position** not functioning.

- Fixed **Children's Week** quests being unavailable for players who completed them last year.

- Fixed an issue where **Vampiric Embrace** could not be cast while moving.

- Fixed **Warsong Gulch** and **Arathi Basin** graveyards.

- Removed the Riding requirement from **Admiral Grumbleshell**.

- Player dual specs will be reset on this restart to remove outdated talent templates.

- Fixed pathfinding in **Stormwind**.

- Fixed an issue where the druid fighting **Rethevus** could be assisted in certain cases.

- Fixed an issue where **Carnage** would refresh the bleed component of **Pounce**.

- Possibly fixed an issue with the **Sunstrider Court Arena**.

- **Voidstone** now persists after death.

- **Unleashed Potential** should now work with greater demons.

- **Pet Command: Take Position** should now work with greater demons.

- Elementals can now be damaged by **Dissolvent Poison**.

- **Lacerate** and **Serpent Sting** can now stack with each other.

- **Call to Arms** quests will now reset weekly and can be completed in a raid group.

- **Faerie Darters** will once again correctly cast **Faerie Dust**.

- **Skyfall Drape**: Reduced Stats from 15 to 14, and reduced Haste from 2% to 1%.

- **Cloak of Draconic Madness**: Fixed an issue that prevented the cloak from being enchanted and added 25 Armor.

- **Molten Emberstone** is now usable in **Feral Form**.

- **Stonelink Leggings**: Corrected item type.

- Fixed an issue where level 60 **Hardcore** players could not access the guild bank.

- Increased **Reverberation** talent values to 0.33, 0.66, and 1.00 respectively.

- **Magilou's Tarot Compendium**: Fixed an issue where the item could not be equipped.

- Fixed an issue where **Handbook of Noxious Assault IV** did not correctly teach the ability.

- **Scholomance**, **Stratholme**, and **Dire Maul** are now limited to a maximum of 5 players.

- **Gnaws**’ respawn time has been corrected.

- Fixed an issue where **Proclaim Champion** would not restore mana to the priest.

- **Warrior** **Flurry** charges are now consumed as expected.

- Fixed an issue where **Basalthar** and **Smoldaring** could get stuck in a half-dead state where they could still attack.

- Illusions will now be removed when using **Ride with the Wild**.

- **Corina Steele** has been returned to **Goldshire**.

- Corrected the level requirement of **Spellstone**.

- Added missing changes to **Gem of Nerubis** and **Master Dragonslayer's Orb**.

- **Demon Gate** cooldown will now be reset in arenas.

- **Baited Shot** is now affected by the **Mortal Shots** and **Efficiency** talents.

- **Ride with the Wild** will now be cancelled if you leave the group.

- Nerfed **Blackrock Invaders**.

- **Amberpaw Gnoll** will no longer cast **Rend** outside of melee range.

- The **Berserking** buff from battlegrounds will now be removed when leaving the battleground.

- **Chaddus Suncarrier** will now offer to teach you the **Riding** skill.

- Removed faction requirements from the quest “**Kezan Fruitcake Imports**.”

- Added a new visual effect for **Intervene**.

- **Sproutling** will no longer attack other players or creatures.

- **Daybreak** will now heal after you take damage, rather than just before.

- Fixed **Taste for Blood** talent not correctly scaling with combo points.

- Added missing block value to **Sulfuron Aegis**.

- The **Blackjack** debuff no longer causes any threat.

- Chests in **Stormwrought Ruins** should no longer respawn.

- Fixed an issue with **dungeon graveyards**.

- Fixed an issue with **Weekly Quests**.****
********Client Build 1.18.0 7228 [Hotfix]********

- ****Fixed an issue where the **LFT** Browse tab scroll range would not update properly.****

- ****Fixed battlefield queue minimap icon size.****

- ******Shadow of Death** has been moved to the **Subtlety** tab.****

- ****Fixed issues with flickering NPCs in the **High Elf** starting zone.****

- ****Corrected the skill range for **Dissolvent Poison** when crafting.****

- ****Fixed a rare crash occurring in **Amberwood Keep**.****

- ****Fixed an issue where **Northwind** had a blank space in front of the zone name.****

- ****Fixed an issue with **Arena Points** display.****

 1. Close the Launcher if you have it open.
 2. Open appdata: To do this, you'll need to press the 'Start' button on your keyboard or click into the Windows Icon on the bottom left of your screen.
 3. Type In: %AppData% and hit Enter on your keyboard.

 5. Open the launcher
 6. Go to configuration change download mirror and clear cache
 7. Go to your game files and delete the WDB folder
 8. Restar the launcher
 9. Try to update the game again
