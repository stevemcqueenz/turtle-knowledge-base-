# 2026 — April 8

## Post 174367 by Torta (Turtle WoW Team) [STAFF] — 2026-04-07T19:05:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=174367#p174367 | page 1 | era: post-1.18.1 -->

![Image](https://turtlecraft.gg/images/changelog/Changelog-2026-04-08-ENG.jpg)

- Restored **Basin of Moonwater**'s gossip, allowing players to obtain the **Shadowsong Orb** in **Moonglade** when conditions are met.

- **Thil'phoral, the Omen of Aln** now correctly triggers from periodic damage effects.

- Fixed an issue where **Tremor Totem** removed **Enslave Demon** effects.

- The quest **Lock Blueprints: Sorcerer-Thane Thaurissan** is now correctly classified as a raid quest.

- Fixed an issue causing **Cannon Master Willey** to not drop **Schematic: Enchanted Thorium Shells**.

- Fixed an awkward flight path transition between **Ratchet**, **Talrendis Point**, and **Shimmering Lake**.

- Added **Level One Lunatic** loot to the **Frostmane Hollow** dungeon.

- **Romantic Royal Gown** can now be repaired.

- Players can now engage members of the same faction in **Sunstrider Court**.

- **Corrupted Totems** will now despawn when the **Nefarian** encounter ends.

- Fixed a rare issue causing **Deathstalker Adamant** and **Sorcerer Ashcrombe** to not move if interacted with simultaneously.

- **Diplomacy** (racial) no longer incorrectly affects reputation loss.

- Fixed an issue with **Rift Tear** enchantments in the trade window.

- **Spiritual Elevation** can now stack with other buffs.

- Fixed an issue causing **Darlen Darkgrin** to not always drop loot.

- Fixed an issue preventing some items from being repaired.

- Buffs exceeding the limit will now become visible once space is available.
