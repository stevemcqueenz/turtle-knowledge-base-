# 2022 — September 11

## Post 24828 by Torta (Turtle WoW Team) [STAFF] — 2022-09-11T11:11:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=24828#p24828 | page 1 | era: pre-1.18.1 -->

Please read the changelog for the upcoming server update and the maintenance:

- Pet Avoidance has been implemented, but Warlocks will still be unable to learn it until patch 1.16.4.

- Fixed rank 2 of Stormstrike.

- Proclaim Champion can now only be used on 1 target.

- Corrected the waypoints of some rares.

- ZG bosses will hopefully not respawn prematurely.

- You can now use Health Funnel on enslaved demons.

- Fixed aggro range of world boss dragons being higher than intended.

- You will no longer get flagged for PvP for challenging people to a duel.

- Codex: Grace of the Sunwell can no longer be used to teach other players the spell.

- The dead Dwarf Mountaineers wlll no longer attack mobs.

- Reputation rewards are no longer reduced when completing the quest on a higher level.

- Reduced the minimum level for quest Torta's Egg.

- The triggered Judgement damage from the Freethinker's Armor set bonus will now scale with spell power.

- Increased the hitbox of Buru the Gorger.

- Dark Reaver of Karazhan will no longer flag players for PvP.

- Reflective Shields should no longer extend creature leash distance when it deals damage.

- Fixed Withered Touch debuff used by some mobs causing mobs to re-enter combat when it deals damage.

- Firemaw, Ebonroc and Flamegor should hopefully always drop the intended amount of items now.

- Fixed quest Glyph Chasing.

- Fixed quest Hive'Ashi Scout Report.

- Abyssal Scepter should now have a 100% drop chance.

- You will no longer get stuck in Blood Ring if the other side doesn't join.

- Shadowguard can now proc when spell damage is absorbed.

- Added some missing vanilla only creatures in Deadwind Pass.

- Vaelstrasz's body should hopefully no longer despawn prematurely.
