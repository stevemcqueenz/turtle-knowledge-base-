# Alternative Tier Sets

## Post 71030 by Dragunovi (Turtle WoW Team) [STAFF] — 2023-10-15T22:51:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=71030#p71030 | page 1 | era: pre-1.18.1 -->

**Greetings! Today we're happy to announce that alternative class armor sets are in the works and slated for release in **1.17.2: Tower of Karazhan**!**

These armor sets allow specializations that struggle with itemization to swap their tier pieces to versions that are tailored towards their preferred version, **complete with all new set bonuses**. If you plan on getting multiple Legacy sets with the intention of changing one of them into its alternative version, make sure to put the Legacy tier set items you want to keep using in your bank as to avoid losing enchantments.

 **Tier 1, 2 and Tier 3 (Rings Only)** gear pieces will be swappable to their alternative counterparts via new quests while you'll need to use the new quest reward swapper NPC introduced in 1.17.2 for Tier 2.5 and 3, meaning you can convert your existing sets using this NPC as the original quests for Tier 2.5 and Tier 3 are now a reward choice between the original set and the alternative set(s), Tier 3.5 won't be available to be swapped using this NPC, pick your set wisely!
In addition, Tier 1 and 2 will be **recolors** of their original sets to further differentiate them.

You can find the details below:
- Specializations listed with a / share the armor set.

- There will be different alternative Tier 2.5 sets for some classes due to existing versions already being tailored towards DPS.

- **Legacy Warlock** and **Hunter** sets have had their set bonuses updated to accomodate for Fire Destruction and Survival specializations and their abilities.
The following specializations will get new alternative tier sets:
- Mage: Arcane

- Priest: Shadow (Tier 1, 2 and 3), Holy (Tier 2.5 Only), Smite (Tier 2.5 Only, Original Tier 2.5 has been converted into the new Smite set while there is a new Holy set for Tier 2.5)

- Warrior: Arms/Fury (Tier 1, 2 and 3, the reason for there being none for Tier 2.5 and 3.5 is that they're hybridized to work for both threat generation oriented tanking and damage dealing.)

- Warlock: Affliction

- Druid: Feral Combat (Tier 1, 2.5 and 3.5 are Cat Form DPS focused while Tier 2 and 3 are Bear Form Tanking focused), Balance (Legacy Tier 2.5 is the new Balance set while there is a new Restoration set for Tier 2.5), Restoration (Tier 2.5 Only)

- Shaman: Enhancement (Tier 2.5 is specialized for tanking builds), Elemental (Legacy Tier 2 and 2.5 are the new Elemental sets while there are new Restoration sets for Tier 2 and 2.5.

- Paladin: Retribution, Protection, Holy (Tier 2.5 now has a new item set while Tier 1 and 2 have been re-itemized to work better for Holy Paladins as the specializations using them previously now have new alternative tier sets.)
Thanks for reading!

My understanding is that there has been work done on them around the time they were announced, even some of them created. But then the developers realized that it would be foolish to release them at this point.

There is a long-standing project called "Class Changes 2". Using volunteers from the community the developers want to address issues the various classes have and generally try to achieve better balance. We're looking at fixes, changes to spells and abilities, reworks of talent trees, etc. Applications for the volunteer positions were sent in many months ago but it turned out to be many hundreds so they are still under review as far as I know.

The problem with releasing alternate tier sets is now twofold:
 1) The set bonuses might go in the same direction as Class Changes 2. After all problems or shortcoming a class might have can be addressed through powerful set bonuses or by reworking the class. So either the subsequent Class Changes would then double up (making the set bonus useless) or would have to avoid fixing the issues the sets have already addressed (which seems shortsighted).
 2) The set bonuses and stat weights might also go in opposite directions. If the Class Changes 2 happen to introduce substantial changes, the set bonuses or item stats might no longer be in high demand.

So my understanding is that alternate tier sets have been shelved indefinitely until Class Changes 2 are done, so the new items can be tailored to the "final" state of the classes.
