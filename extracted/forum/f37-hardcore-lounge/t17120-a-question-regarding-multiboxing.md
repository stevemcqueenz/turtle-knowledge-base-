# A Question Regarding Multiboxing

## Post 116805 by Petter600 — 2025-01-15T11:14:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=116805#p116805 | page 1 | era: pre-1.18.1 -->

Hi all,

The rules state that multiboxing is prohibited in Hardcore mode. However, the description only mentions the simultaneous control of multiple clients!

> Multiboxing is the act of controlling multiple WoW clients simultaneously. This can entail having multiple clients open on a single machine or utilizing multiple machines to control the actions of both accounts at the same time for combat or moving.

What about the case where the clients are not being controlled simultaneously but are running on the same computer?
In theory, it should be allowed as long as both characters are not being controlled at the same time.

Has anyone had any experience with this topic?
