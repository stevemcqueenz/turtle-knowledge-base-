Yes this is normal.

Mobs releash upon taking damage so hamstringing the mob reset that. If you can't outrun the mobs with a swiftness potion hitting them again (hamstring) and using a potion isn't going to make you outrun them, you reset the leash range. You could use an infinite number of swiftness potions it wouldn't have saved you. This is in vanilla working as intended and is how hunters pulled world bosses into cities.

So the same mechanic that killed you is also used to save you. So if you use a ranged weapon to hit a mob and two come after you run backwards hit ONE of them again with ranged and continue to run backwards the one that you didn't hit will reset to it's normal position at camp while the one that you hit reset it's leash. You can do this to pull a single mob off a pack. You could have done this to pull the pesterhide far enough away that when feared you would have not pulled a second one. If one of the two mobs chasing you hits you it does reset the leash for both of them, you can hit them, they can't hit you.

This is an advanced mechanic that normally needs to be practiced and is best done with a thrown weapon due to the low initial attack speed. It is in fact, working as intended. No it does not work in dungeons/raids because mob's leash range is infinite there.
