Technically viable for our game and there are successful cases. I like watching HC death clips of Blizzard's classic servers, in some of which last words are shown with a special addon. This feature is rarely seen in those videos, so I don't think it's that popular as expected. But in my opinion, it's awesome.

The feature would function with quotes included in the announcement popped up when an HC character dies in game. For example, if an HC rogue says "this isn't funny" first and get killed without saying more, the announcement would be added with words like "His last word is 'this isn't funny'". It's a merely entertaining feature although that HC player isn't typically entertained, more like an addon function with surplus elements. Despite this, Turtle WoW is a player-centred private server, so I hope it can be integrated in the game. After all, it doesn't influence balance and we can decide whether it's enabled.
