# 2020 Spring Raid Schedule

## Post 5563 by Gifted (Barrens Chat Casualty) — 2020-03-30T13:23:00Z
<!-- url: https://forum.turtlecraft.gg/viewtopic.php?p=5563#p5563 | page 1 | era: pre-1.18.1 -->

After talking with everyone during yesterday's Blackwing Lair raid I thought it would be prudent to post a current raid schedule so players can figure out when they want to raid with us. We are starting to fill raids so there will be some competition for raid spots. Please see the [raid performance / guides forum post](https://forum.turtlecraft.gg/viewtopic.php?f=28&t=982) for more info on that.

Here's the current weekly raid schedule for spring 2020 (18:00-21:00 server time):

- Wednesday - Zul'Gurub (20 man raid)
- Thursday - Zul'Gurub (con't)
- Friday - Zul'Gurub (con't)
- Saturday - Molten Core (40 man raid, need attunement) / Onyxia's Lair (25 man raid, need attunement)
- Sunday - Blackwing Lair (40 man raid, need attunement) / World Bosses (Turtle, Azuregos, etc...)
The wed/thur/fri raids are to clear Zul'Gurub. These are much less formal raids than our sat/sun raids.

 **~Gifted**
