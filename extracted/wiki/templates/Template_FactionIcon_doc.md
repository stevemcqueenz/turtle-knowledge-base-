# Template:FactionIcon/doc

Humane syntax for specifying faction icons. This template includes the two major factions, Horde and Alliance, as well as the neutral faction shield. This template is intended to match the formatting provided by  and , combining the factions into a single template. If no parameters are supplied, the default will be the neutral crest. If a faction is specified but not the size, the large crest will be shown.

Concise syntax: 

The following samples demonstrate the different possible icons from this template.
- <code>&#123;&#123;FactionIcon&#125;&#125;</code> =   (default)

- <code>&#123;&#123;FactionIcon|Neutral|small&#125;&#125;</code> =  <code>|large&#125;&#125;</code> =  
- <code>&#123;&#123;FactionIcon|Combat|small&#125;&#125;</code> =  <code>|large&#125;&#125;</code> =   <code>|xlarge&#125;&#125;</code> = 
- <code>&#123;&#123;FactionIcon|Boss|small&#125;&#125;</code> =  <code>|large&#125;&#125;</code> =   <code>|xlarge&#125;&#125;</code> = 

  -Main factions**
- <code>&#123;&#123;FactionIcon|Alliance|small&#125;&#125;</code> =  <code>|large&#125;&#125;</code> =   <code>|xlarge&#125;&#125;</code> = 
- <code>&#123;&#123;FactionIcon|Horde|small&#125;&#125;</code> =  <code>|large&#125;&#125;</code> =   <code>|xlarge&#125;&#125;</code> = 
- <code>&#123;&#123;FactionIcon|Both|small&#125;&#125;</code> =  <code>|large&#125;&#125;</code> =   <code>|xlarge&#125;&#125;</code> = 

### Sorting enabled
If you are using this icon in a sortable table, with no other text in the column, add <code><nowiki>|sort=</nowiki></code>. It visually looks identical, but the sorting is enabled. Do not use this feature when using this template in a header (<code><nowiki>==  ==</nowiki></code>)
