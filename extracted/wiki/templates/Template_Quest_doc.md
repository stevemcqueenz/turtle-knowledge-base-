# Template:Quest/doc

**Description&#58;**
  Displays the given quest as a loot link.  The template checks to see if the item exists on [Turtle WoW Wiki](Main Page) before applying brackets.  If the item is missing from the wiki, DB search links are added by Javascript. The pop-up feature is sometimes disabled due to load issues on the website.
  The optional **display name** parameter can be used to show a quest name that is different from the name of the page that is linked to.
**Syntax&#58;**
  
**Example&#58;**
  <nowiki>[The Tower of Lapidis (quest)](The Tower of Lapidis (quest))</nowiki>
**Result&#58;**
  [The Tower of Lapidis (quest)](The Tower of Lapidis (quest))
