# Template:Patchbox/doc

## Usage
<pre></pre>

The command <code>/dump GetBuildInfo()</code> may be helpful for getting the various version numbers.

! Parameter
! Status
! Description
|-
| Patchname
| required
| patch subtitle, if exists
|-
| Image
| optional
| Full image code, 256px width suggested
|-
| Caption
| optional
| Image caption
|-
| Announced
| optional
| Date of announcement. Include a link to the announcement/archived version
|-
| Release
| required
| The date it was released on live servers.
|-
| Latest
| optional
| latest date the patch received an update, typically a hotfix
|-
| Version
| required
| initial release code version, e.g. [Public client builds](Public client builds)
|-
| Latestv
| optional
| latest release build since the initial
|-
| toc
| required
| Addon toc version
|-
| Highlights
| optional
| Brief list of highlights
|-
| Related
| optional
| List related links
|-
| Prev
| required
| Previous patch NUMBER
|-
| Current
| optional
| Current patch NUMBER
|-
| Next
| required
| Next patch NUMBER
