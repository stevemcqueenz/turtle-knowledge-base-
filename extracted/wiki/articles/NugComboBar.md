# NugComboBar

NugComboBar is a customizable addon that replaces the default combo points display for Rogues and Druids.

## How to Install
# Visit the GitHub link you find, then click the green **<> Code** button, and select Download ZIP.
# Use [7zip](https://www.7-zip.org/) to extract the zip into your TWow/Interface/AddOns
# Rename the NugComboBar-vanilla folder to NugComboBar
# Restart the game

## Git Links
- [**(NugComboBar)**](https://github.com/rgd87/NugComboBar/tree/vanilla)

## Commands
Basic Commands

- <code>/ncb</code> — Opens help messages explaining available commands.
- <code>/ncb help</code> — Show usage instructions.
- <code>/ncb lock</code> — Locks the combo bar in place (disables dragging).
- <code>/ncb unlock</code> — Unlocks the combo bar, allowing repositioning.
- <code>/ncb scale x.xx</code> — Sets the size of the combo bar (scale factor between 0.5 and 2.0).
- <code>/ncb showempty</code> — Toggles display of the combo bar when no combo points are active.

## Features
- Customizable lock/unlock state.
- Scale adjustment.
- Show or hide when no combo points are active.
- Smooth fade-in/out animations for combo point highlights.
- Color customization based on combo points.

## How It Works
- The addon replaces the default combo point display with a custom frame.
- It updates on combo point changes and target changes.
- Supports dragging to reposition when unlocked.
- Uses slash commands for configuration.
