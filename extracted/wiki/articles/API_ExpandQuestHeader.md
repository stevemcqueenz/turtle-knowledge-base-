# API ExpandQuestHeader

Expands the quest header.
 ExpandQuestHeader(questID);
----

  - *Arguments***

   (Number questID)

  ; questID
   The quest ID of the header you wish to expand

----

  - *Returns***

  ; nil

----

  - *Example***

 ExpandQuestHeader(3);

  - *Result***

----

  - *Description***

   Expands the quest header.
