# WoW-Voiceover

WoW-Voiceover adds voice-overs to npc's. no custom-made Turtle content is currently voiced!

## How to install
Download the **[1.12 Add-on](https://github.com/mrthinger/wow-voiceover/releases/download/v1.4.3/AI_VoiceOver-WoW_1.12-v1.4.3.zip)** and **[Vanilla Sounds](https://github.com/mrthinger/wow-voiceover/releases/download/v1.3.1/AI_VoiceOverData_Vanilla-v1.0.0.zip)** zips and extract them to your Add-ons folder.

## **Important**
You must use the [manual install method](Addons#Installing%20Addons%20by%20Hand)!
