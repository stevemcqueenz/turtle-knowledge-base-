# Gallows' End Tavern

The **Gallows' End Tavern** features trainers for [warrior](warrior)s, [priest](priest)s, [mage](mage)s, [rogue](rogue)s, [warlock](warlock)s, [enchanter](enchanter)s, and [first aid](first aid). It also has an [innkeeper](innkeeper) and a few other vendors. This tavern is notable because it is the only fully functional tavern known to be run by the [forsaken](forsaken).
