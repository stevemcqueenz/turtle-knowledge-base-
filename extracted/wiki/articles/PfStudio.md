# PfStudio

An ingame IDE with an event viewer.

## How to Install
# Download **[Latest Version](https://github.com/shagu/pfStudio/archive/master.zip)**
# Use [7zip](https://www.7-zip.org/) to extract the zip into your TWow/Interface/AddOns
# Rename the pfStudio-master folder to pfStudio
# Restart the game

## Git Links
[**(shagu)**](https://github.com/shagu/pfStudio)

## Commands
{| class="fandom-table"
!Command
!Description
|-
|/studiopause
|Pauses/Resumes events
|-
|/studioregister EVENT_NAME
|Register specific event
|-
|/studiounregister EVENT_NAME
|Unregister specific event
|-
|/studiounregister all
|Unregister all events
|-
|/studio
|Open the Toolbar
|-
|/rl
|Reload the UI
|}

**Window Management**

- **Alt + Left-Mouse-button** to move windows
- **Alt + Right-Mouse-button** to resize windows
- **Double-Click** on **title-bar** to maximize windows
