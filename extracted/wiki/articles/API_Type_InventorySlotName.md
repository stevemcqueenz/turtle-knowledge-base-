# API Type InventorySlotName

Rather than use hard-coded ID's for inventory slots, each slot is mapped to a numeric ID at runtime using the API GetInventorySlotInfo function. This allows for future expansion and addition of new slots, as well as re-ordering of slots in the underlying code.  Known slot ID's are as follows (and appear to be case insensitive):

## Values
  - <code>"HeadSlot"</code> Head/helmet slot.**
  - <code>"NeckSlot"</code> Necklace slot.**
  - <code>"ShoulderSlot"</code> Shoulder slot.**
  - <code>"BackSlot"</code> Back/Cape slot.**
  - <code>"ChestSlot"</code> Chest slot.**
  - <code>"ShirtSlot"</code> Shirt slot.**
  - <code>"TabardSlot"</code> Tabard slot.**
  - <code>"WristSlot"</code> Wrist/Bracer slot.**
  - <code>"HandsSlot"</code> Hand/Gloves slot.**
  - <code>"WaistSlot"</code> Waist/Belt slot.**
  - <code>"LegsSlot"</code> Legs/Pants slot.**
  - <code>"FeetSlot"</code> Feet/Boots slot.**
  - <code>"Finger0Slot"</code> First finger/ring slot.**
  - <code>"Finger1Slot"</code> Second finger/ring slot.**
  - <code>"Trinket0Slot"</code> First trinket slot.**
  - <code>"Trinket1Slot"</code> Second trinket slot.**
  - <code>"MainHandSlot"</code> Main hand slot.**
  - <code>"SecondaryHandSlot"</code> Secondary hand/Off-hand slot.**
  - <code>"RangedSlot"</code> Ranged slot.**
  - <code>"AmmoSlot"</code> Ranged ammo slot.**
  - <code>"Bag0Slot"</code> First bag slot.**
  - <code>"Bag1Slot"</code> Second bag slot.**
  - <code>"Bag2Slot"</code> Third bag slot.**
  - <code>"Bag3Slot"</code> Fourth bag slot.**
