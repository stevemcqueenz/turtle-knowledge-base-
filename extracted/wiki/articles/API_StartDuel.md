# API StartDuel

Invites the specified player to a duel.
 StartDuel(playerName);
----

** *Arguments***

   (String playerName)

  ; playerName
   The name of the player you wish to duel

----

** *Returns***

  ; nil

----

** *Example***

 StartDuel("Sembiance");

** *Result***

----

** *Description***

   Invites the specified player to a duel. Currently only works for members of the same faction (1.6.1).
