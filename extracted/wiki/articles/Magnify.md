# Magnify

-Magnify** enhances the world map experience by allowing you to zoom in and out, with additional visual improvements and customization options.

## Installation
  -GitAddonsManager**

The easiest way to keep **Magnify** up to date is by using [GitAddonsManager](GitAddonsManager).

# **Add the Repository:** Add the following URL to GitAddonsManager: https://github.com/luskanek/Magnify.git
# **Select the Branch:** Ensure that the master branch is selected.
# **Update:** Using GitAddonsManager, you can check for and install updates for all your AddOns with a single click.

  -Manual Installation**

If you prefer manual installation, follow these steps:

# Go to the main page of the repository.
# Click the **<> Code** dropdown and download the repository as a <code>.zip</code>.
# Unpack the <code>.zip</code> and rename the folder to <code>Magnify</code>, removing the <code>-main</code> suffix.
# Move the folder into your <code>Interface/AddOns</code> directory and restart the game.

## Key Features
- **Map Zooming:** Backported zoom functionality from retail WoW with adjustable zoom levels.
- **Enhanced Player Arrow:** Replaces the default arrow with a high-resolution texture.
- **Arrow Flash Toggle:** Enable or disable the flashing effect of the player indicator arrow when opening the map.
- **Custom Arrow Scale:** Adjust the size of the player arrow.
- **Zoom Level Memory:** Choose whether to remember zoom level upon closing the map.
- **Max Zoom Adjustment:** Set maximum zoom level for the map.
- **Map Appearance Tweaks:** Improved positioning and appearance of map elements for better usability.
