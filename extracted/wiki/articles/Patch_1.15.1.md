# Patch 1.15.1

-Patch 1.15.1** was released on March 11, 2021.

## Patch Notes
- Fixes for missing icons and textures for certain item models.
- Fixes for bugged maps.
- Fixes for missing flight paths and graveyards.
- Distant portraits for the new races.
- Background for the new races when previewing outfits.
- Fixes for visual spell problems.
- New camera for introduction cinematics.
- Fixes for CPU spikes caused by DiscordOverlay.dll.
- Added new music to [Steamwheedle Port](Steamwheedle Port) and [Mudsprocket](Mudsprocket).
- Removed unused tabs from Goblins in the character creation screen.
- Character creation: new Forest Troll skins.
- Character creation: new Wildhammer Dwarf skins.
- Character creation: new Orc faces.
- Character creation: new Night Elf beards and eyebrows.
- Character creation: new Dwarf beards.
- Character creation: new Goblin faces & beards.
- Passive spells for Hardcore mode.
- Fixes for a bug with Scarlet Crusade faction.
- Fixes for going At War with your own faction.
- Misc. graphic and sound assets for future content.
