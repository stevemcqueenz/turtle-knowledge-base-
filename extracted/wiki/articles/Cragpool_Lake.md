# Cragpool Lake

The **Cragpool Lake** is a small lake in [Windshear Crag](Windshear Crag).  An enormous structure created by [Venture Co.](Venture Company) [goblins](goblins) runs above it. From here, [Gerenzo Wrenchwhistle](Gerenzo Wrenchwhistle) oversees a good portion of the Windshear Crag operation.

[Nizzik](Nizzik) has also set up shop near the water-wheel.
