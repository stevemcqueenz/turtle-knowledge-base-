# Quiver

A collection of hunter utilities.

## How to Install
# [Download](https://github.com/SabineWren/Quiver/releases) latest version for releases
# Extract folder from the Zip
# Rename folder from Quiver-x.x.x to Quiver
# Move folder into TWow/Interface/AddOns/
# Restart the game

## Git Links
[**(SabineWren)**](https://github.com/SabineWren/Quiver)

## Commands
Use **/Quiver** or **/qq** to open the configuration menu.
