# Artisan

Compact window for your professions.

## How to Install
# Visit the GitHub link you find, then click the green **<> Code** button, and select Download ZIP.
# Use [7zip](https://www.7-zip.org/) to extract the zip into your TWow/Interface/AddOns
# Rename the Artisan-main folder to Artisan
# Restart the game

## Git Links
[**(Otari98)**](https://github.com/Otari98/Artisan)

## Commands
- **/artisan** - prints version and commands
- **/artisan auto** - auto confirmation of enchant replacements (ON)
- **/artisan icons** - icons next to skill names (ON)

## Features
- Search
- Convenient side tabs for all your professions
- Custom categories
- Key-binds for create buttons
- Auto accept "replace enchant" dialogs
- Shift-click to post required reagents in chat
