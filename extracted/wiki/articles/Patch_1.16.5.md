# Patch 1.16.5

-Patch 1.16.5** was released on January 3, 2023.

## Patch notes
### General
- Fixed Murgot Deepforge aggroing nearby players.
- Fixed Triage quest script.
- Fixed some new quests not giving money reward on level 60.
- Corrected reputation rewards for Chasing Sand quest.
- Grammar overhaul for ~40 quests.
- Pets now will be aggroed at same distance as owner.
- Fixed new Theramore quests reputation rewards.
- Fixed reputation reward for A Heart of Stone.
- Tel'Abim Sand will be stackable.
- Lowered dmg values for Enraged Feral Scar.
- New AQ20 door logic: should not stay closed due to bug.
- Another attempt to fix left-over Ostarius summons.
- Redesigned Brilliance Aura according to this report: https://github.com/slowtorta/turtlewow-bug-tracker/issues/2486
- Wattapo's Bulwark should be a shield.
- Fixed Disgusting Oozeling not reacting to Dark Iron Mug.
- Fixed Tel'Abim tameable creatures beast families.
- Fixed item rewards for The Terrible Krampus.
- Added correct item rewards for Lofty Heights.
- Bonepaw Hyena and Burning Blade Felsworn will not aggro together.
- Whirlwind Shredder and Bonepaw Hyena will not aggro together.
- Fixed pathing issues for Twilight Prophet patrol in Silithus.
- Made Stolen Elwynn Pumpkin usable only when player is on a quest.
- Made Locked Crypt Door usable only when player is on a quest.
- Disallowing overspending of previous exploit for hunter pets with too many talent points.
- Yet another attempt to fix hunter's pet being bugged after teleport.
- New script for Rajaxx and Andorov in AQ20.

### PvP-related
- Added reputation multipliers for battlegrounds: values will be published later.
- Added honor multipliers for battlegrounds: values will be published later.
- Removed snowball player-knockback for player-casters to prevent griefing.

### Client
- New builds 7060 & 7065 (FoV) now both contain 4GB Patch also known as Large Address Aware patch, by default. It will help with the recently introduced memory-related crashes.
