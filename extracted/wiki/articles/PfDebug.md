# PfDebug

A little tool to monitor the memory usage, peaks and garbage collection.

## How to Install
# Download **[Latest Version](https://github.com/shagu/pfDebug/archive/master.zip)**
# Unpack the Zip file
# Rename the folder "pfDebug-master" to "pfDebug"
# Copy "pfDebug" into Wow-Directory\Interface\AddOns
# Restart Wow

## Git links
- [**(shagu)**](https://github.com/shagu/pfDebug)
- [**(me0wg4ming)**](https://github.com/me0wg4ming/pfDebug)

## Usage
- **Left-Click** on the Bar to reset the Peak
- **Right-Click** on the Frame to open the Analyzer
