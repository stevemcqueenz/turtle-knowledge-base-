# DruidManaBar

Displays a mana bar when shapeshifted.

## How to Install
# Visit the GitHub link you find, then click the green **<> Code** button, and select Download ZIP.
# Use [7zip](https://www.7-zip.org/) to extract the zip
# Move the DruidManaBar folder into your AddOns folder
# Restart the game

**Optional:** [SuperWoW](https://github.com/balakethelock/SuperWoW)
