# API CollapseQuestHeader

Collapses the quest header.
 CollapseQuestHeader(questID);
----

** *Arguments***

   (Number questID)

  ; questID
   The quest ID of the header you wish to collapse

----

** *Returns***

  ; nil

----

** *Example***

 CollapseQuestHeader(3);

** *Result***

----

** *Description***

   Collapses the quest header.
