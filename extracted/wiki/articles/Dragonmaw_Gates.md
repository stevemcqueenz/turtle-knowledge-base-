# Dragonmaw Gates

[Dragonmaw Gates](Dragonmaw Gates) are a set of grandoise portals that block the winding path leading up to [Grim Batol](Grim Batol). The gates are guarded by several different types of [dragonkin](dragonkin) of the red dragonflight, as well as the powerful drake [Axtroz](Axtroz). It is possible to pass through the gates and survive, but past the last gate, the area just below the mountain is completely deserted. It is possible this area will contain a red dragon later in the game's development.
