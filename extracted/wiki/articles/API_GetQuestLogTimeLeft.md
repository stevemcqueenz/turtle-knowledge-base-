# API GetQuestLogTimeLeft

Gets the seconds left for the current quest that is being timed.
 local questTimer = GetQuestLogTimeLeft()

## Arguments
   None

## Returns
  ; questTimer
   Number - The seconds remaining to finish the timed quest.
