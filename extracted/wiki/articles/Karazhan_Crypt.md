-Karazhan Crypt** is an instance dungeon located in [Deadwind Pass](Deadwind Pass). Something is twisting the dead back to life in the forlorn catacombs, find the source so the dead may rest again.

## Key questline
Similar to Dire Maul North or the Scholomance, the instance portal to Karazhan Crypt can be entered without any key but is behind an iron gate just outside the instance that requires the [Karazhan Crypt Key](Karazhan Crypt Key) to be opened (or a [Rogue](Rogue) with Lockpicking skill 300). The key can be obtained through a long quest chain:
