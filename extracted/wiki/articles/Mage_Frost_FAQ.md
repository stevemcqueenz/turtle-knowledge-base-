# Mage Frost FAQ

Go back to https://turtle-wow.fandom.com/wiki/Mage_FAQ

## Is Frost good on this server?
Yes frost is quite good since 1.17.2 patch on Nov 8th 2024.  Can read about the changes here https://forum.turtle-wow.org/viewtopic.php?p=102974#p102968 ==
## Is blizzard nerfed / aoe farming as frost dead?
Yes blizzard slow is nerfed from 75% -> 50% with 3/3 Improved blizzard and 3/3 permafrost so can't do 2 full blizzards anymore.  Cone of cold slow is untouched so can still use that to aoe farm with arcane explosion.

Even before this change the popular pathing exploits used to aoe farm as mage in ZF/ZG/Mara/SM have been fixed for a long time.

## What's a good spec for raiding?
Pepo frost

The idea is to use frost nova, cone of cold, and even blizzard to trigger flash freeze in order to get 1 second icicles.

## What is the rotation for frost when raiding?
THIS ONLY APPLIES TO MOBS THAT CANNOT BE FROZEN (most mobs in raid).  Outside of raids most mobs CAN be frozen so these rotations don't apply to leveling or dungeons.

To see a list of exceptions that CAN be frozen (flash freeze won't work so don't follow these rotations) https://docs.google.com/spreadsheets/d/1bvW0ghL4eI8clucl7ilCgzYzQIwJGDN-oyPPSBFWwtI/edit?usp=sharing.

Always keep ice barrier up if possible unless fight is about to end.  Make sure you are refreshing it right before pull.

In general for these rotations anytime you proc flash freeze from a frost spell you should immediately icicle.

Single target: Frost nova -> icicles -> frostbolt 

Aoe up to 5 mobs: Cone of cold -> Icicles if proc -> Frost nova -> icicles -> arcane explosion. 

Aoe more than 5 mobs: Cone of cold -> arcane explosion -> try to use icicles on something at the end when some have died
