# Patch 1.16.2

-Patch 1.16.2** was released on August 8, 2022.

## Patch Notes
- [Compact Harvest Reaper](Compact Harvest Reaper) will now break after 10 minutes.
- Compact Harvest Reaper can no longer be healed through HoTs.
- [Banish](Banish) will now prevent Faerie Fire.
- Added missing [Bubbly Fissures](Bubbly Fissures) for the druid class quest.
- [Wyvern Sting](Wyvern Sting) will now break on damage.
- The resistance portion of [Sanctified Command](Sanctified Command) works.
- Mana gained from Sanctified Command will show up in the combat log.
- Added missing progress text for the [Remember Alterac Valley](Remember Alterac Valley) quest that confused players.
- Fixed cast time for [Decisive Strike](Decisive Strike) not matching the tooltip.
- The crafting time of some professional items is now reduced with increased skill as is blizzlike.
- Fixed respawn time of [Chromatic Elite Guard](Chromatic Elite Guard).
- Implemented [Warlock](Warlock)'s [Demon Portal](Demon Portal) which summons a [Felguard](Felguard) pet.
- [Scourge Footsoldier](Scourge Footsoldier)s spawned during the Priest class quest should no longer evade prematurely.
- [Hunter](Hunter)'s [Entrapment](Entrapment) talent should now work.
- [Battery Powered Crowd Pummelers](Battery Powered Crowd Pummelers) are now implemented and can be crafted.
- [Remove Curse](Remove Curse) is now usable in Tree of Life form.
- Fixed issues with [The Empty Stables](The Empty Stables) quest in AV.
- [Warrior](Warrior)'s Retaliation will now work.
- [Mage](Mage)'s [Ritual of Refreshment](Ritual of Refreshment) will now work.
- [Shaman](Shaman)'s [Feral Spirit](Feral Spirit) will now work.
- If you have multiple guardian pets summoned at once, they will now spread out around you, instead of all stacking on top of each other.
- Fixed client crash in the [Gnomeregan](Gnomeregan) area of [Dun Morogh](Dun Morogh).
- BG Finder now requires a left click instead of a right one.
- Excluded mandatory sound in the background modification.
- [Improved Sap](Improved Sap) will now work.
- [Summon Felguard](Summon Felguard) will now work.
- [Brilliance Aura](Brilliance Aura) will now work.
- Fixed bug with the guild creation charter requiring to be in the main bag.
- [Vampiric Touch](Vampiric Touch) now restores correct mana percentages.
- Added scaling to [Shadow Mend](Shadow Mend).
- Improved description of [Battery Powered Crowd Pummeler](Battery Powered Crowd Pummeler).
- Fixed not being able to use [First Aid](First Aid) during [Divine Shield](Divine Shield).
- Updated visual effect and sound for [Felguard](Felguard).
- Removed spell pushback on damage from [Slam](Slam).
- Fixed hit chance of druid [Natural Weapons](Natural Weapons) talent.
- Increased stats of all guards in the world.
- Added [prevented measurements](Defias Bouncer) from Horde ganking [Defias Messenger](Defias Messenger).
- Fixed Warlock's [Ritual of Souls](Ritual of Souls).
- Fixed returning player to the position he entered from after leaving BG.
- Fixed [Demonic Aegis](Demonic Aegis) warlock talent.
- Increased spell power scaling for Consecration.
- Fixed [Searing Totem](Searing Totem) bonus coefficients.
- Fixed [Judgment of Righteousness](Judgment of Righteousness) bonus coefficients.
- Added condition for earning [Lorekeeper](Lorekeeper) title.
- Added rested bonus to the [Karfang Hold](Karfang Hold).
- [Armored Azure Drake](Armored Azure Drake) has been replaced with [Immortal Champion's Charger](Immortal Champion's Charger) in order to preserve the unique spirit of flight-less Azeroth.
- Added /road sounds to all races.
