# API GetNumQuestItems

Returns the number of items nessecary to complete a particular quest.
 GetNumQuestItems();
----

** *Arguments***

   *none*

----

** *Returns***

   Number numRequiredItems

  ; numRequiredItems
   The number of required items for the quest

----

** *Example***

 local numRequiredItems = GetNumQuestItems()

** *Result***

 5
----

** *Description***

   Returns the number of items nessecary to complete a particular quest.
