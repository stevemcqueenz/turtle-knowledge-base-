# EmoteButtons

**EmoteButtons** adds a convenient menu to access emotes and slash commands via clickable buttons.

## **Installation**
**Manual Installation only**

# Go to the main page of the repository.
# Click the **<> Code** dropdown and download the repository as a <code>.zip</code>.
# Extract the .zip file, move the EmoteButtons folder from inside the EmoteButtons_v1.0 folder to your <code>Interface/AddOns</code> directory
# Restart the game.

## Usage
**Accessing the Emote Menu**
- **Main Button:** Click the central "EmoteButtons" icon to toggle the menu.
- **Shift Click:** Shift + click any button to open its configuration options.
**Navigating the Menu**
- **Main Menu:** Displays primary emote options.
- **Wings (Left/Right):** Expand to access additional emote decks.
- **Decks:** Select different decks (Deck 1 to Deck 8) for custom emotes.
- **Emote/Slash Command:** Click a button to send the associated slash command or emote directly in chat.
**Customizing Emotes**
- Shift + click on a button to configure or assign a new slash command/emote.
- Use the deck selection menu to set custom images for decks.

## Features
**Main Button**
- **Right-click Drag** to move the menu around the screen.
- **Left click:** Toggle main menu (show/hide primary emotes).
- **Hover:** Displays tooltip with description.
**Emote/Wing Buttons**
- **Shift click:** Configure individual buttons.
- **Click:** Execute the assigned emote or slash command.
- **Hover:** Tooltip shows the command and description.
**Decks & Wings**
- Easily switch between different decks (e.g., for different emote sets).
- Left and right wings can hold additional emotes or commands.
- Select a deck to change the images/icons representing the emotes.
**Image Selector**
- Click on images to assign a new icon to an emote.
- Use the slider to browse through available icons.
- Hover over icons for preview.
