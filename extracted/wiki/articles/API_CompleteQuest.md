# API CompleteQuest

Complete the specified quest.
 CompleteQuest();
----

** *Arguments***

   *none*

----

** *Returns***

  ; nil

----

** *Example***

 CompleteQuest();

** *Result***

----

** *Description***

   Complete the specified quest in the quest log window. Called when the CompleteQuest button is pressed.
