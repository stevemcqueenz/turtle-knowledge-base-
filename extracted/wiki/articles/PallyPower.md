# PallyPower

Pally Power provides an easy to use interface that allows you to set blessings and automatically checks for missing buffs with an easy to read indicator.

## How to install
# Visit the GitHub link you find, then click the green **<> Code** button, and select Download ZIP.
# Use [7zip](https://www.7-zip.org/) to extract the zip into your TWow/Interface/AddOns
# Rename the PallyPower-master folder to PallyPower
# Restart the game

## Changes
- Option to change between regular blessings and greater blessings.
- Shows the buff frame when solo.
- Show the max rank of each blessing each paladin has available and if they have talents that buff the blessing.
- Show the correct duration to each blessing.
- Shaman class in the buff table.
- Hunter pet Support.
- Auto self-cast Support.
