# RaidIndex

Each member in a raid group is assigned a numeric index value between 1 and [MAX_RAID_MEMBERS](API MAX RAID MEMBERS) called their **RaidIndex**.

RaidIndex values are used when referring to a raid member with the raidN [UnitId](API Type UnitId) and when querying raid roster information with the [GetRaidRosterInfo](API GetRaidRosterInfo) function.
