# Atlas

Atlas provides detailed maps of dungeons, raids, world bosses, transport routes, and more

## Installation
**GitAddonsManager**

The easiest way to keep **Atlas** up to date is by using [GitAddonsManager](GitAddonsManager).

# **Add the Repository:** Add the following URL to GitAddonsManager: https://github.com/Otari98/Atlas.git
# **Select the Branch:** Ensure that the master branch is selected.
# **Update:** Using GitAddonsManager, you can check for and install updates for all your AddOns with a single click.

**Manual Installation**

If you prefer manual installation, follow these steps:

# Go to the main page of the repository.
# Click the **<> Code** dropdown and download the repository as a <code>.zip</code>.
# Unpack the <code>.zip</code> and rename the folder to Atlas, removing the <code>-master</code> suffix.
# Move the folder into your <code>Interface/AddOns</code> directory and restart the game.

## Features
Features & Usage Tips

- **Dungeon & Raid Maps:** Visual maps for all dungeons and raids, including TurtleWOW-specific locations like Black Morass, Emerald Sanctum, and more.
- **World Boss Locations:** Easy access to spawn points for world bosses.
- **Transport Routes:** Shows boats, zeppelins, and other transport paths.
- **Update Check:** Option to check for new version updates in the options menu.
- **Map Types:** Switch between different map categories (dungeons, raids, world bosses, transports) via dropdown menus.
- **Instance Entrance Maps:** Quick access to entrance maps for various dungeons and raids.
- **Auto-Select Map:** When enabled, Atlas automatically opens the map for your current zone upon login or zone change.
