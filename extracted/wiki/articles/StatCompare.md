# StatCompare

StatCompare is designed for gear checks and player comparisons. It provides detailed character and target gear stats, talents, buffs, enchants, and custom abilities, making it a valuable tool for raiders, guilds, and gear evaluators.

## Installation
  -GitAddonsManager**

The easiest way to keep **StatCompare** up to date is by using [GitAddonsManager](GitAddonsManager).

# **Add the Repository:** Add the following URL to GitAddonsManager: https://github.com/grimfiendish/StatCompare.git
# **Select the Branch:** Ensure that the master branch is selected.
# **Update:** Using GitAddonsManager, you can check for and install updates for all your AddOns with a single click.

  -Manual Installation**

If you prefer manual installation, follow these steps:

# Go to the main page of the repository.
# Click the **<> Code** dropdown and download the repository as a .zip.
# Unpack the .zip and rename the folder to StatCompare, removing the -master suffix.
# Move the folder into your Interface/AddOns directory and restart the game.

  -Optional**: [BetterCharacterStats](BetterCharacterStats)

## Commands
- **Enable:** <code>/statc on</code>
- **Disable:** <code>/statc off</code>
- **Debug Mode on:** <code>/statc debug on</code>
- **<code>Debug Mode off:</code>** <code>/statc debug off</code>
- **Open Options:** <code>/statc config</code>
- **Show Item Collection:** <code>/statc item</code>
- **Compare Sets / Gear:** <code>/statc sets</code>
- **Help & Info:** <code>/statc help</code>

## Usage
- **View Your Own Stats:** Use c key to open the stats panel for your character.
- **Gear Checks:** Take screenshots of your gear or view detailed stats of inspection targets.
- **Selective Display:** Toggle info with icons at the top-right:
  - Armor & Enchants
  - Spell Info
  - Character Stats

## Features
- **Character Stats & Resistances:** Attack Power, Spell Power, Resistances, Hit, Crit, and more.
- **Gear & Enchants:** Lists equipped items and their enchantments.
- **Talent Tree Summary:** Shows your talent specialization.
- **Active Buffs:** Displays current buffs that may influence stats.
- **Custom Abilities:** Supports abilities like Haste, Vampirism, Crusader Strike.

## Compatibility
- Works with standard WoW 1.12.1 client.
- Supports private servers with custom abilities.
- Adjustments may be needed for server-specific features.
- Supports Chinese (zhCN) and English.
