# Category:NPCs

Articles about interactive NPCs in World of Warcraft. This list should exclude non-interactive creatures or mobs, including named mobs and bosses, which have their own categories.

NPCs should be placed in their proper NPC subcategory - specific trainer type, vendor, innkeeper, stable master, riding instructor, weapon master, information giver, flight master, banker, battlemaster, auctioneer, guild master, and/or quest giver.

If the NPC fits in none of these categories, but still counts as being interactive in some way, it can be placed in the base category.
