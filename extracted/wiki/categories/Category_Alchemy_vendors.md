# Category:Alchemy vendors

This category contains NPCs that sell [alchemy](alchemy) supplies. Most of these NPCs have one of the following titles: <Alchemist>, <Journeyman Alchemy>, <Alchemy Supplies>, <Journeyman Alchemist>, <Expert Alchemist>, <Artisan Alchemist>, but this is not a requirement. Note that many [Herbalism vendors](:Category:Herbalism vendors) also sell vials, but this does not automatically make them alchemy vendors.
