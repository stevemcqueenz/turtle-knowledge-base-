# talent-links.jsonl

Talent-calculator build links found in forum posts, with the post, author, authority, date and the 160 characters of text preceding the link (usually the build's name or purpose). Coverage is uneven and the file is not a complete index: every `talents.turtlecraft.gg/<class>/<code>` path-form link in the corpus is here, but the newer `?points=` query form is indexed only for post 149715 — 13 rows out of the 372 distinct (post, `?points=` URL) pairs the corpus holds. The remaining 359 are a known, open gap. The calculator site was already offline (Cloudflare 525) during the crawl, so the codes are not decoded here. The code is the `<code>` path segment on path-form links and the `?points=` query value on query-form ones; path-form codes have three dash-separated segments, one per talent tree, each character encoding talent ranks in tree order; decode against the 1.18.1 Talent.dbc tree order once the alphabet is confirmed (the classic pairwise alphabet used by wowhead-style calculators is the first thing to try). Regenerate with the snippet in the session log or by re-running the link scan over `structured/forum/posts/*.jsonl`.
