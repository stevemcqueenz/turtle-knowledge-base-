# talent-links.jsonl

Talent-calculator build links found in forum posts, with the post, author, authority, date and the 160 characters of text preceding the link (usually the build's name or purpose). Coverage is partial and is a measured count, not a guarantee. Measured 2026-09-12 against the `links` records of `structured/forum/posts/*.jsonl`: the file holds 208 rows; the corpus holds 163 distinct path-form build URLs, of which 23 are not indexed (29 distinct post/URL pairs); and it holds roughly 371 distinct (post, `?points=` URL) query-form pairs — the exact figure moves with the extraction method, since `content_md` also yields truncated link text — of which only 13 are indexed, all from post 149715. Both shortfalls are known, open gaps. Re-measure rather than trusting these numbers after any edit. The calculator site was already offline (Cloudflare 525) during the crawl, so the codes are not decoded here. The code is the `<code>` path segment on path-form links and the `?points=` query value on query-form ones; path-form codes have three dash-separated segments, one per talent tree, each character encoding talent ranks in tree order; decode against the 1.18.1 Talent.dbc tree order once the alphabet is confirmed (the classic pairwise alphabet used by wowhead-style calculators is the first thing to try). Regenerate with the snippet in the session log or by re-running the link scan over `structured/forum/posts/*.jsonl`.
