# talent-links.jsonl

Talent-calculator build links found in forum posts, with the post, author, authority, date and the 160 characters of text preceding the link (usually the build's name or purpose). The calculator site was already offline (Cloudflare 525) during the crawl, so the codes are not decoded here. The code is the `<code>` path segment; codes have up to three dash-separated segments, one per talent tree, each character encoding talent ranks in tree order — the calculator omits trailing empty trees, so of the 195 path-form codes here 121 have three segments, 54 have two and 20 have one; a decoder must pad rather than assume three; decode against the 1.18.1 Talent.dbc tree order once the alphabet is confirmed (the classic pairwise alphabet used by wowhead-style calculators is the first thing to try). Regenerate with the snippet in the session log or by re-running the link scan over `structured/forum/posts/*.jsonl`.
